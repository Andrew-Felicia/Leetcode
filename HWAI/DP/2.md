## 1. Understanding the problem

For every tensor, you know:

```text
memory size
swap cost
recomputation cost
```

For example:

```text
Tensor size:          7
Swap cost:            5
Recomputation cost:   6
```

Both operations release the same amount of NPU memory: `7`.

Therefore, if we select this tensor, we always use the cheaper operation:

```text
cost = min(5, 6) = 5
```

We can simplify every tensor into:

```text
(size, minimum cost)
```

For sample 1:

```text
Sizes:              3  4  5  6  7
Swap costs:         1  2  3  5  5
Recompute costs:    2  3  4  5  6
```

The effective costs are:

```text
Costs:              1  2  3  5  5
```

So the items are:

```text
Tensor 0: size=3, cost=1
Tensor 1: size=4, cost=2
Tensor 2: size=5, cost=3
Tensor 3: size=6, cost=5
Tensor 4: size=7, cost=5
```

We need at least `10` memory.

Selecting sizes `3` and `7` gives:

```text
memory = 3 + 7 = 10
cost   = 1 + 5 = 6
```

So the answer is `6`.

## 2. Why this is 0/1 knapsack

Each tensor has two choices:

```text
0: do not select it
1: select it
```

A tensor cannot be selected more than once. That is why it is called **0/1 knapsack**.

This version differs from the usual knapsack:

```text
Usual knapsack:
maximize value while staying under a capacity

This problem:
minimize cost while reaching at least a memory target
```

## 3. DP definition

Create:

```python
dp = [infinity] * (m + 1)
```

Define:

```text
dp[s] = minimum cost needed to release s memory
```

Index `m` has a special meaning:

```text
dp[m] = minimum cost needed to release m or more memory
```

We do not need indices greater than `m`.

For example, when `m = 10`:

```text
Released 8 memory  -> dp[8]
Released 9 memory  -> dp[9]
Released 10 memory -> dp[10]
Released 12 memory -> also dp[10]
Released 100       -> also dp[10]
```

This is implemented using:

```python
next_freed = min(m, freed + size)
```

## 4. Initial state

Before selecting any tensors:

```text
Released memory = 0
Cost = 0
```

Therefore:

```python
dp[0] = 0
```

Every other state is initially impossible:

```text
dp = [0, inf, inf, inf, ...]
```

## 5. Updating the DP

For each tensor:

```python
for freed in range(reachable, -1, -1):
    next_freed = min(m, freed + size)

    dp[next_freed] = min(
        dp[next_freed],
        dp[freed] + cost
    )
```

There are two possibilities:

### Do not select the tensor

The existing value remains unchanged:

```python
dp[freed]
```

### Select the tensor

The released memory increases:

```python
next_freed = min(m, freed + size)
```

The cost increases:

```python
dp[freed] + cost
```

We keep whichever cost is smaller.

## 6. Why iterate backward?

The loop must go from large memory to small memory:

```python
for freed in range(reachable, -1, -1):
```

Suppose there is only one tensor:

```text
size = 6
cost = 1
target = 10
```

If we iterate forward, the same tensor might incorrectly be used twice:

```text
0 -> 6 -> 10
```

That would produce cost `2`, but there is only one tensor.

Iterating backward ensures that states created by the current tensor are not reused during the same iteration.

## 7. Complete solution

```python
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))

    if not data:
        return

    index = 0

    required_memory = data[index]
    index += 1

    tensor_count = data[index]
    index += 1

    sizes = data[index:index + tensor_count]
    index += tensor_count

    swap_costs = data[index:index + tensor_count]
    index += tensor_count

    recompute_costs = data[index:index + tensor_count]

    # Even selecting every tensor is not enough.
    if sum(sizes) < required_memory:
        print("error")
        return

    # For each tensor, choose its cheaper operation.
    costs = [
        min(swap_costs[i], recompute_costs[i])
        for i in range(tensor_count)
    ]

    infinity = float("inf")

    # dp[s] = minimum cost to release s memory.
    # dp[required_memory] represents required_memory or more.
    dp = [infinity] * (required_memory + 1)
    dp[0] = 0

    reachable = 0

    for size, cost in zip(sizes, costs):
        # Backward traversal makes this a 0/1 knapsack.
        for freed in range(reachable, -1, -1):
            if dp[freed] == infinity:
                continue

            next_freed = min(
                required_memory,
                freed + size
            )

            candidate_cost = dp[freed] + cost

            if candidate_cost < dp[next_freed]:
                dp[next_freed] = candidate_cost

        reachable = min(
            required_memory,
            reachable + size
        )

    if dp[required_memory] == infinity:
        print("error")
    else:
        print(dp[required_memory])


if __name__ == "__main__":
    main()
```

## Why use `min(required_memory, freed + size)`?

Suppose:

```text
freed = 7
new tensor size = 7
```

The actual released memory is:

```text
7 + 7 = 14
```

But our target is only `10`. We don’t care whether the result is `10`, `14`, or `100`; all of them satisfy the requirement.

So:

```python
next_freed = min(10, 14)
           = 10
```

Index `10` represents:

```text
10 or more memory
```

This keeps the DP array small.

## Why loop backward?

This is the most important part:

```python
for freed in range(reachable, -1, -1):
```

Suppose we have only one tensor:

```text
size = 3
cost = 1
```

If we loop forward, this could happen:

```text
dp[0] creates dp[3]
dp[3] creates dp[6]
dp[6] creates dp[9]
```

That incorrectly uses the same tensor three times.

Backward iteration prevents this:

```text
Check dp[3] before dp[3] is created
Then check dp[0] and create dp[3]
End the current tensor's iteration
```

Therefore, each tensor can be selected at most once.

## Understanding each line

```python
reachable = 0
```

Initially, only zero released memory is possible.

```python
for size, cost in zip(sizes, costs):
```

Process one tensor at a time.

```python
for freed in range(reachable, -1, -1):
```

Try adding this tensor to every previously possible state. Go backward to prevent using it repeatedly.

```python
if dp[freed] == infinity:
    continue
```

Skip impossible states.

```python
next_freed = min(required_memory, freed + size)
```

Calculate the new released memory. Store everything at or above the target in the target position.

```python
candidate_cost = dp[freed] + cost
```

Calculate the cost if we add this tensor.

```python
if candidate_cost < dp[next_freed]:
    dp[next_freed] = candidate_cost
```

Keep the cheaper way to reach that amount of released memory.

```python
reachable = min(required_memory, reachable + size)
```

Update the largest amount of memory that can possibly be reached after including this tensor.

The shortest summary is:

> `dp` records the cheapest known cost for each released-memory amount, and every tensor updates those possibilities once, from right to left.
