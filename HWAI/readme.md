💻 编程题核心算法
编程题是重头戏，虽然题目背景会包装成“大模型训练”、“专家调度”等AI场景，但本质大多考察经典的数据结构与算法。
- ​​图论算法：​​ 这是最高频的考点之一。
- ​​搜索：​​ 广度优先搜索（BFS）￼ 常用于求最短路径， 深度优先搜索（DFS）￼ 用于遍历或连通性问题。￼
- ​​并查集￼ ：​​ 专门处理连通性问题，比如判断点是否在同一个簇中，是解决“专家分组”、“CDN选址”等问题的利器。￼
- ​​动态规划（DP）：​​ 用于求解最优化问题。
- ​​常见模型：​​ 背包问题、最长子序列、编辑距离等是基础。
- ​​场景应用：​​ 可能会包装成“模型分段切割”、“任务执行”等，需要自己抽象出DP状态和转移方程。￼
- ​​贪心算法：​​ 在资源分配、调度等问题中很常见。思路通常是每一步都做出当前看起来最优的选择。
- ​​实例：​​ “KV缓存优化”题，本质就是按优先级（注意力分数）进行贪心选择。￼
- ​​经典AI算法实现：​​ 偶尔会直接考察对基础AI算法的理解和实现。
- ​​例如：​​ 实现KNN算法的距离计算和投票，或构建决策树。￼
- ​​其他常见算法：​​ 排序、滑动窗口、 单调队列￼ 、字符串处理等也是必备技能。

✨备考核心策略
	￼	​​吃透经典算法：​​ 别被AI背景迷惑，重点是把并查集、BFS/DFS、DP等经典算法的模板练熟，考场上能直接套用。
	￼	​​选择题刷真题：​​ 选择题重复率高，刷近两年的真题是提分最快的方式，能帮你快速建立信心。
	￼	​​时间管理是关键：​​ 编程题分值高，务必保证至少1小时的解题时间，不要在选择题上纠结过久。

参考44篇笔记

编程题是华为AI岗机考的重头戏，两道题共450分，​​只要能AC一道编程题+做一些选择题，就基本稳过线了。​​ 所以时间充足的话，策略很明确：​​集中火力攻克第一道150分题，有余力再冲第二道。​​
🔑 第一道编程题（150分）—— 必须拿下
这类题本质是"披了AI外衣的传统算法"，核心考点比较集中，基本就这几类：
▶ CART决策树建树（出现频率最高）
遍历特征×切分点，算加权基尼系数，选最优分裂递归建树。细节在于：基尼相同时选编号小的、停止条件的判断、叶子多数投票。
▶ K-Means / K-Median聚类
迭代分配样本到最近聚类中心，再更新中心坐标。需要特别注意：空簇处理、收敛判断（变化量<1e-4）、距离计算方式（欧氏/曼哈顿）。
▶ 窗口滑动 / 字符串模拟
多段窗口规则处理，有时候套了文本处理或卷积的背景，剥开之后就是暴力模拟+边界处理。
▶ 动态规划 / 贪心
偶数出现，但一旦碰上难度就上来了。比如连续分段最小化最大段和、背包类变种。
🔑 第二道编程题（300分）—— 争取拿部分分
更难，通常是大模型组件的手写实现：
- ​​Masked Fused RMSNorm￼​​：残差融合→只在有效长度算RMS→归一化→仿射变换→padding置0。反复出现。
- ​​Attention机制手写​​：GQA分组注意力、多头注意力掩码计算、RoPE 旋转位置编码￼ 。核心是理解公式后逐行实现，不需要AI知识，纯数学模拟。
- ​​LSTM前向传播​​：四个门的实现，按公式一步步抄就行。
- ​​DBSCAN￼ 聚类​​：核心点标记+BFS建簇+噪声点统计。
这类题如果时间不够，​​至少把样例case return掉​​，能骗点通过率。
⏰ 有时间的话，建议这么安排
📌 阶段一：Python语法+ACM模式（2-3天）
华为是 ACM模式￼ （自己处理输入输出），和 LeetCode￼ 不一样。先熟悉标准输入读取、浮点数格式化输出、边界条件处理。
📌 阶段二：刷第一题的高频题型（1-2周）
把CART树、K-Means、K-Median这几类模板题各写2-3遍，做到闭眼能写。每道题重点练边界条件：空输入、单样本、除零、浮点精度。
📌 阶段三：刷第二题的模板（1-2周）
RMSNorm和Attention手写各写两遍。记住公式→用numpy抄→处理mask和padding边界。不需要理解训练原理，纯实现。
📌 阶段四：真题模拟（考前冲刺）
找近两年的真题做全真模拟，卡时间。选择题40分钟内搞定，第一题争取20分钟AC，剩下时间看第二题。
