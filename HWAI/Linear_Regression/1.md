Start with the linear-regression model:

```text
price = b + w1×hardware + w2×system + w3×AI
```

There are four unknown parameters:

```text
b, w1, w2, w3
```

Put them into one vector:

```text
    ┌ b  ┐
w = │ w1 │
    │ w2 │
    └ w3 ┘
```

## 1. Build the feature matrix `X`

Suppose there are `K` known phones.

For each phone, create one row:

```text
[1, hardware, system, AI]
```

The first value is `1` so the model can include the bias `b`.

For example, with three phones:

```text
X =
┌ 1  86   99   20 ┐
│ 1 175  171   90 │
└ 1 194   42   47 ┘
```

The known prices form vector `y`:

```text
y =
┌ 3595 ┐
│ 6596 │
└ 4691 ┘
```

## 2. Matrix multiplication produces predictions

The predicted prices are:

```text
prediction = Xw
```

For the first phone, the first row calculates:

```text
1×b + 86×w1 + 99×w2 + 20×w3
```

Therefore:

```text
Xw =
┌ predicted price 1 ┐
│ predicted price 2 │
└ predicted price 3 ┘
```

Ideally, we would like:

```text
Xw = y
```

But real data usually contains noise, so there may be no `w` that makes every prediction exactly equal to every price.

## 3. Least squares

The prediction errors are:

```text
Xw - y
```

Least squares minimizes the sum of their squares:

```text
loss = ||Xw - y||²
```

This means:

```text
loss =
(prediction1 - price1)²
+ (prediction2 - price2)²
+ ...
```

The best `w` is the point where the derivative of this loss is zero.

The derivative is:

```text
2Xᵀ(Xw - y)
```

Set it to zero:

```text
2Xᵀ(Xw - y) = 0
```

Remove the `2`:

```text
Xᵀ(Xw - y) = 0
```

Expand:

```text
XᵀXw - Xᵀy = 0
```

Move `Xᵀy` to the other side:

```text
(XᵀX)w = Xᵀy
```

This is the normal equation.

## 4. Why multiply by `Xᵀ`?

`X` has shape:

```text
K × 4
```

because there are `K` phones and four parameters.

So:

```text
Xᵀ has shape 4 × K
```

The resulting shapes are:

```text
XᵀX:  (4 × K) × (K × 4) = 4 × 4

Xᵀy:  (4 × K) × (K × 1) = 4 × 1
```

Therefore, the normal equation becomes:

```text
4×4 matrix × 4 unknown weights = 4 known values
```

It is now an ordinary four-variable linear system.

## 5. Matrix inverse approach

Let:

```text
A = XᵀX
c = Xᵀy
```

Then:

```text
Aw = c
```

Mathematically, we could multiply both sides by `A⁻¹`:

```text
w = A⁻¹c
```

Therefore:

```text
w = (XᵀX)⁻¹Xᵀy
```

But calculating the complete inverse is unnecessary. We only want the solution `w`.

## 6. Gaussian elimination

This is similar to solving ordinary equations such as:

```text
2a + b = 5
 a - b = 1
```

We can eliminate `a` or `b` and solve the equations directly. We do not need to calculate a matrix inverse.

For linear regression, Gaussian elimination directly solves:

```text
(XᵀX)w = Xᵀy
```

where the unknown values are:

```text
b, w1, w2, w3
```

So the process is:

```text
Training data
    ↓
Build X and y
    ↓
Calculate A = XᵀX
Calculate c = Xᵀy
    ↓
Solve Aw = c with Gaussian elimination
    ↓
Obtain b, w1, w2, w3
```

The essential idea is:

> The normal equation converts “find the line with the smallest total squared error” into a standard system of four linear equations, and Gaussian elimination solves those equations directly.




# Gauss-Jordan Elimination: Solving a 3-Variable System

Source: supplied transcript of the YouTube lesson on Gauss-Jordan elimination.

## Goal of the method

Gauss-Jordan elimination solves a linear system by turning its **augmented
matrix** into **reduced row echelon form (RREF)**.

For a three-variable system, the desired final shape is:

```text
[ 1  0  0 | x ]
[ 0  1  0 | y ]
[ 0  0  1 | z ]
```

The last column directly gives the values of `x`, `y`, and `z`.

The method changes rows without changing the solution. The useful row
operations are:

```text
1. Swap two rows.
2. Multiply one row by a non-zero number.
3. Replace a row with itself plus a multiple of another row.
```

## Example from the lesson

Solve:

```text
x + y - z  = 7
x - y + 2z = 3
2x + y + z = 9
```

### 1. Convert the equations into an augmented matrix

Keep the coefficient order consistent: `x`, then `y`, then `z`. Put the
constants after the vertical bar.

```text
[ 1   1  -1 | 7 ]
[ 1  -1   2 | 3 ]
[ 2   1   1 | 9 ]
```

### 2. Clear the entries below the first pivot

The first pivot is the top-left `1`.

```text
R2 <- R1 - R2
R3 <- R3 - 2R1

[ 1   1  -1 |  7 ]
[ 0   2  -3 |  4 ]
[ 0  -1   3 | -5 ]
```

Now the first column below the pivot contains zeros.

### 3. Clear the entry below the second pivot

Use row 3 to eliminate the `-1` in column 2:

```text
R3 <- R2 + 2R3

[ 1   1  -1 |  7 ]
[ 0   2  -3 |  4 ]
[ 0   0   3 | -6 ]
```

At this point the matrix is in upper-triangular form. Gauss-Jordan continues
by also clearing entries **above** the pivots.

### 4. Clear the third column above its pivot

First use row 2 to remove the `-1` in row 1, column 3:

```text
R1 <- 3R1 - R2

[ 3   1   0 | 17 ]
[ 0   2  -3 |  4 ]
[ 0   0   3 | -6 ]
```

Then remove the `-3` in row 2, column 3:

```text
R2 <- R2 + R3

[ 3   1   0 | 17 ]
[ 0   2   0 | -2 ]
[ 0   0   3 | -6 ]
```

### 5. Clear the second column above its pivot

```text
R1 <- 2R1 - R2

[ 6   0   0 | 36 ]
[ 0   2   0 | -2 ]
[ 0   0   3 | -6 ]
```

### 6. Make each pivot equal to 1

```text
R1 <- (1/6)R1
R2 <- (1/2)R2
R3 <- (1/3)R3

[ 1   0   0 |  6 ]
[ 0   1   0 | -1 ]
[ 0   0   1 | -2 ]
```

This is RREF, so:

```text
x =  6
y = -1
z = -2
```

Therefore, the solution is:

```text
(x, y, z) = (6, -1, -2)
```

## Practical checklist

```text
1. Write the augmented matrix carefully.
2. Choose a pivot in the first column and zero its column.
3. Move right one column and repeat for the next pivot.
4. Eliminate both below and above every pivot.
5. Scale each pivot row until the pivot is 1.
6. Read variable values from the final column.
```

## Important lesson from the worked example

Arithmetic signs matter. The transcript catches one copying error: the final
entry of row 3 is `-6`, not `6`. A single sign error can change every later
row operation, so it is worth checking each row before continuing.



Think of the function as doing the same row operations you do by hand, but with loops.

It solves:

```text
matrix × unknowns = values
```

Let’s use this example:

```text
2x + y = 5
 x - y = 1
```

We want Python to return:

```python
[2, 1]  # x = 2, y = 1
```

---

## 1. What are `matrix` and `values`?

```python
matrix = [
    [2, 1],
    [1, -1],
]

values = [5, 1]
```

This represents:

```text
[ 2   1 ] [ x ] = [ 5 ]
[ 1  -1 ] [ y ]   [ 1 ]
```

The left matrix contains coefficients. `values` is the right side of the equations.

---

## 2. Why create `augmented`?

```python
augmented = [
    matrix[row][:] + [values[row]]
    for row in range(n)
]
```

It puts the right side at the end of each row:

```text
[ 2   1 | 5 ]
[ 1  -1 | 1 ]
```

The `|` is just a visual separator. Internally, Python stores:

```python
[
    [2, 1, 5],
    [1, -1, 1],
]
```

For the first row:

```python
matrix[0][:]      # [2, 1], a copied row
[values[0]]       # [5]

[2, 1] + [5]      # [2, 1, 5]
```

The `[:]` means “make a copy,” so the original `matrix` stays unchanged.

---

## 3. What is the final target?

We want the left side to become:

```text
[ 1  0 ]
[ 0  1 ]
```

This is called the identity matrix.

Then:

```text
[ 1  0 | 2 ]
[ 0  1 | 1 ]
```

means:

```text
1x + 0y = 2  →  x = 2
0x + 1y = 1  →  y = 1
```

So the last column is the answer.

---

## 4. `for column in range(n)`

```python
for column in range(n):
```

There are two unknowns, so `n = 2`.

The loop runs twice:

```text
column = 0: make the first column become [1, 0]
column = 1: make the second column become [0, 1]
```

---

# First loop: `column = 0`

Current matrix:

```text
[ 2   1 | 5 ]
[ 1  -1 | 1 ]
```

We want column `0` to become:

```text
[ 1 ]
[ 0 ]
```

## 5. Find a pivot row

```python
pivot_row = max(
    range(column, n),
    key=lambda row: abs(augmented[row][column])
)
```

For `column = 0`, look at:

```text
row 0, column 0 = 2
row 1, column 0 = 1
```

Choose the largest absolute value:

```text
max(abs(2), abs(1)) = 2
```

So:

```python
pivot_row = 0
```

A **pivot** is the number we use to clear the rest of its column.

Why choose the biggest absolute value?

- Avoid using `0` as a pivot.
- Reduce floating-point errors.
- This is called partial pivoting.

---

## 6. Swap the pivot row into position

```python
augmented[column], augmented[pivot_row] = (
    augmented[pivot_row],
    augmented[column]
)
```

Here:

```python
column = 0
pivot_row = 0
```

So it swaps row `0` with itself: nothing changes.

But imagine this matrix:

```text
[ 0   1 | 3 ]
[ 2   4 | 8 ]
```

For column `0`, row `1` has the better pivot (`2` instead of `0`), so the function swaps rows:

```text
[ 2   4 | 8 ]
[ 0   1 | 3 ]
```

Now division is safe.

---

## 7. Read the pivot

```python
pivot = augmented[column][column]
```

Currently:

```python
pivot = augmented[0][0]  # 2
```

If it is almost zero:

```python
if abs(pivot) < 1e-12:
    raise ValueError("No unique solution")
```

the function stops, because it cannot make a reliable pivot there.

---

## 8. Divide the pivot row to make its pivot equal to `1`

```python
for j in range(column, n + 1):
    augmented[column][j] /= pivot
```

At this moment:

```python
column = 0
n = 2
```

Therefore:

```python
range(0, 3)  # 0, 1, 2
```

It divides every number in row `0`, including the right-hand-side value:

```text
[ 2   1 | 5 ] / 2

[ 1  0.5 | 2.5 ]
```

Now the first pivot is `1`.

---

## 9. Eliminate the first variable from every other row

```python
for row in range(n):
    if row == column:
        continue
```

We are working on `column = 0`, so skip row `0` because it already contains the pivot.

Only process row `1`:

```text
[ 1   0.5 |  2.5 ]
[ 1  -1.0 | 1.0 ]
```

```python
factor = augmented[row][column]
```

For row `1`:

```python
factor = augmented[1][0]  # 1
```

This means row `1` has a `1` below the pivot. To remove it:

```text
R2 <- R2 - 1 × R1
```

The code does exactly that:

```python
augmented[row][j] -= factor * augmented[column][j]
```

Step by step:

```text
first value:  1 - 1 × 1   = 0
second value: -1 - 1 × 0.5 = -1.5
right side:    1 - 1 × 2.5 = -1.5
```

New matrix:

```text
[ 1   0.5 |  2.5 ]
[ 0  -1.5 | -1.5 ]
```

The first column is now correct:

```text
[ 1 ]
[ 0 ]
```

---

# Second loop: `column = 1`

Now we want the second column to become:

```text
[ 0 ]
[ 1 ]
```

Current matrix:

```text
[ 1   0.5 |  2.5 ]
[ 0  -1.5 | -1.5 ]
```

The pivot is already in row `1`:

```python
pivot = -1.5
```

Divide row `1` by `-1.5`:

```text
[ 0  -1.5 | -1.5 ] / -1.5

[ 0   1 | 1 ]
```

Matrix:

```text
[ 1  0.5 | 2.5 ]
[ 0  1.0 | 1.0 ]
```

Now eliminate the `0.5` above the pivot.

```python
factor = augmented[0][1]  # 0.5
```

So:

```text
R1 <- R1 - 0.5 × R2
```

```text
[ 1  0.5 | 2.5 ]
[ 0  1.0 | 1.0 ]

becomes:

[ 1  0 | 2 ]
[ 0  1 | 1 ]
```

---

## 10. Return the last column

```python
return [
    augmented[row][n]
    for row in range(n)
]
```

Remember:

```python
n = 2
```

So this returns index `2`, the last value in each row:

```python
[
    augmented[0][2],  # 2
    augmented[1][2],  # 1
]
```

Result:

```python
[2, 1]
```

Therefore:

```text
x = 2
y = 1
```

The most important line is this one:

```python
augmented[row][j] -= factor * augmented[column][j]
```

It means:

```text
current row = current row - factor × pivot row
```

That is the row operation that turns unwanted values into zero.
