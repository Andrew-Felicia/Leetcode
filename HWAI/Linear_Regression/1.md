Start with the linear-regression model:

```text
price = b + w1×hardware + w2×system + w3×AI
```

There are four unknown parameters:

```text
b, w1, w2, w3
```

Put them into one vector:

```text
    ┌ b  ┐
w = │ w1 │
    │ w2 │
    └ w3 ┘
```

## 1. Build the feature matrix `X`

Suppose there are `K` known phones.

For each phone, create one row:

```text
[1, hardware, system, AI]
```

The first value is `1` so the model can include the bias `b`.

For example, with three phones:

```text
X =
┌ 1  86   99   20 ┐
│ 1 175  171   90 │
└ 1 194   42   47 ┘
```

The known prices form vector `y`:

```text
y =
┌ 3595 ┐
│ 6596 │
└ 4691 ┘
```

## 2. Matrix multiplication produces predictions

The predicted prices are:

```text
prediction = Xw
```

For the first phone, the first row calculates:

```text
1×b + 86×w1 + 99×w2 + 20×w3
```

Therefore:

```text
Xw =
┌ predicted price 1 ┐
│ predicted price 2 │
└ predicted price 3 ┘
```

Ideally, we would like:

```text
Xw = y
```

But real data usually contains noise, so there may be no `w` that makes every prediction exactly equal to every price.

## 3. Least squares

The prediction errors are:

```text
Xw - y
```

Least squares minimizes the sum of their squares:

```text
loss = ||Xw - y||²
```

This means:

```text
loss =
(prediction1 - price1)²
+ (prediction2 - price2)²
+ ...
```

The best `w` is the point where the derivative of this loss is zero.

The derivative is:

```text
2Xᵀ(Xw - y)
```

Set it to zero:

```text
2Xᵀ(Xw - y) = 0
```

Remove the `2`:

```text
Xᵀ(Xw - y) = 0
```

Expand:

```text
XᵀXw - Xᵀy = 0
```

Move `Xᵀy` to the other side:

```text
(XᵀX)w = Xᵀy
```

This is the normal equation.

## 4. Why multiply by `Xᵀ`?

`X` has shape:

```text
K × 4
```

because there are `K` phones and four parameters.

So:

```text
Xᵀ has shape 4 × K
```

The resulting shapes are:

```text
XᵀX:  (4 × K) × (K × 4) = 4 × 4

Xᵀy:  (4 × K) × (K × 1) = 4 × 1
```

Therefore, the normal equation becomes:

```text
4×4 matrix × 4 unknown weights = 4 known values
```

It is now an ordinary four-variable linear system.

## 5. Matrix inverse approach

Let:

```text
A = XᵀX
c = Xᵀy
```

Then:

```text
Aw = c
```

Mathematically, we could multiply both sides by `A⁻¹`:

```text
w = A⁻¹c
```

Therefore:

```text
w = (XᵀX)⁻¹Xᵀy
```

But calculating the complete inverse is unnecessary. We only want the solution `w`.

## 6. Gaussian elimination

This is similar to solving ordinary equations such as:

```text
2a + b = 5
 a - b = 1
```

We can eliminate `a` or `b` and solve the equations directly. We do not need to calculate a matrix inverse.

For linear regression, Gaussian elimination directly solves:

```text
(XᵀX)w = Xᵀy
```

where the unknown values are:

```text
b, w1, w2, w3
```

So the process is:

```text
Training data
    ↓
Build X and y
    ↓
Calculate A = XᵀX
Calculate c = Xᵀy
    ↓
Solve Aw = c with Gaussian elimination
    ↓
Obtain b, w1, w2, w3
```

The essential idea is:

> The normal equation converts “find the line with the smallest total squared error” into a standard system of four linear equations, and Gaussian elimination solves those equations directly.
