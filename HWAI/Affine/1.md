## 1. What is the problem asking?

An image is just a matrix:

```text
A =
10 20 30
40 50 60
```

Coordinates use:

```text
x = column
y = row
```

Therefore:

```text
A[y][x]
```

For example:

```text
A[0][0] = 10
A[0][2] = 30
A[1][1] = 50
```

The affine transformation moves a source position `(x, y)` to an output position `(x', y')`:

```text
x' = a*x + b*y + tx
y' = c*x + d*y + ty
```

The matrix is:

```text
M =
a  b  tx
c  d  ty
```

It can perform:

- Translation
- Scaling
- Rotation
- Shearing
- Reflection

## 2. Why do we need inverse mapping?

The formula given by the problem goes from the source image to the output:

```text
source (x, y) -> output (x', y')
```

However, we need to fill every position in the output image.

For each output position `(x', y')`, we ask:

> Which source pixel `(x, y)` should be copied here?

Therefore, we calculate in the opposite direction:

```text
output (x', y') -> source (x, y)
```

This is called inverse mapping.

## 3. Remove the translation first

From:

```text
x' = a*x + b*y + tx
y' = c*x + d*y + ty
```

subtract the translation:

```text
u = x' - tx
v = y' - ty
```

Now:

```text
u = a*x + b*y
v = c*x + d*y
```

## 4. Invert the linear matrix

The linear part is:

```text
L =
a b
c d
```

Its determinant is:

```text
det = a*d - b*c
```

If `det = 0`, the matrix cannot be inverted. The problem says to output only zeros in that case.

Otherwise, the original source position is:

```text
x = (d*u - b*v) / det
y = (-c*u + a*v) / det
```

Substitute `u` and `v`:

```text
x = (d*(x' - tx) - b*(y' - ty)) / det

y = (-c*(x' - tx) + a*(y' - ty)) / det
```

## 5. Translation example

Sample 2 uses:

```text
M =
1 0 1
0 1 1
```

Therefore:

```text
x' = x + 1
y' = y + 1
```

The inverse is:

```text
x = x' - 1
y = y' - 1
```

For output position `(1, 1)`:

```text
source x = 1 - 1 = 0
source y = 1 - 1 = 0
```

So we copy:

```text
A[0][0] = 10
```

For output position `(2, 1)`:

```text
source x = 2 - 1 = 1
source y = 1 - 1 = 0
```

So we copy:

```text
A[0][1] = 20
```

For output position `(0, 0)`:

```text
source x = -1
source y = -1
```

This is outside the image, so the output remains `0`.

## 6. Why do we round?

Inverse mapping can produce fractional coordinates.

For example:

```text
source x = 0.5
source y = 1.0
```

But an image can only be indexed with integer positions. The problem uses nearest-neighbor selection:

```python
source_x = math.floor(source_x + 0.5)
source_y = math.floor(source_y + 0.5)
```

Examples:

```text
0.2 -> 0
0.5 -> 1
0.8 -> 1
1.5 -> 2
```

## 7. The central part of the solution

```python
for output_y in range(output_height):
    for output_x in range(output_width):
        shifted_x = output_x - tx
        shifted_y = output_y - ty

        source_x = (
            d * shifted_x - b * shifted_y
        ) / determinant

        source_y = (
            -c * shifted_x + a * shifted_y
        ) / determinant

        source_x = math.floor(source_x + 0.5)
        source_y = math.floor(source_y + 0.5)

        if (
            0 <= source_x < source_width
            and 0 <= source_y < source_height
        ):
            output.append(image[source_y][source_x])
        else:
            output.append(0)
```

The loop visits output pixels in row-first order:

```text
(0,0), (1,0), (2,0), ...
(0,1), (1,1), (2,1), ...
```

So the `output` list is already in the required row-major order.

## Complete process

```text
Read the source image and M
        ↓
Calculate det = a*d - b*c
        ↓
If det is zero, output all zeros
        ↓
Visit every output position (x', y')
        ↓
Inverse-map it to source position (x, y)
        ↓
Round x and y
        ↓
If inside source image, copy A[y][x]
Otherwise, use 0
        ↓
Print the flattened output
```
