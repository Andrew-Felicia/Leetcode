For this binary classification problem, label `1` is “positive.”

For every validation sample, compare prediction with the real label:

| Prediction | Real label | Count |
|---|---:|---|
| `1` | `1` | TP — true positive |
| `1` | `0` | FP — false positive |
| `0` | `1` | FN — false negative |
| `0` | `0` | TN — true negative |

Then calculate:

```python
precision = TP / (TP + FP)
recall = TP / (TP + FN)
f1 = 2 * precision * recall / (precision + recall)
```

A convenient equivalent formula is:

```python
f1 = 2 * TP / (2 * TP + FP + FN)
```

If the denominator is `0`, use `0.0`.

For sample 1 after the best pruning:

```text
prediction: 1, 0, 1
true:       1, 1, 1
```

So:

```text
TP = 2
FP = 0
FN = 1

precision = 2 / (2 + 0) = 1.0
recall    = 2 / (2 + 1) = 2/3
f1        = 2 * 2 / (4 + 0 + 1) = 0.8
```
