## 2. 题目、答案与解释

### 1. Swish 的主要特点

**题目**：Swish 激活函数定义为 `f(x)=x·sigmoid(x)`。相比 ReLU，以下哪项最完整地描述了它的主要特点？

- A. 它是非单调的
- B. 它完全非负
- C. 它的计算成本远低于 ReLU
- D. 它在负区间仍有平滑曲线，可能保留更多信息

**答案：D。**

**基础知识/解释**：

```text
Swish(x) = x × sigmoid(x)
sigmoid(x) = 1 / (1 + e^(-x))
```

ReLU 在负区间直接输出 0；Swish 在负区间仍会输出平滑的小负值，因此不像 ReLU 那样直接丢弃全部负区间信息。Swish 确实在一小段负区间内非单调，但 A 没有说明它相对 ReLU 的主要实际价值；D 最完整。Swish 含指数运算，成本通常高于简单的 ReLU。

### 2. ZeRO-1 的基础通信算子

**题目**：在使用 ZeRO-1 优化的数据并行训练中，每个 GPU 计算完局部梯度后，通常通过哪组基础通信算子完成聚合、分片与更新后参数同步？

- A. All-Gather 和 Broadcast
- B. Broadcast 和 Reduce
- C. Scatter 和 All-Reduce
- D. Reduce-Scatter 和 All-Gather

**答案：D。**

**基础知识/解释**：分布式训练要让多张 GPU 上的梯度信息汇总。`Reduce-Scatter` 可以一边做规约（例如求和），一边把结果分片发给不同 GPU；`All-Gather` 可以把各卡持有的分片重新收集为完整结果。

```text
各卡局部梯度
   -> Reduce-Scatter：聚合并分给各卡一段
   -> 每卡更新自己负责的优化器状态/参数分片
   -> All-Gather：同步为可用于下一轮的完整参数视图
```

严格来说，ZeRO-1 主要分片的是优化器状态；不同框架实现还可能用 All-Reduce 或 Broadcast。但题目给出的“聚合、分片、同步”这一组基础模式中，D 最符合。

### 3. 表格特征输入神经网络

**题目**：表格数据中一列是连续数值，另一列是类别标签。为了输入神经网络，通常如何处理？

- A. 所有列都归一化到 0 至 1
- B. 连续数值做缩放，类别标签做 One-Hot 编码
- C. 所有列都转为字符串
- D. 连续数值做 One-Hot，类别标签做数值归一化

**答案：B。**

**基础知识/解释**：连续值（年龄、金额、温度）通常做标准化或 Min-Max 缩放，避免量纲差异影响训练。类别值（城市、颜色、设备型号）没有天然大小关系，常做 One-Hot：

```text
颜色 = red   -> [1, 0, 0]
颜色 = green -> [0, 1, 0]
颜色 = blue  -> [0, 0, 1]
```

高基数类别也常使用 Embedding，但基本选择题答案是“连续缩放、类别 One-Hot”。

### 4. 正态分布的 3σ 截断

**题目**：对近似服从正态分布 `N(0,σ²)` 的数据采用 `T=3σ` 截断，约有多少比例的数据落在 `[-T,T]` 之外并发生截断？

- A. 约 0.01%
- B. 约 4.5%
- C. 约 31.7%
- D. 约 0.27%

**答案：D，约 0.27%。**

**基础知识/解释**：正态分布的经验规律：

```text
在 μ ± 1σ 内：约 68.3%
在 μ ± 2σ 内：约 95.4%
在 μ ± 3σ 内：约 99.73%
```

因此 3σ 区间外的比例为：

```text
1 - 99.73% = 0.27%
```

### 5. 训练误差小、测试误差大

**题目**：线性回归模型的训练误差很小，但测试误差很大，最可能是什么原因？

- A. 欠拟合
- B. 过拟合
- C. 一定是数据量不足
- D. 一定是特征太少

**答案：B，过拟合。**

**基础知识/解释**：模型在训练集表现很好，却无法泛化到新数据，说明它可能连训练噪声或偶然模式都记住了。

```text
欠拟合：训练误差大，测试误差也常大
过拟合：训练误差小，测试误差大
```

数据少、特征处理不合理都可能是诱因，但不是“一定”的唯一原因。

### 6. 方差、协方差与独立性

**题目**：对于任意两个方差有限的随机变量 X 和 Y，下列命题正确的是？

- A. 若 `Var(X+Y)=Var(X)+Var(Y)`，则 X 与 Y 不相关
- B. 若 `Cov(X,Y)=0`，则 X 与 Y 一定独立
- C. 若 X 与 Y 独立，则 `Cov(X,Y)` 可能不为 0
- D. 若 X 与 Y 服从二维正态分布且不相关，则二者不一定独立

**答案：A。**

**基础知识/解释**：核心公式：

```text
Var(X + Y) = Var(X) + Var(Y) + 2Cov(X,Y)
```

若左边恰好等于前两个方差之和，则 `2Cov(X,Y)=0`，即协方差为 0，称为不相关，因此 A 对。

- 不相关通常不推出独立，所以 B 错；
- 独立且方差有限时，协方差为 0，所以 C 错；
- 对“联合/二维正态”变量，不相关会推出独立，所以 D 错。

### 7. 词向量算术

**题目**：已知二维列向量 `v_cat=[1,2]ᵀ`、`v_animal=[2,3]ᵀ`、`v_dog=[3,1]ᵀ`，则 `v_cat-v_animal+v_dog` 等于什么？

- A. `[2,0]ᵀ`
- B. `[0,2]ᵀ`
- C. `[4,6]ᵀ`
- D. `[2,1]ᵀ`

**答案：A。**

**基础知识/解释**：向量逐分量计算：

```text
[1,2] - [2,3] + [3,1]
= [1-2+3, 2-3+1]
= [2,0]
```

### 8. 对称矩阵的特征值和特征向量

**题目**：对称矩阵 `A=[[2,1],[1,2]]` 的特征值和对应特征向量正确的是？

- A. 特征值 1 对应 `[1,1]ᵀ`，特征值 3 对应 `[1,-1]ᵀ`
- B. 特征值 2 对应 `[1,0]ᵀ`，特征值 1 对应 `[0,1]ᵀ`
- C. 特征值 3 对应 `[1,1]ᵀ`，特征值 1 对应 `[1,-1]ᵀ`
- D. 特征值 4 对应 `[1,1]ᵀ`，特征值 0 对应 `[1,-1]ᵀ`

**答案：C。**

**基础知识/解释**：验证特征向量定义 `Av=λv`：

```text
A[1,1]ᵀ = [3,3]ᵀ = 3[1,1]ᵀ
A[1,-1]ᵀ = [1,-1]ᵀ = 1[1,-1]ᵀ
```

所以特征值 3 对应 `[1,1]ᵀ`，特征值 1 对应 `[1,-1]ᵀ`。

### 9. RNN 适合的数据类型

**题目**：循环神经网络最适合处理哪类数据？

- A. 图数据
- B. 图像
- C. 无顺序的表格数据
- D. 序列数据

**答案：D，序列数据。**

**基础知识/解释**：RNN 通过隐藏状态把前一时刻的信息传到下一时刻，适合文本、语音、时间序列等有顺序的数据：

```text
x1 -> h1 -> h2 -> h3 -> ...
      ↑     ↑     ↑
     x2    x3    x4
```

### 10. 异常值多时的特征缩放

**题目**：数据包含较多异常值，并准备使用 SVM 或 KNN 等对距离敏感的算法。哪种特征缩放方法通常最鲁棒？

- A. 使用均值和标准差的 Standardization
- B. 使用中位数和四分位距的 RobustScaler
- C. 使用最小值和最大值的 Min-Max Scaling
- D. 对所有数值直接取自然对数

**答案：B，RobustScaler。**

**基础知识/解释**：均值、标准差、最小值、最大值都容易被极端值拉动。RobustScaler 使用更抗异常值的统计量：

```text
x_scaled = (x - median) / IQR
IQR = Q3 - Q1
```

中位数与四分位距受到少数离群点影响较小，因此对距离类算法更稳健。

### 11. FP8 训练的数值稳定化

**题目**：模型使用 FP8 训练时，工程上常见的数值稳定化操作是什么？

- A. 梯度缩放
- B. 去掉 Dropout
- C. 使用更小的 batch size
- D. 增大学习率并减少权重衰减

**答案：A，梯度缩放。**

**基础知识/解释**：低精度格式可表示的数值范围和精度有限，小梯度可能下溢成 0。梯度缩放先把 loss 乘一个缩放系数：

```text
scaled_loss = scale × loss
```

反向传播得到较大的梯度后，再在更新前除回 `scale`。这能降低下溢风险；工程中通常还会配合动态缩放和高精度累积。

### 12. 空洞卷积

**题目**：空洞卷积的主要作用是什么？

- A. 在不增加卷积核参数量的情况下扩大感受野
- B. 直接提高特征图分辨率
- C. 以上都不对
- D. 必然减少计算量

**答案：A。**

**基础知识/解释**：空洞卷积在卷积核元素之间插入间隔。例如 3×3 核、膨胀率 2 的有效覆盖范围像 5×5：

```text
普通 3×3:  o o o
            o o o
            o o o

空洞率 2:  o . o . o
            . . . . .
            o . o . o
            . . . . .
            o . o . o
```

实际可学习参数仍是 9 个，却能看更大的区域。

### 13. 多机多卡并行拓扑

**题目**：每台服务器有 8 张通过 NVLink 互联的 GPU，服务器间使用带宽较低、延迟较高的 IB 网络。为了降低通信瓶颈，最合理的并行拓扑映射是？

- A. 所有并行策略随机分配
- B. 流水线并行放在单机内，张量并行跨节点
- C. 数据并行放在单机内，张量并行和流水线并行跨节点
- D. 张量并行放在单机内，流水线并行和数据并行跨节点

**答案：D。**

**基础知识/解释**：张量并行（TP）在每层中频繁通信，对带宽和延迟最敏感，应优先放进 NVLink 单机组。流水线并行（PP）只在相邻 stage 间传激活，跨节点更可接受；数据并行（DP）通常在梯度同步时跨节点通信，也可放在较慢网络层级。

```text
单机 NVLink：TP group
跨服务器 IB：PP stage 连接、DP replica 同步
```

### 14. 相关系数

**题目**：若 `Cov(X,Y)=10、Var(X)=4、Var(Y)=25`，则 X 与 Y 的相关系数是多少？

- A. 0.5
- B. 0.8
- C. 1.0
- D. 0.1

**答案：C，1.0。**

**基础知识/解释**：

```text
ρ(X,Y) = Cov(X,Y) / (sqrt(Var(X)) × sqrt(Var(Y)))
       = 10 / (2 × 5)
       = 1.0
```

相关系数在 `[-1,1]` 内。1 表示完全正线性相关。

### 15. 等距高次插值的端点振荡

**题目**：对函数 `f(x)=1/(1+25x²)` 在区间 `[-1,1]` 上使用等距节点做高次插值，随着次数增大，区间两端通常出现什么现象？

- A. 插值多项式趋于直线
- B. 必然一致收敛到 f(x)
- C. 振荡加剧，误差变大
- D. 插值多项式趋于零

**答案：C。**

**基础知识/解释**：这是经典的 Runge 现象。对某些函数，等距节点的高次多项式插值在区间端点附近会发生明显振荡；次数越高，端点误差反而可能越大。实践中可用 Chebyshev 节点、样条插值等方式缓解。

### 16. SmoothQuant（多选）

**题目**：SmoothQuant 使用正缩放向量 s，把 `Y=XW` 改写为 `(X·diag(s)⁻¹)(diag(s)·W)`。下列说法正确的是？

- A. 对存在大幅离群值的激活通道，按该通道最大幅值选择缩放可压缩激活范围，降低激活量化难度
- B. 缩放会同比放大权重对应行，s 过大可能增加权重量化难度，因此需要权衡
- C. 该方法无法用于注意力模块的 Q、K、V 线性投影
- D. 在有限精度浮点运算中，变换前后的每一位数值都完全相同，绝无舍入差异

**答案：A、B。**

**基础知识/解释**：代数上：
SmoothQuant 把部分激活量化难度迁移到权重侧，因此 A、B 正确；QKV 投影也是线性层。代数表达等价，但有限精度运算仍可能产生舍入差异，D 的“完全相同”过强。
```text
(X diag(s)^(-1)) (diag(s) W)
= X [diag(s)^(-1) diag(s)] W
= XW
```

它把激活通道上的异常大值“迁移”一部分到权重中，使激活更容易量化。但 `s` 太大时会放大权重对应行，也会让权重量化更难，因此 A、B 对。它可用于常见线性层，包括 Q/K/V 投影；有限精度下也可能有微小舍入误差。

### 17. 高维异量纲特征中的 DBSCAN（多选）

**题目**：在高维、不同量纲的用户行为特征上使用 DBSCAN，合理的原因包括哪些？

- A. 能够把低密度异常用户标记为噪声点
- B. 不需要预先指定簇数量
- C. 在任意高维空间中都不受维度灾难影响
- D. 能够发现非球形的任意形状簇

**答案：A、B、D。**

**基础知识/解释**：DBSCAN 根据密度而非“到中心点距离”成簇，能把密度不足的点标为噪声，也不需要预先指定 K，并能发现弯月形等非球形簇。但高维空间距离会变得不容易区分，仍会受到维度灾难影响；使用前也应先缩放不同量纲特征。

### 18. ReAct 架构（多选）

**题目**：关于 ReAct 架构，以下说法正确的是？

- A. 循环可能陷入思考与行动的死循环，需要终止条件
- B. 显式 Thought 步骤能增强过程的可解释性
- C. Observation 可来自工具、搜索引擎或 API 响应
- D. Agent 的行动不需要任何工具调用

**答案：A、B、C。**

**基础知识/解释**：ReAct 通常交替进行：

```text
Thought -> Action -> Observation -> Thought -> ... -> Final
```

工具或 API 的返回结果可以成为 Observation。工程上要设置最大步数、超时和成功/失败终止条件，否则 Agent 可能重复思考或重复调用工具。Action 不一定每次都调用工具，但“行动不需要任何工具调用”不是 ReAct 的正确概括。

### 19. BM25 + 向量混合 RAG（多选）

**题目**：在结合 BM25 与向量相似度的高级 RAG 系统中，下列说法正确的是？

- A. Embedding 是否归一化会影响余弦相似度与点积能否等价，混合打分时应统一口径
- B. Tokenizer 与 BM25 分词规则更兼容可减少词频统计错位
- C. 专业术语场景中 BM25 权重过高可能压制向量语义匹配
- D. 重排模型与 Embedding 模型共享或对齐特征空间，有利于联合优化检索链路
- E. 文档切分只影响向量检索，对 BM25 完全没有影响

**答案：A、B、C、D。**

**基础知识/解释**：

- 向量 L2 归一化后，点积等于余弦相似度；未归一化时二者不同，混合打分前必须明确尺度；
- BM25 依赖词频、词长度和分词结果，所以 Tokenizer/分词规则很重要；
- 专业术语确实适合 BM25，但权重过大可能错过“表达不同、语义相同”的文档；
- Reranker 和 Embedding 检索器的表示/目标越协调，系统越容易联合优化；
- 文档 chunk 会同时改变 BM25 的词频、长度归一化，也会影响向量表示，所以 E 错。

### 20. 常用于分类的损失函数（多选）

**题目**：下列哪些损失函数常用于分类问题？

- A. 交叉熵损失
- B. 均方误差
- C. 平均绝对误差
- D. 焦点损失

**答案：A、D。**

**基础知识/解释**：

- 交叉熵是分类最常见的标准损失；
- Focal Loss 是对类别不平衡/难样本更友好的分类损失；
- MSE、MAE 最典型用于回归任务。

MSE 理论上也能用于某些分类建模，但通常不是分类任务的首选，因此“常用于分类”的标准答案是 A、D。

