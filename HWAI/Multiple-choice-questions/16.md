# 华为 AI 在线笔试选择题学习笔记（第十六组）

## 1. 总结

| 主题 | 核心结论 |
| --- | --- |
| 统计 | 相关系数 -1 表示完全负线性相关；贝叶斯后验可用全概率公式计算。 |
| 归一化和优化 | Loss Scaling 防梯度下溢；LN 会减均值并除标准差，RMSNorm 才省去减均值。 |
| 注意力 | 线性注意力可递推，单步不随上下文长度增长；标准注意力每步仍需访问全部 KV Cache。 |
| 数值方法 | 截断 `sin(x)` 到三次项的主误差是 O(x⁵)；Huber 小误差二次、大误差线性。 |
| CNN | 卷积靠局部连接和权重共享减少参数；同一核在不同位置的梯度必须累加。 |
| 端侧推理 | 权重量化是满足显存预算的基础，KV 滑窗和搜索策略需在质量、延迟、上下文之间权衡。 |

## 2. 题目、答案与解释

### 1. 相关系数为 -1

**题目**：如果相关系数 `ρ_xy=-1`，说明 X 和 Y？

- A. 相互独立
- B. 存在线性函数关系
- C. 完全负线性相关
- D. 完全不相关

**答案：C。**

**基础知识/解释**：相关系数范围为 `[-1,1]`：

```text
ρ =  1：完全正线性相关
ρ = -1：完全负线性相关
ρ =  0：线性不相关（不代表独立）
```

`ρ=-1` 时，点严格落在一条斜率为负的直线上。

### 2. SVD 与矩阵秩

**题目**：实矩阵 `A=UΣV^T`，`rank(A)` 等于？

- A. `trace(Σ)`
- B. Σ 对角线上非零奇异值的个数
- C. V 的行数
- D. U 的列数

**答案：B。**

**基础知识/解释**：SVD 中 Σ 的对角线元素是奇异值。矩阵秩等于非零奇异值数量：

```text
rank(A) = number of non-zero singular values
```

### 3. 贝叶斯后验概率

**题目**：`P(A)=0.4`，`P(B|A)=0.5`，`P(B|¬A)=0.3`，则 `P(A|B)` 最接近？

- A. 0.4
- B. 0.5
- C. 0.3
- D. 0.6

**答案：B，约 0.53，最接近 0.5。**

**基础知识/解释**：

```text
P(B) = P(B|A)P(A) + P(B|¬A)P(¬A)
     = 0.5×0.4 + 0.3×0.6
     = 0.38

P(A|B) = P(B|A)P(A) / P(B)
       = 0.2 / 0.38
       ≈ 0.526
```

### 4. 混合精度中的 Loss Scaling

**题目**：混合精度训练中，常用 Loss Scaling 主要解决什么数值问题？

- A. 梯度爆炸
- B. 梯度下溢
- C. 激活饱和
- D. 权重过大

**答案：B。**

**基础知识/解释**：FP16 能表示的极小数有限。很小的梯度可能被舍入为 0，称为下溢。Loss Scaling 先把 loss 放大，再在更新前把梯度缩回：

```text
loss -> scale × loss -> backward -> gradient / scale
```

### 5. PCA 投影值

**题目**：中心化点 `x=[3,4]^T`，第一主成分单位向量 `w=[0.8,0.6]^T`，投影值是多少？

- A. 3.8
- B. 2.4
- C. 5.0
- D. 4.8

**答案：D，4.8。**

**基础知识/解释**：投影到单位方向 w 的一维坐标是点积：

```text
x·w = 3×0.8 + 4×0.6
    = 2.4 + 2.4
    = 4.8
```

### 6. LayerNorm 的错误描述

**题目**：以下关于 Layer Normalization（LN）说法错误的是？

- A. LN 位置不同可分 Pre-LN 和 Post-LN
- B. 与 RMSNorm 相比，LN 的主要区别在于去掉了减去均值的部分
- C. LN 对每个样本求均值/方差，归一化后再缩放、加偏置
- D. LN 有助于稳定训练

**答案：B。**

**基础知识/解释**：LN 的形式：

```text
LN(x) = γ × (x-mean(x)) / sqrt(var(x)+eps) + β
```

RMSNorm 是简化版，它才是不减均值、只按均方根缩放。因此 B 把两者说反了。

### 7. 狭长山谷中的 SGD

**题目**：损失曲面呈狭长山谷形状，一个方向曲率大、另一个方向曲率小，SGD 容易发生什么？

- A. 梯度爆炸
- B. 快速收敛
- C. 梯度消失
- D. 震荡，收敛缓慢

**答案：D。**

**基础知识/解释**：梯度下降在陡峭方向容易来回跨越山谷，在平缓方向推进很慢，因此出现“左右震荡、沿谷底缓慢前进”。Momentum、Adam 或合适的学习率可以缓解。

### 8. KV Cache 量化的明显缺陷

**题目**：关于 KV Cache 的量化压缩，哪种策略错误或有明显缺陷？

- A. 推理中在线量化，每次访问都重新计算量化参数
- B. INT8/INT4 存 KV，注意力计算时反量化到 FP16
- C. 使用 per-channel/per-head 分组量化
- D. K 和 V 分别逐 token 动态量化

**答案：A。**

**基础知识/解释**：每次访问都重新计算量化参数会引入很大额外开销，抵消量化节省的收益。B、C、D 都是可行设计方向，只是在精度、元数据和速度之间有不同权衡。

### 9. 互斥事件下的贝叶斯计算

**题目**：A、B 互斥，`P(A)=0.3`、`P(B)=0.4`、`P(C|A)=0.8`、`P(C|B)=0.5`、`P(C|¬A∩¬B)=0.1`。求 `P(A|C)`。

- A. 约 0.52
- B. 约 0.38
- C. 约 0.47
- D. 约 0.65

**答案：A。**

**基础知识/解释**：剩余概率为：

```text
P(¬A∩¬B) = 1 - 0.3 - 0.4 = 0.3

P(C) = 0.3×0.8 + 0.4×0.5 + 0.3×0.1
     = 0.47

P(A|C) = 0.3×0.8 / 0.47
       = 0.24 / 0.47
       ≈ 0.511
```

最接近 0.52。

### 10. 注意力机制优化

**题目**：关于 Transformer 注意力优化方案，正确的是？

- A. 滑窗注意力无法捕获任何窗口外依赖
- B. DeepSeek-V3 中 SWA 和全注意力交替时，显存与纯全注意力相同
- C. Flash Attention 用低秩近似把 O(n²) 降到 O(n)
- D. 线性注意力可转化为 RNN 递推，新 token 计算量不随上下文长度增长

**答案：D。**

**基础知识/解释**：线性注意力可维护一个累积状态，因此增量生成不必逐一访问全部历史 KV。SWA 单层只看窗口，但多层堆叠仍可能间接扩大感受野；Flash Attention 主要优化 IO 和内存访问，不是低秩近似。

### 11. sin(x) 泰勒截断误差

**题目**：用 `sin(x)=x-x³/6` 近似 `sin(0.1)`，截断误差主要阶数为？

- A. `O(x^4)`
- B. `O(x^3)`
- C. `O(x^5)`
- D. `O(x^6)`

**答案：C。**

**基础知识/解释**：

```text
sin(x) = x - x³/3! + x⁵/5! - ...
```

省略的第一个非零项是 `x⁵/120`，所以主截断误差为 `O(x⁵)`。

### 12. Huber Loss

**题目**：关于 Huber 损失，正确的是？

- A. 平衡 MSE 对异常值敏感和 MAE 在零点不可导的问题
- B. 存在不可导点
- C. 小误差线性，大误差二次
- D. 所有区间都与 MSE 相同

**答案：A。**

**基础知识/解释**：Huber Loss：

```text
小误差：二次项，平滑可导，类似 MSE
大误差：线性项，对异常值更稳健，类似 MAE
```

它在分界处连续可导。

### 13. Temperature 的作用

**题目**：生成模型解码阶段，Temperature 的正确作用是？

- A. T=1 时 Softmax 输出随机
- B. 温度调节 logits 缩放，影响概率分布
- C. 温度越低越随机
- D. 温度越高越确定

**答案：B。**

**基础知识/解释**：采样前通常计算：

```text
softmax(logits / T)
```

```text
T 低：分布更尖，输出更确定
T 高：分布更平，输出更多样、随机
```

### 14. 端侧后台 AI 调度的关键约束

**题目**：设计端侧后台 AI 任务调度策略时，哪项是需要综合考虑的约束条件？

- A. 用户当前位置
- B. 设备网络连接状态
- C. 当前存储空间使用情况
- D. 设备温度/热预算

**答案：D。**

**基础知识/解释**：端侧 AI 后台任务会消耗算力并发热。若超过热预算，设备可能降频、耗电上升或影响用户体验。因此热管理是端侧调度的关键硬约束。实际工程也可能考虑网络和存储，但题目问最核心的端侧 AI 运行约束时，D 最合适。

### 15. 子空间的必要条件

**题目**：子空间的必要条件是？

- A. 向量个数有限
- B. 向量两两正交
- C. 所有向量长度相等
- D. 包含零向量

**答案：D。**

**基础知识/解释**：子空间还必须对向量加法、标量乘法封闭；但这四项中，包含零向量是必要条件。若集合没有零向量，一定不是子空间。

### 16. 训练范式选择（多选）

**题目**：关于训练范式选择，哪些判断合理？

- A. 做了强化学习就不再需要 SFT
- B. 奖励设计不合理可能导致策略偏移或奖励黑客
- C. 领域知识不足时可继续预训练/领域预训练
- D. 仅靠 SFT 往往难以完全替代基于环境反馈的策略优化

**答案：B、C、D。**

**基础知识/解释**：SFT 通常是对齐和能力训练的基础；奖励设计有漏洞时，模型可能学会“刷奖励”而不是完成真正目标；领域知识缺失可通过继续预训练补充。环境交互型任务中，SFT 常难以完全替代 RL。

### 17. 浮点误差（多选）

**题目**：关于浮点数计算误差，哪些正确？

- A. 大数加小数可能吞掉小数
- B. 计算机不能精确表示所有十进制小数
- C. 浮点加法满足结合律
- D. 相近数相减可能严重丢失有效位

**答案：A、B、D。**

**基础知识/解释**：有限精度下：

```text
大数 + 极小数：极小数可能因舍入消失
相近数相减：前面的有效数字抵消，误差相对放大
(a+b)+c：可能不等于 a+(b+c)
```

### 18. Transformer 稳定训练技术（多选）

**题目**：Transformer 训练中，哪些技术用于稳定训练或加速收敛？

- A. 学习率预热
- B. 梯度裁剪
- C. 残差连接
- D. 层归一化

**答案：A、B、C、D。**

**基础知识/解释**：预热避免初期大更新；梯度裁剪限制爆炸梯度；残差连接提供更直接的梯度通路；LayerNorm 稳定激活分布。它们共同帮助深层 Transformer 训练。

### 19. CNN 卷积特性（多选）

**题目**：CNN 中卷积操作的特性包括？

- A. 参数量随输入空间尺寸线性增长
- B. 局部感受野减少参数规模
- C. 卷积保证对任意平移严格不变
- D. 同一卷积核在不同位置复用，反向传播梯度需要累加

**答案：B、D。**

**基础知识/解释**：卷积核大小、输入输出通道数固定时，参数量不随 H/W 增长。卷积有平移等变性而非严格不变性；池化、全局汇聚或数据增强可帮助增强平移不变性。权重共享意味着所有位置对同一卷积核参数的梯度要相加。

### 20. 端侧模型推理方案（多选）

**题目**：要求实时生成、质量较高、内存不超过 8GB；原始 FP32 权重 16GB，输入 20 token、生成 60 token。哪些方案最合理？

- A. 关闭 Prefill，仅保留 Decode
- B. 启用 KV Cache 滑动窗口（30）控制缓存占用
- C. INT8 量化将权重压缩至约 4GB
- D. 束搜索 K=3 + Top-P=0.8，兼顾质量与速度

**答案：C**

**基础知识/解释**：

A 错误，跳过 Prefill 阶段模型将无法理解输入的 prompt。B 错误，总上下文长度为 20+60=80，如果窗口仅设为 30，会丢失大量早期关键信息，导致生成质量崩塌。D 错误，Beam Search 会成倍增加计算量，且通常不与核采样（Top-P）混用，难以满足≤300ms的延迟要求。C 正确，INT8量化能将 16GB 的 FP32 权重压缩至 4GB，符合 ≤8GB 内存要求，同时大幅降低延迟，且一般不会导致生成质量（BLEU分数）明显下降。
