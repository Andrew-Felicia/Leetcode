# 华为 AI 在线笔试选择题学习笔记（第九组）

## 1. 总结

| 主题 | 核心结论 |
| --- | --- |
| 混合精度训练 | FP16 参数本身不等于训练总显存；梯度、FP32 主权重、Adam 两个状态和激活都需要显存。 |
| 分布式训练 | 浮点加法不满足结合律，不同 AllReduce 累加顺序会造成舍入误差。 |
| Transformer | 原始 Transformer 为机器翻译提出；多头注意力让模型同时从多个表示子空间关注不同信息。 |
| 评估指标 | 漏检正类成本高看 Recall；误报正类成本高看 Precision。 |
| 数值计算 | 高条件数或接近奇异的矩阵会放大输入扰动；Newton 与 Lagrange 是同一个插值多项式的不同写法。 |
| 无监督学习 | 无标签聚类可用轮廓系数、DBI、CH 指数；不能直接用 Accuracy。 |

## 2. 题目、答案与解释

### 1. 7B 模型的 Adam 混合精度训练显存

**题目**：设模型参数量 `N=7B`，训练数据量 `T=1T token`，采用 FP16 混合精度训练和 Adam 优化器。以下关于显存占用的估算，说法正确的是？

- A. 使用梯度检查点会增加显存占用
- B. 训练时需保存 FP32 主权重、FP16 参数、FP16 梯度，以及 Adam 的一阶和二阶矩（FP32），仅这些状态总显存约为 `7B×16 Byte≈112GB`
- C. 训练总显存约等于 FP16 模型参数占用的 14GB
- D. 训练显存只取决于参数量，与 batch size 和序列长度无关

**答案：B。**

**基础知识/解释**：每个参数的常见存储估算：

```text
FP32 主权重：4 Byte
FP16 模型参数：2 Byte
FP16 梯度：2 Byte
Adam 一阶矩 m：4 Byte
Adam 二阶矩 v：4 Byte
-------------------
合计：16 Byte / 参数
```

因此：

```text
7 × 10⁹ × 16 Byte = 112 × 10⁹ Byte ≈ 112 GB
```

这还没有计算激活值、临时张量、通信缓冲区等。梯度检查点是用额外计算换取更低激活显存；显存也会随 micro batch 和序列长度变化。

### 2. 互斥且独立的事件

**题目**：已知事件 A 与 B 既互斥又独立，则下列哪项一定成立？

- A. `P(A)=P(B)=0.5`
- B. `P(A∩B)=1`
- C. `P(A∪B)=1`
- D. `P(A)=0` 或 `P(B)=0`

**答案：D。**

**基础知识/解释**：互斥表示：

```text
P(A ∩ B) = 0
```

独立表示：

```text
P(A ∩ B) = P(A) × P(B)
```

两式合并：

```text
P(A) × P(B) = 0
```

所以至少有一个事件概率为 0。

### 3. 梯度累积与 micro batch

**题目**：训练脚本支持梯度累积。把 micro batch 从 1 调到 4，同时相应减小累积步数，使 global batch 保持不变。通常最可能出现哪种变化？

- A. 吞吐量一定下降
- B. 模型参数量减少
- C. 显存占用上升
- D. 模型一定收敛得更好

**答案：C。**

**基础知识/解释**：每个 micro batch 的前向和反向传播都要保存激活值。micro batch 变大，单次需要保存的激活更多：

```text
micro batch ↑ -> 激活显存 ↑
```

global batch 不变时，累积次数减少，但参数量不变，收敛也不保证更好。

### 4. Transformer 最初提出的任务

**题目**：Transformer 模型最初主要是为哪类任务提出的？

- A. 文本生成
- B. 图像分类
- C. 语音识别
- D. 机器翻译

**答案：D，机器翻译。**

**基础知识/解释**：2017 年论文《Attention Is All You Need》提出 Transformer 时，目标是机器翻译任务，采用 Encoder-Decoder 架构：

```text
源语言句子 -> Encoder -> Decoder -> 目标语言句子
```

之后 Transformer 才被扩展到文本生成、视觉、语音、多模态等大量领域。

### 5. BLIP-2 的 Q-Former

**题目**：BLIP-2 中 Q-Former 的核心设计是“可查询的 Transformer”。关于其机制和训练策略，以下描述最准确的是？

- A. Q-Former 包含查询之间的双向自注意力和查询到视觉特征的交叉注意力；冻结视觉编码器后，查询通过交叉注意力提取压缩视觉信息
- B. Q-Former 替代视觉编码器，直接输入原始像素并只用图文生成损失训练
- C. 查询仅通过自注意力与文本交互，不需要交叉注意力，并且训练时必须解冻视觉编码器
- D. 三个训练目标都会更新视觉编码器的参数

**答案：A。**

**基础知识/解释**：BLIP-2 的目标之一是连接冻结的视觉编码器与冻结的大语言模型。Q-Former 使用少量可学习 query token，通过交叉注意力从视觉特征中“查询”关键信息：

```text
图像 -> 冻结视觉编码器 -> 视觉特征
                              ↑
可学习 Query token -> Q-Former 交叉注意力 -> 压缩视觉表示
```

因此它不是直接处理原始像素，也不要求解冻视觉编码器。

### 6. 双线性插值

**题目**：在 3D 模型纹理映射中，与最近邻插值相比，双线性插值主要可以减少什么？

- A. 数据存储
- B. 精度损失
- C. 计算时间
- D. 视觉锯齿

**答案：D，视觉锯齿。**

**基础知识/解释**：最近邻插值只选择最近像素，放大或缩放时容易出现明显方块和锯齿。双线性插值根据周围 4 个像素加权平均，画面更平滑，但计算会比最近邻略多。

### 7. AllReduce 的累加顺序差异

**题目**：分布式训练时，AllReduce 的浮点累加顺序不同会使最终参数产生微小差异。这属于哪类误差？

- A. 舍入误差
- B. 模型结构误差
- C. 采样误差
- D. 截断误差

**答案：A，舍入误差。**

**基础知识/解释**：浮点数只能表示有限精度，小数运算时会发生舍入。而浮点加法通常不满足结合律：

```text
(a + b) + c 可能不等于 a + (b + c)
```

不同通信拓扑或不同归约顺序可能改变累加顺序，从而产生很小的舍入差异。

### 8. 三阶张量的收缩

**题目**：设三阶张量 T 的分量为 `Tᵢⱼₖ`。对第 1 个指标与第 3 个指标进行收缩后得到 S。以下表述最准确的是？

- A. `Sᵢₖ=ΣⱼTᵢⱼₖ`，S 是二阶张量
- B. 收缩只对二阶方阵有定义
- C. 收缩后张量阶数仍为 3
- D. `Sⱼ=ΣᵢTᵢⱼᵢ`，S 是一阶张量

**答案：D。**

**基础知识/解释**：收缩是把两个指标设为同一个指标并求和。三阶张量收缩一对指标后，阶数减少 2：

```text
Tᵢⱼₖ  -- 收缩 i 与 k -->  Sⱼ = Σᵢ Tᵢⱼᵢ
```

所以三阶张量会变成一阶张量（向量）。

### 9. 欺诈检测中的漏检成本高

**题目**：在欺诈检测中，漏检真实欺诈样本的成本远高于误报成本。模型评估时应优先关注哪个指标？

- A. 准确率
- B. 均方误差
- C. 召回率
- D. 特异度

**答案：C，召回率。**

**基础知识/解释**：把“欺诈”设为正类：

```text
Recall = TP / (TP + FN)
```

FN 是真实欺诈却没有识别出来的数量。漏检成本高，就应重点减少 FN、提高 Recall。

### 10. 误报成本高的二分类

**题目**：在二分类模型评估中，如果把负样本误报为正样本的代价较高，应优先关注哪个指标？

- A. Precision
- B. Accuracy
- C. Recall
- D. 样本总数

**答案：A，Precision。**

**基础知识/解释**：

```text
Precision = TP / (TP + FP)
```

FP 是“真实为负，却被预测为正”。误报代价高时，应让预测为正的样本尽量可靠，即提高 Precision。

### 11. 两条生产线的贝叶斯反推

**题目**：某工厂有甲、乙两条生产线，次品率分别为 0.1 和 0.2，甲线产量占总产量的 70%。随机抽到一件次品，该次品来自甲线的概率约为多少？

- A. 0.1
- B. 0.47
- C. 0.53
- D. 0.7

**答案：C，约 0.53。**

**基础知识/解释**：设 `D` 表示次品，`A` 表示甲线：

```text
P(A) = 0.7
P(B) = 0.3
P(D|A) = 0.1
P(D|B) = 0.2
```

使用贝叶斯公式：

```text
P(A|D)
= P(D|A)P(A) / [P(D|A)P(A) + P(D|B)P(B)]
= 0.1×0.7 / (0.1×0.7 + 0.2×0.3)
= 0.07 / 0.13
≈ 0.538
```

最接近 0.53。

### 12. 多头注意力的优势

**题目**：相比单头注意力，多头注意力的核心优势是什么？

- A. 减少推理阶段的 KV Cache 显存占用
- B. 允许模型在不同表示子空间中并行关注不同位置的信息
- C. 显著降低模型总参数量
- D. 彻底消除序列中的位置依赖

**答案：B。**

**基础知识/解释**：每个头有不同的 Q、K、V 投影，可以学习不同关系：

```text
Head 1：关注相邻词
Head 2：关注主谓关系
Head 3：关注远距离指代
...
```

多头注意力通常不会减少 KV Cache；头数更多时，传统 MHA 的 KV Cache 反而更多。

### 13. 线性回归的损失函数

**题目**：线性回归通常采用哪种损失函数估计参数？

- A. 均方误差
- B. 交叉熵损失
- C. Hinge 损失
- D. 0-1 损失

**答案：A，均方误差。**

**基础知识/解释**：线性回归最常见的目标是最小二乘：

```text
MSE = (1/n) Σ(y_true - y_pred)²
```

若误差被假设为正态分布，最小化平方误差也对应最大似然估计。

### 14. Newton 与 Lagrange 插值

**题目**：Newton 插值多项式与 Lagrange 插值多项式的关系正确的是？

- A. Lagrange 只适用于等距节点，Newton 适用于任意节点
- B. 二者是同一个插值多项式的不同表示形式
- C. Newton 只适用于等距节点，Lagrange 适用于任意节点
- D. Newton 只能近似，而 Lagrange 是精确插值

**答案：B。**

**基础知识/解释**：对同一组互异节点和相同函数值，次数不超过 `n` 的插值多项式是唯一的。因此 Newton 形式和 Lagrange 形式只是表达方式不同，结果是同一个多项式。两者都可用于任意互异节点。

### 15. RGB 图像展平维度

**题目**：将一张 `224×224` 的 RGB 图像展平为一维向量，其维度是多少？

- A. 448
- B. 150528
- C. 50176
- D. 224

**答案：B，150528。**

**基础知识/解释**：RGB 有 3 个通道：

```text
224 × 224 × 3 = 150528
```

其中 `224×224=50176` 是单通道图像展平后的长度。

### 16. 线性方程组的病态性（多选）

**题目**：以下哪些因素通常表明线性方程组 `Ax=b` 更容易受到数据扰动影响？

- A. 矩阵 A 的维数 n 很大
- B. 矩阵 A 有彼此接近的特征值
- C. 矩阵 A 的条件数很大
- D. 在相同量级的元素尺度下，矩阵 A 的行列式接近零

**答案：C、D。**

**基础知识/解释**：条件数大意味着输入数据很小的扰动也可能导致解发生很大变化，因此 C 是最直接的判断指标。对同等量级的矩阵元素，行列式接近 0 常意味着矩阵接近奇异，通常也更病态。

维度大不必然病态；特征值彼此接近也不必然导致不可逆或病态，关键是是否存在接近 0 的奇异值。

### 17. 无监督聚类评估指标（多选）

**题目**：在没有真实标签的无监督场景下，哪些指标可用于评估聚类效果？

- A. 轮廓系数
- B. Davies-Bouldin 指数
- C. 准确率
- D. Calinski-Harabasz 指数

**答案：A、B、D。**

**基础知识/解释**：

- 轮廓系数：比较簇内紧密程度和簇间分离程度，通常越大越好；
- Davies-Bouldin 指数：衡量簇内离散与簇间距离，通常越小越好；
- Calinski-Harabasz 指数：衡量簇间离散相对簇内离散，通常越大越好。

Accuracy 需要真实类别标签，因此不适合无标签的纯聚类场景。

### 18. 最大似然估计的适用场景（多选）

**题目**：下列哪些场景适合使用最大似然估计？

- A. 需要快速得到一个参数点估计
- B. 参数取值离散且候选数量较少，可以枚举比较似然
- C. 没有明确的先验信息
- D. 样本量较大

**答案：A、B、C、D。**

**基础知识/解释**：MLE 的目标是选择让观测数据出现概率（或概率密度）最大的参数：

```text
θ_hat = argmax_θ P(data | θ)
```

它天然给出参数点估计；离散候选参数可直接比较似然；没有可靠先验时适合使用；样本量大时通常也有良好的渐近性质。

### 19. 双向调节过拟合与欠拟合的方法（多选）

**题目**：以下哪些方法本身能够通过双向调节，在不同设置下分别用于缓解过拟合或欠拟合？

- A. 调整模型复杂度
- B. 只做特征删除
- C. 只增加训练数据
- D. 固定使用 Bagging

**答案：A。**

**基础知识/解释**：模型太简单可能欠拟合，模型太复杂可能过拟合：

```text
复杂度提高：可缓解欠拟合，但过高会加重过拟合
复杂度降低：可缓解过拟合，但过低会加重欠拟合
```

因此“调整模型复杂度”可以双向调节。只删除特征、只增加数据或固定 Bagging 都不是这种直接的双向控制旋钮。

### 20. Weierstrass 逼近定理（多选）

**题目**：关于 Weierstrass 逼近定理及其数值实现，以下哪些说法正确？

- A. 对任意目标精度，逼近多项式的次数都可以任意低
- B. 实际数值计算常使用收敛和稳定性更好的 Chebyshev 展开，而非直接使用 Bernstein 多项式
- C. 闭区间上的任意连续函数都能被多项式一致逼近到任意精度
- D. Bernstein 多项式总是收敛极快，因此最适合实际高精度计算

**答案：B、C。**

**基础知识/解释**：Weierstrass 逼近定理表示：在闭区间上，任何连续函数都可以被多项式以任意小的一致误差逼近，因此 C 对。

但想达到更小误差，通常需要足够高的多项式次数，A 错。Bernstein 多项式可用于证明该定理，但实际高精度数值计算中常更偏好 Chebyshev 多项式和节点，因为数值稳定性与收敛性质通常更好，故 B 对、D 错。
