# 华为 AI 在线笔试选择题学习笔记（第七组）

## 1. 总结

这一组把“模型为什么训练不动”和“模型为什么推理更快”放在了一起考察。

| 主题 | 关键结论 |
| --- | --- |
| CUDA 双缓冲 | 一边计算当前数据，一边预取下一批数据，用重叠执行隐藏访存延迟。 |
| ReLU 死亡神经元 | 输出长期为 0，导数也为 0，因而梯度无法更新该神经元。 |
| 优化器 | Adam 的 bias correction 修正训练初期动量估计偏小的问题。 |
| RNN/Transformer | RNN 长序列易梯度消失或爆炸；Transformer 训练可并行、长距离依赖建模更好。 |
| 分类损失 | 多分类通常是 Softmax + 交叉熵；类别不平衡可使用 Focal Loss。 |
| 概率 | 指数分布具有无记忆性；离散变量期望是“取值 × 概率”之和。 |
| 数值计算 | 截断误差来自近似，舍入误差来自有限精度。 |
| 大模型 | MoE 降低每个 Token 的激活计算；长上下文时注意力的二次复杂度可能成为主导。 |

## 2. 题目、答案与解释

### 1. CUDA 双缓冲的作用

**题目**：CUDA 中的双缓冲（Double Buffering）技术主要用于解决什么问题？

- A. 减少显存占用
- B. 掩盖访存延迟（Hide Latency）
- C. 避免死锁
- D. 提高计算精度

**答案：B。**

**基础知识/解释**：GPU 计算很快，但从全局显存读取数据可能较慢。双缓冲准备两块缓冲区：

```text
缓冲区 A：GPU 正在计算当前数据
缓冲区 B：同时从显存搬运下一批数据

下一轮交换 A、B
```

这样“搬数据”和“做计算”可以重叠，GPU 不必在计算结束后空等数据，因此隐藏了访存延迟。它的重点不是减少总显存，而是提高流水线利用率。

### 2. ReLU 的死亡神经元

**题目**：深层神经网络的隐藏层均使用 ReLU。训练时某些神经元的输出和梯度始终为 0，这种现象称为什么？

- A. 梯度消失
- B. 神经元死亡
- C. 梯度爆炸
- D. 过拟合

**答案：B，神经元死亡（Dead ReLU）。**

**基础知识/解释**：

```text
ReLU(z) = max(0, z)
```

当一个神经元对所有训练样本长期有 `z < 0` 时，它的输出是 0，而在负半轴的导数也是 0。反向传播无法给它提供梯度，参数不再更新，它就像“死亡”了一样。Leaky ReLU 会在负半轴保留很小斜率，可缓解此问题。

### 3. 牛顿迭代法

**题目**：使用牛顿迭代法求方程 `x²-3=0` 的正根，初始点 `x₀=2`，单次迭代后的 `x₁` 是多少？

- A. 1.75
- B. 1.8
- C. 1.667
- D. 1.5

**答案：A，1.75。**

**基础知识/解释**：对方程 `f(x)=0`，牛顿迭代公式为：

```text
x_(t+1) = x_t - f(x_t) / f'(x_t)
```

这里：

```text
f(x)  = x² - 3
f'(x) = 2x

x₁ = 2 - (2² - 3) / (2×2)
   = 2 - 1/4
   = 1.75
```

### 4. 朴素贝叶斯后验概率

**题目**：朴素贝叶斯垃圾文本过滤中，`P(Spam)=0.4`，垃圾文本包含 `W1、W2` 的条件概率分别为 `0.5、0.6`；正常文本对应概率为 `0.1、0.2`。假设类条件独立，同时包含 `W1、W2` 的文本为垃圾文本的后验概率最接近多少？

- A. 0.5
- B. 0.83
- C. 0.75
- D. 0.91

**答案：D，约 0.91。**

**基础知识/解释**：朴素贝叶斯假设：给定类别后，词之间条件独立。

```text
P(W1,W2 | Spam)    = 0.5 × 0.6 = 0.30
P(W1,W2 | Normal)  = 0.1 × 0.2 = 0.02
P(Normal)          = 1 - 0.4 = 0.6

P(Spam | W1,W2)
= (0.30 × 0.4) / (0.30×0.4 + 0.02×0.6)
= 0.12 / 0.132
≈ 0.909
```
它来自两条基本公式：贝叶斯公式 + 全概率公式。

先把事件简写：

```text
S = Spam
N = Normal
E = 同时出现 W1 和 W2
```

我们想求的是：

```text
P(S | E)
```

即“已知看到了 W1、W2，这封邮件是垃圾邮件的概率”。

---

第一步：使用贝叶斯公式

贝叶斯公式本身是：

```text
P(S | E) = P(E | S) × P(S) / P(E)
```

对应到题目：

```text
P(Spam | W1, W2)
= P(W1, W2 | Spam) × P(Spam)
  --------------------------------
           P(W1, W2)
```

现在只差分母 `P(W1, W2)`：随机拿到一封邮件，它同时有 W1、W2 的总概率是多少？

---

第二步：把所有可能来源加起来

一封邮件只有两类：

```text
邮件
├── Spam
└── Normal
```

因此，出现 `W1、W2` 的邮件，要么来自垃圾邮件，要么来自正常邮件。

```text
P(W1, W2)
= P(W1, W2 且 Spam)
+ P(W1, W2 且 Normal)
```

根据条件概率乘法公式：

```text
P(A 且 B) = P(A | B) × P(B)
```

所以：

```text
P(W1, W2 且 Spam)
= P(W1, W2 | Spam) × P(Spam)
```

```text
P(W1, W2 且 Normal)
= P(W1, W2 | Normal) × P(Normal)
```

合起来：

```text
P(W1, W2)
= P(W1, W2 | Spam) × P(Spam)
+ P(W1, W2 | Normal) × P(Normal)
```

---

第三步：代回贝叶斯公式

```text
P(Spam | W1, W2)
= P(W1, W2 | Spam) × P(Spam)
  ----------------------------------------------------
  P(W1, W2 | Spam) × P(Spam)
  + P(W1, W2 | Normal) × P(Normal)
```

分子表示：

```text
“既是垃圾邮件，又同时包含 W1、W2”的概率
```

分母表示：

```text
“所有同时包含 W1、W2 的邮件”的概率
```

所以整体就是：

```text
在所有出现 W1、W2 的邮件中，
有多大比例属于垃圾邮件。
```

所以最接近 0.91。

### 5. Adam 的偏置校正

**题目**：关于 Adam 中偏置校正（bias correction）的作用，下列说法最准确的是？

- A. 防止梯度爆炸并替代梯度裁剪
- B. 修正一阶矩和二阶矩在训练初期因初始化为 0 而产生的估计偏小
- C. 让 Adam 退化成 SGD
- D. 减少模型参数数量

**答案：B。**

**基础知识/解释**：Adam 维护梯度的一阶矩（近似平均梯度）`m` 和二阶矩（近似平方梯度平均）`v`。开始时 `m=v=0`，前几步会天然偏向 0。它使用：

```text
m_hat = m / (1 - β₁^t)
v_hat = v / (1 - β₂^t)
```

来纠正这种初期偏小。偏置校正不是梯度裁剪，也不会改变参数数量。

### 6. Transformer 相比 RNN 的非典型优势

**题目**：以下哪项不是 Transformer 优于传统 RNN 的典型特征？

- A. 推理时的单步解码时间复杂度更低
- B. 更高的训练并行度
- C. 更强的长距离依赖建模能力
- D. 训练深层模型时更好地缓解梯度消失

**答案：A。**

**基础知识/解释**：Transformer 在训练时可以并行处理序列位置，而 RNN 必须按时间步顺序计算。自注意力也能让远处 Token 直接建立联系。

但在自回归生成的 Decode 阶段，Transformer 每生成一个 Token 都要与已有 KV Cache 交互；它的单步解码复杂度并不天然比 RNN 更低。Transformer 的优势主要体现在训练并行性和长距离依赖。

### 7. 量化的主要目的

**题目**：下列哪项不是模型量化的主要目的？

- A. 减小模型体积
- B. 提升推理吞吐量
- C. 提高训练收敛速度
- D. 适配移动端硬件

**答案：C。**

**基础知识/解释**：量化把 FP32 等高精度数转换为 INT8、INT4 等低位宽表示，常用于推理：

- 权重和 KV Cache 更小；
- 内存带宽压力更低；
- 低比特硬件指令可能更快；
- 更适合端侧设备。

它不是为了让训练更快收敛；低比特训练反而常需额外处理数值稳定性。

### 8. 范德蒙德矩阵条件数过大

**题目**：用二次多项式拟合一段 Token 的 Attention Score 趋势时，范德蒙德矩阵的条件数随节点增加迅速增大，这会导致什么？

- A. 拟合残差必然变为 0
- B. 硬件吞吐量线性提升
- C. 自动微分失效
- D. 计算结果的数值稳定性变差

**答案：D。**

**基础知识/解释**：条件数描述问题对输入微小误差的敏感程度。条件数很大意味着：输入或浮点舍入中一点点误差，都可能被放大成结果中的明显误差。

范德蒙德矩阵常出现在多项式插值中：

```text
[1  x0  x0² ...]
[1  x1  x1² ...]
...
```

节点增多时它容易病态，计算结果数值稳定性变差。

### 9. 多分类交叉熵的输出激活

**题目**：多分类任务中的交叉熵损失通常与哪个输出激活函数配合使用？

- A. Tanh
- B. Softmax
- C. Sigmoid
- D. ReLU

**答案：B，Softmax。**

**基础知识/解释**：单标签多分类中，类别互斥，例如一张图片只能是猫、狗或鸟之一。Softmax 把多个 logits 转成和为 1 的概率分布：

```text
p_i = exp(z_i) / Σ exp(z_j)
```

随后交叉熵只惩罚真实类别对应概率不够高的情况。Sigmoid 更常用于二分类或多标签分类。

### 10. 类别不平衡与 Focal Loss

**题目**：对于类别不平衡的分类任务，哪种损失函数可着重关注难样本并缓解不平衡问题？

- A. 普通交叉熵损失
- B. Focal Loss
- C. Hinge 损失
- D. 均方误差

**答案：B，Focal Loss。**

**基础知识/解释**：类别不平衡时，大量容易分类的负样本可能淹没少数正样本的学习信号。Focal Loss 会降低“已经预测得很对”的样本权重，把注意力集中给难样本：

```text
Focal Loss ≈ -(1 - p_t)^γ log(p_t)
```

当 `p_t` 很大，表示该样本已容易正确分类，前面的权重会变小。

### 11. Agent 的长期记忆

**题目**：客服 Agent 在多轮对话中无法识别用户反复提出的“网络延迟”问题。以下改进方案最符合长期记忆机制？

- A. 将关键信息结构化写入长期记忆，并通过语义检索在后续对话中触发
- B. 只增大当前对话的短期窗口
- C. 只新增网络排障工具
- D. 只在提示词中加入关键词示例

**答案：A。**

**基础知识/解释**：短期上下文窗口只能保留当前输入范围内的信息，窗口之外会被遗忘。长期记忆通常是：

```text
对话关键信息 -> 结构化记录/向量化 -> 存入数据库
新问题 -> 语义检索相关记忆 -> 注入当前上下文
```

这能在跨很长时间、很多轮对话后，仍找回“用户之前一直反馈网络延迟”的信息。

### 12. RNN 长序列训练问题

**题目**：RNN 在处理长序列时最典型的训练问题是什么？

- A. 梯度消失或爆炸
- B. 参数数量必然过多
- C. 无法使用任何内存
- D. 输出维度固定

**答案：A。**

**基础知识/解释**：RNN 的时间展开会把同一组参数重复经过很多步。反向传播时包含许多 Jacobian/导数连乘，连乘结果可能趋近 0（消失）或变得极大（爆炸）。LSTM、GRU 的门控结构就是为缓解长距离依赖问题而设计的。

### 13. 离散随机变量的期望

**题目**：随机变量 `X` 满足 `P(X=1)=0.2、P(X=2)=0.5、P(X=3)=0.3`，其期望 `E(X)` 是多少？

- A. 2.1
- B. 2.0
- C. 1.8
- D. 2.5

**答案：A，2.1。**

**基础知识/解释**：离散变量的期望是加权平均：

```text
E(X) = 1×0.2 + 2×0.5 + 3×0.3
     = 0.2 + 1.0 + 0.9
     = 2.1
```

### 14. 指数分布的无记忆性

**题目**：某服务处理时间服从指数分布。已处理 10 分钟仍未结束后，还需至少 5 分钟的概率，与全新请求处理至少 5 分钟的概率相比如何？

- A. 无法比较
- B. 两者相等
- C. 前者更大
- D. 前者更小

**答案：B，两者相等。**

**基础知识/解释**：指数分布满足无记忆性：

```text
P(X > s+t | X > s) = P(X > t)
```

因此已等待 10 分钟不会改变“还要等待至少 5 分钟”的概率，它和一个全新请求等待至少 5 分钟的概率相同。

### 15. 从反向传播理解死亡神经元

**题目**：从反向传播角度看，“死亡神经元”是指什么？

- A. 偏置项过大
- B. 激活函数爆炸
- C. 输出恒为 0 且梯度恒为 0，权重不再更新
- D. 权重一定变成 NaN

**答案：C。**

**基础知识/解释**：这是第 2 题的反向传播版本。对于负半轴 ReLU：

```text
ReLU(z) = 0
ReLU'(z) = 0
```

所以损失对该神经元前面权重的梯度会乘上 0，更新量为 0，神经元无法恢复。

### 16. 选择激活函数时的考虑因素（多选）

**题目**：激活函数的选择通常需要考虑哪些因素？

- A. 训练数据的特点
- B. 计算资源限制
- C. 网络深度
- D. 任务类型（分类或回归）

**答案：A、B、C、D。**

**基础知识/解释**：所有选项都合理。例如：

- 深层网络常避免易饱和的 Sigmoid；
- 端侧设备可能偏好计算简单的 ReLU；
- 回归输出层常不用激活，二分类常用 Sigmoid，多分类常用 Softmax；
- 数据分布、是否稀疏、是否有负值也会影响选择。

### 17. 截断误差与舍入误差（多选）

**题目**：关于截断误差与舍入误差，下列说法正确的有哪些？

- A. 截断误差来自近似替代，舍入误差来自有限精度运算
- B. 截断误差只存在于无穷级数，舍入误差只存在于小数运算
- C. 截断误差必然是系统性误差，舍入误差必然是随机误差
- D. 增加近似项数可减小截断误差，提高计算精度可减小舍入误差

**答案：A、D。**

**基础知识/解释**：

- 截断误差：用有限步骤代替无限过程，例如只保留 `sin(x)` 泰勒展开的前三项；
- 舍入误差：电脑浮点数只能保存有限位，例如 `1/3` 不能精确存为有限十进制/二进制位。

增加近似项通常可降低截断误差；使用 float64 替代 float32 等更高精度通常可降低舍入误差。B、C 说得过于绝对。

### 18. 数据质量评估（多选）

**题目**：数据质量评估通常需要检查哪些方面？

- A. 一致性
- B. 完整性
- C. 准确性
- D. 时效性

**答案：A、B、C、D。**

**基础知识/解释**：

- 一致性：同一字段、不同系统的规则和值是否冲突；
- 完整性：是否有缺失字段、缺失样本；
- 准确性：数据是否接近真实情况，标签是否正确；
- 时效性：数据是否过期，能否反映当前业务状态。

高质量模型的前提往往是高质量数据。

### 19. 聚类与降维（多选）

**题目**：关于聚类和降维，下列描述正确的有哪些？

- A. DBSCAN 不需要预先指定聚类数
- B. K-Means 保证找到全局最优聚类结果
- C. PCA 的不同主成分相互正交
- D. t-SNE 是适合高维数据可视化的非线性降维方法
- E. K-Means 需要预先指定聚类数 K

**答案：A、C、D、E。**

**基础知识/解释**：
K-Means 对初始化敏感，通常只能保证收敛到局部最优；其余四项均是对应方法的典型性质。
- DBSCAN 用半径 `eps` 与最小点数 `min_samples` 找密集区域，无需提前给 K；
- K-Means 需要先指定 K，且受初始化影响，通常只能保证收敛到局部最优；
- PCA 的主成分是协方差矩阵的正交特征向量；
- t-SNE 是非线性降维，特别适合把高维数据投到 2D/3D 进行可视化，但不适合保留可靠的全局距离。

### 20. 参数量与计算量（多选）

**题目**：关于大模型计算量与参数量的关系，下列说法正确的有哪些？

- A. 总参数量相同的情况下，稀疏 MoE 每个 Token 只激活部分专家，实际激活计算量可低于 Dense 模型
- B. 注意力计算量对序列长度 L 通常为二次量级，FFN 对 L 为一次量级，L 足够大时注意力计算可占主导
- C. Decoder-only 模型每个 Token 的一次前向传播计算量常近似为 2N FLOP，其中 N 为参与计算的参数量
- D. 推理 FLOP 与训练前向完全相同，因此推理速度必然严格是训练速度的三倍

**答案：A、B、C。**

**基础知识/解释**：

```text
Dense：每个 Token 使用全部 FFN 参数。
MoE：路由器只选择少数 top-k 专家，因此每个 Token 激活的参数更少。
```

自注意力会形成 Token 两两交互，主项常是 `O(L²d)`；FFN 对每个 Token 独立处理，常是 `O(Ld²)`。当 L 很长，`L²` 可能使注意力成为瓶颈。

常见粗略估算中，一个参数参与一次乘加约为 2 FLOP，因此 Decoder-only 单 Token 前向常近似 `2N` FLOP。D 错在“完全相同”和“严格三倍”都过于绝对：训练还包括反向传播、优化器状态与不同的并行/批处理行为，真实速度取决于硬件和实现。
