这一组题的重点是“概率分布、向量表示、统计估计、Transformer、检索与工程实践”。很多选择题只要先认清概念，就不需要复杂计算。

| 主题 | 最基础的记忆点 |
|---|---|
| 概率分布 | 分布描述随机变量可能取值；KL 散度衡量两个分布差异；条件概率可用贝叶斯公式。 |
| 统计估计 | MLE 是“让已观察样本最可能出现”的参数；正态方差 MLE 的分母是 `n`。 |
| 向量 | 内积同时受方向和长度影响；余弦相似度只看方向；Word2Vec 学习稠密语义向量。 |
| 模型训练 | 类别不平衡不能只看准确率；Sigmoid 分类常配交叉熵；学习率可使用预热和衰减。 |
| Transformer/LLM | BERT 是 Encoder-only；滑动窗口只留最近 KV；近似检索用速度/内存换取少量精度。 |
| 工程 | 可复现需要数据版本、样本 ID、切分信息和环境依赖记录。 |

## 1. 衡量两个概率分布差异

**题目**

下列哪个量专门用于衡量两个概率分布的差异？

- A. 欧氏距离
- B. KL 散度
- C. 余弦相似度
- D. 曼哈顿距离

**答案：B. KL 散度**

**基础知识**

概率分布表示一个随机变量“各种结果出现的可能性”。例如分类模型输出：

```text
真实分布 P = [0, 1, 0]
预测分布 Q = [0.1, 0.8, 0.1]
```

KL 散度专门比较两个概率分布：

```text
KL(P || Q) = Σ P(x) log(P(x) / Q(x))
```

它越小，说明 `Q` 越接近 `P`。欧氏距离、曼哈顿距离和余弦相似度可以比较普通向量，但不是专门为概率分布设计的。

## 2. 线性回归的外生性

**题目**

经典线性回归的外生性要求最接近哪项？

- A. 所有特征服从标准正态分布
- B. 样本数等于特征数
- C. `E[e | X] = 0`
- D. 特征两两独立

**答案：C. `E[e | X] = 0`**

**基础知识**

线性回归常写成：

```text
y = Xβ + e
```

其中：

```text
X：特征
β：要学习的参数
e：误差项，即模型未解释的因素
```

外生性要求：给定特征 `X` 后，误差的平均值为 0：

```text
E[e | X] = 0
```

直觉是：不能存在某个遗漏因素，它既影响 `X`，又影响 `y`。否则模型估计会产生偏差。

## 3. 滑动窗口注意力

**题目**

滑动窗口注意力支持长上下文的关键逻辑是什么？

- A. 把全部历史 KV 压成一个向量
- B. 只量化每个 KV
- C. 随机丢弃部分 KV
- D. 只保留最近窗口内的 KV

**答案：D**

**基础知识**

自回归 Transformer 会为历史 token 保存 Key/Value：

```text
历史 token → KV Cache
```

完整注意力会让 KV Cache 随 token 数持续增长。滑动窗口注意力规定：

```text
当前位置只看最近 W 个 token
```

因此也只需要保留最近窗口内的 KV。

## 4. 余弦相似度与内积的排序

**题目**

给定：

```text
A = [1, 0]
B = [0, 100]
C = [1, 1]
```

余弦相似度与内积的排序正确的是？

- A. 余弦 `A-C > B-C > A-B`；内积 `B-C > A-C > A-B`
- B. 余弦 `A-C = B-C > A-B`；内积 `A-C > B-C > A-B`
- C. 余弦 `A-C = B-C > A-B`；内积 `B-C > A-C > A-B`
- D. 余弦 `A-C > B-C > A-B`；内积 `A-C > B-C > A-B`

**答案：C**

**基础知识**

内积：

```text
x·y = Σ xi yi
```

余弦相似度：

```text
cos(x, y) = x·y / (||x|| ||y||)
```

计算内积：

```text
A·C = 1
B·C = 100
A·B = 0
```

所以内积排序：

```text
B-C > A-C > A-B
```

计算余弦：

```text
cos(A, C) = 1/√2
cos(B, C) = 100/(100√2) = 1/√2
cos(A, B) = 0
```

所以余弦排序：

```text
A-C = B-C > A-B
```

余弦消除了向量长度 `100` 的影响；内积没有。

## 5. 检测近似数据泄露

**题目**

检测训练集中的同义改写、轻微编辑等近似泄露，哪种方法最有效？

- A. 只看答对率
- B. 语义向量检索或 MinHash 近似去重
- C. 只检查文件名
- D. 只做完全字符串匹配

**答案：B**

**基础知识**

数据泄露指测试数据与训练数据过于相似，导致模型测试成绩虚高。

完全字符串匹配只能发现：

```text
“今天天气很好”
“今天天气很好”
```

但很难发现：

```text
“今天天气很好”
“今天的天气真不错”
```

语义向量检索可以发现语义相近文本；MinHash 常用于发现词集合高度重叠的近似重复文本。

## 6. 均匀分布

**题目**

`X` 在 `[2, 10]` 上均匀分布，则 `P(3≤X≤6)` 与 `E[X]` 分别为？

- A. `3/8，6`
- B. `1/4，6`
- C. `1/3，6`
- D. `3/8，4`

**答案：A. `3/8，6`**

**基础知识**

均匀分布表示区间内每一段等长区域的概率相同。

总区间长度：

```text
10 - 2 = 8
```

目标区间长度：

```text
6 - 3 = 3
```

因此：

```text
P(3≤X≤6) = 3/8
```

均匀分布 `[a, b]` 的期望是区间中点：

```text
E[X] = (a+b)/2 = (2+10)/2 = 6
```

## 7. BERT 的架构

**题目**

BERT 属于哪种主架构？

- A. Encoder-Decoder
- B. Decoder-only
- C. Prefix Decoder
- D. Encoder-only

**答案：D. Encoder-only**

**基础知识**

Transformer 常见三种结构：

```text
Encoder-only：BERT，擅长理解、分类、抽取
Decoder-only：GPT，擅长自回归生成
Encoder-Decoder：T5，擅长输入到输出的转换任务
```

BERT 使用双向 Encoder 编码上下文，因此是 Encoder-only。

## 8. 极度类别不平衡

**题目**

正类占 `1%`、负类占 `99%` 时，较合理的处理是什么？

- A. 只保留正类
- B. 重采样或类别加权，并使用 F1/AUC-PR 等指标
- C. 仅优化准确率
- D. 单纯增大学习率

**答案：B**

**基础知识**

若模型永远预测负类：

```text
准确率 = 99%
```

但它一个正类也找不到，实际没有价值。

常见处理：

```text
过采样少数类
欠采样多数类
类别加权
使用 F1、Precision、Recall、AUC-PR
```

## 9. Z-score 反推原始值

**题目**

正态数据均值为 `50`、标准差为 `10`，Z-score 为 `2.5` 的原始值是多少？

- A. `70`
- B. `75`
- C. `80`
- D. `65`

**答案：B. 75**

**基础知识**

Z-score 的公式：

```text
z = (x - μ) / σ
```

变形得到：

```text
x = μ + zσ
  = 50 + 2.5×10
  = 75
```

## 10. 逻辑回归为何常用交叉熵

**题目**

带 Sigmoid 输出的逻辑回归通常不采用 MSE 的主要原因是？

- A. 组合后容易产生不利优化的非凸形状和饱和梯度
- B. MSE 不支持梯度下降
- C. MSE 无法接受 0-1 标签
- D. MSE 的计算量必然过大

**答案：A**

**基础知识**

Sigmoid：

```text
σ(z) = 1 / (1 + e^(-z))
```

当 `z` 很大或很小时，Sigmoid 接近 `1` 或 `0`，导数很小，称为饱和。

对于二分类，Sigmoid 配合二元交叉熵有很简洁的梯度：

```text
梯度 ∝ prediction - label
```

通常比 Sigmoid + MSE 更容易优化。

## 11. 线性变换的性质

**题目**

线性变换必须满足哪个性质？

- A. `T(0)=1`
- B. `T(u)=u²`
- C. `T(u+v)=T(u)+T(v)`
- D. `T(uv)=T(u)T(v)`

**答案：C**

**基础知识**

线性变换必须满足：

```text
T(u + v) = T(u) + T(v)
T(cu) = cT(u)
```

因此也一定有：

```text
T(0) = 0
T(-u) = -T(u)
```

## 12. 正态方差的最大似然估计

**题目**

正态分布均值已知时，方差的最大似然估计使用哪项？

- A. 样本极差
- B. 分母为 `n-1` 的样本方差
- C. 样本中位数
- D. 分母为 `n` 的平均平方偏差

**答案：D**

**基础知识**

最大似然估计（MLE）的思想是：选择一个参数，让当前观察到的数据出现的概率最大。

当均值 `μ` 已知时：

```text
σ²_MLE = (1/n) Σ(xi - μ)²
```

注意：分母 `n-1` 的样本方差是常见的无偏估计，但它不是这里的 MLE。

## 13. 均匀分布参数的 MLE

**题目**

误差服从 `U[-a, a]`，样本为 `{-0.5, 1.2, -0.8}`，`a` 的 MLE 是？

- A. `1.5`
- B. `0.5`
- C. `1.2`
- D. `0.8`

**答案：C. 1.2**

**基础知识**

`U[-a, a]` 表示样本必须落在：

```text
[-a, a]
```

要包含全部样本，必须有：

```text
a ≥ max(|-0.5|, |1.2|, |-0.8|)
  = 1.2
```

均匀分布的密度是 `1/(2a)`；`a` 越小，密度越大。因此选择能覆盖样本的最小 `a`：

```text
a_MLE = 1.2
```

## 14. Word2Vec 与 One-hot

**题目**

Word2Vec 相比 One-hot 的主要优势是什么？

- A. 天然处理所有 OOV
- B. 能表达词语间的语义相似性
- C. 维度一定更高
- D. 任何任务都更快

**答案：B**

**基础知识**

One-hot 例子：

```text
“猫” → [1, 0, 0, 0]
“狗” → [0, 1, 0, 0]
```

任何不同单词的 one-hot 内积都是 0，无法表达“猫和狗比猫和汽车更相似”。

Word2Vec 会学习稠密向量：

```text
“猫” → [0.2, 0.7, ...]
“狗” → [0.3, 0.6, ...]
```

语义相近的词向量通常也更接近。

## 15. PCA 前的预处理

**题目**

PCA 前通常采用什么预处理来消除量纲影响？

- A. 标准化为均值 0、方差 1
- B. 一律取对数
- C. 二值化
- D. 只缩放到 `[0,1]`

**答案：A**

**基础知识**

标准化通常是：

```text
x_standard = (x - mean) / standard_deviation
```

标准化后，每个特征大致具有：

```text
均值 = 0
方差 = 1
```

这样 PCA 不会被数值范围较大的特征主导。

## 16. 贝叶斯思想在机器学习中的应用（多选）

**题目**

哪些属于贝叶斯思想在机器学习中的直接应用？

- A. L2 正则化可解释为高斯先验下的 MAP
- B. 贝叶斯优化用于超参数搜索
- C. 标准 SVM 的间隔最大化
- D. 朴素贝叶斯分类器

**答案：A、B、D**

**基础知识**

贝叶斯公式：

```text
后验 ∝ 似然 × 先验
```

其中：

```text
MAP：最大后验估计
```

若给权重加高斯先验，取 MAP 等价于加入 L2 正则化。朴素贝叶斯分类器直接使用贝叶斯公式；贝叶斯优化也使用概率代理模型指导超参数搜索。

标准 SVM 的间隔最大化不是直接的贝叶斯方法。

## 17. 近似最近邻（ANN）（多选）

**题目**

关于近似最近邻算法，正确的有哪些？

- A. IVF 搜索永远只查一个簇，且召回率与聚类数严格成反比
- B. HNSW 的 `ef_construction` 越大通常索引质量越好但构建越慢
- C. HNSW 搜索 `ef` 越大通常召回更高但延迟更大
- D. PQ 可降内存但会引入量化误差

**答案：B、C、D**

**基础知识**

近似最近邻的目标：

```text
不保证 100% 找到真正最近邻
换取更快搜索、更低内存
```

```text
IVF：先聚类，查询时可搜索多个候选簇，不是永远一个簇
HNSW：图结构检索；ef 更大通常搜索更多候选，召回更高但更慢
PQ：把向量压缩编码，省内存但存在量化误差
```

## 18. 训练可复现与可追溯（多选）

**题目**

为保证训练可复现、可追溯，应强制纳入哪些工程规范？

- A. 记录样本唯一 ID、版本及切分抽样元数据
- B. 只保留最终权重和中间 checkpoint 摘要即可完整复现
- C. 允许未记录的非确定性算子
- D. 记录环境快照及二进制依赖哈希

**答案：A、D**

```text

随机种子与采样规则

```

## 19. 实对称矩阵（多选）

**题目**

`A` 为实对称方阵，哪些结论必然正确？

- A. `A` 可被正交对角化
- B. 若 `A` 的某个正整数次幂为零矩阵，则 `A=0`
- C. `A` 的秩等于非零特征值数量（按重数）
- D. `e^A` 总是正定矩阵

**答案：A、B、C、D**

**基础知识**

实对称矩阵满足谱定理：

```text
A = QΛQᵀ
```

其中：

```text
Q：正交矩阵
Λ：实数特征值组成的对角矩阵
```

因此：

```text
A：可正交对角化
A^k = 0：所有 λ^k = 0，因此所有 λ=0，因此 A=0
rank(A)：等于非零特征值的个数（按重数）
e^A：特征值为 e^λ，始终大于 0，因此正定
```

## 20. 学习率调度策略（多选）

**题目**

哪些属于合理的学习率调度策略？

- A. 训练初期预热（Warmup）
- B. Step Decay
- C. 余弦退火（Cosine Annealing）
- D. 指数衰减

**答案：A、B、C、D**

**基础知识**

学习率决定每次参数更新的步长：

```text
参数新值 = 参数旧值 - 学习率 × 梯度
```

常见调度：

```text
Warmup：开始时从小学习率逐步增大，避免训练初期不稳定
Step Decay：每隔若干轮把学习率乘一个较小系数
Cosine Annealing：按余弦曲线逐渐减小学习率
指数衰减：学习率按固定比例持续衰减
```

以上四种都是合理且常见的策略。
