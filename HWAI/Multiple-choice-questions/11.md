# 华为 AI 在线笔试选择题学习笔记（第十一组）

## 1. 总结

| 主题 | 核心结论 |
| --- | --- |
| 向量检索 | L2 归一化后，点积等于余弦相似度；可直接用高效点积检索。 |
| Agent 安全 | Write + Exec 的组合会让“写入恶意脚本再执行”成为链式风险，属于权限收敛。 |
| 模态模型 | 早期/适配式 VLM 常冻结视觉编码器；原生多模态模型通常端到端联合训练。 |

| 检索和生成 | KV Cache 使每一步只新增当前 Token 的 K/V；Greedy Search 每步选最大概率 Token。 |

## 2. 题目、答案与解释

### 1. L2 归一化向量的相似度

**题目**：在通信故障诊断 RAG 系统中，使用领域微调 Embedding 模型将用户查询与历史故障案例转换为 768 维向量。为提升检索精度，系统对所有向量执行 L2 归一化（向量模长为 1）。下列关于相似度计算的工程实践选择，最优的是？

- A. 采用欧氏距离计算相似度，距离越小表示故障案例与查询匹配度越高
- B. 采用点积相似度计算，其结果与余弦相似度等价，且计算效率更高
- C. 采用曼哈顿距离计算，更适合高维稀疏的故障文本向量场景
- D. 采用余弦相似度计算，需额外对向量模长进行归一化处理

**答案：B。**

**基础知识/解释**：余弦相似度为：

```text
cos(x, y) = (x · y) / (||x|| × ||y||)
```

已做 L2 归一化时：

```text
||x|| = ||y|| = 1
cos(x, y) = x · y
```

因此可直接计算点积，结果与余弦相似度完全等价。D 错在“需额外归一化”：题目已经归一化过了。

### 2. Agent 的 Write + Exec 风险

**题目**：Agent 具有写文件权限（Write）和执行脚本权限（Exec）。攻击者利用间接注入让 Agent 写入 Base64 负载、赋予执行权限并运行脚本。这种攻击组合在权限风险矩阵中属于？

- A. 权限提权（Privilege Escalation）
- B. 权限收敛（Privilege Convergence）
- C. 职责分离缺失（Lack of Segregation of Duties）
- D. 跨站脚本（XSS）

**答案：B，权限收敛。**

**基础知识/解释**：Write 单独看只是在文件系统写内容；Exec 单独看只是执行已有程序。但两个权限组合后：

```text
Write 恶意脚本 -> chmod -> Exec 恶意脚本
```

风险会“收敛”为远程代码执行能力。这不一定是权限提权，因为 Agent 未必获得了原本没有的更高系统权限；重点在于多个权限组合带来的危险能力。

### 3. 当前多模态模型与原生多模态模型

**题目**：当前主流多模态模型（如 LLaVA、Qwen-VL）与原生多模态模型（如 Gemini、GPT-4o）的核心架构差异是？

- A. 当前模型使用 Transformer，原生多模态使用 CNN+RNN 混合架构
- B. 当前模型冻结视觉编码器 + 训练投影层，原生多模态端到端联合训练视觉和语言组件
- C. 当前模型参数量小，原生多模态参数量大，这是唯一区别
- D. 当前模型只支持文本输出，原生多模态支持图像生成

**答案：B。**

**基础知识/解释**：这是一种常见的架构对比：

```text
适配式 VLM：视觉编码器 -> 投影层 -> 已训练 LLM
             （常冻结）    （重点训练）

原生多模态：视觉、音频、文本等组件更深度地端到端联合训练
```

真实模型细节各不相同，但 B 描述了题目想考的核心区别。参数量、输出模态都不是唯一或必然差异。

### 4. Mini-batch 梯度噪声

**题目**：在随机梯度下降中，使用小批量梯度代替全梯度。关于噪声 `ε = g_tilde - g` 对数值稳定性的影响，正确的是？

- A. 噪声可通过增大学习率来完全消除
- B. 噪声方差与批量大小 m 成正比，增大 m 可增加噪声
- C. 噪声在接近最优解时帮助逃离鞍点，但可能导致在最优解附近波动
- D. 噪声导致目标函数值单调下降，但收敛点随机波动

**答案：C。**

**基础知识/解释**：mini-batch 只是全梯度的随机估计。通常 batch 越大，估计越稳定、噪声越小。噪声有两面性：

```text
好处：可帮助跳出鞍点或较差局部区域
代价：最优点附近会来回抖动，损失不保证单调下降
```

### 5. 经典“丢票乘客”问题

**题目**：150 人的电影院中，第一位观众随机坐一个位置；之后每个人优先坐自己的位置，若被占则随机选空位。最后一位观众坐到自己座位的概率是多少？

- A. 113 / 150
- B. 49 / 150
- C. 77 / 150
- D. 1 / 2

**答案：D，1 / 2。**

**基础知识/解释**：第一位观众随机坐后，过程不断把“随机选择权”传递给下一个发现自己座位被占的人。最终只剩两个特殊座位：

```text
第一位观众的座位
最后一位观众的座位
```

最后触发随机选择的人，在这两个座位之间等概率选一个。因此最后一位坐自己座位的概率为 `1/2`，与人数 150 无关。

### 6. Greedy Search

**题目**：关于贪婪搜索（Greedy Search）的描述，正确的是？

- A. 它在每一步都选择当前概率最高的 Token，容易陷入局部最优或重复循环
- B. 它通过引入随机性来提高文本的创造力
- C. 它会考虑所有可能的序列路径，寻找全局最优解
- D. 它的计算量远大于束搜索（Beam Search）

**答案：A。**

**基础知识/解释**：贪婪搜索规则：

```text
next_token = argmax P(token | previous_tokens)
```

它快、确定，但只看当前一步最优，可能错过整体更优序列，也可能发生重复。B 描述采样，C 更接近穷举，D 错在贪婪搜索通常比 Beam Search 更省算力。

### 7. CLIP 对比学习的梯度来源

**题目**：在 CLIP 的对比学习中，batch size 为 N。对正样本对 `(i,i)`，其梯度对图像特征 `z_i^I` 的贡献包含哪些部分？

- A. 仅来自对角线位置的梯度，非对角线位置梯度为 0
- B. 仅来自图像→文本方向的正样本梯度
- C. 来自图像→文本的正样本梯度，以及作为其他样本负样本时的梯度
- D. 来自两个方向：图像→文本的正样本梯度 + 文本→图像的正样本梯度

**答案：C。**

**基础知识/解释**：CLIP 会构造一个 batch 内相似度矩阵：

```text
        Text 0  Text 1  ... Text N-1
Image 0    正       负
Image 1    负       正
...
```

图像 `i` 不只影响自己的正样本 `(i,i)`；它也会作为其他文本/图像配对里的负样本参与对比。因此梯度不仅来自对角线正样本，也来自非对角线负样本。

### 8. DBSCAN 的显著优点

**题目**：与 K-Means 不同，DBSCAN 算法的一个显著优点是能够识别并处理哪种类型的数据点？

- A. 噪声点（离群点）
- B. 核心点
- C. 中心点
- D. 边界点

**答案：A。**

**基础知识/解释**：DBSCAN 可以将低密度区域、无法归类到任何高密度簇的点标记为噪声。K-Means 则会强制把每一个点分进某个簇。

### 9. 自适应数值积分

**题目**：自适应数值积分（adaptive quadrature）的基本策略是？

- A. 在整个区间上均匀加密节点
- B. 在估计误差较大的子区间上局部加密，误差较小的子区间保持不变
- C. 随机选择加密位置
- D. 先用高阶公式再用低阶公式

**答案：B。**

**基础知识/解释**：函数平滑的区域不需要过多计算；变化快的区域才需要更多节点。自适应积分的思想是“把算力花在难的地方”。

### 10. Precision 的定义

**题目**：在评估一个二分类模型的性能时，如果关注的是模型预测为正类的样本中真正为正的比例，应该使用哪个指标？

- A. 精确率
- B. F1 分数
- C. 准确率
- D. 召回率

**答案：A，精确率。**

**基础知识/解释**：

```text
Precision = TP / (TP + FP)
```

分母是“所有被预测为正的样本”，所以它回答的问题正是：预测为正的样本中，有多少真的为正。

### 11. 激活函数的主要作用

**题目**：激活函数的主要作用是？

- A. 加快训练
- B. 提高模型精度
- C. 增加模型参数
- D. 引入非线性

**答案：D，引入非线性。**

**基础知识/解释**：没有激活函数时，多层线性层叠加仍然是一个线性变换。激活函数使神经网络能够拟合非线性关系。

### 12. Focal Loss 的调制因子

**题目**：Focal Loss 主要通过哪种机制调节不同样本对总损失的贡献？

- A. 动态权重衰减
- B. 调制因子 `(1-p_t)^γ`，对已预测准确的简单样本降权
- C. 硬采样，直接丢弃所有简单样本
- D. 标签平滑

**答案：B。**

**基础知识/解释**：Focal Loss 常写为：

```text
FL = -(1 - p_t)^γ log(p_t)
```

当样本已被正确预测、`p_t` 很大时，`(1-p_t)^γ` 很小，损失贡献下降；模型会更关注难样本。

### 13. KV Cache 复用时新增的 K/V

**题目**：Prefill 缓存了 10 个 Token 的 K/V，当前已生成 5 个 Token。第 6 个 Token 生成时，自注意力计算需新增计算的 K/V 向量数量为？

- A. 1 个
- B. 6 个
- C. 5 个
- D. 15 个

**答案：A，1 个。**

**基础知识/解释**：已有：

```text
10 个 Prompt Token KV
+ 5 个已生成 Token KV
```

第 6 个 Token 只需计算它自己的 K 和 V，并把它追加到 Cache；历史 15 个 Token 的 K/V 都可直接复用。

### 14. ZeRO-2 的分片内容

**题目**：ZeRO-2 具体对哪些状态进行了分片来降低显存占用？

- A. 优化器状态、模型参数做切片
- B. 对梯度、模型参数做切片
- C. 对优化器状态、梯度做切片
- D. 对优化器状态、模型参数、梯度做切片

**答案：C。**

**基础知识/解释**：ZeRO 各阶段：

```text
ZeRO-1：分片优化器状态
ZeRO-2：分片优化器状态 + 梯度
ZeRO-3：分片优化器状态 + 梯度 + 模型参数
```

### 15. n-gram 的一阶依赖假设

**题目**：n-gram 语言模型假设当前词出现的概率只依赖于前一个词。这种假设对应的数学模型是？

- A. 泊松过程
- B. 独立同分布序列
- C. 隐马尔可夫模型
- D. 一阶马尔可夫链

**答案：D。**

**基础知识/解释**：一阶马尔可夫性质：

```text
P(w_t | w_1, w_2, ..., w_(t-1))
= P(w_t | w_(t-1))
```

也就是当前状态只依赖前一个状态。

### 16. Krylov 子空间方法（多选）

**题目**：以下关于 Krylov 子空间方法的说法，正确的有？

- A. Krylov 方法要求显式存储完整的系数矩阵 A
- B. Krylov 方法总在 k=1 步就收敛
- C. 共轭梯度法（CG）是对称正定情况下的 Krylov 方法
- D. GMRES 适用于一般非对称方程组

**答案：C、D。**

**基础知识/解释**：Krylov 方法重点是反复计算矩阵-向量乘法 `Av`，不一定需要显式存完整矩阵，因此很适合大型稀疏系统。

```text
CG：适用于对称正定矩阵
GMRES：适用于一般非对称矩阵
```

收敛步数取决于矩阵条件和问题结构，不会总是一步收敛。

### 17. 训练 Profile 的优化方向（多选）

**题目**：Profile 显示 forward/backward 占 40%、allreduce 占 45%、dataloader 占 15%。哪些优化方向合理？

- A. 考虑 ZeRO/FSDP 分片策略重配
- B. 增加通信与计算重叠
- C. 把 tokenizer 换成更大词表
- D. 调整梯度 bucket 大小

**答案：A、B、D。**

**基础知识/解释**：AllReduce 占比 45%，说明通信是主要瓶颈之一。合理方向包括：

- 使用 ZeRO/FSDP 等策略重新评估分片与通信模式；
- 将梯度通信与后续反向计算重叠；
- 调整 bucket 大小，平衡小消息开销与重叠机会。

换更大词表不直接解决 AllReduce 瓶颈，还可能增加 Embedding 参数量。

### 18. 均值、中位数、众数完全重合（多选）

**题目**：在描述数据分布特征时，均值、中位数和众数在什么情况下会完全重合？

- A. 数据呈偏态分布
- B. 数据呈连续型均匀分布
- C. 数据呈标准正态分布
- D. 数据呈对称的单峰分布

**答案：C、D。**

**基础知识/解释**：标准正态分布以 0 为中心，且对称、单峰：

```text
mean = median = mode = 0
```

更一般地，对称单峰分布通常三者都在对称中心。偏态分布常有 `均值、中位数、众数` 不同；连续均匀分布没有唯一众数。

### 19. 混合精度训练（多选）

**题目**：关于混合精度训练，以下哪些描述是正确的？

- A. 使用 FP16 存储参数和梯度可以减少显存占用，且有精度保障，常被设置为默认模型训练精度
- B. BP 梯度回传与模型推理过程类似，一般具有相同的精度要求
- C. 训练过程中主权重通常保存为 FP32 以保证数值稳定性
- D. 损失缩放用于防止梯度下溢

**答案：A、C、D。**

**基础知识/解释**：混合精度通常让大部分计算使用 FP16/BF16 来节省显存并加速，同时保留关键状态为更高精度：

```text
FP16/BF16：参数副本、激活、部分计算
FP32：主权重、优化器状态、关键归约
```

损失缩放把梯度暂时放大，避免 FP16 下很小的梯度变成 0。反向传播比纯推理更需要关注数值稳定性，因此 B 错。

### 20. 多模态 DPO（多选）

**题目**：多模态 DPO 使用图像 `v`、查询 `x`、优选回复 `y_w` 和非优选回复 `y_l` 训练视觉语言模型。关于其梯度行为和训练机制，哪些说法正确？

- A. 模型严重错误排序时，`σ(-β·Δr)` 接近 1，梯度幅度较大，模型获得强修正信号
- B. 增大 β 会增强偏好学习强度、更快偏离参考模型；但过大可能导致训练不稳定或破坏视觉语言对齐
- C. 视觉投影层梯度仅来自第一个生成 Token，因为视觉特征只在初始位置注入
- D. 若优选回复比非优选回复长很多，累积对数概率可能让梯度受长度主导，使模型偏向长回复而非质量

**答案：A、B、D。**

**基础知识/解释**：DPO 的损失可写成：

```text
L = -log σ(βΔr)
```

若模型给坏回复更高偏好，`Δr` 为负且较小，修正信号会更强，因此 A 对。β 控制偏好优化强度，但过大可能过度偏离参考模型，B 对。

视觉投影层虽然在输入前缀位置注入视觉特征，但后续 Token 的预测依然通过 Transformer 注意力依赖该视觉上下文，因此梯度并不只来自第一个 Token，C 错。序列对数概率通常按 token 累加，长短回复不平衡可能带来长度偏置，D 对。
