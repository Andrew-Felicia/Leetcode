## 2. 原题、答案、解释与基础知识

### 1. 原题

下列哪个不是大语言模型（LLM）的典型特点？

A 主要基于Transformer架构  
B 通过海量数据训练获得通用能力  
C 保证事实的绝对准确性  
D 参数规模通常达到数十亿至万亿级别

单选题

**答案：C。**

**解释：** LLM 的输出是基于训练分布的概率预测，并不等于事实检索或逻辑证明，因此可能出现“幻觉”、过时知识或错误事实，不能保证绝对准确。

**基础知识：** Transformer、超大参数量和大规模预训练数据是现代 LLM 的常见特征；但模型能力强不代表每次回答都真实可靠。

### 2. 原题

下列哪个算法属于监督学习？

A 主成分分析（PCA）  
B 线性回归  
C K-means 聚类

单选题

**答案：B。**

**解释：** 线性回归根据输入特征 `x` 和已有目标值 `y` 学习关系，因此是监督学习。PCA 和 K-Means 都不使用标签，属于无监督学习。

**基础知识：**

- 监督学习：分类、回归，需要标签。
- 无监督学习：聚类、降维，不需要标签。

### 3. 原题

在RLHF流程中，奖励模型的作用，以下描述最准确的是？

A 奖励模型是可微分的人类偏好代理，将主观判断转化为可导的奖励信号  
B 奖励模型本身是强化学习智能体  
C 奖励模型目标是学习模仿人类写作风格  
D 奖励模型直接修改基座模型权重

单选题

**答案：A。**

**解释：** 人工通常只能说“回答 A 比 B 好”，不能直接给每一步训练一个可用的数值梯度。奖励模型从偏好对中学习一个评分函数，把这种偏好变为奖励信号，供 PPO 等方法优化策略模型。

**基础知识：** RLHF 常见路径：预训练 → SFT → 人类偏好对 → Reward Model → 强化学习优化策略。Reward Model 不是最终生成回答的策略模型。

### 4. 原题

关于先验概率和后验概率，正确的是

A 后验概率可以大于1  
B 后验概率必须通过贝叶斯定理计算  
C 先验概率是已知条件概率后的修正结果  
D 先验概率是未考虑新信息前的初始概率

单选题

**答案：D。**

**解释：** 先验概率是观察当前证据前的原始相信程度；后验概率是看到新证据后更新得到的概率。概率不能大于 1。

**基础知识：**

```text
P(A|B) = P(B|A) × P(A) / P(B)
```

其中 `P(A)` 是先验，`P(A|B)` 是后验。

### 5. 原题

下列方法中没有考虑先验分布的是

A 贝叶斯分类器  
B 最大似然估计  
C 贝叶斯学习  
D 最大后验估计

单选题

**答案：B。**

**解释：** 最大似然估计（MLE）只选择最能解释观测数据的参数，并不使用参数先验。
MLE 只最大化似然 P(D|θ)，不引入先验；其余三个都使用先验分布。

**基础知识：**

```text
MLE: θ_MLE = argmax P(data|θ)
MAP: θ_MAP = argmax P(data|θ)P(θ)
```

MAP 和贝叶斯学习考虑先验 `P(θ)`；MLE 不考虑。

### 6. 原题

考虑一个简单的马尔可夫决策过程（MDP），包含两个状态：s1和s2，其中s2是终止状态。在每个状态有两个可行动作：a1和a2。环境的动态如下：在状态s1：执行动作a1：以概率1转移到s2，获得即时奖励r=3。

执行动作a2：以概率1转移到s2，获得即时奖励r=-1。

在状态s2：为终止状态，无动作可执行。

使用Q-learning算法进行学习，折扣因子γ=0.9，学习率α=0.1。初始Q值全为0。

假设智能体从s1开始，执行动作a1，转移到s2，并终止。

问题：请根据此次经历，使用Q-learning更新规则，计算更新后的Q(s1, a1)的值。

A 0.4  
B 0.3  
C 0.2  
D 0.5

单选题

**答案：B，0.3。**

**解释：** Q-learning 的更新规则：

```text
Q(s,a) ← Q(s,a) + α × [r + γ max_a' Q(s',a') - Q(s,a)]
```

代入本题：初始 `Q(s1,a1)=0`；奖励 `r=3`；下一状态 `s2` 是终止状态，所以未来最大 Q 值为 0：

```text
Q(s1,a1) = 0 + 0.1 × [3 + 0.9×0 - 0]
         = 0.3
```

Q-learning 更新公式 Q ← Q + α[r + γ·maxQ' − Q]。s2 是终止态所以 maxQ(s2,·)=0，初始 Q=0，r=3，代入 α=0.1 得 Q(s1,a1) = 0 + 0.1×(3 + 0 − 0) = 0.3。

**基础知识：**

- MDP：由状态、动作、转移概率、奖励组成。
- Q(s,a)：在状态 s 做动作 a 的长期回报估计。
- α：学习率，决定这一次经历影响旧估计的程度。
- γ：折扣因子，控制未来奖励的重要程度。
- 终止状态没有后续动作，未来回报按 0 处理。

### 7. 原题

在高斯混合模型（GMM）中，EM算法的E步主要计算

A 参数更新  
B 后验概率  
C 特征函数  
D 先验概率

单选题

**答案：B。**

**解释：** E 步计算每个样本由各高斯分量生成的后验概率，也称责任度（responsibility）。M 步才更新模型参数。

**基础知识：** EM = Expectation-Maximization。E 步估计隐藏类别；M 步在这些估计下重新估计均值、协方差和混合权重。

### 8. 原题

设矩阵B=[2,1;0,2]，关于B的说法正确的是

A 特征值为1,3，且B不可对角化  
B 特征值为2,2，且B可对角化  
C 特征值为1,3，且B可对角化  
D 特征值为2,2，且B不可对角化

单选题

**答案：D。**

**解释：** B 为上三角矩阵，特征值是对角线元素 `2,2`。对 λ=2：

```text
B - 2I = [[0,1],
          [0,0]]
```

只能得到一个线性无关特征向量。2 阶矩阵需要 2 个线性无关特征向量才能对角化，因此不可对角化。

**基础知识：** “重根”不必然不可对角化；关键要看该特征值对应的线性无关特征向量数量是否足够。

### 9. 原题

设二阶矩阵A=[1,2;3,4]，向量x=[5;6]。则A·x的结果是

A [17,23;39,53]  
B [5,6;15,24]  
C [23;34]  
D [17;39]

单选题

**答案：D。**

**解释：**

```text
Ax = [1×5 + 2×6] = [17]
     [3×5 + 4×6]   [39]
```

**基础知识：** 矩阵乘列向量，结果第 i 个元素是矩阵第 i 行与向量做点积。

### 10. 原题

矩阵A的奇异值分解为A=UΣV^T。下列关于这三个矩阵的说法正确的是

A V是m×m正交矩阵，列向量是A^T A特征向量  
B U是m×n正交矩阵，列向量是A^T A特征向量  
C Σ是m×n对角矩阵，对角元素非负且按降序排列  
D 若A可逆，则Σ对角元素均为0

单选题

**答案：C。**

**解释：** 若 `A∈R^(m×n)`，完整 SVD 满足：

```text
U: m×m 正交矩阵
Σ: m×n 对角型矩阵，奇异值 ≥ 0
V: n×n 正交矩阵
```

通常奇异值从大到小排列。V 的列向量是 `A^TA` 的特征向量；U 的列向量是 `AA^T` 的特征向量。可逆时奇异值均大于 0。

SVD 中 U 是 m×m 正交矩阵，V 是 n×n 正交矩阵，Σ 是 m×n 对角矩阵，对角元素（奇异值）非负且按降序排列。

### 11. 原题

设实矩阵A∈R^(m×n)满足m≥n且rank(A)=n。以下哪一句话一定正确

A 若m>n，则Ax=b没有解  
B det(A^T A)=0  
C A的列向量线性相关  
D 方程A^T Ax=A^T b有唯一解

单选题

**答案：D。**

**解释：** `rank(A)=n` 表示 A 满列秩，列向量线性无关。因此 `A^TA` 可逆，正规方程有唯一解。

```text
x^T A^T A x = ||Ax||² > 0  （x≠0）
```

**基础知识：** 当方程组超定（m>n）时，`Ax=b` 未必有精确解；最小二乘法转而解正规方程。

### 12. 原题

已知矩阵A是3阶不可逆矩阵，α1,α2是齐次方程Ax=0的基础解系，α3是A属于特征值λ=2的特征向量。不是矩阵A特征向量的是

A 2α1+α3  
B 3α1-4α2  
C -5α3  
D α1+2α2

单选题

**答案：A。**

**解释：** α1、α2 对应特征值 0，α3 对应特征值 2。不同特征值的特征向量混合后通常不再是特征向量：

```text
A(2α1+α3) = 2α3
```

它不是某个常数乘 `2α1+α3`。


α1、α2 是特征值 0 的特征向量，α3 是特征值 2 的特征向量。B（3α1−4α2）、D（α1+2α2）仍是特征值 0 的特征向量（同特征值线性组合仍属于该特征空间），C（−5α3）是特征值 2 的特征向量。A（2α1+α3）是不同特征值特征向量的非零组合，不是任何特征值的特征向量
**基础知识：** 同一特征值对应的特征空间是子空间，任何非零线性组合仍是特征向量；不同特征空间混合一般不成立。

### 13. 原题

给定样本矩阵X∈R^(n×d)，若要在不丢失信息前提下进行降维，使得重构误差最小，应采用

A QR分解  
B LU分解  
C Cholesky分解  
D 奇异值分解（SVD）截断

单选题

**答案：D。**

**解释：** 截断 SVD 保留最大的前 k 个奇异值，在秩 k 限制下可获得最小平方重构误差。

**基础知识：** Eckart–Young 定理说明 SVD 截断给出最佳低秩近似。PCA 通常也可通过中心化数据的 SVD 计算。

### 14. 原题

在RLHF中，reward model的训练依赖于

A 监督数据  
B 蒙特卡罗采样  
C 随机初始化  
D 人类偏好排序

单选题

**答案：D。**

**解释：** Reward Model 的核心训练信号是人类偏好排序，例如同一问题下哪个回答更好。

### 15. 原题

设A=[−11,4;−30,11]，则(A+E)(E−A+A²−A³+A⁴−A⁵+A⁶)的结果是

A [−10,4;−30,12]  
B [12,4;30,10]  
C [10,4;30,12]  
D [−12,4;−30,10]

多选题

**答案：A。**

**解释：** 这里 E 是单位矩阵 I。直接计算得 `A²=I`，于是：

```text
I-A+A²-A³+A⁴-A⁵+A⁶
= I-A+I-A+I-A+I
= 4I-3A

(A+I)(4I-3A)
= 4A+4I-3A²-3A
= A+I
= [[-10,4],[-30,12]]
```

**基础知识：** 若矩阵满足简单代数关系，例如 `A²=I`，高次幂可循环化简，无须逐次相乘。

### 16. 原题

关于注意力的表述，正确的是

A 并非所有注意力变体都需计算QK^T  
B MHA的参数量可能不随头数线性增长  
C MLA的训练速度通常快于MHA  
D GQA在推理时可减少K/V缓存的内存占用

多选题

**答案：A、B、D。**

**解释：**

- A：正确。线性注意力等变体不一定显式构造完整 `QK^T`。
- B：正确。固定总隐藏维度时，多头通常只是拆分通道，总参数量仍约按 `d_model²` 规模。
- C：错误。MLA 的核心收益是减少 KV Cache，训练速度不必然快于 MHA。
- D：正确。GQA 让多个 Query 头共享较少的 K/V 头，推理缓存更小。

**基础知识：** MHA 是多头注意力；GQA 是分组查询注意力；MLA 常指多头潜在注意力，目标之一是降低推理 KV Cache 成本。

### 17. 原题

关于连续型随机变量，以下说法正确的是

A 连续型随机变量的概率密度函数（PDF）在任意点的值可以大于1  
B 连续型随机变量的累积分布函数（CDF）一定是连续函数  
C 若X是连续型随机变量，则P(X=a)=0对任意实数a成立  
D 对于连续型随机变量X，若其概率密度函数f(x)是常数，则X的分布关于0对称

多选题

**答案：A、B、C。**

**解释：** PDF 是密度，不是概率；例如均匀分布 `U[0,0.5]` 的 PDF 为 2。连续变量单点概率为 0，CDF 连续。若 PDF 在 `[1,2]` 上为常数，只表示均匀分布，并不关于 0 对称。

**基础知识：** 区间概率由积分得到：`P(a≤X≤b)=∫_a^b f(x)dx`，而不是单点 PDF 值。

### 18. 原题

误差来源中，截断误差和舍入误差的区别正确表述有哪些？

A 舍入误差源于有限精度表示  
B 截断误差源于有限步近似无穷过程（如泰勒级数截断）  
C 两者均可完全消除  
D 迭代法中，通常情况下，截断误差随迭代减小，舍入误差随迭代累积

多选题

**答案：A、B、D。**

**解释：** 截断误差是数学近似只保留有限项造成的；舍入误差是浮点数位数有限造成的。通常无法同时完全消除。迭代加深时截断误差常变小，而舍入误差可能累计。

**基础知识：** 例如 `sin(x)=x-x³/6+x⁵/120-...`，只取前两项会有截断误差；`0.1` 不能被二进制浮点精确表示会产生舍入误差。

### 19. 原题

关于BPE与WordPiece两种常见子词分词算法，以下说法正确的是

A 在BPE中，每轮迭代总是合并出现频次最高的符号对  
B WordPiece在每次合并时基于语言模型最大化似然，而非简单频次  
C 两者都会把罕见词切分为更频繁的子词单元  
D 如果使用相同语料训练，BPE与WordPiece最终得到的词表一定完全相同

多选题

**答案：A、B、C。**

**解释：** BPE 的经典规则是合并最高频相邻符号对；WordPiece 的选择与语言模型似然增益有关。二者都可把罕见词切成子词。合并标准不同，即使语料相同，最终词表也不保证完全相同。

**基础知识：** 子词分词缓解 OOV（未登录词）问题。例如罕见单词可以拆成多个词根、前后缀或字符片段。

### 20. 原题

关于Causal Mask的作用，正确的是

A 防止解码器在训练时看到未来的信息  
B 是一个上三角为负无穷的矩阵  
C 用于编码器的自注意力层以增强局部性  
D 仅适用于文本生成任务

多选题

**答案：A、B。**

**解释：** Causal Mask 让位置 i 只能注意到位置 `≤i` 的 token，阻止训练阶段偷看未来答案。常见实现是对主对角线右上方添加 `-∞`，Softmax 后未来 token 的概率为 0。

```text
      key:  0    1    2
query 0   [ 0, -∞, -∞]
query 1   [ 0,  0, -∞]
query 2   [ 0,  0,  0]
```

**基础知识：** 它不仅适用于文本，也用于任何自回归生成序列，如语音、代码、时间序列。标准双向 Encoder 自注意力通常不使用 Causal Mask。
