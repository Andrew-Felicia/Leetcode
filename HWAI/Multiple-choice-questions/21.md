## 一、单选题

### 1. 二次型 f = 5x₁² + 5x₂² + c·x₃² − 2x₁x₂ + 6x₁x₃ − 6x₂x₃ 的秩为 2，则 c = ？
- A. 3
- B. 5
- C. 9
- D. 6

**答案：A**

**详解：**
1. 先写出二次型对应的对称矩阵（平方项系数放对角线，交叉项系数的一半放两侧）：

   A = [[5, −1, 3], [−1, 5, −3], [3, −3, c]]

2. 二次型的秩就是矩阵 A 的秩。3 阶矩阵秩为 2，说明它**不满秩**，所以 |A| = 0。
3. 计算行列式：|A| = 5(5c − 9) + (−c + 9) − 36 = 24c − 72。
4. 令 24c − 72 = 0，得 **c = 3**。
5. 检验：左上角 2×2 子式 = 25 − 1 = 24 ≠ 0，所以秩至少为 2，加上 |A| = 0，秩正好为 2。

### 2. 情感分类数据 9:1 严重不平衡时，哪个评估指标最不能客观反映性能？
- A. 召回率
- B. AUC
- C. F1-score
- D. 准确率

**答案：D**

**详解：** 假设 100 条数据里 90 条是正面。模型什么都不学，**全部预测为正面**，准确率也能达到 90%，看起来很高，其实模型毫无用处。所以数据不平衡时，准确率最容易"骗人"。召回率、F1、AUC 都会关注少数类的表现，更客观。

### 3. A 为 3 阶矩阵，|A| = 2，则 |(⅓A)⁻¹ − ½A*| = ？
- A. 1
- B. 125/16
- C. 4
- D. −4/27

**答案：C**

**详解：**
1. 逆矩阵的性质：(kA)⁻¹ = (1/k)·A⁻¹，所以 (⅓A)⁻¹ = 3A⁻¹。
2. 伴随矩阵公式：A* = |A|·A⁻¹ = 2A⁻¹，所以 ½A* = A⁻¹。
3. 相减：3A⁻¹ − A⁻¹ = 2A⁻¹。
4. 3 阶矩阵乘常数 k，行列式乘 k³：|2A⁻¹| = 2³ × |A⁻¹| = 8 × (1/2) = **4**。

### 4. A 是 3 阶方阵，A 的第 1、2 列交换得 B，再把 B 的第 2 列加到第 3 列得 C，满足 AQ = C 的可逆矩阵 Q 为？
- A. [[0,1,0]; [1,0,0]; [1,0,1]]
- B. [[0,1,0]; [1,0,0]; [0,1,1]]
- C. [[0,1,1]; [1,0,0]; [0,0,1]]
- D. [[0,1,0]; [1,0,1]; [0,0,1]]

**答案：C**

**详解：** 记忆口诀：**右乘矩阵 = 对列做操作**（左乘才是对行操作）。
1. 交换第 1、2 列：B = A·P₁，其中 P₁ = [[0,1,0],[1,0,0],[0,0,1]]（单位矩阵交换第 1、2 列得到）。
2. 第 2 列加到第 3 列：C = B·P₂，其中 P₂ = [[1,0,0],[0,1,1],[0,0,1]]（单位矩阵做同样操作得到）。
3. 所以 C = A·P₁·P₂，Q = P₁P₂ = [[0,1,1],[1,0,0],[0,0,1]]，对应选项 C。

**验证：** 用 A 的三列 (a₁, a₂, a₃) 看，C 应该是 (a₂, a₁, a₁ + a₃)。Q 的第 3 列 (1,0,1)ᵀ 表示第 3 列 = 1×a₁ + 1×a₃，吻合。

### 5. 大模型训练中的 LoRA 主要作用是？
- A. 解决推理时幻觉
- B. 在微调阶段通过低秩矩阵减少要更新的参数量
- C. 提升上下文窗口长度
- D. 降低预训练阶段计算成本

**答案：B**

**详解：** LoRA（低秩适配）的思路：**冻结原模型权重 W 不动**，只额外训练两个很小的矩阵 B 和 A（相乘后是低秩矩阵），实际权重变成 W + BA。需要训练的参数从几十亿变成几百万，显存和算力需求大幅下降。它是一种**微调**方法，不是用来预训练、改善幻觉或扩展上下文的。

### 6. 向量 A = [1, 2, 3, 0, −3] 的 L1 范数为？
- A. 3
- B. √23
- C. 4
- D. 9

**答案：D**

**详解：** L1 范数 = 各元素**绝对值之和**：|1| + |2| + |3| + |0| + |−3| = **9**。
（顺带记一下：L2 范数是平方和开根号，本题 L2 = √(1+4+9+0+9) = √23，就是选项 B 的陷阱。）

### 7. 若模型过拟合，下列操作能缓解的是？
- A. 在原数据集上重新训练
- B. 添加正则化
- C. 将数据集复制后再训练
- D. 减少数据集后再训练

**答案：B**

**详解：** 过拟合 = 模型把训练数据"背"下来了。
- **B 对**：正则化（L1、L2、Dropout 等）限制模型复杂度，防止死记硬背。
- A 错：原数据重训，还是那个结果。
- C 错：复制数据没有带来新信息，模型反而更会背。
- D 错：数据越少越容易过拟合。

### 8. Transformer 位置编码主要作用？
- A. 增强非线性
- B. 提供序列位置信息
- C. 提升并行带宽
- D. 降低计算量

**答案：B**

**详解：** 注意力机制本身是同时看所有词，**不知道词的先后顺序**（"我爱你"和"你爱我"在它眼里一样）。位置编码给每个位置加上一个独特的"位置标记"，让模型知道每个词在句子的第几个位置。

### 9. 将 28×28 灰度图像转为特征向量且**完整保留信息**的操作是？
- A. 仅保留边缘后像素
- B. 每个 4×4 块取均值成 49 维
- C. 按行展开为 784 维向量
- D. 直接用原像素矩阵

**答案：C**

**详解：** 28×28 = 784 个像素。把每一行首尾相接排成一长串，得到 784 维向量，**一个像素都没丢**，且可以还原。
- A、B 都丢了信息（边缘以外、块内细节）。
- D 虽然也没丢信息，但它是矩阵而不是"特征向量"，不符合题目"转为向量"的要求。

### 10. LoRA 推理时延几乎不受影响的原因是？
- A. 权重量化为 INT4
- B. 低秩更新 r 很小且与原乘法并行融合
- C. 仅训练期生效，推理期完全丢弃
- D. 低秩矩阵乘法可离线编译入权重

**答案：D**

**详解：** 训练完后，可以直接把 BA **加到原权重里**：W' = W + BA。这个合并是提前（离线）做好的，推理时只用一个 W'，计算量和原模型**一模一样**，所以几乎没有额外延迟。
- A 错：量化是另一种技术（QLoRA 才结合）。
- C 错：推理时 LoRA 的效果仍然需要，不能丢弃，否则微调就白做了。
- B 说的是不合并、并行计算，那样仍有一点额外开销，不是"几乎不受影响"的根本原因。

### 11. 某 12 层 Transformer，hidden size = 768，MLP 扩展比 = 4，每层 MLP 参数量约为？
- A. 18.88 M
- B. 9.44 M
- C. 4.72 M
- D. 2.36 M

**答案：C**

**详解：** MLP 有两个线性层：
1. 第一层：768 → 768×4 = 3072，参数 768 × 3072 = 2,359,296。
2. 第二层：3072 → 768，参数同样 2,359,296。
3. 合计：2 × 2,359,296 = 4,718,592 ≈ **4.72 M**（忽略偏置项）。

层数 12 是干扰信息，题目只问**每层**。

### 12. A ∈ ℝ²ˣ² 的特征值为 λ₁ = 3，λ₂ = −1，则 A 的迹为？
- A. 3
- B. 4
- C. −1
- D. 2

**答案：D**

**详解：** 重要结论：**矩阵的迹 = 所有特征值之和**（行列式 = 特征值之积）。所以迹 = 3 + (−1) = **2**。

### 13. 梯形法则求定积分，二阶导在 [a,b] 上最大为 M，区间等分 n 段，截断误差上界为？
- A. M(b−a)²/(2n²)
- B. M(b−a)³/(12n²)
- C. M(b−a)/n
- D. M(b−a)⁴/(24n³)

**答案：B**

**详解：** 这是梯形公式的标准误差上界：|E| ≤ M(b−a)³ / (12n²)。
可以这样记：误差和 n² 成反比（把区间分得越细，误差按平方速度变小），系数是 12。

### 14. 多模态对齐采用对比学习时的损失可选？
- A. log( exp(sim(Vᵢ,Tᵢ)) / Σⱼ exp(sim(Vᵢ,Tⱼ)) )
- B. CrossEntropy(Vᵢ,Tⱼ)
- C. KL-Divergence(Vᵢ ‖ Tⱼ)
- D. MSE(Vᵢ,Tⱼ)

**答案：A**

**详解：** 这是 CLIP 使用的 InfoNCE 对比损失（实际使用时前面加负号）。思路：一批图文对里，图 Vᵢ 和它**配对的文本 Tᵢ** 相似度要尽量高，和其他文本 Tⱼ 相似度要尽量低。分子是正样本相似度，分母是和所有文本的相似度之和，本质就是一个 softmax。
B、C、D 都只是在比较两个向量的差距，没有"拉近正样本、推远负样本"的对比结构。

### 15. 二分法（Bisection）的收敛速度是？
- A. 超线性
- B. 不收敛
- C. 二次
- D. 线性

**答案：D**

**详解：** 二分法每次把区间缩小**一半**，误差按固定比例 1/2 缩小，这属于线性收敛。它稳定可靠但比较慢。牛顿法才是二次收敛，割线法是超线性收敛。

## 二、多选题

### 16. 以下说法正确的是？
- A. 线性相关当且仅当任意一个向量可由其余表示
- B. (α₁−α₂, …, α_{n−1}−αₙ, 2(αₙ−α₁)) 一定线性相关
- C. 若 AB = 0 且 A、B 非零，则 A 的列或 B 的行向量线性相关
- D. 若 3 阶非零实方阵 A 的伴随矩阵 A* = −Aᵀ，则 det(A) < 0

**答案：BCD**

**详解：**
- **A 错**：线性相关只要求"**至少有一个**向量可由其余表示"，不是"任意一个"。例如 (1,0)、(2,0)、(0,1) 线性相关，但 (0,1) 就不能由前两个表示。
- **B 对**：把前 n−1 个向量相加，中间项全部抵消，得 α₁ − αₙ。再加上最后一个向量的一半 (αₙ − α₁)，结果为 0。存在不全为零的系数使线性组合为零，所以线性相关。
- **C 对**：AB = 0 说明 B 的每一列都是 Ax = 0 的解。B 非零，所以 Ax = 0 有非零解，A 的列向量线性相关。（同时 r(A) + r(B) ≤ n，B 的行数 n 大于它的秩，所以 B 的行向量也线性相关。）
- **D 对**：由 AA* = |A|·I 和 A* = −Aᵀ，得 |A|·I = −AAᵀ。两边取迹：3|A| = −tr(AAᵀ)。而 tr(AAᵀ) 是 A 所有元素的平方和，A 非零所以大于 0。因此 3|A| < 0，即 det(A) < 0。

### 17. PCA 的前 k 个主成分的性质？
- A. 方差依次最大
- B. 原始数据旋转后主成分不变
- C. 主成分之间正交
- D. 与原始特征线性无关

**答案：AC**

**详解：**
- **A 对**：第一主成分是方差最大的方向，第二主成分是在与第一个正交的前提下方差最大的方向，依此类推。
- B 错：数据旋转后，主成分方向也会跟着旋转，不是"不变"的。
- **C 对**：各主成分方向由协方差矩阵的特征向量给出，对称矩阵的不同特征向量相互正交。
- D 错：主成分就是原始特征的**线性组合**，和原始特征是线性相关的。

### 18. 关于 LLM 优化器的论断，成立或广泛认可的是？
- A. Adam 的偏差校正有助于早期收敛
- B. "峡谷"地形中 Adam/RMSprop 自适应学习率抑制振荡、加速收敛
- C. 梯度长期稀疏时 Adam/RMSprop 的有效学习率调整更稳健
- D. 自适应优化器维护二阶动量，显著增加状态内存

**答案：ABCD**

**详解：**
- **A 对**：Adam 的动量初始值为 0，刚开始会偏小，偏差校正把它"补"回来，让训练初期更稳。
- **B 对**：峡谷地形指某个方向很陡、另一个方向很平。自适应学习率给陡的方向小步长、平的方向大步长，减少来回振荡。
- **C 对**：对很少更新的参数，自适应方法会自动给更大的有效学习率，更稳健。
- **D 对**：Adam 每个参数要额外保存一阶动量 m 和二阶动量 v，相当于多存 2 倍参数量的状态，训练大模型时显存压力很大。

### 19. A₁、A₂、A₃ 构成划分，P(A₁)=0.2，P(A₂)=0.3，P(A₃)=0.5，P(B|A₁)=0.1，P(B|A₂)=0.4，P(B|A₃)=0.6。哪些正确？
- A. P(A₂|B) = P(B|A₂)
- B. P(B) = 0.44
- C. P(A₁|B) ≈ 0.045
- D. P(A₂|B) ≈ 0.273

**答案：BCD**

**详解：**
1. **全概率公式**：P(B) = 0.2×0.1 + 0.3×0.4 + 0.5×0.6 = 0.02 + 0.12 + 0.30 = **0.44**，B 对。
2. **贝叶斯公式**：P(Aᵢ|B) = P(Aᵢ)P(B|Aᵢ) / P(B)。
   - P(A₁|B) = 0.02 / 0.44 ≈ **0.045**，C 对。
   - P(A₂|B) = 0.12 / 0.44 ≈ **0.273**，D 对。
3. A 错：P(A₂|B) 约 0.273，而 P(B|A₂) = 0.4，二者不相等。"已知 B 求 A" 和 "已知 A 求 B" 是不同的概率，不要搞混。

### 20. 以下优化算法，说法正确的是？
- A. L-BFGS 是二阶优化方法
- B. Momentum 是二阶优化方法
- C. Adam 是一阶优化方法
- D. AdaGrad 是一阶优化方法
- E. AdamW 是一阶优化方法

**答案：ACDE**

**详解：** 判断标准：**只用梯度（一阶导数）的是一阶方法，用到 Hessian（二阶导数）信息的是二阶方法。**
- **A 对**：L-BFGS 属于拟牛顿法，用历史梯度近似 Hessian 的逆，归入二阶方法。
- B 错：Momentum（动量）只用梯度的历史累积，是一阶方法。
- **C 对**：Adam 虽然有"二阶动量"，但那只是梯度平方的滑动平均，**并不是二阶导数**，所以仍是一阶方法。这是常见的名字陷阱。
- **D 对**：AdaGrad 累积梯度平方来调学习率，是一阶方法。
- **E 对**：AdamW 只是把权重衰减从梯度里解耦出来，仍是一阶方法。
