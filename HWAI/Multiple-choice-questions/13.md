# 华为 AI 在线笔试选择题学习笔记（第十三组）

## 1. 总结

| 主题 | 核心结论 |
| --- | --- |
| NMF 与 LDA | NMF 面向非负且强调可解释性的分解；监督式 LDA 最大化类间散度相对类内散度。 |
| CNN 与 GPU | MobileNet 用 Depthwise + Pointwise 卷积降成本；寄存器/共享内存属于低延迟 SRAM 层级。 |
| 训练优化 | L2 防过拟合；AdamW 的关键是解耦 Weight Decay；Dead ReLU 可用 Leaky ReLU 缓解。 |
| 大模型并行 | Megatron MLP 常采用第一层列切、第二层行切，减少不必要通信。 |
| 数值方法 | 前向差分 O(h)、中心差分 O(h²)、Richardson 外推 O(h⁴)。 |
| 概率与线代 | 正交变换保持内积、L2 距离与余弦；独立不自动传递到事件交集。 |

## 2. 题目、答案与解释

### 1. NMF 的适用场景

**题目**：非负矩阵分解（NMF）的适用场景是？

- A. 数据含负值的场景
- B. 矩阵可逆的场景
- C. 数据非负且需解释性的场景（如文本聚类）
- D. 高维数据降维场景

**答案：C。**

**基础知识/解释**：NMF 试图把非负矩阵 `V` 分解为：

```text
V ≈ WH
```

其中 `W`、`H` 都要求非负。因为没有正负抵消，结果常能解释为“部件的加和”。例如词频矩阵非负，可把主题理解为若干词的非负权重组合，因此适合文本主题、图像部件、推荐等强调可解释性的非负数据。

### 2. 条件数定义

**题目**：矩阵的条件数 `cond(A)` 的定义为？

- A. `||A^-1||/||A||`
- B. `||A|| / ||A^-1||`
- C. `||A|| + ||A^-1||`
- D. `||A||·||A^-1||`

**答案：D。**

**基础知识/解释**：对可逆矩阵：

```text
cond(A) = ||A|| × ||A^(-1)||
```

条件数大表示 `Ax=b` 对输入扰动更敏感；条件数接近 1 通常表示数值性质较好。

### 3. MobileNet 的核心创新

**题目**：MobileNet 核心创新点在于将标准卷积分解为？

- A. 空间卷积和时间卷积
- B. 深度卷积（Depthwise）和逐点卷积（Pointwise）
- C. 1×1 卷积和 3×3 卷积的并行计算
- D. 全连接层和池化层的组合

**答案：B。**

**基础知识/解释**：标准卷积同时做空间特征提取和通道混合，成本较高。MobileNet 拆成：

```text
Depthwise Conv：每个通道独立做空间卷积
Pointwise Conv：用 1×1 卷积混合通道
```

这能显著减少参数量和计算量。

### 4. LDA 降维

**题目**：在机器学习降维中，关于线性判别分析（LDA），下列说法正确的是？

- A. LDA 是无监督降维方法
- B. LDA 的目标是最大化类间散度与类内散度的比值
- C. LDA 降维后的维度可以任意指定，最多等于特征数
- D. LDA 适用于任何类型的数据分布

**答案：B。**

**基础知识/解释**：这里的 LDA 指 Linear Discriminant Analysis，不是主题模型中的 Latent Dirichlet Allocation。它需要类别标签，是监督式降维。目标是：

```text
类间距离尽可能大
类内距离尽可能小
```

最多可降到 `类别数 - 1` 维，而不是任意维。

### 5. 指令遵循的工业评测

**题目**：对大模型进行指令遵循能力量化测评时，最符合工业界工程实践的是？

- A. 使用 LLM-as-a-judge 时，为缓解长度偏见，可交换选项顺序或限制输出长度
- B. 应完全依赖 ROUGE-L 的字面重合度
- C. MMLU 主要采用多轮对话，是最直接对齐指标
- D. Pass@1 很高即可断定复杂推理极其鲁棒

**答案：A。**

**基础知识/解释**：LLM-as-a-judge 可能偏好更长、更流畅的答案，即使答案并不更正确。工程上常做：

```text
交换 A/B 答案顺序
控制答案长度
使用多个 Judge 或人工抽检
```

ROUGE 只看字面重合，MMLU 主要是知识/选择题能力，Pass@1 也不能单独证明鲁棒性。

### 6. FP16 训练的主要动机

**题目**：在深度学习中使用半精度（FP16）训练的主要动机是？

- A. 降低内存占用与加速计算
- B. 增加模型的泛化能力
- C. 提高数值稳定性
- D. 减少舍入误差

**答案：A。**

**基础知识/解释**：FP16 每个数通常占 2 Byte，FP32 占 4 Byte。低精度可以减少显存、内存带宽，并利用 Tensor Core 等硬件提高速度；但数值范围更小，反而常需要 Loss Scaling、FP32 主权重等机制维持稳定性。

### 7. 多任务学习共享主干

**题目**：在多任务学习中，共享主干模型的主要优势体现在哪个方面？

- A. 提升任务之间的隔离性
- B. 确保所有任务训练速度一致
- C. 只减少部署成本，不考虑训练效率
- D. 通过共享主干实现参数、计算和表征的复用

**答案：D。**

**基础知识/解释**：多个任务共享底层特征提取器：

```text
输入 -> Shared Backbone -> Task A Head
                         -> Task B Head
                         -> Task C Head
```

这样可复用参数和计算，也可能通过相关任务帮助学习更通用的表征。

### 8. GPU 中低延迟、高带宽的存储层级

**题目**：在 GPU 的存储层次中，哪一种存储器具有最低的访问延迟和最高的聚合带宽？

- A. 系统内存
- B. HBM
- C. SRAM（共享内存 / 寄存器）
- D. L2 缓存

**答案：C。**

**基础知识/解释**：从快到慢大致为：

```text
寄存器 / Shared Memory（SRAM）
-> L1/L2 Cache
-> HBM / Global Memory
-> CPU 系统内存
```

SRAM 容量小、成本高，但延迟低、带宽高。

### 9. 逻辑回归的 L2 正则化

**题目**：在逻辑回归中加入 L2 正则化的主要目的是？

- A. 防止过拟合，提高泛化能力
- B. 加速梯度下降收敛
- C. 自动进行特征选择
- D. 处理类别不平衡问题

**答案：A。**

**基础知识/解释**：L2 在损失中加入 `λΣw_i²`，限制权重过大，让模型更平滑，通常用于缓解过拟合。自动得到稀疏特征选择更接近 L1 正则。

### 10. Megatron-LM 的 MLP 张量并行

**题目**：在 Megatron-LM 的张量并行架构中，Transformer 层 MLP 两个全连接层的切分策略是？

- A. 第一层按列切分，第二层按行切分
- B. 两层都按行切分
- C. 第一层按行切分，第二层按列切分
- D. 两层都按列切分

**答案：A。**

**基础知识/解释**：MLP 常写为：

```text
X -> Linear(D, 4D) -> activation -> Linear(4D, D)
```

第一层按输出列切分，让每张卡计算一部分 `4D` 激活；第二层按输入行切分，接收对应激活分片。这样中间激活不必立刻全量同步，只在需要时做通信，降低通信开销。

### 11. SFT 与偏好/奖励强化学习

**题目**：关于 SFT 与基于偏好或奖励的强化学习阶段，下列哪项表述更准确？

- A. 强化学习阶段不需要任何反馈信号
- B. 两个阶段目标完全相同且可互相替代
- C. SFT 主要模仿高质量示例，强化学习阶段进一步按奖励或偏好优化行为
- D. SFT 只用于图像模型

**答案：C。**

**基础知识/解释**：

```text
SFT：学习“示范答案长什么样”
RLHF / DPO：利用偏好、奖励，让模型更偏向人类偏好的答案
```

两者常是顺序互补关系，不是完全替代。

### 12. AdamW 中的 W

**题目**：在 AdamW 中，“W”代表什么改进？

- A. Windowing
- B. Warming
- C. Weight Initialization
- D. Weight Decay decoupling

**答案：D。**

**基础知识/解释**：AdamW 将 weight decay 与 Adam 自适应梯度更新解耦。它不是把 `λw` 简单混进梯度，而是单独做参数衰减更新，实践中通常比传统 Adam + L2 正则更符合预期。

### 13. 二项分布概率

**题目**：硬币正面概率为 0.6，抛 5 次，恰好出现 3 次正面的概率是？

- A. `(0.6)^3 × (0.4)^2`
- B. `(0.6)^2 × (0.4)^3`
- C. `C_5^2 × (0.6)^2 × (0.4)^3`
- D. `C_5^3 × (0.6)^3 × (0.4)^2`

**答案：D。**

**基础知识/解释**：二项分布公式：

```text
P(X=k) = C(n,k)p^k(1-p)^(n-k)
```

代入 `n=5、k=3、p=0.6` 即得 D。

### 14. 数值微分误差阶

**题目**：给定步长 h，前向差分、中心差分和 Richardson 外推法的误差阶数分别是？

- A. 前向差分：`O(h)`，中心差分：`O(h²)`，Richardson 外推：`O(h⁴)`
- B. 前向差分：`O(h²)`，中心差分：`O(h)`，Richardson 外推：`O(h)`
- C. 三种方法误差阶相同
- D. 步长越小，结果越精确

**答案：A。**

**基础知识/解释**：

```text
前向差分：(f(x+h)-f(x))/h              误差 O(h)
中心差分：(f(x+h)-f(x-h))/(2h)          误差 O(h²)
Richardson 外推：消去低阶误差项         常见误差 O(h⁴)
```

D 不总对：h 过小时会因浮点舍入误差被除以很小的 h，误差可能反而变大。

### 15. PagedAttention 的错误说法

**题目**：关于 PagedAttention 与传统 Attention 的显存管理区别，下列说法错误的是？

- A. 传统连续 KV Cache 分配易产生碎片化
- B. PagedAttention 将 KV Cache 分页存储，可利用离散显存碎片
- C. PagedAttention 通过页表实现分页分配与回收
- D. 传统 KV Cache 与序列长度正相关，PagedAttention 可突破该关联

**答案：D。**

**基础知识/解释**：PagedAttention 改善的是内存分配方式和利用率，不会改变 KV Cache 随序列长度增长的本质：

```text
KV Cache 大小仍正比于序列长度
```

### 16. 二分类混淆矩阵（多选）

**题目**：关于二分类混淆矩阵，下列说法正确的有？

- A. `Recall = TP / (TP + FN)`
- B. `TPR = TN / (TN + FP)`
- C. `Accuracy = (TP + TN) / (TP + TN + FP + FN)`
- D. `Precision = TP / (TP + FP)`

**答案：A、C、D。**

**基础知识/解释**：

```text
Recall / TPR = TP / (TP + FN)
Specificity / TNR = TN / (TN + FP)
```

B 写的是 Specificity，不是 TPR。

### 17. 正交变换保持的度量（多选）

**题目**：对非零向量 u、v 同时施加正交矩阵 Q，哪些度量保持不变？

- A. 内积 `<Qu,Qv>`
- B. 欧氏距离 `||Qu-Qv||_2`
- C. 曼哈顿距离 `||Qu-Qv||_1`
- D. 余弦相似度

**答案：A、B、D。**

**基础知识/解释**：正交矩阵满足 `Q^TQ=I`：

```text
(Qu)^T(Qv) = u^TQ^TQv = u^Tv
||Qu||_2 = ||u||_2
```

所以内积、L2 距离、余弦都保持。L1/曼哈顿距离一般不保持，例如旋转坐标轴后分量绝对值之和可能改变。

### 18. 事件独立性（多选）

**题目**：关于事件 A、B、C，哪些说法正确？

- A. 若 `P(A)=P(A|B)` 且 `P(B)>0`，则 A 和 B 独立
- B. 恒有 `P(A∩B|C)=P(A|C)P(B|C)`
- C. 若 A 与 B 独立，则 `P(A∩B)=P(A)P(B)`
- D. 若 A 与 B 独立且 A 与 C 独立，则 A 与 `B∩C` 独立

**答案：A、C。**

**基础知识/解释**：独立定义可写成：

```text
P(A|B)=P(A)  <=>  P(A∩B)=P(A)P(B)
```

B 需要“给定 C 后 A、B 条件独立”才能成立，不是恒成立。D 只给出了两两独立，不保证 A 与交集 `B∩C` 独立；这需要更强的相互独立条件。

### 19. 训练中的统计分布与量化（多选）

**题目**：在大规模深度学习模型训练时，关于统计分布的应用，下列说法正确的有？

- A. Batch 足够大时，模型梯度的均值估计通常可近似高斯
- B. 多元正态权重相互独立时，其协方差矩阵是对角矩阵
- C. Laplace 激活分布采用线性对称量化通常优于非线性量化
- D. 为最小化 MSE，最优量化截断阈值通常小于观测最大值

**答案：A、B、D。**

**基础知识/解释**：

- 大 batch 的均值估计常可由中心极限定理近似为高斯；
- 独立变量的协方差为 0，因此协方差矩阵非对角元素为 0；
- Laplace 分布通常尖峰厚尾，非线性量化或更合适的分布感知量化往往更有优势；
- 极端离群值会拉大量化范围。为减少整体 MSE，实践中常对少量极端值截断，因此阈值可能小于观测最大值。

### 20. Dead ReLU（多选）

**题目**：关于 Dead ReLU 问题，以下描述正确的有？

- A. 学习率过大可能使参数更新过猛，让神经元落到 ReLU 负半轴
- B. Leaky ReLU 可以有效缓解 Dead ReLU
- C. 输入小于 0 时，ReLU 梯度为 0，可能导致对应权重无法更新
- D. 一旦神经元死亡，后续训练中永远不会再被激活

**答案：A、B、C。**

**基础知识/解释**：

```text
ReLU(x) = max(0, x)
ReLU'(x) = 0, 当 x < 0
```

过大学习率可能使神经元进入负区间；Leaky ReLU 在负区间保留一个小斜率，可提供梯度。D 过于绝对：若其他层参数改变，输入分布变化，神经元仍有机会重新得到正输入。
