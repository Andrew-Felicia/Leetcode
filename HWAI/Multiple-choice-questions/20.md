## 一、单选题

### 1. 在RLHF中，reward model的训练依赖于：
- A. 人类偏好排序
- B. 监督数据
- C. 蒙特卡罗采样
- D. 随机初始化

**答案：A**

**详解：** RLHF 是"基于人类反馈的强化学习"，大致分三步：
1. 让模型对同一个问题生成多个回答。
2. 人类对这些回答**排序**（哪个好、哪个差）。
3. 奖励模型（reward model）从这些排序中学习，给人类喜欢的回答打高分，之后大模型就朝着"高分"方向优化。

所以奖励模型靠的是**人类偏好排序**，而不是普通的标注数据。

### 2. h=8，GQA 分组数 g=2，K/V 矩阵的共享情况是：
- A. 仅Q矩阵分组
- B. 每2个头共享K/V，共4组
- C. 每组4个头共享K/V
- D. 所有头共享同一组K/V

**答案：C**

**详解：** 先认识三种注意力：
- **MHA（多头注意力）**：每个头都有自己的 K/V，8 个头就有 8 组。
- **MQA（多查询注意力）**：所有头共用 1 组 K/V。
- **GQA（分组查询注意力）**：折中方案，把头分成 g 组，每组共用 1 组 K/V。

这里 g=2，即 2 组，每组 8÷2=**4 个头**共享一组 K/V。B 选项说的是 g=4 的情形，所以错误。GQA 的好处是 KV Cache 变小，推理更快。

### 3. 缩放点积注意力与点积注意力的区别（键向量维度为 d_k）：
- A. 点积结果乘以 d_k
- B. 点积结果除以 d_k
- C. 点积结果除以 √d_k
- D. 点积结果乘以 √d_k

**答案：C**

**详解：** 公式为：Attention = softmax(QKᵀ / √d_k) · V

为什么要除以 √d_k？
- 当 d_k 很大时，点积的数值会变得很大。
- softmax 遇到很大的数会变得"极端"（几乎只有一个位置是 1，其余是 0），梯度接近 0，模型很难训练。
- 假设 Q、K 每个元素均值为 0、方差为 1，则点积的方差是 d_k，标准差是 √d_k，所以除以 √d_k 刚好把方差拉回 1。

### 4. 算法 A 复杂度 O(nk)，算法 B 复杂度 O(n log(n)·k)，以下正确的是：
- A. 对相同的 n 和 k，A 的运行耗时比 B 短
- B. 当 k 不变而 n 变大时，A 的运行耗时增长速度比 B 慢
- C. 对相同的 n 和 k，A 的结果精度比 B 高
- D. 当 n 不变而 k 变大时，A 的运行耗时与 B 保持一致

**答案：B**

**详解：** 大 O 描述的是**增长趋势**，不是具体耗时。
- A 错：大 O 会忽略常数系数，具体的 n、k 下，B 说不定反而更快。
- **B 对**：k 固定时，A 约按 n 增长，B 约按 n·log n 增长。log n 会随 n 变大，所以 B 增长得更快，A 更慢。
- C 错：时间复杂度和结果精度没有关系。
- D 错：虽然两者都与 k 成线性关系，但 B 多了一个 log n 因子，并不"一致"。

### 5. 多模态 Transformer 中，视觉输入被分块（patch）处理，哪项正确？
- A. 分块嵌入与文本嵌入维度对齐
- B. 分块大小不影响模型性能
- C. 分块数量与模型参数量无关
- D. 分块仅适用于卷积神经网络

**答案：A**

**详解：** ViT（视觉 Transformer）把图片切成许多小方块（patch），每个方块展平后通过线性层映射成一个向量，相当于图像里的"单词"。要和文本 token 一起送进同一个 Transformer，这些向量的维度必须和文本嵌入**对齐**。
- B 错：patch 大小决定了细节程度和序列长度，会影响性能。
- C 错：比如 patch 嵌入层的输入维度就由 patch 大小决定，patch 数量也影响位置编码等。
- D 错：分块正是 ViT 的标志性做法，ViT 并不是卷积网络。

### 6. A∈ℝ³ˣ³ 是实对称正定矩阵，哪种分解一定存在且唯一？
- A. LU分解
- B. QR分解
- C. 奇异值分解（SVD）
- D. Cholesky分解 A=LLᵀ

**答案：D**

**详解：** Cholesky 分解就是专门为**对称正定矩阵**设计的：A = L·Lᵀ，其中 L 是下三角矩阵（要求 L 对角线元素为正时，分解唯一）。
- LU：一般情况可能需要换行（主元选取），不是这道题想要的"一定存在且唯一"。
- QR：存在，但**不唯一**（Q 的列向量符号可以翻转）。
- SVD：存在，但 U、V **不唯一**（符号、奇异值重复时都有自由度）。

### 7. TP=80, FP=20, TN=180, FN=20，求 F1-score：
- A. 0.80
- B. 0.83
- C. 0.85
- D. 0.77

**答案：A**

**详解：**
- 精确率 Precision = TP / (TP + FP) = 80 / 100 = 0.8（预测为正的样本中，真正为正的比例）
- 召回率 Recall = TP / (TP + FN) = 80 / 100 = 0.8（所有真正为正的样本中，被找出来的比例）
- F1 = 2 × P × R / (P + R) = 2 × 0.8 × 0.8 / 1.6 = **0.80**

注意：TN 在 F1 的计算中用不到。

### 8. 交叉熵损失函数通常用于？
- A. 增加模型的泛化能力
- B. 无监督学习中优化数据分布
- C. 回归任务中衡量预测值与真实值的差异
- D. 分类任务中衡量预测概率与真实标签的差异

**答案：D**

**详解：** 分类模型输出的是概率（比如"90% 是猫"）。交叉熵衡量这个概率和真实标签差多远：如果正确类别的概率很低，损失就很大。回归任务（预测数值）一般用 MSE、MAE，那是 C 选项的陷阱。

### 9. 哪种情况最可能表明问题病态？
- A. 求解线性方程组时，系数矩阵的行列式值接近 0
- B. 数值积分时，步长过大导致截断误差增大
- C. 牛顿迭代法求根时，初值选择不当导致收敛变慢
- D. 浮点数运算时，舍入误差累积导致结果偏离真值

**答案：A**

**详解：** "病态"是**问题本身**的性质：输入的微小扰动会让输出剧烈变化。系数矩阵行列式接近 0，说明矩阵接近奇异，系数或右端项稍有变动，解就会剧烈变化。
B、C、D 都是**算法或计算过程**的问题（步长、初值、舍入误差），不是问题本身对扰动的敏感性。（严格来说，衡量病态的精确指标是"条件数"，但本题 A 最贴切。）

### 10. 下雨概率 0.4，刮风概率 0.3，两者独立，既下雨又刮风的概率？
- A. 0.5
- B. 0.12
- C. 0.1
- D. 0.7

**答案：B**

**详解：** 独立事件同时发生的概率等于各自概率相乘：P(A且B) = 0.4 × 0.3 = **0.12**。

### 11. 3 阶矩阵 A 满足 A* = Aᵀ，且 a₁₁、a₁₂、a₁₃ 是三个相等的正数，则 a₁₁ 为？
- A. √3/3
- B. √3
- C. 1/3
- D. 3

**答案：A**

> **说明：** 原题文字有误。标准题目中，A* 是 A 的**伴随矩阵**，Aᵀ 是 A 的**转置**。下面按标准题解答。

**详解：**
1. 先记住一个公式：A·A* = |A|·I。
2. 因为 A* = Aᵀ，所以 A·Aᵀ = |A|·I。
3. 对 A* = Aᵀ 两边取行列式：3 阶矩阵有 |A*| = |A|²，而 |Aᵀ| = |A|，所以 |A|² = |A|，即 |A| = 0 或 1。
4. A·Aᵀ 的对角线元素是 A 每一行各元素的平方和。第一行元素都是正数，所以平方和 > 0，因此 |A| ≠ 0，即 |A| = 1，于是 A·Aᵀ = I。
5. 第一行平方和为 1：a₁₁² + a₁₁² + a₁₁² = 1，即 3a₁₁² = 1，又 a₁₁ > 0，所以 a₁₁ = **√3/3**。

### 12. 逻辑回归使用的损失函数是？
- A. RMSE
- B. MAE
- C. MSE
- D. 交叉熵损失函数

**答案：D**

**详解：** 逻辑回归通过 sigmoid 函数输出一个概率，用于二分类。配套的损失函数是交叉熵（也叫对数损失 log loss）。RMSE、MAE、MSE 都是回归任务的损失函数。

### 13. θ̂₁、θ̂₂ 均是 θ 的无偏估计量，满足什么条件称 θ̂₁ 比 θ̂₂ 更有效？
- A. D(θ̂₁) ≤ D(θ̂₂)
- B. MSE(θ̂₁) < MSE(θ̂₂)
- C. D(θ̂₁) > D(θ̂₂)
- D. E|θ̂₁| < E|θ̂₂|

**答案：A**

**详解：** "无偏"表示估计量平均来说是准确的。在两个都无偏的估计量里，**方差更小**的那个更稳定，称为**更有效**。这是教材中的标准定义（D 表示方差）。
- C 恰好反了。
- D 是绝对值的期望，和有效性无关。
- B 有迷惑性：对无偏估计量，MSE 就等于方差，思想相近，但标准定义用的是方差，所以选 A。

### 14. 逻辑回归的输出通常解释为哪种概率？
- A. 样本属于正类别的概率
- B. 输入特征的概率
- C. 样本属于负类别的概率
- D. 模型参数的概率

**答案：A**

**详解：** sigmoid 的输出是 P(y=1 | x)，即样本属于**正类**的概率。负类的概率则是 1 减去它。按惯例，输出对应的是正类。

### 15. 关于先验概率和后验概率，正确的是：
- A. 先验概率是已知条件概率后的修正结果
- B. 先验概率是未考虑新信息前的初始概率
- C. 后验概率可以大于 1
- D. 后验概率必须通过贝叶斯定理计算

**答案：B**

**详解：** 用天气预报来类比：
- **先验概率**：看到新证据之前，你原有的判断（比如"明天下雨的概率是 30%"）。
- **后验概率**：看到新证据后修正的概率（比如"看到乌云后，下雨的概率变成 70%"）。

A 把先验和后验说反了。C 错，因为任何概率都不超过 1。D 错，因为后验概率不是"必须"用贝叶斯定理，有时可以直接估计或用其他方法得到。

## 二、多选题

### 16. 避免过拟合的正则化方法包括？
- A. Dropout
- B. L1 正则（Lasso）
- C. L2 正则（Ridge）
- D. 交叉验证

**答案：ABC**

**详解：** "过拟合"就是模型把训练数据背下来了，换新数据就表现很差。
- **Dropout**：训练时随机"关掉"一部分神经元，防止模型过度依赖某些节点。
- **L1 正则**：惩罚权重的绝对值，能让很多权重变成 0（得到稀疏模型）。
- **L2 正则**：惩罚权重的平方，让权重变小、模型更平滑。
- **交叉验证**：它是**评估模型、选择超参数**的方法，用来发现过拟合，本身并不是正则化手段，所以不选 D。

### 17. 政务报告生成场景，一次生成多个候选报告，关于 LLM 推理生成策略，正确的有？
- A. 贪心搜索在每一步随机采样，因此能自然生成多个不同候选
- B. 需确保文本包含"乡村振兴""数字经济"等关键词，可采用带约束的束搜索
- C. 为增强差异性，使用较低的温度参数，让模型探索低概率词
- D. 采用 top-p 采样，在保证流畅的同时引入适度随机性，提升多样性

**答案：BD**

**详解：**
- A 错：贪心搜索每一步都选**概率最大**的词，结果是确定的，每次都一样，不是随机采样。
- **B 对**：Constrained Beam Search 可以强制要求输出包含指定词汇。
- C 错：温度**越低**，模型越保守、越倾向高概率词；想要更有创造性应**提高**温度。
- **D 对**：top-p（核采样）只在累计概率达到 p 的候选词里随机选，既流畅又有多样性。

### 18. 下列哪些项是马尔可夫链的特征？
- A. 所有状态之间都可以互相到达
- B. 下一状态仅依赖于当前状态
- C. 状态空间可以是连续的
- D. 状态转移矩阵是固定的

**答案：BCD**

**详解：**
- **B 对**：这是马尔可夫性（无记忆性）的核心，"未来只取决于现在，与过去无关"。
- A 错：状态之间能否互相到达叫"不可约"，只是某些马尔可夫链的性质，并非所有马尔可夫链都具备。
- **C 对**：广义的马尔可夫链/过程的状态空间可以是连续的（比如 MCMC 采样中的连续状态）。
- **D 对**：通常讨论的（时齐）马尔可夫链，转移概率不随时间变化，转移矩阵是固定的。

> 提示：C、D 在不同教材里的口径略有差异，但 B 是最核心、一定要选的。

### 19. 推荐系统中用嵌入表示用户和商品，N、M 都比较小，哪些操作能提升模型效果？
已知 r̂ᵢⱼ = Uᵢ·Vⱼᵀ，U∈ℝ^(N×d)，V∈ℝ^(M×d)。
- A. 将嵌入维度 d 从 16 增加到 256
- B. 对 Uᵢ 和 Vⱼ 做 L2 归一化
- C. 用商品 ID 的独热编码直接作为输入特征
- D. 添加有效的负采样损失函数

**答案：BD**

**详解：**
- A 错：N、M 很小，说明数据量很少，把维度加到 256 会让参数过多，更容易**过拟合**。
- **B 对**：L2 归一化后点积变成余弦相似度，不受向量长度影响，训练更稳定，也能抑制数值过大。
- C 错：直接用独热编码相当于绕开了"嵌入"，没有学到稠密的语义表示，也不会提升效果。
- **D 对**：负采样损失既拉近用户和喜欢的商品，又推远用户和没交互过的商品，能让模型学到区分度。

### 20. min-max 归一化，数据最大值 2.0050×10⁶，最小值 1.9950×10⁶，关于有效数字，正确的有？
- A. 该类数据原本的有效数字应有 6 位
- B. 归一化后，有效数字下降到 2 位
- C. 计算机浮点数用二进制，因此十进制有效数字不受影响
- D. 减法操作在两个数量级相似时可能导致有效数字位数降低

**答案：D**

**详解：**
- A 错：2.0050 有 **5 位**有效数字（2、0、0、5、0），不是 6 位。
- B 错：min-max 归一化要算 (x − min)/(max − min)。分母 max − min = 0.0100×10⁶ = 1.00×10⁴，只剩 **3 位**有效数字，不是 2 位。
- C 错：不管用二进制还是十进制，数据本身的精度是客观的，相减抵消掉的有效位数会真实地丢失，"不受影响"的说法不对。
- **D 对**：这就是"相近数相减导致有效数字损失"（灾难性抵消）。比如 2.0050 − 1.9950 = 0.0100，前面的数字都抵消了，有效数字从 5 位掉到 3 位。
