# 华为 AI 在线笔试选择题学习笔记（第十二组）

| 主题 | 核心结论 |
| --- | --- |
| 逻辑回归 | Sigmoid 输出是 S 形，但分类概率为 0.5 的决策边界仍是线性超平面。 |

## 2. 题目、答案与解释

### 1. 逻辑回归的决策边界

**题目**：逻辑回归的决策边界是？

- A. 一条 S 形曲线
- B. 特征空间中的超平面 `w^T x+b=0`
- C. 以原点为圆心的超球面
- D. 由核函数决定的非线性曲面

**答案：B。**

**基础知识/解释**：逻辑回归先计算：

```text
z = w^T x + b
p = sigmoid(z)
```

当分类阈值为 `p=0.5` 时：

```text
sigmoid(z) = 0.5  <=>  z = 0
```

所以边界是：

```text
w^T x + b = 0
```

二维中是一条直线，三维中是一个平面，更高维中叫超平面。S 形是 Sigmoid 函数曲线，不是特征空间中的分类边界。

### 2. CUDA 寄存器溢出

**题目**：当 CUDA 内核因寄存器压力过大导致寄存器溢出时，溢出的数据会被存储到哪种内存中？

- A. L1 缓存
- B. 局部内存（Local Memory，由全局内存物理支持）
- C. 常量内存
- D. 共享内存

**答案：B。**

**基础知识/解释**：每个线程可用的寄存器数量有限。若编译器无法把局部变量都放进寄存器，就会发生 register spilling：

```text
寄存器不够 -> 溢出的线程私有数据 -> local memory
```

CUDA 的 local memory 名字中有“local”，但物理上通常位于 global memory，因此访问延迟和带宽代价都比寄存器高很多。

### 3. 固定页 KV Cache 的直接好处

**题目**：采用固定页管理 KV-Cache（页大小固定）在显存碎片严重的场景下，最直接的好处是？

- A. 减少小对象频繁分配导致的碎片与分配开销
- B. 减少碎片对不齐，提高数值精度
- C. 降低显存访问的带宽压力
- D. 降低小对象的内存访问延迟

**答案：A。**

**基础知识/解释**：不同请求的长度不同，连续分配 KV Cache 容易留下无法使用的小内存空洞。固定页管理把内存分成 block：

```text
请求 A -> 页 1、页 9、页 12
请求 B -> 页 2、页 3
```

这样能复用离散空页，减少频繁申请不同大小连续内存带来的碎片和分配开销。

### 4. 长文本生成中的温度调节

**题目**：在长文本生成模型中，关于温度（Temperature）系数下面说法正确的是？

- A. 初始温度 `T=0.4`，随长度递增逐渐增至 `0.8`
- B. 保持温度 `T=0.8`，保证变化量一致
- C. 初始温度 `T=0.8`，随长度递增逐渐降至 `0.4`
- D. 每 1000 Token 随机设置温度 T

**答案：A。**

**基础知识/解释**：温度控制采样随机性：

```text
高温：分布更平，更多样但更容易跑题
低温：分布更尖，更稳定但更保守
```

长文本越往后越容易主题漂移。常见的工程策略是前段用稍高温度保持表达多样性，后段逐步降低温度，提高连贯性和稳定性。因此 C 最合理。

### 5. Decoder-only 的错误说法

**题目**：关于 Decoder-only，下列哪一项说法是错误的？

- A. 常用于文本续写和对话生成
- B. 输入提示和输出文本常被组织为同一连续序列
- C. 必须包含独立编码器才能生成输出
- D. 常见训练思路是根据已有上下文继续预测后续 token

**答案：C。**

**基础知识/解释**：Decoder-only 模型只有 Decoder 堆叠，没有独立 Encoder。训练目标常是自回归语言建模：

```text
P(x_1, x_2, ..., x_n)
= Π P(x_t | x_1, ..., x_(t-1))
```

GPT 类模型就是典型 Decoder-only 架构。

### 6. PPO 截断代理目标

**题目**：在 PPO 中使用截断代理目标函数（clipped surrogate objective）的主要目的是什么？

- A. 使策略梯度估计保持无偏性
- B. 消除价值函数估计带来的偏差
- C. 保证每次策略更新都严格满足 KL 散度约束
- D. 限制策略更新幅度，防止因更新过大导致训练不稳定

**答案：D。**

**基础知识/解释**：PPO 比较新旧策略的概率比值：

```text
r_t(θ) = π_θ(a_t|s_t) / π_old(a_t|s_t)
```

它把过大的变化截断在一定区间附近，避免一次更新让策略变化过猛。它是近似限制更新，而不是严格满足 KL 约束。

### 7. Prompt Tuning / Prefix Tuning

**题目**：关于 Prompt Tuning（或 Prefix Tuning）的描述，正确的是？

- A. 微调整个预训练模型的全部参数
- B. 对模型进行知识蒸馏
- C. 完全冻结模型参数，仅调整输出层
- D. 在输入前添加可学习的连续向量，仅更新这些向量的参数

**答案：D。**

**基础知识/解释**：Prompt/Prefix Tuning 属于参数高效微调（PEFT）：

```text
冻结预训练模型
在输入前插入可学习的虚拟 token / 连续向量
只训练这些新增向量
```

它通常不训练整个模型，也不仅训练输出层。

### 8. 梯度爆炸与权重矩阵

**题目**：梯度爆炸问题通常与权重矩阵的什么性质相关？

- A. 特征值过大
- B. 行列式为 0
- C. 秩为 1
- D. 非对称性

**答案：A。**

**基础知识/解释**：深层网络/RNN 的梯度包含许多矩阵和导数的连乘。若这些变换的谱半径或特征值尺度持续大于 1，连乘可能快速放大：

```text
1.2^50 -> 非常大
```

这会导致梯度爆炸。

### 9. 二项分布参数的 MLE

**题目**：设样本 `X_1, X_2, ..., X_n` 来自二项分布 `B(m,p)`，其中 m 已知、p 未知，则 p 的最大似然估计值为？

- A. `S²/m`
- B. `X_bar`
- C. `X_bar/m`
- D. `S²`

**答案：C，`X_bar/m`。**

**基础知识/解释**：每个 `X_i` 表示 m 次试验里的成功次数，因此：

```text
E(X_i) = mp
```

样本均值 `X_bar` 估计的是 `mp`，所以：

```text
p_hat = X_bar / m
```

### 10. Attention 矩阵扩展显存倍数

**题目**：将上下文窗口从 4096（4K）扩展到 32768（32K），保持其他条件不变，仅一个 Attention Head 的 `N×N` 打分矩阵显存理论上膨胀多少倍？

- A. 512 倍
- B. 64 倍
- C. 8 倍
- D. 16 倍

**答案：B，64 倍。**

**基础知识/解释**：长度变为：

```text
32768 / 4096 = 8 倍
```

注意力打分矩阵大小为 `N²`，所以：

```text
8² = 64 倍
```

### 11. 缩放点积注意力除以 √d_k

**题目**：在 Transformer 的标准缩放点积注意力中，为什么要除以 `sqrt(d_k)`？

- A. 降低计算复杂度
- B. 避免点积结果过大导致 Softmax 进入饱和区，梯度极小
- C. 对查询和键向量的模长进行归一化
- D. 防止梯度消失，使训练更加稳定

**答案：B。**

**基础知识/解释**：Q、K 维度变大时，点积数值典型范围会变大，Softmax 可能非常尖锐，导致多数梯度接近 0。除以 `sqrt(d_k)` 用于稳定分数尺度。

### 12. PCA 重构矩阵维度

**题目**：中心化矩阵 `X∈R^(N×D)`，投影矩阵 `W∈R^(D×K)`，降维得到 `Z` 后再重构为 `X_hat`。`X_hat` 的维度是多少？

- A. `N×K`
- B. `N×D`
- C. `D×D`
- D. `K×D`

**答案：B，`N×D`。**

**基础知识/解释**：降维：

```text
Z = XW
(N×D)(D×K) = N×K
```

重构：

```text
X_hat = ZW^T
(N×K)(K×D) = N×D
```

### 13. 逻辑回归概率计算

**题目**：某用户停留时长为 10 分钟，逻辑回归斜率为 1.5、截距为 -15。潜在用户概率是多少？

- A. 0.4
- B. 0.5
- C. 1
- D. 0.9

**答案：B，0.5。**

**基础知识/解释**：

```text
z = 1.5×10 - 15 = 0
sigmoid(0) = 1 / (1 + e^0) = 0.5
```

### 14. SFT 后过度道歉

**题目**：某模型经过 SFT 后，出现频繁“抱歉，作为一个 AI 助手……”的过度道歉现象，最可能的原因是什么？

- A. FP16 导致数值精度损失
- B. SFT 学习率过高
- C. 参数量太小
- D. 训练数据中包含大量安全审核后的样本，模型学习到了保守回答风格

**答案：D。**

**基础知识/解释**：SFT 会模仿训练样本中的回复风格。若安全审核数据中存在大量拒答、免责声明、道歉模板，模型可能把这种保守表达当作高频、正确的回答方式。

### 15. 贝叶斯网络链式结构

**题目**：贝叶斯网络链式结构 `A→B→C` 中，在 B 已被观测时，A 与 C 的关系是？

- A. A 与 C 完全相关
- B. A 与 C 条件独立（给定 B）
- C. A 与 C 边缘独立
- D. A 与 C 的关系与 B 是否被观测无关

**答案：B。**

**基础知识/解释**：链结构中，B 是 A 到 C 的唯一通路。给定 B 后，这条路径被阻断：

```text
A ⟂ C | B
```

未给定 B 时，A 和 C 一般相关。

### 16. KV Cache 机制（多选）

**题目**：关于 KV 缓存机制在大模型推理中的作用，以下说法正确的有？

- A. 使用 KV 缓存后，自回归生成的总注意力计算复杂度可从 O(n³) 降低到 O(n²)
- B. KV 缓存存储的是历史 token 的 Key 和 Value 向量
- C. Query 向量不会被缓存，因为每个新 token 的 Query 需要重新计算
- D. KV 缓存大小与序列长度、批大小、层数、头数成正比

**答案：A、B、C、D。**

**基础知识/解释**：若每步都重新对完整前缀计算注意力，总生成过程会重复计算历史部分，累积代价可达 `O(n³)`；使用 KV Cache 后，每步只新增当前 token 的 K/V，总注意力相关计算可降到 `O(n²)`。

缓存大小的典型主项：

```text
batch × sequence_length × layers × heads × head_dim × 2(K,V)
```

### 17. 描述统计量（多选）

**题目**：对于数据集 `3, 4, 5, 3, 8, 7`，以下描述正确的是？

- A. 中位数 = 4
- B. 方差 = 11/3
- C. 平均数 = 5
- D. 众数 = 3

**答案：C、D。**

**基础知识/解释**：排序后：

```text
3, 3, 4, 5, 7, 8
```

```text
平均数 = (3+4+5+3+8+7)/6 = 30/6 = 5
中位数 = (4+5)/2 = 4.5
众数 = 3
```

无论按总体方差还是样本方差计算，结果都不是 `11/3`。

### 18. 工业级特征处理与选择（多选）

**题目**：关于嵌入式方法、PCA、排列重要性和特征哈希，下列说法正确的有？

- A. Lasso 等嵌入式方法可在损失函数中通过 L1 正则实现特征选择；传统过滤式方法通常不直接考虑特征组合效应
- B. PCA 前必须进行标准化
- C. 强相关特征组中，Permutation Importance 往往低估单个特征的重要性
- D. 特征哈希可固定高基数类别维度，但会带来哈希冲突，可视为不可控的特征混叠/噪声

**答案：A、B,C、D。**

**基础知识/解释**：

- Lasso 用 L1 正则让部分权重变为 0，从而完成嵌入式特征选择；
- PCA 前常标准化，但“必须”过于绝对：若特征同量纲，或量纲本身就有意义，未必应标准化；
- 置换一个强相关特征后，模型仍可利用与它相近的特征，因此性能下降不明显；
- Hashing Trick 节省维度，但不同类别可能映射到同一位置，产生冲突。

### 19. INT8 量化精度影响因素（多选）

**题目**：在 INT8 量化部署中，以下哪些因素会影响量化后模型的精度？

- A. 校准集分布是否接近真实数据
- B. 激活范围统计是否稳定
- C. 是否存在离群值导致 scale 不合理
- D. 是否使用了浮点数进行训练

**答案：A、B、C。**

**基础知识/解释**：PTQ 的 scale/zero point 常依赖校准集。校准数据若不代表真实输入，或激活范围统计不稳定、被极端离群值拉大，INT8 的有效刻度就会被浪费，量化误差增加。是否“使用浮点训练”不是决定部署量化误差的直接因素；更相关的是是否做 QAT、校准方案和量化粒度。

### 20. Prefill 与 Decode（多选）

**题目**：关于模型推理中 Prefill 和 Decode 阶段的区别，下列说法正确的有？

- A. Prefill 计算并缓存 KV Cache，Decode 复用 KV Cache，仅新增计算当前 token 的 K/V
- B. Prefill 一次性处理所有输入 token，Decode 逐 token 处理
- C. Prefill 和 Decode 存在于所有模型推理
- D. Prefill 耗时与输入 token 数量正相关，Decode 耗时与生成 token 数量正相关

**答案：A、B、D。**

**基础知识/解释**：Prefill/Decode 是自回归生成模型（例如 Decoder-only LLM）中特有的常用划分：

```text
Prompt -> Prefill -> 初始化 KV Cache
逐个生成 -> Decode -> 复用历史 KV Cache
```

分类模型、普通回归模型等一次前向推理结束的模型，并没有这种逐 token Decode 阶段，因此 C 错。
