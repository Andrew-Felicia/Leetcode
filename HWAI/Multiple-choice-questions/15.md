# 华为 AI 在线笔试选择题学习笔记（第十五组）

## 1. 总结

| 主题 | 核心结论 |
| --- | --- |
| DDP 与 TP | DDP 用 All-Reduce 聚合梯度；TP 在同一层内按矩阵维度切分权重。 |
| K-Means 与线性映射 | K-Means 必须指定 K；`(n×d)(d×k)=n×k`。 |
| RAG 检索 | MIPS 按点积最大召回；长上下文评测需要 needle/multi-hop，防止模型靠猜。 |
| 统计 | 正态均值 MLE 为样本均值；互信息可捕获复杂非线性依赖。 |
| 量化与线性代数 | SmoothQuant 将激活尺度迁移至权重；零空间是所有满足 Ax=0 的解。 |
| 数值方法 | Newton-Schulz 误差平方迭代，具有二次收敛；插值点处必精确，但高次插值不总更好。 |

## 2. 题目、答案与解释

### 1. DDP 的梯度通信

**题目**：标准数据并行 DDP 中，每个 GPU 独立计算梯度后，为保持模型权重一致，每次迭代需要执行什么通信操作？

- A. Broadcast
- B. All-Gather
- C. Send/Recv
- D. All-Reduce

**答案：D，All-Reduce。**

**基础知识/解释**：每张 GPU 对不同 mini-batch 计算本地梯度。All-Reduce 会把所有 GPU 的梯度求和或求平均，并将相同结果发送回每张卡：

```text
GPU 0 梯度 \ 
GPU 1 梯度  -> All-Reduce -> 每张 GPU 得到相同的聚合梯度
GPU 2 梯度 /
```

各卡用同一梯度更新，因此权重保持一致。

### 2. K-Means 必须指定的参数

**题目**：使用 K-Means 聚类之前，必须预先指定的关键参数是？

- A. 初始坐标
- B. 聚类数量 K
- C. 密度阈值
- D. 学习率

**答案：B。**

**基础知识/解释**：K-Means 的 K 就是要分成多少个簇。初始中心可以随机、使用 K-Means++，或像机考题一样指定前 K 个点；但不管初始化策略如何，簇数量 K 必须提前知道。

### 3. 线性映射后的矩阵维度

**题目**：`X∈R^(n×d)`，`W∈R^(d×k)`，线性映射 `Z=XW` 后，Z 的维度是？

- A. `n×d`
- B. `n×k`
- C. `d×k`
- D. `k×n`

**答案：B，`n×k`。**

**基础知识/解释**：矩阵乘法规则：

```text
(n × d) × (d × k) = n × k
```

中间维度 d 相同，会被消去。

### 4. Softmax 相等输入

**题目**：输入 `[4,4,4]` 经过标准 Softmax 后输出什么？

- A. `[1,1,1]`
- B. `[0.5,0.5,0.5]`
- C. `[0,0,1]`
- D. `[1/3,1/3,1/3]`

**答案：D。**

**基础知识/解释**：

```text
softmax(z_i) = exp(z_i) / Σ exp(z_j)
```

三个输入相等，所以三个指数值相等，每个概率都是总和的三分之一。

### 5. K-Means 的样本分配准则

**题目**：K-Means 迭代中，衡量样本点归属的核心准则是？

- A. 到质心的欧氏距离最小
- B. 密度最大
- C. 余弦相似度
- D. 连通性

**答案：A。**

**基础知识/解释**：标准 K-Means 的分配步骤是：

```text
样本 x 分给 argmin_j ||x - center_j||² 的簇
```

因为平方根不影响大小比较，也常使用平方欧氏距离。

### 6. 用于减少维度并保留主要信息的操作

**题目**：特征工程中，通常用于减少特征维度并保留主要信息的操作是？

- A. 特征降维
- B. 特征选择
- C. 特征编码
- D. 特征缩放

**答案：A。**

**基础知识/解释**：降维如 PCA 会把原始高维特征投影到更低维的主成分空间，尽可能保留主要方差信息。特征选择是保留原特征的一部分；编码和缩放通常不以减少维数为核心目标。

### 7. MIPS 检索

**题目**：查询 `q=[1,2]^T`，文档向量 `d1=[2,1]^T`、`d2=[-1,2]^T`。使用最大内积搜索 MIPS，会召回哪个文档、得分多少？

- A. d1，得分 4
- B. d2，得分 4
- C. d2，得分 3
- D. d1，得分 5

**答案：A。**

**基础知识/解释**：

```text
q · d1 = 1×2 + 2×1 = 4
q · d2 = 1×(-1) + 2×2 = 3
```

MIPS 取最大内积，因此召回 d1，得分 4。

### 8. 正态总体均值的 MLE 条件

**题目**：正态总体 `N(μ,σ²)` 中 μ 未知、σ² 已知，使似然函数最大时，μ 满足什么条件？

- A. `Σ(X_i-μ)=σ²`
- B. `Σ(X_i-μ)²=0`
- C. `Σ(X_i-μ)²=nσ²`
- D. `Σ(X_i-μ)=0`

**答案：D。**

**基础知识/解释**：最大化似然等价于最小化：

```text
Σ(X_i - μ)²
```

对 μ 求导并令其为 0：

```text
Σ(X_i - μ) = 0
```

解得 `μ_hat = X_bar`。

### 9. R² 的正确描述

**题目**：线性回归中关于 R²（决定系数），下列说法正确的是？

- A. 增加无关特征会使 R² 降低
- B. R² 是常用拟合优度指标；含截距 OLS 在训练集上通常位于 [0,1]
- C. R² 可用于比较不同数据集上模型优劣
- D. R² 越接近 0 拟合越好

**答案：B。**

**基础知识/解释**：

```text
R² = 1 - SSE / SST
```

训练集上增加特征时，普通 R² 通常不会下降，即使特征无关。R² 越接近 1，一般表示拟合越好；不同数据集的目标变量尺度和难度不同，不能只用 R² 直接横向比较。

### 10. 长上下文能力的高质量评测

**题目**：评测长上下文能力时，为避免模型靠猜测/泛化蒙对，常见高质量题型设计是？

- A. 长文埋入多个相似实体或数值，要求定位并跨段整合（needle/multi-hop）
- B. 询问大意
- C. 短文重复 10 次
- D. 测能输出多少 token

**答案：A。**

**基础知识/解释**：高质量长上下文题应要求模型：

```text
找到关键信息
区分相似干扰项
把多处信息组合推理
```

这样才能检查模型是否真正使用了长上下文。

### 11. 非线性特征重要性

**题目**：X 与 Y 可能存在 `Y=X²` 或周期关系，且 X 不服从正态分布，哪种方法最适合评估关联性？

- A. Spearman 等级相关
- B. ANOVA F-value
- C. Pearson 相关
- D. 互信息 MI

**答案：D。**

**基础知识/解释**：Pearson、Spearman 主要适合线性或单调关系。`Y=X²` 不是单调关系，Pearson 可能接近 0。互信息衡量“知道 X 后，Y 的不确定性减少多少”，能捕获更一般的非线性依赖。

### 12. SVD 无法直接应用的场景

**题目**：矩阵奇异值分解 SVD 无法直接应用于以下哪个场景？

- A. 图像去噪
- B. 决策树分类
- C. 文本主题建模
- D. 推荐系统评分矩阵降维

**答案：B。**

**基础知识/解释**：SVD 是矩阵分解工具，可用于低秩近似、降维、去噪、推荐。决策树分类的核心是按特征阈值递归分裂，不能直接由 SVD 完成。

### 13. SmoothQuant 的核心思想

**题目**：SmoothQuant 是常用大模型量化方法，其核心思想是？

- A. 将权重 scale 转移到 activation
- B. 将 activation scale 转移到权重
- C. 减少层数
- D. 减少 batch

**答案：B。**

**基础知识/解释**：对于：

```text
Y = XW
```

SmoothQuant 使用通道缩放 `s`：

```text
Y = (X diag(s)^(-1)) (diag(s) W)
```

它把部分激活异常值尺度迁移到权重中，让 activation 更平滑、更容易量化。

### 14. 实矩阵的零空间

**题目**：实数矩阵 A 的零空间是指？

- A. 与列空间正交的空间
- B. 列向量张成的空间
- C. 满足 `Ax=0` 的所有 x 构成的空间
- D. 行向量张成的空间

**答案：C。**

**基础知识/解释**：零空间定义：

```text
Null(A) = {x | Ax = 0}
```

补充：A 的零空间确实与 A 的行空间正交；而 A 的左零空间才与 A 的列空间正交，因此 A 不是准确描述。

### 15. 神经网络相对线性模型的优势

**题目**：神经网络相比线性模型的优势在于？

- A. 参数更少
- B. 不需要激活函数
- C. 计算更简单
- D. 可以学习非线性关系

**答案：D。**

**基础知识/解释**：激活函数引入非线性，多个网络层可构建复杂决策边界。没有激活函数时，多层线性层仍可合并为一层线性变换。

### 16. Newton-Schulz 求逆迭代（多选）

**题目**：Newton-Schulz 迭代 `X_(k+1)=X_k(2I-AX_k)`，定义 `E_k=I-AX_k`。哪些说法正确？

- A. 若存在相容矩阵范数使 `||E_0||<1`，迭代二次收敛，且 `||E_k||<=||E_0||^(2^k)`
- B. 若谱半径 `ρ(E_0)<1`，迭代收敛到 `A^-1`
- C. 若 A 可逆，迭代对初值 X0 不敏感
- D. `E_(k+1)=E_k³`，收敛阶为 3

**答案：A、B。**

**基础知识/解释**：代入定义可得：

```text
E_(k+1)
= I - AX_k(2I-AX_k)
= (I-AX_k)²
= E_k²
```

因此误差是平方迭代，呈二次收敛。初值必须足够好，否则不保证收敛；D 的三次方错误。

### 17. 自适应学习率优化器（多选）

**题目**：哪些优化器属于按参数/维度自适应缩放学习率的方法？

- A. SGD
- B. Adam
- C. AdamW
- D. RMSprop

**答案：B、C、D。**

**基础知识/解释**：Adam、AdamW、RMSprop 都会根据梯度平方的统计量，对不同参数使用不同有效步长。普通 SGD 通常所有参数共享同一个全局学习率。

### 18. 神经网络层的描述（多选）

**题目**：关于神经网络的层，哪些说法正确？

- A. 输入层通常只传递数据
- B. 隐藏层可以有多个
- C. 输出层神经元数通常由任务决定，例如类别数
- D. 所有层神经元数必须相同

**答案：A、B、C。**

**基础知识/解释**：输入层通常不做可学习映射；网络可有很多隐藏层；输出层宽度取决于任务。不同层宽度可以不同，例如 `784 -> 256 -> 128 -> 10`。

### 19. 期望与方差性质（多选）

**题目**：X、Y 是随机变量，a、b、c 是常数，哪些说法正确？

- A. `E[XY]=E[X]E[Y]` 总成立
- B. `Var(X)=E[X²]-(E[X])²` 恒成立
- C. `E[aX+bY+c]=aE[X]+bE[Y]+c`
- D. `E[X²] >= (E[X])²`

**答案：B、C、D。**

**基础知识/解释**：

```text
Var(X) = E[(X-E[X])²] = E[X²]-(E[X])² >= 0
```

由方差非负可得到 D。A 需要 X、Y 独立才成立，不是总成立。

### 20. 插值多项式（多选）

**题目**：关于插值多项式的说法，哪些正确？

- A. 插值多项式在节点处一定等于给定函数值
- B. 给定 n+1 个互异节点，次数不超过 n 的插值多项式存在且唯一
- C. 高次插值多项式通常总能更好逼近原函数
- D. Lagrange 与 Newton 构造的插值多项式相同

**答案：A、B、D。**

**基础知识/解释**：插值多项式的定义就是经过所有给定节点。互异节点对应的低于等于 n 次插值多项式唯一。Lagrange 和 Newton 只是同一多项式的两种表达方式。

C 错：高次等距插值可能在端点振荡加剧，即 Runge 现象。
