# 华为 AI 在线笔试选择题学习笔记（第六组）

## 1. 总结

这一组题覆盖了几个常见主题：概率统计、线性代数、优化、卷积网络、Transformer 注意力，以及大模型训练并行。

| 主题 | 这组最重要的结论 |
| --- | --- |
| 图像/向量相似度 | 亮度整体变化主要改变向量长度；余弦相似度更关注方向。 |
| 概率统计 | MLE 是“让已观察数据出现得最可能”的参数；贝叶斯公式用于反推条件概率。 |
| 神经网络优化 | 多层链式求导中，许多小于 1 的导数相乘会造成梯度消失；Momentum 用历史梯度减少震荡。 |
| Attention | GQA 让多个 Query 头共享较少的 Key/Value 头；MQA 是只有一组 KV 头的极端情形。 |
| 线性代数 | 向量空间需要零向量、加法封闭、数乘封闭；对角矩阵的行列式是对角线元素之积。 |
| 大模型系统 | 3D 并行把数据并行、流水线并行、张量并行组合，以突破单卡容量和通信瓶颈。 |

## 2. 题目、答案与解释

### 1. 亮度不同但内容相似的图像

**题目**：比较两张亮度差异较大但内容相似的图片时，哪种相似度度量更合适？

- A. 余弦相似度
- B. 曼哈顿距离
- C. 汉明距离
- D. 欧氏距离

**答案：A，余弦相似度。**

**基础知识/解释**：把图片或图片特征看成向量 `x`。若一张图只是整体变亮，常可近似写成 `y = a x`（`a > 0`）。余弦相似度为：

```text
cos(x, y) = (x · y) / (||x|| ||y||)
```

当 `y = a x` 时，余弦相似度仍为 1，因此它对整体长度/亮度变化相对不敏感。欧氏距离、曼哈顿距离会直接受到数值大小变化影响；汉明距离主要适合二进制编码。

### 2. 灯泡合格率的最大似然估计

**题目**：抽检 5 个灯泡，寿命为 `[2年, 0年, 3年, 0年, 4年]`。合格品寿命服从指数分布，不合格品寿命为 0，合格率 `p` 的最大似然估计是多少？

- A. 0.7
- B. 0.6
- C. 0.5
- D. 0.4

**答案：B，0.6。**

**基础知识/解释**：寿命大于 0 的 3 个灯泡是合格品；寿命为 0 的 2 个是非合格品。因此关于 `p` 的似然部分为：

```text
L(p) ∝ p³(1-p)²
```

这种二项模型的 MLE 就是样本中的合格比例：

```text
p_hat = 3 / 5 = 0.6
```

指数分布的具体寿命值会影响指数分布自身的参数，但题目只问合格率 `p`。

### 3. 贝叶斯定理

**题目**：贝叶斯定理的正确表达式是哪一个？

- A. `P(A|B)=P(B|A)·P(A)/P(B)`
- B. `P(A|B)=P(B|A)/P(B)`
- C. `P(A|B)=P(A)·P(B)/P(B|A)`
- D. `P(A|B)=P(A∩B)+P(B)`

**答案：A。**

**基础知识/解释**：

```text
P(A | B) = P(B | A) × P(A) / P(B)
```

它表达“看到证据 B 后，事件 A 的概率如何更新”。其中 `P(A)` 是先验概率，`P(B|A)` 是在 A 成立时看到 B 的概率，`P(A|B)` 是后验概率。

### 4. PCA 保留多少主成分

**题目**：使用 PCA 降维时，通常依据哪个指标选择保留的主成分数量？

- A. 后续模型准确率
- B. 原始特征数量
- C. 累计解释方差比例
- D. 样本数量

**答案：C，累计解释方差比例。**

**基础知识/解释**：PCA 会按“能解释的数据方差”从大到小排列主成分。通常选取最少的前 `r` 个主成分，使：

```text
(前 r 个特征值之和) / (全部特征值之和) ≥ 阈值
```

常见阈值是 90%、95% 或 99%。后续模型准确率也可以作为实践验证指标，但 PCA 本身最常用的选取依据是累计解释方差比例。

### 5. 损失不降且梯度趋近 0

**题目**：神经网络训练中损失几乎不下降，梯度在多层传递后逐渐趋近于 0，最合理的分析是什么？

- A. 数据集过小，与反向传播无关
- B. 梯度爆炸
- C. 学习率过高，应继续调大
- D. 梯度消失，常见于深层网络或饱和激活函数

**答案：D。**

**基础知识/解释**：反向传播要通过链式法则把梯度从后层传向前层。若多层导数不断相乘，且它们大多小于 1，结果会越来越接近 0。早期层几乎得不到更新，训练停滞，这就是梯度消失。Sigmoid、Tanh 在饱和区导数很小，深层网络中尤其容易出现。

### 6. 激活函数导数长期小于 1

**题目**：反向传播中，若激活函数导数长期小于 1，最可能出现哪种数值问题？

- A. 梯度爆炸
- B. 维度崩溃
- C. 数值上溢
- D. 梯度消失

**答案：D，梯度消失。**

**基础知识/解释**：例如 20 层网络中，如果每层局部导数都约为 `0.5`，则梯度中会出现：

```text
0.5²⁰ ≈ 0.000001
```

它非常小。相反，如果大量导数或权重相关项持续大于 1，才更容易出现梯度爆炸。

### 7. 向量空间的核心条件

**题目**：判断一个集合是否为向量空间时，以下哪项概括了必须满足的核心条件？

- A. 所有向量的欧氏长度相等
- B. 只需对向量加法封闭
- C. 包含零向量，并且对加法和数乘封闭
- D. 只需对数乘封闭

**答案：C。**

**基础知识/解释**：向量空间完整定义还有结合律、分配律等公理；但在选择题里，最核心的判断点是：

```text
0 在集合中
u, v 在集合中 => u + v 在集合中
u 在集合中、标量 a => a u 在集合中
```

例如所有二维向量构成向量空间；“长度恰好等于 1 的二维向量”不构成向量空间，因为两个单位向量相加后长度通常不再是 1。

### 8. Momentum 的主要作用

**题目**：与普通 SGD 相比，Momentum 的主要作用是什么？

- A. 保证找到全局最优解
- B. 不再需要学习率
- C. 利用历史梯度减少震荡并加快收敛
- D. 自动消除训练数据噪声

**答案：C。**

**基础知识/解释**：普通 SGD 只使用当前梯度。Momentum 额外维护“速度” `v`：

```text
v = βv + gradient
w = w - learning_rate × v
```

连续方向一致时，历史梯度会累积，让模型更快前进；在左右反复震荡的方向，梯度会部分抵消。它仍需要学习率，也不保证全局最优。

### 9. GQA 与 MHA 的区别

**题目**：分组查询注意力 GQA 相较于多头注意力 MHA 的主要结构变化是什么？

- A. 增加 Value 头维度
- B. 多个 Query 头共享一组 Key、Value 头
- C. 增加 Key、Value 头数量
- D. 减少 Query 头数量

**答案：B。**

**基础知识/解释**：MHA 中每个 Query 头通常有各自的 K、V 头；GQA 保留较多 Query 头，但让一组 Query 头共享同一个 KV 组：

```text
MHA: Q1-K1-V1, Q2-K2-V2, Q3-K3-V3, Q4-K4-V4
GQA: Q1,Q2 -> K1,V1     Q3,Q4 -> K2,V2
```

这样仍能保持较丰富的 Query 表达，同时减少 KV Cache 的体积和访问成本。

### 10. 右偏分布的均值、中位数、众数

**题目**：数据分布呈右偏（正偏）时，均值、中位数、众数通常是什么关系？

- A. 均值 < 中位数 < 众数
- B. 均值 > 中位数 > 众数
- C. 无法确定任何关系
- D. 三者相等

**答案：B。**

**基础知识/解释**：右偏表示右侧有长尾，少量非常大的值会把均值拉向右边：

```text
众数  <  中位数  <  均值
```

记忆方法：长尾朝哪边，均值通常就被拉向哪边。

### 11. MQA 对 KV Cache 的影响

**题目**：原模型的 MHA 有 64 个注意力头，改为只有一组 KV 头的 MQA 后，KV Cache 理论上约减少多少倍？

- A. 8 倍
- B. 64 倍
- C. 32 倍
- D. 4 倍

**答案：B，64 倍。**

**基础知识/解释**：KV Cache 为每个 KV 头保存历史 token 的 Key 和 Value。MHA 有 64 组 KV；MQA 只有 1 组 KV。因此忽略其他开销时：

```text
KV Cache 缩减倍数 = 64 / 1 = 64
```

### 12. 卷积输出形状

**题目**：输入图像大小为 `224×224×3`，卷积层含 96 个 `11×11` 卷积核，步长 4、无填充，输出特征图大小是多少？

- A. `55×55×96`
- B. `57×57×96`
- C. `54×54×96`
- D. `56×56×96`

**答案：C，`54×54×96`。**

**基础知识/解释**：无 padding 时，单个空间维度的输出大小：

```text
out = floor((input - kernel) / stride) + 1
    = floor((224 - 11) / 4) + 1
    = floor(53.25) + 1
    = 54
```

96 个卷积核产生 96 个输出通道，所以最终是 `54×54×96`。

### 13. Embedding 的定义

**题目**：Embeddings 的核心定义是什么？

- A. 将离散数据映射到连续的低维向量空间
- B. 将离散数据映射到离散低维空间
- C. 将连续数据映射到离散高维空间
- D. 将连续数据映射到连续高维空间

**答案：A。**

**基础知识/解释**：词、商品 ID、用户 ID、类别标签都是离散符号。Embedding 用一个可学习的连续向量表示它们，例如：

```text
“猫” -> [0.12, -0.44, 0.80, ...]
“狗” -> [0.10, -0.39, 0.76, ...]
```

相似对象可学习到相近向量。相对 one-hot，Embedding 通常低维、稠密，并能表达语义关系。

### 14. SGD 的错误描述

**题目**：关于 SGD 的说法，错误的是哪一项？

- A. 可能收敛较慢
- B. 需要设置学习率
- C. 每次使用整个数据集计算梯度
- D. 代表随机梯度下降

**答案：C。**

**基础知识/解释**：SGD 是 Stochastic Gradient Descent（随机梯度下降），每步使用一个样本或很小的 mini-batch 估计梯度。每次使用全部训练集计算梯度的是 Batch Gradient Descent（批量梯度下降）。

### 15. 对角矩阵的行列式

**题目**：对角矩阵 `A=[[3,0],[0,3]]` 的行列式是多少？

- A. 6
- B. 27
- C. 9
- D. 3

**答案：C，9。**

**基础知识/解释**：对角矩阵的行列式等于对角线元素相乘：

```text
det(A) = 3 × 3 = 9
```

二维矩阵也可用 `ad - bc`：`3×3 - 0×0 = 9`。

### 16. 凸函数的性质（多选）

**题目**：以下关于凸函数的性质，正确的有哪些？

- A. 两个凸函数之和仍是凸函数
- B. 凸函数的非负线性组合仍是凸函数
- C. 凸函数的任意局部最小值都是全局最小值
- D. 凸函数与凹函数之和一定是凸函数

**答案：A、B、C。**

**基础知识/解释**：凸函数像“碗形”，任意两点连线位于函数图像上方。重要结论：

- 凸函数相加仍凸；
- 使用非负系数相加仍凸；
- 凸优化中，局部最小点就是全局最小点。

凹函数相当于“倒碗形”。凸函数与凹函数相加不一定凸，例如 `x² + (-2x²) = -x²` 是凹函数。

### 17. 注意力权重接近均匀的原因（多选）

**题目**：某层注意力权重接近均匀分布，可能的原因有哪些？

- A. 仅仅使用了因果掩码
- B. 输入序列所有 Token 的嵌入相同
- C. 查询和键的维度过高
- D. Softmax 温度参数设置过大

**答案：B、D。**

**基础知识/解释**：注意力权重来自：

```text
weights = softmax(scores / temperature)
```

若所有 Token 的嵌入相同（忽略位置编码等额外差异），各分数容易相同，softmax 后自然均匀。温度越大，`scores / temperature` 的差别越小，softmax 越平；温度越小则越尖锐。因果掩码只限制“不能看未来”，不会单独导致可见位置之间均匀。维度高本身也不是充分原因。

### 18. 线性相关与线性无关（多选）

**题目**：关于线性相关与线性无关，正确的有哪些？

- A. 包含零向量的向量组必线性相关
- B. n 维向量空间中任意 n+1 个向量必线性相关
- C. 若向量组线性相关，则其中每个向量都可由其余向量线性表示
- D. 单个非零向量构成的向量组线性无关

**答案：A、B、D。**

**基础知识/解释**：向量组线性相关表示存在“不全为 0”的系数，使线性组合等于 0。

- 包含零向量时，令零向量系数为 1，就得到非平凡组合，因此 A 对；
- n 维空间最多只能容纳 n 个线性无关向量，n+1 个必相关，因此 B 对；
- 线性相关只保证**至少有一个**向量可由其他向量表示，不是每一个，所以 C 错；
- `a v = 0` 且 `v != 0` 时只能 `a=0`，所以 D 对。

### 19. 分类指标计算（多选）

**题目**：已知 `TP=50、FN=10、FP=5、TN=200`，下列计算正确的有哪些？

- A. 精确率约为 0.91
- B. 召回率约为 0.83
- C. TPR 约为 0.83
- D. 准确率约为 0.96

**答案：A、B、C。**

**基础知识/解释**：

```text
Precision = TP / (TP + FP) = 50 / 55 ≈ 0.91
Recall    = TP / (TP + FN) = 50 / 60 ≈ 0.83
TPR       = Recall ≈ 0.83
Accuracy  = (TP + TN) / (TP + TN + FP + FN)
          = 250 / 265 ≈ 0.94
```

所以 D 的 `0.96` 不正确。

### 20. 3D 混合并行的原因（多选）

**题目**：大模型训练采用 TP、PP、DP 的 3D 混合并行，主要原因有哪些？

- A. 提高扩展性
- B. 减少单一并行方式的通信或容量瓶颈
- C. 充分利用多节点 GPU
- D. 自动减少模型参数

**答案：A、B、C。**

**基础知识/解释**：三种并行分别解决不同问题：

```text
DP（数据并行）：每张卡一份模型，分不同数据，最后同步梯度。
TP（张量并行）：把同一层的大矩阵切到多张卡，解决单层过大问题。
PP（流水线并行）：把不同网络层放到不同卡，解决整模型放不下问题。
```

组合后可以把更大模型、更大 batch 放到多节点集群训练，并在容量、通信、吞吐之间折中。它不会让模型本身的参数数量自动减少。
