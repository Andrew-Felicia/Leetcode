## 2. 原题、答案、解释与基础知识

### 1. 原题

设 A为实正交矩阵（即 ATA=1），则以下结论正确的是：

A A 的列向量不一定线性无关  
B A^T=A^{-1}  
C det(A)=-1  
D A^T=A

单选题

**答案：B。**

**解释与基础知识：** 正交矩阵定义为 `A^T A=I`，所以 `A^T` 就是 A 的逆：`A^T=A^{-1}`。正交矩阵可逆，列向量必线性无关；行列式可为 `+1` 或 `-1`；也不必是对称矩阵。

### 2. 原题

在一个标准的Transformer Block中,一个Multi-Head Attention子层之后通常会跟一个Position-wise FFN子层。关于这两个子层处理信息方式的描述,以下哪项最为准确?

A Multi-Head Attention和FFN都独立地处理每个位置的向量,不进行位置间的信息交换。  
B FFN负责在不同位置间混合信息,而Multi-Head Attention则对每个位置的向量进行独立的非线性变换。  
C Multi-Head Attention在不同位置间混合信息,而FFN则对每个位置的向量进行独立的非线性变换。  
D Multi-Head Attention和FFN都负责在整个序列的不同位置间进行信息交换。

单选题

**答案：C。**

**解释与基础知识：** Attention 中每个位置会对其他位置的 Value 加权求和，因此负责 token 间信息混合；Position-wise FFN 对每个 token 独立地应用同一组 MLP 参数，负责逐 token 的非线性特征变换。

### 3. 原题

在 Transformer Encoder 中，用来显式注入序列位置信息的模块是

A Feed-Forward Network  
B Positional Embedding  
C Self-Attention  
D Layer Normalization

单选题

**答案：B。**

**解释与基础知识：** 自注意力本身不包含“第几个 token”的顺序概念。位置编码/位置嵌入将位置信息加入 token embedding，使模型知道词序。

### 4. 原题

聚类算法在计算和迭代的过程中，需要反复计算不同点之间的距离，采用不同的距离公式通常会有不同的聚类效果，请问曼哈顿距离公式是以下哪个？

A d(x,y)=max_{i=1,2,3,...,n}|x_i-y_i|  
B d(x,y)=sqrt(sum_{i=1}^n(x_i-y_i)^2)  
C d(x,y)=sum_{i=1}^n|x_i-y_i|  
D d(x,y)=[sum_{i=1}^n(x_i-y_i)^p]^(1/p)

单选题

**答案：C。**

**解释与基础知识：** 曼哈顿距离是各维绝对差之和：`L1` 距离。B 是欧氏距离（L2）；A 是切比雪夫距离（L∞）；D 是一般 p 范数的形式，严格说应对差的绝对值取 p 次方。

### 5. 原题

考虑一个智能体 (Agent) 需要通过调用 API 来完成任务的情况，如果该 Agent 采用了 ReAct 框架来进行决策制定，那么以下哪一项描述了 ReAct 的核心机制？

A Agent 依赖外部反馈来调整其行为  
B Agent 先思考可能的结果再决定采取什么行动  
C Agent 首先执行动作然后才思考后果  
D Agent 同时思考和行动，以达到最佳效果

单选题

**答案：D。**

**解释：** ReAct 是 Reasoning + Acting。Agent 反复执行：Thought（思考）→ Action（调用工具）→ Observation（读取结果）→ Thought。D 最接近“交织推理和行动”的核心思想。

**基础知识：** A 只描述一般强化学习/Agent 的反馈；ReAct 的特点是把显式推理轨迹与工具行动结合起来。

### 6. 原题

在分类任务中，Softmax函数的作用是？

A 将输入映射到[-1,1]区间用于激活  
B 将输入转换为对数概率用于交叉熵损失  
C 限制输出范围以防止梯度爆炸  
D 将输入映射到[0,1]区间表示概率分布

单选题

**答案：D。**

**解释与基础知识：**

```text
softmax(z_i) = exp(z_i) / Σ_j exp(z_j)
```

每个输出在 `(0,1)`，且所有类别概率之和为 1，因此用于多分类概率分布。

### 7. 原题

在一个二分类问题中，混淆矩阵为：TP=50, FP=10, TN=30, FN=10。模型的准确率（Accuracy）是多少？

A 0.75  
B 0.8  
C 0.83  
D 0.9

单选题

**答案：B，0.8。**

**解释：**

```text
Accuracy = (TP+TN)/(TP+FP+TN+FN)
         = (50+30)/(50+10+30+10)
         = 80/100 = 0.8
```

### 8. 原题

在Flash-Attention v2中，将序列并行度(sequence parallel)从1提升到4，理论上总显存占用

A 降至1/2  
B 降至1/4  
C 几乎不变  
D 增加4倍

单选题

**答案：C。**

**解释与基础知识：** Sequence Parallel 通常改变的是序列相关计算和激活在不同设备上的分布方式，主要降低单卡局部占用或提升并行效率；从所有设备相加的**总**显存角度，数据并没有凭空消失，理论总量通常几乎不变。

### 9. 原题

下面关于 Transformer 的结构描述不正确的？

A Transformer 中编码器和解码器都由多层自注意力层和前馈神经网络层组成  
B Transformer 中编码器用于将源语言句子编码为一系列的向量  
C 编码器中位置编码（Positional Encoding）的主要作用是解决 RNN 的梯度消失问题  
D Transformer 中解码器将向量翻译生成目标语言

单选题

**答案：C。**

**解释：** Transformer 并不是 RNN；位置编码的作用是注入 token 顺序，而不是解决 RNN 梯度消失。

**基础知识：** 标准 Encoder-Decoder Transformer 中，Decoder 还包含对 Encoder 输出的交叉注意力。

### 10. 原题

假设随机变量X~Uniform(0,2)，求E[X²]

A 2/3  
B 1/3  
C 4/3  
D 2

单选题

**答案：C，4/3。**

**解释：** Uniform(0,2) 的密度为 `1/2`：

```text
E[X²] = ∫_0^2 x² × (1/2) dx
      = (1/2) × [x³/3]_0^2
      = 4/3
```

### 11. 原题

在 GPT-NeoX、Llama 等新一代 LLM 中，用 RMSNorm 取代 LayerNorm 的直接收益主要体现在

A 训练中减少一次矩阵乘法  
B 减少参数总量约 10%  
C 去掉均值计算，推理与训练均可省去一次减法  
D 可用更高学习率

单选题

**答案：C。**

**解释：** LayerNorm 需减均值并按标准差缩放；RMSNorm 不减均值，只使用均方根缩放。因此计算更简单。

**基础知识：** RMSNorm：

```text
x / sqrt(mean(x²)+ε)
```

LayerNorm 则还包含 `x - mean(x)`。

### 12. 原题

使用雅格比法求线性方程组 Ax = b 的解，其中 A 是一个 n 阶方阵。该算法收敛的一个充分条件是？

A A为正定矩阵  
B A为半正定矩阵，且b为零向量  
C A的每个对角元素均大于1，每个非对角元素均属于[-1/n,0]  
D A的每个对角元素的绝对值均大于同一行的任一非对角元素的绝对值

单选题

**答案：C。**

**解释：** C 保证严格对角占优：同一行中非对角项绝对值之和至多小于 1，而对角元素大于 1。严格对角占优是 Jacobi 收敛的充分条件。

**基础知识：** 正定性足以保证共轭梯度法等方法的一些性质，但对一般 Jacobi 法，常用充分条件是严格对角占优。D 只比较“每一个”非对角项，不保证对角元素大于所有非对角项之和。

### 13. 原题

以下关于矩阵秩的叙述中，正确的是？  
A 矩阵的秩等于其行空间维数，与列空间维数无关  
B 任意两个矩阵乘积的秩满足rank(AB)≥rank(A)  
C 初等行变换不改变矩阵的秩  
D 若矩阵 A 可逆，则rank(A)≠rank(A^{-1})

单选题

**答案：C。**

**解释与基础知识：** 初等行变换不改变行空间维数，因此不改变秩。行秩等于列秩，所以 A 错；`rank(AB)≤rank(A)`，B 方向错误；可逆 n 阶矩阵及其逆的秩都等于 n，D 错。

### 14. 原题

关于GPT、BERT、T5三种模型的架构，哪项描述是正确的？

A GPT是encoder-only，BERT是decoder-only，T5是encoder-decoder  
B GPT是encoder-decoder，BERT是decoder-only，T5是encoder-only

### 15. 原题

假设一个 10 层的卷积神经网络，使用 16GB 显存的 GPU 需要半小时训练完成，在测试过程中单个数据的推理时延为 3s。更改此网络架构，在第 5 和第 6 层中增加 Dropout，新架构在测试所用的时间会变为多少？

A 时间随机，无法估计  
B 小于 3s  
C 大于 3s  
D 仍是 3s

多选题

**答案：D。**

**解释与基础知识：** 正常推理/测试模式下 Dropout 被关闭，不会随机丢弃神经元，也不会增加实际计算路径，所以理论推理时延仍为 3 秒。

### 16. 原题

泊松时间流 (Poisson temporal flow) 也称为泊松流或最简单流, 是一种连续时间参数的随机过程, 用于描述在随机时刻出现的事件序列。泊松时间流具有哪些典型性质?

A 无偏性  
B 无后效性  
C 非负性  
D 平稳性  
E 普通性

多选题

**答案：B、D、E。**

**解释与基础知识：** 泊松过程常见性质是独立增量/无后效性、平稳增量和普通性。普通性表示足够短时间内发生两个及以上事件的概率是高阶小量。

### 17. 原题

设 A∈R^(m×n), B∈R^(n×p)，关于乘积 AB 的秩，下列结论哪些总是正确？

A 若 A 或 B 为零矩阵，则rank(AB)=0  
B rank(AB)≤rank(A)  
C rank(AB)≤rank(B)  
D 若 A 与 B 均满秩，则rank(AB)=min{m,p}

多选题

**答案：A、B、C。**

**解释：**

```text
rank(AB) ≤ min(rank(A), rank(B))
```

所以 A、B、C 都正确。D 不总对：例如 `A` 是 5×2 满秩、`B` 是 2×5 满秩，AB 的秩最多为 2，不可能等于 `min(5,5)=5`。

### 18. 原题

以下哪些可以作为SVM的核函数()

### 19. 原题

关于注意力的表述，正确的是

A 并非所有注意力变体都需计算 QK^T  
B GQA 在推理时可减少 K/V 缓存的内存占用  
C MLA 的训练速度通常快于 MHA

### 20. 原题

以下关于聚类算法的说法中，哪些是正确的？

A K-Means算法在每次迭代中都会更新所有簇中心的位置  
B 高斯混合模型（GMM）可以为每个数据点分配到多个簇的概率  
C 层次聚类算法只能生成固定的层次结构，无法形成扁平化的簇集合  
D DBSCAN算法能够自动确定聚类的数量，并且可以处理噪声数据

多选题

**答案：A、B、D。**

**解释：** K-Means 的标准迭代包含“分配样本”和“更新质心”；GMM 是软聚类，给出属于各簇的概率；DBSCAN 不需要预先指定 K，能将低密度点标为噪声。层次聚类可把树状图在某一高度切开得到扁平簇，因此 C 错。
