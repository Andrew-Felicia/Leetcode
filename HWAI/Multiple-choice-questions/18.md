## 2. 原题、答案、解释与基础知识

### 1. 原题

Transformer模型的核心机制是？

A 线性回归  
B 卷积神经网络  
C 循环神经网络  
D 自注意力机制

单选题

**答案：D。**

**解释与基础知识：** Transformer 的核心是自注意力（Self-Attention）。每个 token 可根据与其他 token 的相关性，动态聚合全局信息。它不是以 RNN 的逐步递推或 CNN 的局部卷积为核心。

### 2. 原题

关于三次样条插值的描述，错误的是：

A 插值函数在节点处二阶导数不连续  
B 在每个子区间上用三次多项式逼近函数  
C 插值函数通过所有给定数据点  
D 相比高次多项式插值，三次样条能避免Runge现象

单选题

**答案：A。**

**解释：** 三次样条由多个分段三次多项式组成，并要求节点处函数值、一阶导数和二阶导数连续。因此 A 的“二阶导数不连续”错误。

**基础知识：** 高次全局多项式在端点附近可能剧烈振荡（Runge 现象）；三次样条以局部低阶多项式拼接，通常更稳定。

### 3. 原题

循环神经网络（RNN）相比前馈神经网络更适合处理以下哪种任务：

A 时间序列预测  
B 高维数据降维  
C 图像分类  
D 文本分类

单选题

**答案：A。**

**解释：** RNN 的隐藏状态可将过去时间步的信息带到当前时间步，因此特别适合有时间顺序、前后依赖的时间序列预测。

**基础知识：** 文本分类也可使用 RNN，因为文本也是序列；但本题在单选中，A 更直接体现 RNN 相比普通前馈网络的典型优势。

### 4. 原题

在模型评估中，精确率（Precision）与召回率（Recall）的关系是？

A 一般情况下，精确率和召回率是相互矛盾的指标  
B 精确率越高，召回率一定越高  
C 精确率衡量真正例的比例，召回率衡量预测为正例的样本中实际为正的比例  
D 精确率和召回率均与阈值无关

单选题

**答案：A。**

**解释：** 一般调整分类阈值会产生权衡：阈值降低，预测正类变多，召回率往往提高，但可能带来更多 FP，使 Precision 降低；阈值升高则常相反。

**基础知识：**

```text
Precision = TP / (TP + FP)
Recall    = TP / (TP + FN)
```

C 把二者的含义说反了。

### 5. 原题

设X是非负整数的随机变量，则P(X≥1)与E[X]满足

A P(X≥1)=E[X]  
B P(X≥1)≥E[X]  
C 无必然关系  
D P(X≥1)≤E[X]

单选题

**答案：D。**

**解释：** 对每个结果都有：

```text
X ≥ 1{X≥1}
```

左边是 X，右边是事件发生时取 1、否则取 0 的指示变量。两边取期望：

```text
E[X] ≥ E[1{X≥1}] = P(X≥1)
```

### 6. 原题

在分类模型评估中，以下哪项指标对类别不平衡最不敏感？

A AUC  
B Accuracy  
C Recall  
D Precision

单选题

**答案：A。**

**解释：** AUC 衡量不同阈值下正负样本排序的区分能力，相比 Accuracy 不容易被多数类样本数量主导。

**基础知识：** 若 99% 都是负类，全部预测为负类也有 99% Accuracy，但模型完全无法找出正类。因此不平衡问题中常看 AUC、PR-AUC、Recall、F1 等，而不只看 Accuracy。

### 7. 原题

集成学习通过组合多个学习器来提升整体模型性能，Bagging类算法属于集成学习的一种，通过学习多个训练器，采用投票的方式降低模型方差，以下属于Bagging类算法的是

A Random Forest  
B GBDT  
C Decision Tree  
D Linear Regression

单选题

**答案：A。**

**解释：** 随机森林训练多棵带随机性的决策树，再投票或平均，是典型 Bagging。

**基础知识：** Bagging 主要并行训练多个学习器以降低方差；GBDT 是 Boosting，通常按顺序让后续树拟合前面模型的残差。

### 8. 原题

给定二维数据集，包含三个样本 {(0,0), (1,1), (2,2)}，求其协方差矩阵的迹（Trace）

A 2/3  
B 0  
C 4/3  
D 2

单选题

**答案：D**

**解释：** 两个维度的均值均为 1，每个维度的偏差为 `-1, 0, 1`。使用分母 n 的协方差定义时：

```text
协方差矩阵的迹即为主对角线上元素之和，等于各特征的方差之和。这里有三个样本点，均值为(1,1)。
第一维度的样本方差为：[(0-1)² + (1-1)² + (2-1)²] / (3-1) = (1 + 0 + 1) / 2 = 1。
第二维度的样本方差同理也是 1。
因此协方差矩阵的迹为 1 + 1 = 2。
```

**基础知识：** 协方差矩阵的迹等于各维度方差之和，也可理解为数据总方差。

### 9. 原题

关于预训练的目标，错误的是

A 必须依赖标注数据  
B 主要使用交叉熵损失函数  
C 通过无监督学习捕捉语言统计规律  
D 模型需学习上下文表示能力

单选题

**答案：A。**

**解释：** 大语言模型的预训练通常从原始文本中构造预测任务，例如预测下一个 token，并不需要人工标注数据。

**基础知识：** 自监督学习利用数据自身构造标签；例如输入前文，目标是下一个 token。训练常使用交叉熵损失。

### 10. 原题

强大数律（SLLN）与弱大数律（WLLN）的关键差别在于：

A 随机变量是否独立  
B 样本容量  
C 收敛方式  
D 矩条件

单选题

**答案：C。**

**解释与基础知识：** 两者都说明样本均值趋近总体均值，但收敛方式不同：

```text
WLLN：依概率收敛
SLLN：几乎处处收敛
```

几乎处处收敛更强，因此 SLLN 是更强的结论。

### 11. 原题

在机器学习中特征选择过程中，下列关于常用方法的说法正确的是

A 过滤法（Filter Method）依据已训练模型的特征重要性进行特征筛选。因此可降低模型复杂度。  
B 包裹法（Wrapper Method）应用交叉验证评估候选特征子集性能，计算成本高但能有效减少过拟合风险。  
C 嵌入法（Embedded Method）在模型训练前计算特征与目标的相关系数，独立于模型进行选择。  
D 方差阈值法（Variance Threshold）通过保留方差较低特征，增强模型对噪声的鲁棒性，防止过拟合。

单选题

**答案：B。**

**解释：** Wrapper Method 反复训练/验证模型评估候选特征子集，计算贵，但直接按模型性能选择特征。

**基础知识：**

- Filter：训练前用方差、相关性、互信息等统计指标筛选。
- Wrapper：用模型表现评估特征子集。
- Embedded：模型训练过程中同时完成选择，例如 Lasso、树模型重要性。
- 方差阈值通常删除低方差特征，而不是保留它们。

### 12. 原题

已知函数 f(x)，用中心差分近似导数 f'(x)，公式为 
f′(x)≈f(x+h)−f(x−h) / 2h，请向近似导数的误差分析原因。

A O(h)  
B O(h log h)  
C O(h^3)  
D O(h^2)

单选题

**答案：D，O(h²)。**

**解释：** 对 `f(x+h)` 和 `f(x-h)` 分别做泰勒展开，相减后偶数阶项抵消：

```text
[f(x+h)-f(x-h)]/(2h)
= f'(x) + O(h²)
```

**基础知识：** 前向差分 `(f(x+h)-f(x))/h` 的截断误差是 `O(h)`；中心差分通常更准确，为 `O(h²)`。

### 13. 原题

假设输入组 a = [0, 1, 2, 3]，则以下ReLU激活函数后，输出向量为：

A [0, 1, 2, 3]  
B [0, 8, -1, 2, 2, 1]  
C [0, 186, 0, 050, 0, 764]  
D [0, -1, 2, 0]

单选题

**答案：A。**

**解释与基础知识：**

```text
ReLU(x) = max(0, x)
```

大模型中的“涌现能力”（Emergent Abilities）是指？

A 模型参数减少到一定程度后出现的新能力

### 15. 原题

RLHF阶段使用的典型算法是

A 监督式微调（SFT）  
B 最大化人类偏好得分  
C DQN (Deep Q-Network)  
D PPO (Proximal Policy Optimization)

多选题

**答案：D。**

**解释：** PPO 是经典 RLHF 中常用的策略优化算法。B 更像训练目标描述，而不是具体算法；SFT 通常是 RLHF 之前的阶段；DQN 不适合这种大词表生成策略的典型训练方式。

**基础知识：** PPO 用裁剪目标限制一次更新幅度，避免策略骤变，使强化学习训练更稳定。

### 16. 原题

在扩散模型推理中，以下哪些技术被用于一步/少步生成？

A DDIM inversion（DDIM逆过程）  
B Progressive Distillation（渐进式蒸馏）

### 17. 原题

一位深度学习工程师正在分析一个标准Transformer模型的性能瓶颈和训练动态。在深入研究其基础运算单元时，得出了以下几个结论，请判断哪些结论是正确的：

A 在计算softmax时，为了防止因输入值过大导致exp()函数结果溢出，一个标准的实现技巧是先从所有输入值中减去它们的最大值，这个操作在数学上是等价的。

B 在LayerNorm中，可学习的仿射变换参数gamma（增益）和beta（偏置）的主要作用是严格维持归一化后的数据分布为标准正态分布（均值为0，方差为1），从而加速模型收敛。

C 采用子词（subword）分词的Tokenizer，其词汇表大小（V）直接决定了模型输入端嵌入层（Embedding Layer）的参数量。一个拥有64000个词元的词汇表和一个512维的d_model，其嵌入层的参数数量级约为3200万。

D 当序列长度N远大于模型的隐藏维度d_model时（例如在处理长文档时），自注意力机制中与N^2相关的计算会成为主要的计算瓶颈；反之，当N较小时，前馈网络（FFN）的计算量通常会占据主导地位。

多选题

**答案：A、C、D。**

**解释：**

- A：正确。`softmax(z)=softmax(z-max(z))`，但数值更稳定。
- B：错误。LN 的 gamma、beta 让模型恢复合适的缩放和平移能力，不是保证输出仍为标准正态。
- C：正确。参数量约 `64000×512=32,768,000`，约 3200 万。
- D：正确。注意力相关计算约 `O(N²d)`；FFN 约 `O(Nd²)`。N 很大时前者更突出，N 较小时后者常更重。

### 19. 原题

以下哪些措施可以提高迭代法的收敛性?

A 使用稀疏矩阵存储  
B 选择适当的松弛因子  
C 增加计算精度  
D 改进迭代初始值

多选题

**答案：B、D。**

**解释：** 合适的松弛因子可改善 Jacobi、Gauss-Seidel、SOR 等方法的收敛行为；更好的初始值能减少到达解附近所需迭代次数。稀疏存储只节省内存/计算；更高精度主要改善数值稳定性，不会改变理论收敛条件。

### 20. 原题

设A、B、C为三个事件，则下面的等式中正确的是

A (A - B) ∩ (A - C) = A - (B ∪ C)  
B A ∪ B - B = A - B  
C (A ∪ B) - C = A ∪ (B - C)  
D (A - B) ∪ B = A

多选题

**答案：A、B。**

**解释：**

- A：正确。都表示“属于 A，但既不属于 B，也不属于 C”。
- B：正确。`(A∪B)\B = A\B`。
- C：错误。左边应为 `(A\C)∪(B\C)`，右边的 A 没有减去 C。
- D：错误。`(A\B)∪B = A∪B`，若 B 有 A 外元素，就不等于 A。

**基础知识：** 集合差 `A-B` 表示“属于 A 且不属于 B”。在概率题中，事件也可以按集合运算处理。
