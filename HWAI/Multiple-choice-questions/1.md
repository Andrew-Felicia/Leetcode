## 1. Variance of a linear combination

**Question**

Independent random variables:

```text
X ~ N(1, 2)
Y ~ N(2, 3)
Z = 2X - Y
```

What is the variance of `Z`?

- A. `1`
- B. `11`
- C. `7`
- D. `5`

**Answer: B. 11**

**Explanation**

For independent variables:

```text
Var(aX + bY) = a²Var(X) + b²Var(Y)
```

Therefore:

```text
Var(2X - Y)
= 2² × Var(X) + (-1)² × Var(Y)
= 4 × 2 + 1 × 3
= 11
```

The means `1` and `2` do not affect variance.

## 2. Activation checkpointing

**Question**

When training a large model, what is the main purpose of activation checkpointing?

- A. Reduce the number of parameters
- B. Automatically improve accuracy
- C. Reduce peak memory usage
- D. Save as many activations as possible to reduce computation

**Answer: C. Reduce peak memory usage**

**Explanation**

Normal training saves many intermediate activations for backpropagation:

```text
forward pass → save activations → backward pass
```

Activation checkpointing saves fewer activations:

```text
forward pass → save selected activations
backward pass → recompute missing activations
```

Trade-off:

```text
lower memory usage, higher computation cost
```

## 3. Probability density normalization

**Question**

A probability density function is:

```text
f(x) = c(1 - x²),  -1 ≤ x ≤ 1
```

What is the normalization constant `c`?

- A. `1`
- B. `1/2`
- C. `3/4`
- D. `3/2`

**Answer: C. 3/4**

**Explanation**

A probability density must satisfy:

```text
∫ f(x) dx = 1
```

So:

```text
c × ∫[-1,1](1 - x²)dx = 1

c × [x - x³/3] from -1 to 1 = 1

c × 4/3 = 1

c = 3/4
```

## 4. L2 regularization

**Question**

Why can L2 regularization improve model stability?

- A. It limits weight magnitude and reduces sensitivity to small input changes.
- B. It guarantees a global optimum.
- C. It removes all zero eigenvalues.
- D. It always shortens training time.

**Answer: A**

**Explanation**

L2 regularization adds a penalty:

```text
loss = original_loss + λ × Σw²
```

Large weights can make a model overly sensitive:

```text
small input change → very large output change
```

L2 discourages large weights, often making the model smoother and more stable.

## 5. Cross-entropy loss

**Question**

Given:

```text
one-hot label:         [0, 1, 0]
predicted probability: [0.1, 0.8, 0.1]
```

What is the cross-entropy?

- A. `log(0.8)`
- B. `-log(0.8)`
- C. `-(log(0.1) + log(0.8) + log(0.1))`
- D. `0.8`

**Answer: B. -log(0.8)**

**Explanation**

Cross-entropy is:

```text
CE = -Σ yi log(pi)
```

Only the real class has label `1`:

```text
CE = -(0×log(0.1) + 1×log(0.8) + 0×log(0.1))
   = -log(0.8)
```

## 6. PCA standardization

**Question**

Why are features usually standardized before PCA?

- A. Standardization directly creates principal components.
- B. PCA can only process normally distributed data.
- C. It makes variance from different units comparable.
- D. It guarantees that features are linearly independent.

**Answer: C**

**Explanation**

PCA finds directions with the largest variance.

Suppose one feature is:

```text
height: 150–190
```

and another is:

```text
income: 10,000–100,000
```

Without standardization, income may dominate only because its numerical scale is larger.

## 7. Late fusion

**Question**

In a multimodal task, what does Late Fusion mean?

- A. Use only images.
- B. Encode each modality independently, then fuse near the decision layer.
- C. Directly concatenate all raw inputs.
- D. Use one encoder for every modality.

**Answer: B**

**Explanation**

Late fusion structure:

```text
image → image encoder ┐
                       ├→ fusion → final decision
text  → text encoder  ┘
```

Each modality is first processed separately.

Which statement is most accurate?

- A. Cosine mainly measures direction; Euclidean distance is affected by both direction and length.
- B. They are equivalent for every input.
- C. Both are independent of vector length.
- D. Cosine considers absolute length while Euclidean distance does not.

**Explanation**

```text
cosine similarity → angle/direction

```

```text
[1, 1] and [10, 10]
```

They point in the same direction:

```text
cosine similarity = 1
```

## 18. ResNet shortcut connections — multiple choice

**Question**

Which statements about ResNet shortcut connections are correct?

- A. They help alleviate vanishing gradients.
- B. They provide an identity mapping, so deeper networks can at least represent shallower solutions.
- C. Identity shortcuts have no benefit and must always contain parameters.
- D. Residual ideas can be used in MLPs, CNNs, RNNs, and other structures.

**Answer: A, B, D**

**Explanation**

A residual block is:

```text
output = F(x) + x
```

If the learned residual is zero:

```text
F(x) = 0
```

then:

```text
output = x
```

So the deep block can preserve an earlier representation.

## 19. Dot product and cosine similarity — multiple choice

**Question**

For nonzero vectors, which statements are correct?

- A. If the dot product is negative, cosine similarity is negative.
- B. If bounded cosine similarity replaces attention dot products, missing temperature scaling may make attention distributions too flat.
- C. Dot product contains both direction and magnitude information.
- D. Cosine similarity is the dot product after L2 normalization.

**Answer: A, B, C, D**

**Explanation**

Cosine similarity is:

```text
cos(x, y) = x·y / (||x|| × ||y||)
```

Since vector norms are positive:

```text
negative dot product → negative cosine similarity
```

Cosine is bounded:

```text
-1 ≤ cosine ≤ 1
```

Without temperature scaling, softmax may receive small, limited logits and become too flat.

## 20. Dual-branch multimodal training — multiple choice

**Question**

Which statements are correct?

- A. Branch gradients can be normalized to reduce update imbalance.
- B. Different gradient magnitudes may create modality bias.
- C. Swish has derivative close to `1` for large positive inputs, helping gradient propagation.
- D. Branch-level gradient clipping can be applied to an image branch.

**Answer: A, B, C, D**

**Explanation**

In a dual-branch model:

```text
image branch gradient = very small
text branch gradient  = very large
```

The text branch may dominate the update.

Possible solutions include:

```text
gradient normalization
branch-level gradient clipping
loss balancing
different learning rates
```

All four statements are correct.
