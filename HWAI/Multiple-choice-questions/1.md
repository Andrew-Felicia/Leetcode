# 1. 总结

这些题目主要考察核心概念，而不是复杂计算。

| 主题 | 核心要点 |
|---|---|
| 概率统计 | 方差计算时系数必须平方；概率密度函数的积分必须为 1。 |
| 机器学习基础 | 交叉熵使用真实类别的预测概率；L2 正则限制大权重；无标签聚类属于无监督学习。 |
| 特征方法 | PCA 会受特征尺度影响；Pearson 适合不同评分习惯；余弦相似度衡量方向。 |
| 神经网络 | 隐藏层学习非线性特征；ResNet 快捷连接改善梯度传播。 |
| 多模态 | Late Fusion 先分别编码各模态，再在输出附近融合。 |
| 大模型系统 | Checkpointing 用额外计算换取更低训练显存；KV Cache 主要是推理显存问题。 |

# 2. 题目、答案与解释

## 1. 线性组合的方差

**题目**

独立随机变量：

```text
X ~ N(1, 2)
Y ~ N(2, 3)
Z = 2X - Y
```

`Z` 的方差是多少？

- A. `1`
- B. `11`
- C. `7`
- D. `5`

**答案：B. 11**

**解释**

对于独立随机变量：

```text
Var(aX + bY) = a²Var(X) + b²Var(Y)
```

因此：

```text
Var(2X - Y)
= 2² × Var(X) + (-1)² × Var(Y)
= 4 × 2 + 1 × 3
= 11
```

均值 `1` 和 `2` 不影响方差。

## 2. Activation Checkpointing

**题目**

训练大模型时，使用 Activation Checkpointing 的主要目的是什么？

- A. 减少参数量
- B. 自动提高精度
- C. 降低显存峰值
- D. 保存尽量多激活以减少计算

**答案：C. 降低显存峰值**

**解释**

普通训练会保存许多中间激活值，供反向传播使用：

```text
前向传播 → 保存激活值 → 反向传播
```

Activation Checkpointing 只保存部分激活值：

```text
前向传播 → 只保存部分激活值
反向传播 → 重新计算未保存的激活值
```

代价是：

```text
显存更低，计算量更高
```

## 3. 概率密度函数归一化

**题目**

概率密度函数为：

```text
f(x) = c(1 - x²),  -1 ≤ x ≤ 1
```

归一化常数 `c` 是多少？

- A. `1`
- B. `1/2`
- C. `3/4`
- D. `3/2`

**答案：C. 3/4**

**解释**

概率密度函数必须满足：

```text
∫ f(x) dx = 1
```

所以：

```text
c × ∫[-1,1](1 - x²)dx = 1

c × [x - x³/3] 从 -1 到 1 = 1

c × 4/3 = 1

c = 3/4
```

## 4. L2 正则化

**题目**

为什么 L2 正则化通常有助于提升模型稳定性？

- A. 限制权重大小，降低对输入微扰的敏感性
- B. 保证全局最优
- C. 消除所有零特征值
- D. 必然缩短训练时间

**答案：A**

**解释**

L2 正则化会给损失函数加上一项惩罚：

```text
loss = 原始损失 + λ × Σw²
```

权重过大时，模型可能出现：

```text
输入很小的变化 → 输出很大的变化
```

L2 会抑制过大的权重，使模型通常更平滑、更稳定。

## 5. 交叉熵损失

**题目**

给定：

```text
one-hot 标签： [0, 1, 0]
预测概率：     [0.1, 0.8, 0.1]
```

交叉熵为多少？

- A. `log(0.8)`
- B. `-log(0.8)`
- C. `-(log(0.1) + log(0.8) + log(0.1))`
- D. `0.8`

**答案：B. `-log(0.8)`**

**解释**

交叉熵公式：

```text
CE = -Σ yi log(pi)
```

只有真实类别对应的标签为 `1`：

```text
CE = -(0×log(0.1) + 1×log(0.8) + 0×log(0.1))
   = -log(0.8)
```

## 6. PCA 前的标准化

**题目**

为什么 PCA 前通常要对特征进行标准化？

- A. 标准化直接产生主成分
- B. PCA 只能处理正态分布数据
- C. 让不同量纲特征的方差具有可比性
- D. 保证特征线性无关

**答案：C**

**解释**

PCA 寻找方差最大的方向。

例如：

```text
身高：150–190
收入：10,000–100,000
```

不标准化时，收入可能仅仅因为数值范围更大而主导 PCA。标准化可以使不同特征的尺度更可比。

## 7. Late Fusion

**题目**

多模态任务中的后融合（Late Fusion）是指什么？

- A. 只使用图像
- B. 各模态独立编码后，在决策层附近融合
- C. 在输入层直接拼接
- D. 单一编码器处理全部模态

**答案：B**

**解释**

后融合的结构通常是：

```text
图像 → 图像编码器 ┐
                  ├→ 融合 → 最终决策
文本 → 文本编码器 ┘
```

先分别处理图像、文本等模态，再在靠近输出的位置融合。

## 8. 隐藏层的作用

**题目**

深度网络隐藏层的主要作用是什么？

- A. 只显示最终结果
- B. 不变地转发原始数据
- C. 通过非线性变换学习高阶特征表示
- D. 存储损失值

**答案：C**

**解释**

隐藏层通常执行：

```text
输入 → 线性变换 → 激活函数 → 新特征
```

非线性激活函数让网络能够学习比直线关系更复杂的模式。

## 10. 不同评分尺度下的相似性

**题目**

当用户评分尺度差异明显时，更适合使用哪种相似性？

- A. 汉明距离
- B. 欧氏距离
- C. 皮尔逊相关系数
- D. 曼哈顿距离

**答案：C. 皮尔逊相关系数**

**解释**

两个用户可能具有相同的偏好趋势：

```text
用户 A：2, 3, 4, 5
用户 B：6, 7, 8, 9
```

绝对评分不同，但喜欢和不喜欢的趋势一致。皮尔逊相关系数关注这种变化趋势。

## 11. PagedAttention 的 Block Size

**题目**

PagedAttention 的 Block Size 设置为 `1` 的主要问题是什么？

- A. 模型无法加载
- B. 显存利用率必然为 100%
- C. 吞吐量必然大幅增加
- D. 映射元数据开销大且访问更不连续

**答案：D**

**解释**

Block Size 为 `1` 时：

```text
1 个 token → 1 个 block
```

大量 token 会产生大量 block 和映射元数据，内存访问也更容易碎片化、不连续。

## 12. 困惑度（Perplexity）

**题目**

对于高质量且符合目标分布的文本，模型困惑度通常如何？

- A. 越高越好
- B. 只反映多样性
- C. 越低表示模型预测越准确
- D. 与质量无关

**答案：C**

**解释**

困惑度表示模型对文本的“惊讶程度”：

```text
困惑度低 → 模型给文本分配了较高概率
困惑度高 → 模型认为文本较难预测
```

## 13. 滑动窗口注意力

**题目**

滑动窗口大小为 `20`。Prefill 处理 `30` 个 token 后，又 Decode `15` 个 token。此时保留 token 数和注意力上下文长度为多少？

- A. `20，20`
- B. `15，20`
- C. `45，45`
- D. `20，15`

**答案：A. `20，20`**

**解释**

模型一共处理了：

```text
30 + 15 = 45 个 token
```

但滑动窗口大小为 `20`，因此只保留最新的 `20` 个 token：

```text
保留 token 数 = 20
注意力上下文长度 = 20
```

## 14. 奇异值分解（SVD）

**题目**

关于 SVD，哪项正确？

- A. `U` 和 `V` 可取为正交矩阵
- B. 矩阵必须可逆
- C. 仅方阵可做 SVD
- D. 奇异值可为负

**答案：A**

**解释**
任意实矩阵均可 SVD，奇异值非负。
SVD 的形式为：

```text
A = UΣVᵀ
```

主要性质：

```text
U、V：正交矩阵
Σ：包含非负奇异值
A：可以是矩形矩阵，也可以不可逆
```

## 15. 余弦相似度与欧氏距离

**题目**

关于余弦相似度与欧氏距离，哪项最准确？

- A. 余弦主要反映方向，欧氏距离同时受方向和长度影响
- B. 二者在任何输入上都等价
- C. 二者都与长度无关
- D. 余弦考虑绝对长度而欧氏不考虑

**答案：A**

**解释**

```text
余弦相似度 → 衡量夹角/方向
欧氏距离   → 衡量实际空间距离
```

例如：

```text
[1, 1] 和 [10, 10]
```

它们方向完全相同：

```text
余弦相似度 = 1
```

但它们的欧氏距离很大。

## 16. Activation Checkpointing（多选）

**题目**

关于 Activation Checkpointing，正确的有哪些？

- A. 反向传播时需要额外前向重算
- B. 一定降低训练时间
- C. 只适用于推理
- D. 减少保存的中间激活以降低显存

**答案：A、D**

**解释**

```text
Checkpointing：更少激活显存 + 更多重算
```

所以它可能增加训练时间，而不是一定降低训练时间。

## 17. 训练与推理显存优化（多选）

**题目**

关于训练和推理显存优化，合理的有哪些？

- A. 使用 KV Cache 后显存与层数无关
- B. PagedAttention 改善推理 KV Cache 的分页和碎片问题
- C. 训练可用重计算降低激活显存
- D. 降低数值位宽通常可减少 KV Cache 占用

**答案：B、C、D**

**解释**
KV cache 仍随层数增长，其他三项均是常见优化。
KV Cache 显存大致随以下因素增长：

```text
层数 × token 数 × 隐藏维度/注意力头维度 × 数值精度
```

所以 A 错误：KV Cache 与层数有关。

## 18. ResNet 快捷连接（多选）

**题目**

关于 ResNet 的 shortcut connection，正确的有哪些？

- A. 有助于缓解梯度消失
- B. 提供恒等映射能力，使加深网络至少能表达浅层方案
- C. Identity shortcut 没有好处，必须带参数
- D. 残差思想可用于 MLP、CNN、RNN 等结构

**答案：A、B、D**

**解释**

一个残差块可写为：

```text
output = F(x) + x
```

若学习到的残差为：

```text
F(x) = 0
```

那么：

```text
output = x
```

因此更深的网络至少可以保留浅层网络的表达能力。

## 19. 点积与余弦相似度（多选）

**题目**

对于非零向量，以下哪些说法正确？

- A. 点积为负则余弦相似度为负
- B. 以有界余弦替代注意力点积时，缺少温度缩放可能令分布过平
- C. 点积同时包含方向与模长信息
- D. 余弦相似度是 L2 归一化后的点积

**答案：A、B、C、D**

**解释**

余弦相似度：

```text
cos(x, y) = x·y / (||x|| × ||y||)
```

由于向量范数为正：

```text
点积为负 → 余弦相似度为负
```

余弦相似度范围有限：

```text
-1 ≤ cosine ≤ 1
```

若没有温度缩放，Softmax 接收到的值范围较小，注意力分布可能过于平坦。

## 20. 双分支多模态模型训练（多选）

**题目**

双分支多模态模型训练中，正确的有哪些？

- A. 可对分支梯度做归一化以缓解更新失衡
- B. 分支梯度幅值差异可能造成模态偏倚
- C. Swish 在较大正输入处导数接近 `1`，有利于梯度传播
- D. 可对图像分支做分支级梯度裁剪

**答案：A、B、C、D**

**解释**

双分支模型中可能出现：

```text
图像分支梯度：很小
文本分支梯度：很大
```

此时文本分支可能主导参数更新，造成模态偏倚。常见缓解方法包括：

```text
梯度归一化
分支级梯度裁剪
损失权重平衡
不同分支使用不同学习率
```

以上四项均正确。
