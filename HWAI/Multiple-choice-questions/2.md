# 1. 总结

这组题覆盖统计指标、贝叶斯概率、线性代数、聚类、Transformer 与大模型训练。

| 主题 | 核心记忆点 |
|---|---|
| 回归与统计 | RMSE 对极端异常值敏感；泊松分布的均值和方差都为 λ。 |
| 贝叶斯概率 | 后验概率 = 先验 × 条件概率，再除以总概率。 |
| 线性代数与误差 | 转置是线性变换；线性变换保持相反数；加法绝对误差上界相加。 |
| 表示学习与聚类 | 监督度量学习让同类近、异类远；KNN 有维度灾难、K 敏感等问题。 |
| Transformer/LLM | SFT 用 instruction-output；decoder 需要因果 mask 与 padding mask；Pre-LN 利于梯度传播。 |
| 视觉模型 | ToMe 在 Transformer 内合并相似视觉 token。 |

## 1. 回归指标与异常值

**题目**

回归数据中含有少量极端异常值时，哪个指标通常最敏感？

- A. MAE
- B. 中位数绝对误差
- C. RMSE
- D. MAPE

**答案：C. RMSE**

**解释**

```text
MAE  = 平均 |误差|
RMSE = sqrt(平均 误差²)
```

RMSE 会先对误差平方。若一个预测误差从 `10` 变成 `100`：

```text
MAE 中的影响：10 倍
RMSE 平方项中的影响：100 倍
```

因此极端异常值通常对 RMSE 最敏感。

## 2. 贝叶斯公式：垃圾邮件后验概率

**题目**

某词在垃圾邮件和正常邮件中的出现概率分别为 `0.8`、`0.1`，垃圾邮件先验概率为 `20%`。邮件包含该词时，它是垃圾邮件的概率是多少？

- A. `0.5`
- B. `0.8`
- C. `0.2`
- D. `0.667`

**答案：D. 0.667**

**解释**

设：

```text
S：垃圾邮件
W：出现该词

P(S) = 0.2
P(非 S) = 0.8
P(W | S) = 0.8
P(W | 非 S) = 0.1
```

根据贝叶斯公式：

```text
P(S | W)
= P(W | S)P(S) / P(W)
= 0.8×0.2 / (0.8×0.2 + 0.1×0.8)
= 0.16 / 0.24
= 2/3
≈ 0.667
```

## 3. 泊松分布的样本均值与样本方差

**题目**

泊松样本的样本均值与无偏样本方差的期望关系是？

- A. 两者都不等于 `λ`
- B. 仅样本方差期望为 `λ`
- C. 仅样本均值期望为 `λ`
- D. 两者期望都为 `λ`

**答案：D**

**解释**

若：

```text
X ~ Poisson(λ)
```

那么：

```text
E[X] = λ
Var(X) = λ
```

样本均值是总体均值的无偏估计；无偏样本方差也是总体方差的无偏估计。因此二者的期望都为 `λ`。

## 4. t-SNE 坐标用于下游分类

**题目**

把 t-SNE 的二维可视化坐标直接用于下游分类，效果可能显著下降，主要原因是什么？

- A. 任何可视化都与训练冲突
- B. t-SNE 低维特征必然更适合训练
- C. 只因为其复杂度较高
- D. t-SNE 强调局部邻域，可能扭曲全局距离且坐标无稳定绝对含义

**答案：D**

**解释**

t-SNE 的核心目的通常是可视化，而不是生成可用于稳定下游任务的通用特征。

它重点保留：

```text
局部邻居关系：谁和谁比较接近
```

但可能扭曲：

```text
簇与簇之间的全局距离
坐标轴的绝对含义
不同运行之间的位置关系
```

所以二维图看起来分得很开，不代表这两个坐标适合直接用于分类。

## 5. 转置是否为线性变换

**题目**

在 `2×2` 矩阵空间中，`T(A)=Aᵀ` 是否为线性变换？

- A. 否，因为元素换位
- B. 否，因为乘积转置会逆序
- C. 是
- D. 否，因为不可逆

**答案：C. 是**

**解释**

线性变换只需要满足：

```text
T(A + B) = T(A) + T(B)
T(cA) = cT(A)
```

转置满足：

```text
(A + B)ᵀ = Aᵀ + Bᵀ
(cA)ᵀ = cAᵀ
```

因此转置是线性变换。

## 6. 监督式线性嵌入

**题目**

要求线性嵌入满足“同类样本相近、异类样本相远”，最合理的方案是？

- A. 独热编码后随机投影
- B. 利用标签监督优化线性变换的类内与类间距离
- C. 完全随机变换
- D. 忽略类别的随机映射

**答案：B**


## 7. SFT 数据格式

**题目**

哪种数据格式最适合直接用于监督微调（SFT）？

- A. 包含 `chosen/rejected` 的偏好对
- B. 包含 `instruction` 与 `output` 的配对
- C. 包含答案和标量评分
- D. 仅一段无指令文本

**答案：B**

**解释**

SFT 的目标是学习：

```text
输入指令 → 目标回答
```

因此最典型的数据是：

```json
{
  "instruction": "解释什么是 PCA",
  "output": "PCA 是一种降维方法……"
}
```

`chosen/rejected` 偏好对更常用于偏好学习、奖励模型或 DPO 类训练。

## 8. Decoder-only 模型的右侧 Padding

**题目**

训练 decoder-only 模型并使用右侧 padding 时，attention mask 通常如何处理？

- A. 同时应用因果 mask 和 padding mask
- B. 只使用因果 mask
- C. 只使用 padding mask
- D. 完全不使用 mask

**答案：A**

**解释**

```text

```

## 9. 条件概率：喜欢编程的人中男生的比例

**题目**

班级男生占 `60%`、女生占 `40%`；男生喜欢编程的比例为 `25%`，女生喜欢编程的比例为 `50%`。随机选一名喜欢编程者，该学生是男生的概率是多少？

- A. `3/7`
- B. `60%`
- C. `25%`
- D. `1/2`

**答案：A. 3/7**

**解释**

设全班有 100 人：

```text
男生：60 人，喜欢编程：60×25%=15 人
女生：40 人，喜欢编程：40×50%=20 人
```

喜欢编程的总人数：

```text
15 + 20 = 35
```

其中男生的概率：

```text
15 / 35 = 3/7
```

## 10. Pre-LN Transformer

**题目**

Pre-LN Transformer 更易训练深层网络的主要原因是什么？

- A. 残差主路径提供更直接的梯度传播
- B. 必须使用更大 batch
- C. 参数量显著更少
- D. 去掉了残差连接

**答案：A**

**解释**

Pre-LN 常见形式：

```text
x_{l+1} = x_l + F(LN(x_l))
```

残差中的 `x_l` 提供了更直接的恒等路径，梯度更容易跨越许多层传播，因此深层网络通常更容易优化。

## 11. GELU 激活函数

**题目**

关于 GELU，哪项正确？

- A. 是精确线性函数
- B. 负区间全部截断为零
- C. 一定比 Swish 慢很多
- D. 是基于概率门控直觉的平滑 ReLU 近似

**答案：D**

**解释**

GELU 常写作：

```text
GELU(x) = xΦ(x)
```

其中 `Φ(x)` 是标准正态分布的累积分布函数。它是平滑的概率门控形式，不像 ReLU 一样把全部负数直接截断为 0。

## 12. 误差传播

**题目**

关于误差传播，哪项最合理？

- A. 误差永不放大
- B. 乘法绝对误差等于各绝对误差乘积
- C. 加法结果的绝对误差上界为各项绝对误差之和
- D. 加法相对误差必等于各项相对误差之和

**答案：C**

**解释**

若：

```text
a 的绝对误差最多为 Δa
b 的绝对误差最多为 Δb
```

则：

```text
(a + b) 的绝对误差上界 ≤ Δa + Δb
```

这是由三角不等式得到的常见误差上界。

**题目**

视觉 Token Merging（ToMe）的核心思想是什么？

- A. 使用卷积步长下采样
- B. 在 Transformer 层中匹配并合并相似 token
- C. 随机丢弃一半 token

## 15. 线性变换的必然性质

**题目**

线性变换必然满足哪项？

- A. 保持夹角
- B. `T(v)=v²`
- C. `T(-v)=-T(v)`
- D. 保持长度

**答案：C**

**解释**

线性变换满足齐次性：

```text
T(cv) = cT(v)
```

令 `c=-1`：

```text
T(-v) = -T(v)
```

一般线性变换不一定保持长度或夹角。

## 16. 优化器选择（多选）

**题目**

关于优化器选择，哪些判断合理？

- A. 所有任务最终应使用同一优化器
- B. 训练损失低就必然泛化好
- C. 稀疏梯度场景中 Adam 类方法常有优势
- D. 更换优化器通常需联动调整学习率等超参数

**答案：C、D**

**解释**
优化器和超参数依任务而定，训练损失也不能保证泛化。

Adam 会对不同参数自适应调整学习率，因此在稀疏梯度等场景中常有优势。

优化器与学习率、weight decay、batch size 等超参数通常需要一起调整。低训练损失不保证测试集表现好，因此 B 错误。

## 17. 层次聚类的 Linkage（多选）

**题目**

哪些是层次聚类常见的簇间距离定义？

- A. Average Linkage
- B. Single Linkage
- C. Ward Linkage
- D. Complete Linkage

**答案：A、B、C、D**

**解释**

常见方法：

```text
Single Linkage：两簇最近样本之间的距离
Complete Linkage：两簇最远样本之间的距离
Average Linkage：两簇所有样本对距离的平均值
Ward Linkage：选择使簇内平方误差增加最小的合并方式
```

## 18. Transformer 归一化（多选）

**题目**

关于 Transformer 归一化，正确的有哪些？

- A. 归一化通常有助于训练收敛
- B. LN 与 BN 完全等价，可无条件互换
- C. RMSNorm 省去均值平移，主要做均方根缩放
- D. LN 对每个样本的特征维度归一化

**答案：A、C、D**

**解释**

```text
LN：对每个样本的特征维度计算均值和方差
BN：通常依赖 batch 维度统计量
RMSNorm：不减均值，使用 RMS 进行缩放
```

LN 与 BN 的统计维度、训练/推理行为不同，不能无条件互换。

## 19. K 近邻（KNN）归组的挑战（多选）

**题目**

K 近邻归组的常见挑战有哪些？

- A. 高维近邻关系不稳定
- B. K 值敏感
- C. 受异常点和噪声影响
- D. 大规模近邻搜索开销高

**答案：A、B、C、D**

**解释**

```text

异常点：会影响邻居投票和邻域结构
大规模数据：精确搜索通常需要较高计算开销
```

## 20. 递推算法的数值稳定性（多选）

**题目**

关于递推算法数值稳定性，正确的有哪些？

- A. 误差传播系数绝对值大于 1 时，正向误差可能放大
- B. 选择递推方向很关键
- C. 所有递推都不稳定
- D. 不稳定的正向递推有时可改用反向递推

**答案：A、B、D**

**解释**

递推中的舍入误差会不断传到下一步。若误差每一步大约乘以 `|r|`：

```text
|r| > 1 → 误差可能不断放大
|r| < 1 → 误差通常逐渐衰减
```

有些问题正向递推不稳定，但反向递推稳定。因此递推方向很重要，并非所有递推都不稳定。
