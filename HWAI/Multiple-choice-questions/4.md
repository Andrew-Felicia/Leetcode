# 1. 总结

这一组重点考察大模型生成、RAG、注意力机制、RNN/LSTM、激活函数、PCA 与反向传播。

| 主题 | 最基础的记忆点 |
|---|---|
| 生成策略 | Beam Search 同时保留多条高概率生成路径；温度影响随机采样，不是 Beam Search 的目的。 |
| RAG 与 Embedding | Embedding 将文本转成语义向量，用于向量相似度检索。 |
| Transformer | Q、K、V 是输入经过不同可学习投影得到的；自注意力建模 token 之间依赖。 |
| RNN/LSTM | RNN 处理序列、共享参数并维护状态；LSTM 用门控缓解长依赖梯度问题。 |
| 激活函数 | Sigmoid 输出 `(0,1)` 且非零中心，易饱和；ReLU 正半轴梯度为 1、计算简单。 |
| 数学与训练 | 方差中的系数要平方；PCA 保留足够累计方差；反向传播高效计算所有参数梯度。 |

# 2. 题目、答案与解释

## 1. Beam Search 的作用

**题目**

在解码过程中，Beam Search 的主要作用是？

- A. 搜索高概率的生成路径
- B. 减少单步矩阵乘法耗时
- C. 保证每次生成结果随机
- D. 增大采样温度

**答案：A**

**基础知识**

语言模型生成一句话时，每一步都会预测下一个 token 的概率：

```text
“我喜欢” → 电影: 0.4，音乐: 0.3，跑步: 0.1，……
```

贪心搜索每次只保留一个概率最大的 token。Beam Search 同时保留 `B` 条候选路径：

```text
Beam Size = 3
保留当前总概率最高的 3 条句子前缀
```

这样可能避免“当前一步最优、整句却不优”的问题。它的核心是搜索高概率路径，而不是随机采样或加速矩阵乘法。

## 2. Embedding 在 RAG 中的作用

**题目**

以下哪项不是 Embedding 在 RAG 中的核心作用？

- A. 把查询和文档映射到统一语义空间
- B. 压缩原始文档以减少磁盘占用
- C. 支持基于向量相似度的语义检索
- D. 借助多语言模型支持跨语言检索

**答案：B**

**基础知识**

RAG 的基本流程：

```text
用户问题 → Embedding 向量 → 检索相似文档 → 把文档交给 LLM 回答
```

Embedding 将文本映射为数字向量：

```text
“如何退款？” → [0.12, -0.31, ...]
“退款流程说明” → [0.10, -0.29, ...]
```

语义相近的文本通常向量也接近，因此可做语义检索和跨语言检索。Embedding 不是以减少原始文档磁盘占用为核心目的。

## 3. Sigmoid 的错误说法

**题目**

关于 Sigmoid 激活函数，下列说法错误的是？

- A. 函数平滑且可导
- B. 深层网络中容易出现梯度消失
- C. 输出以 0 为中心
- D. 输出范围为 `(0,1)`

**答案：C**

**基础知识**

Sigmoid 公式：

```text
σ(x) = 1 / (1 + e^(-x))
```

其输出范围：

```text
0 < σ(x) < 1
```

例如：

```text
σ(0) = 0.5
σ(很大正数) 接近 1
σ(很大负数) 接近 0
```

输出总是正数，不以 0 为中心。并且在两端容易饱和，导数接近 0，深层网络中可能发生梯度消失。

## 4. 对比损失与匹配损失

**题目**

多模态对齐训练中，关于对比损失与匹配损失的描述，哪项正确？

- A. 对比损失不使用负样本
- B. 两者目标完全相同
- C. 对比损失塑造正负样本的相对距离，匹配损失主要学习二分类边界
- D. 匹配损失固定只需一个负样本

**答案：C**

**基础知识**

例如图文对齐：

```text
图片“猫” + 文本“猫”     → 正样本对
图片“猫” + 文本“汽车”   → 负样本对
```

对比损失希望：

```text
正样本向量更近
负样本向量更远
```

匹配损失通常把“是否匹配”当作二分类：

```text
匹配 → 1
不匹配 → 0
```

所以两者相关，但任务形式不同。

## 5. Q、K、V 的来源

**题目**

自注意力机制中的 Q、K、V 通常如何得到？

- A. 由循环神经网络逐项生成
- B. 输入分别乘以三个可学习的投影矩阵
- C. 随机初始化后保持固定
- D. 直接复制输入且不做变换

**答案：B**

**基础知识**

输入序列表示为矩阵 `X`。注意力层学习三组参数：

```text
Q = XWq
K = XWk
V = XWv
```

其中 `Wq`、`Wk`、`Wv` 都是可训练矩阵。

直觉上：

```text
Q：当前位置“想查询什么”
K：每个位置“可以被如何匹配”
V：真正要传递的信息内容
```

## 6. Softmax 输出性质

**题目**

Softmax 函数输出的正确性质是？

- A. 各分量之和为 1
- B. 输出可能为负数
- C. 同一输入每次输出不同
- D. 输出与输入呈线性关系

**答案：A**

**基础知识**

Softmax：

```text
softmax(zi) = e^zi / Σ e^zj
```

因此：

```text
每一项 > 0
所有项之和 = 1
```

所以 Softmax 常用于把模型分数变成类别概率分布。

## 7. 自注意力的主要作用

**题目**

Transformer 中自注意力机制的主要作用是什么？

- A. 强制降低输入维度
- B. 生成最初的词表
- C. 建模序列元素之间的长距离依赖
- D. 把任意序列压成单个固定向量

**答案：C**

**基础知识**

在句子中：

```text
“小明把书放在桌子上，因为它太重了。”
```

理解“它”指什么，可能需要关注较远位置的词。自注意力允许每个 token 根据需要关注其他 token，因此擅长建模长距离依赖。

## 8. RNN 的特点

**题目**

下列哪项最完整地概括了循环神经网络（RNN）的特点？

- A. 适合处理序列数据
- B. 适合序列、跨时间步共享参数并具有状态记忆
- C. 只具有参数共享
- D. 只具有记忆能力

**答案：B**

**基础知识**

RNN 对序列逐步处理：

```text
h_t = f(Wx_t + Uh_(t-1))
```

其中：

```text
x_t：当前输入
h_(t-1)：前一步隐藏状态，即记忆
W、U：每一个时间步共享的参数
```

因此 RNN 同时具有序列处理、参数共享和状态记忆。

## 9. 方差的线性变换

**题目**

已知 `Var(X)=4`，则 `Var(3X-2)` 等于多少？

- A. `36`
- B. `10`
- C. `34`
- D. `12`

**答案：A. 36**

**基础知识**

方差关注随机变量的波动大小。

```text
Var(aX+b) = a²Var(X)
```

原因是加常数 `b` 只会整体平移，不改变波动；乘以 `a` 会把偏离均值的距离放大 `a` 倍，因此方差放大 `a²` 倍。

```text
Var(3X-2) = 3²×4 = 36
```

## 10. PCA 主成分个数

**题目**

PCA 的前五个特征值依次为 `45、25、10、8、2`，全部特征值之和为 `100`。若累计方差贡献率至少为 `85%`，最少保留几个主成分？

- A. `2`
- B. `5`
- C. `3`
- D. `4`

**答案：D. 4**

**基础知识**

PCA 中，每个特征值表示对应主成分解释的方差量。

累计贡献率：

```text
前 1 个：45/100 = 45%
前 2 个：(45+25)/100 = 70%
前 3 个：80%
前 4 个：88%
```

至少要达到 `85%`，所以最少保留 4 个。

## 11. LSTM 的目的

**题目**

RNN 中引入 LSTM 的主要目的，是通过门控机制缓解什么问题？

- A. 所有计算都无法并行
- B. 所有形式的过拟合
- C. 长距离依赖中的梯度消失或爆炸
- D. 输入维度过高

**答案：C**

**基础知识**

普通 RNN 在很长序列中不断重复乘矩阵：

```text
很小的数不断相乘 → 梯度趋近 0（梯度消失）
很大的数不断相乘 → 梯度变得极大（梯度爆炸）
```

LSTM 使用遗忘门、输入门、输出门来控制信息流，使长期信息更容易保留。

## 12. 几何分布之和

**题目**

若 `X1` 至 `Xn` 独立同分布，且都服从参数为 `p` 的几何分布，它们的和服从什么分布？

- A. 几何分布
- B. 正态分布
- C. 泊松分布
- D. 负二项分布

**答案：D. 负二项分布**

**基础知识**

几何分布可以理解为：

```text
第一次成功前，需要多少次试验
```

多个独立几何分布相加，可以理解为：

```text
获得第 n 次成功前，需要多少次试验
```

这正是负二项分布的典型含义。

## 13. Flash Decoding

**题目**

Flash Decoding 主要优化大语言模型推理的哪个阶段？

- A. Decode
- B. Embedding
- C. Tokenization
- D. Prefill

**答案：A. Decode**

**基础知识**

大模型推理通常分两阶段：

```text
Prefill：处理已有提示词，可并行处理多个 token
Decode：每次生成一个新 token，重复很多次
```

Decode 阶段经常受到 KV Cache 访问和较小计算规模的限制。Flash Decoding 主要针对这一阶段优化。

## 14. ReLU 的非典型优势

**题目**

相比 Sigmoid，以下哪项不是 ReLU 的典型优势？

- A. 在正半轴有助于缓解梯度消失
- B. 计算只需简单阈值判断
- C. 能够产生稀疏激活
- D. 输出天然以 0 为中心

**答案：D**

**基础知识**

ReLU：

```text
ReLU(x) = max(0, x)
```

优点：

```text
正数区域导数为 1
计算简单
负数输出为 0，因此可产生稀疏激活
```

但 ReLU 输出范围是 `[0, +∞)`，不是零中心。

## 15. 多头注意力的参数量和计算量

**题目**

标准多头注意力中，输入长度为 `n`、隐藏维度为 `d`。忽略 bias，关于参数量和主要计算量的说法正确的是？

- A. 参数量约 `4d²`，计算量只含 `O(nd²)`
- B. 参数量随 `n` 变化
- C. 参数量约 `3h(d/h)²+d²`，计算量为 `O(n²d²)`
- D. 参数量约 `4d²`，注意力矩阵相关计算量为 `O(n²d)`

**答案：D**

**基础知识**

标准注意力通常有 4 个投影矩阵：

```text
Wq、Wk、Wv、Wo
```

每个大致是 `d×d`，所以参数量约为：

```text
4d²
```

注意力分数矩阵：

```text
QKᵀ 的大小为 n×n
```

计算主要为：

```text
O(n²d)
```

这也是长序列注意力成本高的原因。

## 16. 深层网络常用 ReLU 的原因（多选）

**题目**

深层网络中更常使用 ReLU 而非 Sigmoid，合理原因有哪些？

- A. Sigmoid 在饱和区梯度接近 0
- B. Sigmoid 输出非零中心，可能降低优化效率
- C. ReLU 依赖指数运算，因此计算更高效
- D. ReLU 在正半轴导数为 1，有利于梯度传播

**答案：A、B、D**

**解释**

Sigmoid 需要指数计算，而 ReLU 只是：

```text
max(0, x)
```

所以 C 错误。A、B、D 都是 ReLU 在深层网络中常见的优势。

## 17. KNN 归组的挑战（多选）

**题目**

基于 K 近邻关系进行样本归组时，常见挑战有哪些？

- A. 容易受异常点和局部噪声影响
- B. 大规模数据的近邻搜索开销较高
- C. 高维空间中的近邻关系可能不稳定
- D. K 的选择会显著影响分组结果

**答案：A、B、C、D**

**基础知识**

```text
异常点：可能成为错误邻居
大规模数据：需要计算大量距离
高维空间：距离差异变小，谁是“近邻”变得不明显
K 值：太小易受噪声影响；太大可能混入其他类别
```

## 18. 反向传播的优势（多选）

**题目**

反向传播算法的优势包括哪些？

- A. 能够复用链式法则高效计算梯度
- B. 计算流程规则清晰，便于自动微分实现
- C. 适用于含大量层和参数的神经网络
- D. 相对逐参数数值差分，梯度计算复杂度较低

**答案：A、B、C、D**

**基础知识**

神经网络由很多复合函数组成：

```text
输入 → 层 1 → 层 2 → 损失
```

反向传播利用链式法则，从损失向前逐层计算梯度，并复用中间结果。

如果逐个参数做数值差分，参数有一百万个，就需要非常多次前向计算；反向传播通常只需一次前向加一次反向，就能得到所有参数的梯度。

## 19. 一定可逆的方阵（多选）

**题目**

下列哪些方阵一定可逆？

- A. 单位矩阵
- B. 满秩方阵
- C. 零矩阵
- D. 行列式非零的方阵

**答案：A、B、D**

**基础知识**

对 `n×n` 方阵，下列条件等价：

```text
可逆
满秩
行列式不为 0
列向量线性无关
```

单位矩阵的逆还是它自己。零矩阵的行列式为 0，不可逆。

## 20. 模型对齐失效的风险（多选）

**题目**

关于模型对齐失效，哪些因素可能增加模型输出有害内容的风险？

- A. 安全微调数据质量不足
- B. 推理温度设置过高，低概率不安全输出更易被采样
- C. 训练语料含大量未妥善处理的有害内容
- D. 攻击者构造越狱提示词

**答案：A、B、C、D**

**基础知识**

模型对齐的目标是让模型输出更符合安全、有帮助、诚实等要求。

以下情况都会提高风险：

```text
安全微调数据差：模型没学好拒答或安全边界
高温度：更容易采样到低概率、不可控的 token
有害训练语料未处理：模型可能学到不良模式
越狱提示：攻击者试图绕过安全指令
```

所以四项都正确。
