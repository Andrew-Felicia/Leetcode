| 主题 | 核心结论 |
| --- | --- |
| 通信领域 RAG | 结构化命令、IP、MAC、端口等应保留并用领域词表、语义切分和领域 Embedding 处理。 |

## 2. 题目、答案与解释

### 1. 通信故障 RAG 的文本处理

**题目**：网络配置命令、日志和故障案例包含大量命令行、MAC/IP 地址、端口、VLAN ID、OID 等结构化内容。最合适的检索处理方式是？

- A. 对命令行、IP、MAC、端口等增加专用词表，按命令块/日志条目切分，使用通信领域微调 Embedding
- B. 全部小写并去除符号
- C. 固定长度切分，使用通用分词与通用 Embedding
- D. 只使用 BM25，不使用 Embedding

**答案：A。**

**基础知识/解释**：`display interface`、IP、MAC、端口和 OID 都有重要结构含义。去掉符号可能破坏 IP/MAC/命令语义；固定长度切分也可能把一条日志或一段命令拆开。更合理的链路：

```text
按日志条目/命令块切分
-> 保留结构化 token
-> 通信领域词表或 tokenizer
-> 领域微调 Embedding
-> 可结合 BM25 + 向量检索
```

### 2. 比较三种训练数据配比准确率

**题目**：对比纯指令、指令+多轮对话、指令+知识三种训练数据配比下的模型准确率，最适合展示并进行组间比较的图表是？

- A. 分组柱状图
- B. 雷达图
- C. 饼图
- D. 直方图

**答案：A。**

**基础知识/解释**：分组柱状图适合比较多个离散组的数值：

```text
横轴：训练数据配比
纵轴：准确率
柱子：不同实验组
```

饼图适合组成比例，直方图适合连续数据分布，雷达图不如柱状图适合精确比较单一指标。

### 3. 牛顿迭代公式

**题目**：牛顿迭代法的迭代公式为？

- A. `x_(n+1)=x_n - f(x_n)/f'(x_n)`
- B. `x_(n+1)=x_n - f(x_n)`
- C. `x_(n+1)=x_n + f(x_n)/f'(x_n)`
- D. `x_(n+1)=x_n - f'(x_n)/f(x_n)`

**答案：A。**

**基础知识/解释**：在当前点 `x_n` 用函数切线近似曲线，切线与 x 轴交点就是下一次估计：

```text
x_(n+1) = x_n - f(x_n) / f'(x_n)
```

### 4. 张量并行 TP 的切分逻辑

**题目**：张量并行（TP）主要用于解决单卡无法容纳单个模型层权重的问题，其切分逻辑是？

- A. 按优化器状态切分
- B. 按网络层深度切分
- C. 按 batch 大小切分
- D. 按矩阵运算维度切分，同一层内权重拆分到不同 GPU

**答案：D。**

**基础知识/解释**：

```text
TP：同一层的大矩阵切到多张卡
PP：不同网络层切到不同卡
DP：不同 batch 样本切到不同卡
ZeRO：优化器/梯度/参数状态分片
```

### 5. 一定可逆的矩阵

**题目**：下列哪个矩阵一定可逆？

- A. 对称矩阵
- B. 行列式为零的矩阵
- C. 单位矩阵
- D. 所有元素都为零的矩阵

**答案：C。**

**基础知识/解释**：单位矩阵 `I` 满足：

```text
I × I = I
```

因此它的逆矩阵就是自己。对称矩阵不一定可逆，例如零矩阵也是对称矩阵；行列式为 0 则一定不可逆。

### 6. 推理显存满时的处理

**题目**：在多轮对话推理系统中，如果 GPU/NPU 显存已满但仍有新的 token 需要生成，系统通常采用什么策略？

- A. 将部分 KV Cache swap 到 CPU 或进行 recomputation
- B. 自动降低模型精度
- C. 重启服务器
- D. 直接杀掉进程

**答案：A。**

**基础知识/解释**：KV Cache 是长对话显存大户。显存不足时可将短期不用的缓存转移到 CPU，或不保存某些张量、需要时重算，用计算时间交换显存空间。

### 7. Conv + BN Folding

**题目**：推理部署阶段将卷积层与 BatchNorm 层融合，最准确的描述是？

- A. 为了加快 BN 梯度反向传播
- B. 编译期将 BN 缩放、偏移吸收到 Conv 权重和偏置，运行时没有 BN 开销
- C. 运行时传入 BN 均值方差并行计算
- D. 融合必然轻微改变输出精度，且不能用 Tensor Core

**答案：B。**

**基础知识/解释**：推理时 BN 使用固定的 running mean/variance，因此可以代数合并：

```text
Conv -> BN
等价改写为
新的 Conv 权重 + 新的 Conv 偏置
```

融合后少一个算子、少一次读写，通常提升推理效率。

### 8. Pipeline Bubble

**题目**：流水线并行中，某些 GPU 在等待上游 Stage 结果时出现空闲，这种现象称为？

- A. Pipeline Bubble
- B. 显存碎片
- C. GPU Context Switch
- D. 网络拥塞

**答案：A。**

**基础知识/解释**：流水线刚开始和快结束时，部分 stage 没有 micro-batch 可处理，形成“气泡”。增加 micro-batch 数、使用更好的调度（如 1F1B）可缓解，但不能总是完全消除。

### 9. HAC 的簇间距离定义

**题目**：在层次聚类 HAC 中，哪一种是定义簇间距离的常见方式？

- A. Expectation-Maximization
- B. K-Means
- C. DBSCAN
- D. Complete Linkage

**答案：D。**

**基础知识/解释**：HAC 常见 linkage：

```text
Single Linkage：两簇最近点距离
Complete Linkage：两簇最远点距离
Average Linkage：两簇所有点对距离平均
Ward Linkage：最小化合并后的方差增量
```

### 10. Micro-F1 主要反映哪个类别

**题目**：类别 A 有 1000 个样本，类别 B 有 10 个样本。使用 Micro-F1 时，主要反映哪个类别性能？

- A. 两者权重相同
- B. 取决于具体 F1 公式
- C. 类别 B
- D. 类别 A

**答案：D。**

**基础知识/解释**：Micro-F1 是先把所有类别的 TP、FP、FN 汇总，再计算 F1。因此样本多的类别贡献更大，结果被多数类 A 主导。若想让各类别更平等，可看 Macro-F1。

### 11. PyTorch 优化器更新

**题目**：PyTorch 中哪个函数用于执行优化器的一步更新？

- A. `optimizer.zero_grad()`
- B. `optimizer.backward()`
- C. `optimizer.step()`
- D. `optimizer.update()`

**答案：C。**

**基础知识/解释**：典型训练顺序：

```python
optimizer.zero_grad()
loss.backward()
optimizer.step()
```

`zero_grad()` 清空旧梯度，`backward()` 由 loss 对模型调用，`step()` 根据梯度更新参数。

### 12. 蒙特卡洛积分与黎曼积分

**题目**：关于蒙特卡洛积分与黎曼积分的对比，正确的是？

- A. MC 只适合低维，高维应使用黎曼积分
- B. MC 收敛 `O(N^-2)`，黎曼 `O(N^-1)`
- C. MC 总是首选
- D. MC 收敛 `O(N^-1/2)`，等距高阶黎曼/求积规则可达 `O(N^-2)`

**答案：D。**

**基础知识/解释**：蒙特卡洛误差常为：

```text
O(1 / sqrt(N))
```

它的优点是收敛率不强依赖维度，适合高维积分。对一维平滑函数，复合梯形/中点等确定性求积规则可有更快的误差阶，因此不应说 MC 总是首选。

### 13. 高维稀疏向量相似度

**题目**：适合高维稀疏向量相似度计算的是？

- A. 余弦相似度
- B. 切比雪夫距离
- C. 欧氏距离
- D. 曼哈顿距离

**答案：A。**

**基础知识/解释**：高维稀疏文本向量常关心“词分布方向是否相似”，不想被文本长度影响。余弦相似度可弱化向量长度影响，因此常用于 TF-IDF 与 Embedding 检索。

### 14. Encoder-Decoder Attention 的 Query 来源

**题目**：Transformer 的编码器-解码器注意力中，Query 来自哪里？

- A. 输入序列
- B. 解码器上一层输出
- C. 位置编码
- D. 编码器输出

**答案：B。**

**基础知识/解释**：交叉注意力中：

```text
Q：Decoder 当前层输入/上一子层输出
K,V：Encoder 输出
```

Decoder 用自己的状态作为问题（Q），去查询 Encoder 提供的源序列信息（K、V）。

### 15. 余弦相似度计算

**题目**：给定 `a=[1,2,3]`、`b=[4,5,6]`，余弦相似度为？

- A. 1.0
- B. 0.87
- C. 0.97
- D. 0.67

**答案：C，约 0.97。**

**基础知识/解释**：

```text
a·b = 1×4 + 2×5 + 3×6 = 32
||a|| = sqrt(1+4+9) = sqrt(14)
||b|| = sqrt(16+25+36) = sqrt(77)

cos(a,b) = 32 / (sqrt(14) × sqrt(77))
         ≈ 0.9746
```

### 16. 视觉-语言 Connector（多选）

**题目**：多模态大模型中，常见的视觉-语言连接器包括？

- A. MLP
- B. 线性投影层
- C. 卷积池化层
- D. Q-Former

**答案：A、B、D。**

**基础知识/解释**：Connector 的作用是把视觉编码器输出映射到语言模型可接受的表示空间。常见做法包括线性投影、MLP 和 Q-Former。卷积/池化更常被视为视觉编码或特征处理模块，而不是主流视觉-语言 Connector 的典型答案。

### 17. 特征向量相似度度量（多选）

**题目**：适用于机器学习中度量两个特征向量相似度的有？

- A. 欧氏距离
- B. 余弦相似度
- C. 汉明距离
- D. KL 散度

**答案：A、B、C。**

**基础知识/解释**：欧氏距离和余弦相似度常用于连续向量；汉明距离可用于二进制向量或编码。KL 散度用于比较两个概率分布，通常不作为一般特征向量的通用距离。

### 18. 正态分布的 MLE（多选）

**题目**：设 `X_1,...,X_n ~ N(μ,σ²)`，正确的有？

- A. μ 的 MLE 是样本均值 `X_bar`
- B. μ 的 MLE 是无偏的
- C. σ² 的 MLE 是 `(1/n)Σ(X_i-X_bar)²`
- D. σ² 的 MLE 是无偏的

**答案：A、B、C。**

**基础知识/解释**：

```text
μ_hat_MLE = X_bar
σ²_hat_MLE = (1/n) Σ(X_i-X_bar)²
```

样本均值是 μ 的无偏估计。方差的 MLE 分母为 n，但它有偏；分母为 `n-1` 的样本方差才是无偏估计。

### 19. 反向传播效率（多选）

**题目**：以下关于反向传播计算效率的说法正确的是？

- A. 反向传播计算量大约是前向传播的 2 倍
- B. 符号微分和数值微分只能二选一
- C. 反向传播需要保存中间层激活值，因此显存消耗大
- D. 相比数值微分，符号/自动微分计算梯度通常更高效

**答案：A、C、D。**

**基础知识/解释**：一次训练 step 通常包含前向、反向和更新。反向计算常约为前向的 2 倍量级，并且需要保存激活，导致训练显存显著高于纯推理。数值微分需要对每个参数反复扰动，参数很多时极慢；自动微分/反向传播可高效复用链式法则。

### 20. vLLM 晚高峰 TTFT 上升（多选）

**题目**：vLLM 服务在晚高峰出现：TTFT 从 0.9s 升至 2.4s、Decode tokens/s 基本不变、平均输入长度从 700 升至 2200、GPU 接近满载。本班次可立即执行哪些动作？

- A. 对超长输入先走摘要压缩链路，再送主模型
- B. 增大 temperature 到 1.2
- C. 把 max_new_tokens 从 512 调到 1024
- D. 开启/优化 prefix cache（固定 system prompt 场景）

**答案：A、D。**

**基础知识/解释**：问题主要是输入 Prompt 变长，Prefill 负担增加，TTFT 上升。合理动作：

```text
超长输入压缩/摘要 -> 减少 Prefill token
Prefix Cache         -> 复用固定系统提示的计算结果
```

Temperature 不会减少 Prompt 计算；增大 `max_new_tokens` 还可能增加 Decode 占用与排队压力。
