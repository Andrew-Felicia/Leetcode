## 一、单选题

### 1. 岭回归中，当 λ 较大时，偏差和方差如何变化？
- A. 偏差增大，方差减小
- B. 偏差减小，方差增大
- C. 偏差增大，方差增大
- D. 偏差减小，方差减小

**答案：A**

**详解：** λ 是"惩罚力度"。λ 越大，模型的权重被压得越小，模型越简单、越"死板"。
- 简单模型拟合不了数据的细节，所以**偏差增大**（欠拟合倾向）。
- 但它对训练数据的小变化不敏感，所以**方差减小**。

记忆口诀：**模型越简单，偏差大、方差小；模型越复杂，偏差小、方差大。**

### 2. 伯努利分布样本 {1,0,1,1}，对 p 的最大似然估计为？
- A. 样本中位数
- B. 0.75
- C. 0.5
- D. 0.25

**答案：B**

**详解：** 伯努利分布的 MLE 就是**样本均值**，也就是"1 出现的比例"。4 个样本里有 3 个 1，所以 p̂ = 3/4 = **0.75**。

推导（选看）：似然函数 L = p³(1−p)，取对数 3ln p + ln(1−p)，求导令其为 0：3/p − 1/(1−p) = 0，解得 p = 0.75。

### 3. 最大似然估计中，为什么通常对似然函数取对数？
- A. 增加模型复杂度
- B. 使参数估计更准确
- C. 引入先验分布
- D. 把乘法转化为加法，简化计算

**答案：D**

**详解：** 似然函数是很多个概率**相乘**，求导麻烦，而且很多小数相乘容易下溢（变成 0）。取对数后乘法变加法：ln(a·b) = ln a + ln b，求导容易，数值也更稳定。又因为对数是单调递增函数，不会改变最大值的位置，所以估计结果不变（B 错）。

### 4. 图像分类中，模型将大量负样本误判为正样本，说明？
- A. Accuracy 偏高
- B. Precision 偏高
- C. Recall 偏低
- D. Precision 偏低

**答案：D**

**详解：** 把负样本误判为正样本，就是**假正例（FP）变多**。
Precision（精确率）= TP / (TP + FP)，FP 变大，分母变大，所以 **Precision 偏低**。
Recall = TP / (TP + FN)，与 FP 无关，所以不选 C。

### 5. 在 ℝ² 中，下列集合是子空间的有？
- A. {(x,y) | y=0}
- B. {(x,y) | y=0}（与 A 等价）
- C. {(x,y) | x+y=1}
- D. {(x,y) | x+1=2y}

**答案：A（B 与 A 内容完全相同，也成立）**

> **说明：** 原题 A、B 选项重复，可能是录入错误。作为单选题，按选项 A 作答；如果允许多选，则 A、B 都对。

**详解：** 子空间必须满足：**包含零向量**，并且对加法和数乘封闭。
- {y=0} 是 x 轴，包含 (0,0)，任意两点相加、数乘后仍在 x 轴上，所以是子空间。
- {x+y=1}：(0,0) 代入得 0≠1，不含零向量，**不是**子空间。
- {x+1=2y}：(0,0) 代入得 1≠0，不含零向量，**不是**子空间。

快速判断技巧：先看零向量在不在，不在就直接排除。

### 6. 神经网络中，反向传播用于？
- A. 计算梯度
- B. 前向计算
- C. 更新权重
- D. 初始化参数

**答案：A**

**详解：** 反向传播（Backpropagation）利用链式法则，从输出层往回一层层算出**损失对每个权重的梯度**。
注意区分：**更新权重**是优化器（如 SGD、Adam）利用梯度完成的，不是反向传播本身。前向计算是反向传播的"反面"。

### 7. 深度学习中的"早停法"是？
- A. 初始化时停止训练
- B. 为减少计算提前结束训练
- C. 训练初期停止避免梯度爆炸
- D. 当验证集性能不再提升时停止训练

**答案：D**

**详解：** 训练时，训练集的损失会一直下降，但验证集的损失到某个时刻开始上升，这就是**过拟合**的信号。早停法就是监控验证集，性能不再提升（或开始变差）时就停止训练，是一种防止过拟合的方法。

### 8. Scaled Dot-Product Attention 中对 QKᵀ 除以 √d_k 的主要目的是？
- A. 引入归一化的位置信息
- B. 缩小 softmax 输入方差，避免梯度饱和
- C. 提高模型容量
- D. 减少计算量

**答案：B**

**详解：** d_k 很大时，点积的方差约为 d_k，数值会很大。softmax 遇到很大的数会变得极端（接近 one-hot），梯度几乎为 0，训练困难（"梯度饱和"）。除以 √d_k 把方差拉回约 1，让 softmax 保持平滑。它不引入位置信息，也不提高容量和减少计算量。

### 9. 对于一个满秩矩阵（方阵），以下哪项一定成立？
- A. 零空间包含非零向量
- B. 行列式为 0
- C. 可逆
- D. 特征值全为零

**答案：C**

**详解：** 满秩方阵等价于下面这些说法（可以背下来）：
- 可逆
- 行列式 ≠ 0
- 零空间只有零向量
- 所有特征值都 ≠ 0

所以 A、B、D 都是它的反面，只有 **C 可逆**一定成立。

### 10. 设事件 A 与自身独立，则 A 的概率为？
- A. 0.5
- B. 1
- C. 0
- D. 0 或 1

**答案：D**

**详解：** 独立的定义：P(A∩A) = P(A)·P(A)。
而 A∩A = A，所以 P(A) = P(A)²，即 P(A)(P(A) − 1) = 0，解得 P(A) = **0 或 1**。

### 11. 向量组 {(1,0,1), (0,1,1), (1,1,2)} 的线性关系是？
- A. 线性无关，秩为 3
- B. 线性无关，秩为 2
- C. 线性相关，秩为 2
- D. 线性相关，秩为 1

**答案：C**

**详解：** 观察发现：(1,0,1) + (0,1,1) = (1,1,2)，即第三个向量可以由前两个表示，所以**线性相关**。
前两个向量 (1,0,1)、(0,1,1) 彼此不成比例，线性无关，所以秩为 **2**。

### 12. Transformer 中，位置编码的作用是？
- A. 提供序列中不同词的位置信息
- B. 增加模型的非线性
- C. 优化注意力权重
- D. 压缩序列长度

**答案：A**

**详解：** 注意力机制是同时看所有词的，本身不知道谁在前、谁在后（"我爱你"与"你爱我"对它是一样的）。位置编码给每个词加上位置标记，让模型知道词序。

### 13. 最大似然估计的核心思想是？
- A. 找到使观测数据出现概率最大的参数
- B. 最小化预测误差平方和
- C. 优先选择先验概率最大的参数
- D. 用样本矩匹配总体矩

**答案：A**

**详解：** MLE 的思想：既然这批数据已经发生了，那就选一个参数，让这批数据"最可能出现"。
- B 是最小二乘法。
- C 是贝叶斯方法（MAP）。
- D 是矩估计。

### 14. 交叉熵损失函数主要用于？
- A. 回归
- B. 降维
- C. 分类
- D. 聚类

**答案：C**

**详解：** 交叉熵衡量模型预测的概率分布与真实标签之间的差距，用于**分类**任务。回归一般用 MSE。

### 15. 下列哪一项**不是**泊松过程的特征？
- A. 事件发生的间隔服从指数分布
- B. 不重叠区间事件相互独立
- C. 事件发生的时间间隔服从正态分布
- D. 单位时间内事件数服从泊松分布

**答案：C**

**详解：** 泊松过程的标准性质：
- 事件间隔服从**指数分布**（A 对）
- 不重叠区间的事件数**独立**（B 对，即独立增量）
- 一段时间内事件数服从**泊松分布**（D 对）

间隔是指数分布而不是正态分布，所以 C 是错误的描述，也就是本题要选的"不是"。

## 二、多选题

### 16. 关于自注意力机制及其变体，哪些陈述准确？
- A. GQA 中不同组 Query 必须串行计算，无法并行
- B. 从 MHA 到 GQA/MQA 的动机之一是减小推理时 KV 缓存以降显存
- C. 单个头内部 Q 和 K 的维度 d_k 必须相等，Value 维度可不同
- D. 将 QKᵀ 除以 √d_k 有助于稳定梯度，避免 softmax 饱和

**答案：BCD**

**详解：**
- A 错：不同组之间互相独立，完全可以并行，GPU 本来就是并行计算。
- **B 对**：GQA/MQA 让多个头共享 K/V，KV Cache 变小，推理更省显存。
- **C 对**：Q 和 K 要做点积，维度必须相等；V 是被加权求和的对象，维度可以不同（输出维度由 V 决定）。
- **D 对**：见第 8 题。

### 17. 关于多模态大模型（BLIP-2、LLaVA、GPT-4V），正确的是？
- A. LLaVA 完全移除视觉编码器
- B. 多数开源多模态 LLM 的视觉适配层参数量远小于语言模型主体，可视作 PEFT
- C. GPT-4V 将视觉信息 token 化并与文本一起在统一 Transformer 建模
- D. BLIP-2 冻结视觉编码器 + Q-former，将视觉特征对齐到语言模型可用空间

**答案：BD**（C 见下方说明）

**详解：**
- A 错：LLaVA 使用 CLIP 视觉编码器，没有移除，只是用一个投影层把视觉特征接到语言模型上。
- **B 对**：适配层（如线性层或 MLP）参数很少，训练时往往只训练它（有时加 LoRA），与参数高效微调的思想一致。
- **D 对**：BLIP-2 冻结视觉编码器和语言模型，只训练中间的 Q-Former，把视觉特征转成语言模型能用的表示。
- C 的情况：GPT-4V 的架构**官方并未公开**，"统一 Transformer 建模"只是常见推测，不是确认的事实，所以严谨的做法不选。如果你们的参考答案选了 C（认为这是业内通行的说法），则答案为 BCD。

### 18. 矩阵分解方法在推荐系统中的应用，正确的有？
- A. PCA 用于降维
- B. NMF 用于非负矩阵分解
- C. QR 分解用于求解线性方程、最小二乘
- D. SVD 用于协同过滤

**答案：ABCD**

**详解：**
- **A**：PCA 可对用户或物品特征降维。
- **B**：NMF 把评分矩阵分解成两个非负矩阵，结果可解释（如"兴趣主题"）。
- **C**：QR 分解数值稳定，常用于最小二乘问题（如交替最小二乘 ALS 中的求解）。
- **D**：SVD 是经典的协同过滤方法，把评分矩阵分解成用户矩阵和物品矩阵（隐语义模型）。

四项描述的都是各方法的常见用途，所以全选。

### 19. 单位矩阵 Iₙ 的性质，哪些一定成立？
- A. 所有特征值都等于 1
- B. 与任何同形矩阵左乘或右乘都保持该矩阵不变
- C. 秩等于 n
- D. 行列式为 0

**答案：ABC**

**详解：**
- **A 对**：Iv = 1·v，所以特征值全是 1。
- **B 对**：I 就是矩阵乘法里的"数字 1"，A·I = I·A = A。
- **C 对**：I 是满秩的，秩为 n。
- D 错：det(I) = **1**，不是 0。

### 20. 关于连续型随机变量，以下说法正确的是？
- A. 若 PDF f(x) 为偶函数，则分布关于 0 对称
- B. CDF 一定是连续函数
- C. 对任意实数 a 有 P(X=a)=0
- D. PDF 在某点可大于 1 但积分为 1

**答案：ABCD**

**详解：**
- **A 对**：f(−x) = f(x) 表示密度图像关于 y 轴对称，所以分布关于 0 对称。
- **B 对**：连续型随机变量的 CDF 是 PDF 的变上限积分，一定是连续函数。
- **C 对**：单个点的"面积"为 0，所以取到某个具体值的概率为 0。
- **D 对**：PDF 的值不是概率，可以大于 1。例如在 [0, 0.5] 上的均匀分布，密度恒为 2，但总积分仍为 1。
