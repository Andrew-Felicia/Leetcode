# 1. 总结

这一组重点考察回归、重计算、激活函数、线性代数、数值计算、检索优化、量化和最大似然估计。

| 主题 | 最基础的记忆点 |
|---|---|
| 回归 | 连续数值预测通常使用线性输出层，即最后一层不加激活函数。 |
| 训练显存 | 重计算少存激活、反向时重算，用时间换显存。 |
| 分类指标 | 精确率 `Precision = TP / (TP + FP)`。 |
| 数值计算 | 浮点数不能精确表示所有小数；加法可能不满足结合律。 |
| 检索/RAG | 好的 Chunk、Rerank、证据引用/拒答能快速改善检索质量。 |
| 量化 | INT4/INT8 通常降低显存，但可能带来误差累积。 |

## 1. 降雨量回归的输出层

**题目**

使用 MLP 预测每月降雨量时，输出层推荐使用什么激活？

- A. ReLU
- B. Tanh
- C. Sigmoid
- D. 不使用激活函数

**答案：D. 不使用激活函数**

**基础知识**

降雨量是连续数值回归问题，例如：

```text
12.3 mm
87.5 mm
250.0 mm
```

回归输出一般希望不被固定范围限制，所以常用：

```text
y = wᵀx + b
```

即最后一层使用线性输出，不加激活函数。

```text
Sigmoid：限制到 (0,1)
Tanh：限制到 (-1,1)
ReLU：限制到 [0,+∞)，可能不适合一般回归且会截断负值
```

若业务明确保证输出非负，有时也可使用 ReLU/Softplus；但标准回归题的默认答案是线性输出层。

## 2. 重计算策略的错误说法

**题目**

关于重计算策略的“时间换空间”原理，下列说法错误的是？

- A. 重计算仅适用于推理阶段，不适用于训练阶段
- B. 缓存的关键中间特征越少，显存越低但重复计算越多
- C. 重计算通常不改变模型输出，只影响时间和显存
- D. 核心是按需重构中间特征，而非全程缓存

**答案：A**

**基础知识**

重计算最常见的场景恰恰是训练阶段。

普通训练：

```text
前向传播 → 保存大量激活值 → 反向传播读取激活值
```

重计算：

```text
前向传播 → 少保存一些激活值
反向传播 → 需要时重新跑一部分前向传播
```

因此：

```text
保存越少 → 显存越低 → 重算越多 → 时间通常更长
```

## 3. Tanh 的权重初始化

**题目**

隐藏层使用 Tanh 时，权重初始化应注意什么？

- A. 全部初始化为 0
- B. 初始化为很大的值
- C. 随机初始化为较小的值，例如 Xavier 初始化
- D. 全部初始化为负数

**答案：C**

**基础知识**

Tanh 输出范围为：

```text
(-1, 1)
```

若权重很大，层输出容易落到 `-1` 或 `1` 附近，进入饱和区，导数接近 0，导致梯度消失。

Xavier 初始化会让初始激活和梯度的尺度更稳定。全部初始化为 0 会让神经元完全对称，无法学到不同特征。

## 4. 对数几率的取值范围

**题目**

对数几率：

```text
ln(p / (1-p))
```

的取值范围是什么？

- A. `(-∞, +∞)`
- B. `(0, +∞)`
- C. `[0,1]`
- D. `[-1,1]`

**答案：A**

**基础知识**

概率满足：

```text
0 < p < 1
```

当：

```text
p → 0，p/(1-p) → 0，对数 → -∞
p → 1，p/(1-p) → +∞，对数 → +∞
```

所以 Logit（对数几率）把概率区间 `(0,1)` 映射到全体实数。

## 5. 精确率 Precision

**题目**

混淆矩阵：

```text
TP=40，FP=10，FN=20，TN=30
```

精确率是多少？

- A. `80%`
- B. `50%`
- C. `66.7%`
- D. `57.1%`

**答案：A. 80%**

**基础知识**

```text
TP：预测为正，实际也为正
FP：预测为正，实际为负
FN：预测为负，实际为正
TN：预测为负，实际也为负
```

精确率问的是：

```text
“所有被模型判成正类的样本中，有多少是真的正类？”
```

```text
Precision = TP / (TP + FP)
          = 40 / (40 + 10)
          = 80%
```

## 6. Lagrange 插值增加节点

**题目**

Lagrange 插值从节点 `x0、x1、x2` 增加到 `x3` 后，关于新三次插值多项式 `P` 与原二次多项式 `L`，哪项正确？

- A. 构造 `P` 必须重新计算所有差商
- B. `P` 的 Lagrange 基函数与 `L` 完全相同
- C. 在 `x0、x1、x2` 上，`P` 与 `L` 的函数值相同
- D. `P-L` 的系数一定是三阶以前的差商

**答案：C**

**基础知识**

插值多项式的目标是穿过给定节点：

```text
L(x0)=y0，L(x1)=y1，L(x2)=y2
```

增加节点后，新三次多项式 `P` 需要同时满足：

```text
P(x0)=y0，P(x1)=y1，P(x2)=y2，P(x3)=y3
```

所以在旧的三个节点上，`P` 与 `L` 的函数值仍相同；但两者不一定是同一个多项式，基函数也会改变。

## 7. 线性变换的核心性质

**题目**

线性变换的核心性质是什么？

- A. 保持正交性
- B. 保持线性组合
- C. 保持向量方向
- D. 保持向量长度

**答案：B. 保持线性组合**

**基础知识**

线性变换 `T` 满足：

```text
T(au + bv) = aT(u) + bT(v)
```

这叫保持线性组合。

一般线性变换可以拉伸、旋转、压缩或剪切向量，因此不一定保持方向、长度或正交性。

## 8. 线性模型输出

**题目**

```text
w=(1,2)，x=(3,4)，b=1
y=wᵀx+b
```

输出是多少？

- A. `13`
- B. `10`
- C. `12`
- D. `11`

**答案：C. 12**

**解释**

先计算内积：

```text
wᵀx = 1×3 + 2×4 = 3 + 8 = 11
```

再加偏置：

```text
y = 11 + 1 = 12
```

## 9. 损失函数的作用

**题目**

梯度下降训练中，损失函数的作用是什么？

- A. 记录训练总时间
- B. 自动增加训练数据
- C. 决定测试集最高分上限
- D. 作为优化目标，其参数梯度指明更新方向

**答案：D**

**基础知识**

损失函数衡量预测与真实答案的差距：

```text
预测越差 → 损失越大
预测越好 → 损失越小
```

梯度是损失对参数的变化率：

```text
参数新值 = 参数旧值 - 学习率 × 梯度
```

减去梯度，是为了向损失下降最快的方向移动。

## 10. 大模型评测数据污染

**题目**

大模型评测中的“数据污染”通常指什么？

- A. 评测题出现在模型训练语料中，导致评分虚高
- B. 训练数据含错别字
- C. 模型输出敏感词
- D. 数据库感染病毒

**答案：A**

**基础知识**

评测应检查模型对未见数据的泛化能力。

若评测题已出现在训练语料中：

```text
模型可能记住题目或答案
评测分数会虚高
不能真实代表泛化能力
```

这就是评测数据污染。

## 11. 一元线性模型的截距

体重减少量 `y` 与每周运动时长 `x` 满足：

y = 0.3x + b

本周运动 `2` 小时，体重减少 `0.56 kg`，截距是多少？

**答案：A. -0.04**

## 12. 模型未运行在 NPU 上的排查

**题目**

排查模型未在 NPU 上运行时，应优先检查哪项？

- A. 推理速度是否低于 CPU
- B. 输入格式是否符合要求
- C. 训练精度是否达到预期
- D. 模型转换日志是否有 unsupported op、fallback 或 compile fail

**答案：D**

**基础知识**

模型部署到 NPU 通常经历：

```text

```

若日志出现：

```text
unsupported op：算子不支持
fallback：回退到 CPU
compile fail：编译失败
```

就能直接定位为何没有运行在 NPU。

## 13. HAC 层次凝聚聚类的增量更新

**题目**

关于 HAC 层次凝聚聚类的增量更新能力，哪项最准确？

- A. 完全无法接收新增样本
- B. 层次合并具有全局依赖性，严格增量更新通常较困难
- C. 新增样本无需计算距离
- D. 可高效在线更新且与全量重跑结果完全一致

**答案：B**

**基础知识**

HAC 从每个样本单独成簇开始，不断合并距离最近的簇：

```text
很多小簇 → 少量大簇 → 一棵聚类树
```

新样本加入后，早期“哪两个簇先合并”的决定也可能改变，因此严格得到与全量重跑完全相同的层次树通常较困难。

## 14. 归一化后的欧氏距离与余弦

**题目**

图像特征：

```text
a=(1,2)，b=(2,1)，查询向量 c=(3,3)
```

以下说法最严谨的是？

- A. 向量整体加 `(1,1)` 后余弦相似度一定不变
- B. L2 归一化后，欧氏距离与余弦相似度单调相关
- C. 曼哈顿距离为 2，因此在任何检索任务中都优于其他距离
- D. `a` 与 `c` 的余弦相似度高于 `b` 与 `c`

**答案：B**

**基础知识**

对 L2 归一化向量 `u、v`：

```text
||u|| = ||v|| = 1
```

有：

```text
||u-v||² = ||u||² + ||v||² - 2u·v
         = 2 - 2cos(u,v)
```

因此归一化后：

```text
余弦越大 → 欧氏距离越小
```

本题中 `a` 和 `b` 相对 `c` 是对称的，余弦相似度相同，所以 D 错误。给向量加同一常量会改变方向，因此 A 错误。

## 16. 浮点数运算（多选）

**题目**

关于浮点数运算，正确的有哪些？

- A. 机器精度刻画浮点运算可达到的相对舍入精度量级
- B. 浮点数可以精确表示所有十进制小数
- C. 浮点加法不满足结合律
- D. 对普通有限数值，浮点乘法满足交换律

**答案：A、C、D**

**基础知识**

计算机通常以二进制表示浮点数，因此很多十进制小数无法精确表示：

```text
0.1 + 0.2 可能得到 0.30000000000000004
```

舍入会造成：

```text
(a+b)+c 不一定等于 a+(b+c)
```

这说明加法不满足结合律。对普通有限数值，`a×b` 与 `b×a` 通常相同，所以乘法满足交换律。

## 17. 缓解梯度消失的激活函数（多选）

**题目**

哪些激活函数更有助于缓解深层网络的梯度消失？

- A. Sigmoid
- B. Leaky ReLU
- C. Tanh
- D. ReLU

**答案：B、D**

**基础知识**

```text
Sigmoid、Tanh：在饱和区导数接近 0
ReLU：正半轴导数为 1
Leaky ReLU：负半轴保留一个小的非零斜率
```

因此 ReLU 和 Leaky ReLU 更有助于缓解梯度消失。

## 18. 快速改善 RAG 检索链路（多选）

**题目**

抽样失败案例发现 Top5 中常有 2 至 3 条不相关文档，哪些是可快速上线的检索链路改进？

- A. 按段落或标题语义切分 Chunk，并保留适量重叠
- B. 只把生成温度降为 0，不调整检索
- C. 检索后增加 Rerank，并只把 Top2 至 Top3 高质量片段送入生成
- D. 要求回答引用片段 ID，未命中证据时拒答

**答案：A、C、D**

**基础知识**

RAG 链路通常是：

```text
查询 → 初步检索 TopK → Rerank → 把高质量证据交给 LLM → 回答
```

```text
Chunk：切得合理能减少无关文本混入
Rerank：对初步候选做更精细排序
引用/拒答：没有证据时避免模型编造
```

降低生成温度只影响生成随机性，不能解决“检索到了无关文档”的问题。

## 19. 端侧 Transformer 量化（多选）

**题目**

端侧部署 3B Transformer 时采用 INT4 权重量化与 INT8 KV Cache 量化，正确的有哪些？

- A. 降低 KV Cache 占用后可以支持更长生成序列
- B. 量化必然提升精度并增加延迟
- C. 量化可降低显存占用
- D. 长文本生成中量化误差可能累积

**答案：A、C、D**

**基础知识**

量化把高精度数值压缩为低位宽整数：

```text
FP16：每个数约 16 bit
INT8：每个数约 8 bit
INT4：每个数约 4 bit
```

所以量化通常降低权重和 KV Cache 的显存占用。更小的 KV Cache 可容纳更多历史 token，从而支持更长生成。

但量化会引入近似误差，长序列中误差可能累积；它不保证提高精度。

## 20. 最大似然估计 MLE（多选）

**题目**

关于最大似然估计（MLE），正确的有哪些？

- A. 似然是观测样本联合概率或密度关于参数的函数
- B. MLE 一定无偏
- C. 通常取对数似然以便求导和避免连乘数值问题
- D. MLE 的目标是最大化似然函数

**答案：A、C、D**

**基础知识**

给定样本 `x1, x2, ..., xn`，似然函数把样本看作已知，把参数 `θ` 看作变量：

```text
L(θ) = P(data | θ)
```

MLE 选择让当前数据最可能出现的参数：

```text
θ_MLE = argmax L(θ)
```

常取对数：

```text
log(Π pi) = Σ log(pi)
```

这样更容易求导，也避免很多很小概率连乘后下溢。MLE 不一定无偏。
