什么是梯度爆炸和梯度消失？它们的原因是什么？



梯度消失和梯度爆炸都发生在反向传播过程中：

- **梯度消失**：越靠近输入层，梯度越来越小，参数几乎无法更新。
- **梯度爆炸**：梯度在逐层传播时快速增大，导致参数更新过猛，Loss 剧烈波动甚至出现 NaN/Inf。

## 1. 为什么会出现

假设一个深层网络：

```text
x → 第1层 → 第2层 → ... → 第L层 → Loss
```

反向传播依赖链式法则。前面层的梯度大致是很多层局部导数和权重矩阵的连乘：

```text
dLoss/dx
= J1 × J2 × ... × JL × dLoss/doutput
```

其中 `Jl` 是第 `l` 层的局部 Jacobian。

如果每一层的梯度缩放比例都约为 `0.5`：

```text
0.5^10  ≈ 0.001
0.5^100 ≈ 0
```

梯度就会消失。

如果每层缩放比例都约为 `1.5`：

```text
1.5^10  ≈ 57.7
1.5^100 ≈ 4.1×10^17
```

梯度就会爆炸。

所以根本原因是：

> 反向传播要连续乘许多权重矩阵和激活函数导数；这些乘积的尺度长期小于1或大于1，就会指数级衰减或增长。

---

# 2. 梯度消失

## 表现

- 前面几层的梯度接近0；
- 深层参数在更新，浅层参数几乎不变；
- Loss 下降很慢或早早停止；
- 网络加深后反而训练不动；
- RNN 难以学习长期依赖；
- Sigmoid 神经元进入饱和区。

例如：

```text
输出层梯度：  1e-1
中间层梯度：  1e-5
输入附近：    1e-12
```

## 原因一：Sigmoid 和 Tanh 饱和

Sigmoid：

```text
sigmoid(x) = 1 / (1 + exp(-x))
```

导数：

```text
sigmoid'(x) = sigmoid(x) × (1 - sigmoid(x))
```

其最大值只有 `0.25`。

连续经过多层 Sigmoid 时，仅激活函数导数就会不断把梯度缩小：

```text
0.25^10 ≈ 9.5×10^-7
```

当输入绝对值很大时，Sigmoid 输出接近0或1，导数更接近0：

```text
x 很大  → sigmoid(x) ≈ 1 → 导数 ≈ 0
x 很小  → sigmoid(x) ≈ 0 → 导数 ≈ 0
```

Tanh 的最大导数可以达到1，但进入饱和区后导数仍接近0。

## 原因二：权重初始化过小

反向传播经过线性层时：

```text
上一层梯度 = W^T × 当前梯度
```

如果权重矩阵整体尺度过小，梯度每经过一层都会缩小。

## 原因三：网络太深

即使每层只轻微缩小梯度，经过几十或几百层后，也可能变得极小。

## 原因四：RNN 序列太长

普通 RNN 在时间维度重复使用同一个权重：

```text
h1 → h2 → h3 → ... → hT
```

反向传播需要穿过所有时间步，梯度包含循环权重矩阵的多次连乘。因此长序列中特别容易发生梯度消失。

这使普通 RNN 很难学习：

```text
序列开头的信息
影响很久之后的输出
```

## 原因五：归一化和残差设计不合理

深层网络如果没有适当的：

- 残差连接；
- LayerNorm、BatchNorm 或 RMSNorm；
- 合理残差缩放；
- Pre-Norm；

各层激活和梯度的尺度更难保持稳定。

# 3. 梯度爆炸

## 表现

- Loss 突然剧烈上升；
- 梯度范数快速增大；
- 参数数值变得特别大；
- 训练出现 NaN 或 Inf；
- 模型输出突然异常；
- 不同 step 之间波动极大。

例如：

```text
step 100：gradient norm = 2.3
step 101：gradient norm = 18
step 102：gradient norm = 9000
step 103：loss = NaN
```

## 原因一：权重矩阵尺度过大

如果每层反向传播都将梯度放大，连续多层后会指数增长。

从矩阵角度看，如果连乘矩阵的主导奇异值长期大于1，梯度容易爆炸。

## 原因二：网络或序列过深

深层网络和长序列 RNN 都需要更长的梯度传播路径。即使每一步只放大一点，累积后也可能非常大。

## 原因三：初始化不合理

权重方差过大，会同时导致：

- 前向激活持续增大；
- 反向梯度持续增大。

## 原因四：学习率过高

严格来说，学习率不直接改变当前反向传播算出的梯度，但过高学习率会造成：

```text
参数更新过大
→ 参数进入不稳定区域
→ 下一步激活和梯度变大
→ 参数继续剧烈变化
```

最终形成失控循环。

## 原因五：异常数据或 Loss 缩放错误

例如：

- 极端标签；
- 输入没有归一化；
- `mean` 错写成 `sum`；
- batch size 或序列长度增大但 Loss 未归一化；
- 除以接近0的数；
- 对0取对数；
- 多任务 Loss 权重过大；
- 梯度累积时忘记除以累积步数。

这些问题可能让某个 batch 的梯度突然异常。

## 原因六：低精度数值溢出

FP16 数值范围有限。当激活或梯度太大时可能变成：

```text
Inf
```

后续计算就可能变成：

```text
NaN
```

# 4. 梯度消失和梯度爆炸的区别

| 维度 | 梯度消失 | 梯度爆炸 |
|---|---|---|
| 梯度大小 | 趋近于0 | 急剧增大 |
| 参数更新 | 几乎不更新 | 更新幅度过大 |
| Loss 表现 | 下降缓慢、停滞 | 剧烈波动、突然上升 |
| 常见结果 | 学不动 | NaN/Inf、训练崩溃 |
| 常见位置 | 靠近输入的前层 | 可能迅速影响所有层 |
| 常见诱因 | 饱和激活、权重过小 | 权重过大、异常 batch、高学习率 |
| 典型网络 | 深层 Sigmoid、普通 RNN | 深层网络、长序列 RNN、低精度训练 |

二者也可能同时存在：部分层梯度接近0，另一些分支或参数梯度非常大。

# 5. 常见解决方法

## 使用合理的权重初始化

### Xavier 初始化

适合 Tanh、Sigmoid 等激活函数，目标是让前向激活和反向梯度的方差保持相对稳定。

大致尺度：

```text
Var(W) ≈ 2 / (fan_in + fan_out)
```

### He 初始化

适合 ReLU 及其变体：

```text
Var(W) ≈ 2 / fan_in
```

## 使用非饱和激活函数

深层隐藏层通常优先考虑：

- ReLU；
- Leaky ReLU；
- GELU；
- SiLU。

它们比多层 Sigmoid 更不容易造成严重梯度消失。

Sigmoid 仍适合：

- 二分类输出层；
- 门控结构；
- 概率输出。

## 使用残差连接

残差结构：

```text
y = x + F(x)
```

其梯度包含一条直接路径：

```text
dLoss/dx
= dLoss/dy
+ 经过 F 的梯度
```

即使 `F` 分支的梯度很小，梯度仍可以沿恒等路径传播。

这是 ResNet 和 Transformer 能训练很深的重要原因。

## 使用归一化

常见方法：

- BatchNorm；
- LayerNorm；
- RMSNorm；
- GroupNorm。

它们可以稳定激活尺度，间接改善梯度传播。

## 梯度裁剪

如果梯度范数超过阈值：

```text
如果 ||g|| > threshold：
    g = g × threshold / ||g||
```

常见代码：

```python
torch.nn.utils.clip_grad_norm_(
    model.parameters(),
    max_norm=1.0
)
```

梯度裁剪主要缓解梯度爆炸，在 RNN、Transformer 和混合精度训练中很常见。

它是保护措施，不应该代替对数据、Loss 或学习率错误的排查。

## 使用较小学习率和 Warmup

- 降低初始学习率；
- 训练开始时使用 Warmup；
- 使用合理的学习率衰减；
- 恢复训练时正确恢复优化器和 scheduler 状态。

## 使用门控循环结构

LSTM 和 GRU 通过门控与加法状态更新，改善普通 RNN 的长期梯度传播。

但它们不能保证完全消除长序列中的梯度问题。

## 混合精度保护

- 使用动态 Loss Scaling；
- 梯度裁剪前先 `unscale`；
- 硬件支持时考虑 BF16；
- Softmax、归一化、Loss 等敏感操作保持较高精度；
- 监控 NaN、Inf 和 GradScaler 的变化。

# 6. 怎么判断是否发生了梯度问题

训练时应记录：

```text
各层 gradient norm
全局 gradient norm
parameter norm
activation mean/std/max
参数更新比例 ||ΔW|| / ||W||
NaN/Inf 数量
```

如果发现：

```text
越靠近输入层，gradient norm 越接近0
```

通常是梯度消失。

如果发现：

```text
gradient norm 突然从个位数变成几千、几百万
```

通常是梯度爆炸。

还可以画每层梯度的分布：

```text
输入层                     输出层
1e-12  1e-10  1e-7 ... 1e-1
```

这种明显递增结构说明浅层很可能收不到有效梯度。

核心可以记成：

> **梯度消失和爆炸都来自链式法则中的连续乘法：局部 Jacobian 的尺度长期小于1，梯度就消失；长期大于1，梯度就爆炸。初始化、激活函数、网络深度、残差与归一化共同决定梯度能否稳定流动。**
