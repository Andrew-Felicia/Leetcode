常见的聚类算法有哪些？如何评价聚类效果？


聚类是无监督学习：**在没有标签的情况下，把相似样本分到同一组，不同组尽量分开。**不同算法对“什么叫一簇”的假设不同，因此没有一种算法适合所有数据。

## 一、常见聚类算法

| 算法 | 认为簇是什么形状 | 是否要指定簇数 | 主要优点 | 主要缺点 |
|---|---|---:|---|---|
| K-Means | 近似球形、大小相近 | 是 | 快、简单、可扩展 | 怕异常值，不能处理复杂形状 |
| K-Medoids | 围绕真实代表样本分布 | 是 | 比 K-Means 抗异常值 | 计算更慢 |
| GMM | 若干高斯分布 | 是 | 软聚类，可处理椭圆形簇 | 对初始化和分布假设敏感 |
| 层次聚类 | 由相似度逐层合并或拆分 | 可选 | 可生成树状结构，解释性好 | 大数据上计算和内存开销大 |
| DBSCAN | 高密度连通区域 | 否 | 能识别任意形状和噪声点 | 密度不均时难调参数 |
| HDBSCAN | 不同密度下稳定存在的区域 | 否 | 比 DBSCAN 更适合密度不均数据 | 结果和参数解释稍复杂 |
| OPTICS | 不同密度的层次结构 | 否 | 能观察多个密度尺度 | 输出不如普通标签直观 |
| 谱聚类 | 相似度图中的连通结构 | 是 | 能处理非凸、环形簇 | 相似度矩阵成本高 |
| Mean Shift | 密度函数的峰值 | 否 | 自动寻找簇数 | 对带宽敏感，大数据较慢 |
| BIRCH | 特征空间中的紧凑子簇 | 可选 | 适合大量样本和增量处理 | 对非球形结构效果有限 |
| Affinity Propagation | 围绕代表点形成簇 | 否 | 自动选择代表点 | 内存开销大，参数敏感 |

## 二、主要算法怎么理解

### 1. K-Means

目标是最小化簇内平方距离：

\[
\min \sum_{k=1}^{K}\sum_{x_i\in C_k}
\lVert x_i-\mu_k\rVert^2
\]

过程是：

1. 初始化 \(K\) 个中心；
2. 把样本分给最近的中心；
3. 重新计算每个簇的均值；
4. 重复直到稳定。

适合：

- 数值型特征；
- 样本量大；
- 簇大致呈球形；
- 各簇尺度和样本数相近。

注意：

- 必须先做特征标准化；
- 对初始中心敏感，通常使用 K-Means++ 并运行多次；
- 离群点会明显拉动均值；
- 类别型数据不能直接使用普通 K-Means。

变体包括 Mini-Batch K-Means、K-Medoids，以及类别数据使用的 K-Modes。

### 2. 高斯混合模型 GMM

假设数据由多个高斯分布混合产生：

\[
p(x)=\sum_{k=1}^{K}\pi_k
\mathcal N(x\mid\mu_k,\Sigma_k)
\]

GMM 输出的是概率：

```text
样本 A：属于簇 1 的概率 0.75，属于簇 2 的概率 0.25
```

因此它是软聚类，而 K-Means 通常是硬聚类。

适合：

- 簇之间有重叠；
- 希望得到归属概率；
- 簇可能呈椭圆形。

不足是仍需选择 \(K\)，并且容易受到初始化、异常值和协方差估计的影响。簇数可以结合 AIC、BIC 选择。

### 3. 层次聚类

凝聚式层次聚类最常见：

```text
每个样本各自一簇
→ 合并最相近的两个簇
→ 继续合并
→ 得到树状图 Dendrogram
```

簇间距离的定义称为 linkage：

- Single linkage：两个簇最近样本的距离，容易形成“链”；
- Complete linkage：最远样本的距离，倾向产生紧凑簇；
- Average linkage：平均样本距离；
- Ward linkage：选择使簇内方差增加最少的合并，常用且接近 K-Means 的偏好。

优点是可以观察多层级结构，再通过切割树状图决定簇数。缺点是通常难以扩展到特别大的数据集。

### 4. DBSCAN

根据两个参数定义密集区域：

- `eps`：邻域半径；
- `min_samples`：形成密集区域所需的最少样本数。

样本会被分成：

- 核心点；
- 边界点；
- 噪声点。

优点：

- 不需要预先指定簇数；
- 能发现弯曲、环形等非凸簇；
- 能显式识别异常点。

缺点：

- 对特征尺度和距离度量敏感；
- 高维空间中的距离容易失去区分度；
- 不同簇密度差异大时，一个 `eps` 很难兼顾。

密度不均时，可以优先考虑 HDBSCAN 或 OPTICS。

### 5. 谱聚类

先构造样本相似度图，再对图的拉普拉斯矩阵做特征分解，最后在新的表示空间里聚类。

它能把原空间中难以分开的结构转换成更容易分开的结构，因此适合：

- 环形簇；
- 月牙形簇；
- 图结构或社区发现；
- 非线性边界。

主要问题是相似度矩阵和特征分解成本较高，不适合直接处理超大规模数据。

## 三、如何评价聚类效果

聚类评价分为三类：

1. 内部评价：没有真实标签；
2. 外部评价：存在真实标签；
3. 稳定性与业务评价：结果是否可靠、可解释、有用。

## 四、无标签时的内部指标

### 1. 轮廓系数 Silhouette Score

对样本 \(i\)：

- \(a(i)\)：与同簇样本的平均距离；
- \(b(i)\)：与最近其他簇样本的平均距离。

\[
s(i)=\frac{b(i)-a(i)}
{\max(a(i),b(i))}
\]

范围是 \([-1,1]\)：

- 接近 1：簇内紧密、簇间分离；
- 接近 0：样本位于簇边界；
- 小于 0：样本可能分错了簇。

优点是容易理解，可以评价整体，也可以检查单个簇和单个样本。

缺点：

- 计算大量两两距离时成本较高；
- 偏好紧凑、分离的凸形簇；
- 对 DBSCAN 发现的复杂形状不一定公平。

### 2. Calinski–Harabasz 指数

比较簇间离散程度和簇内离散程度：

\[
CH=
\frac{\text{簇间离散度}/(K-1)}
{\text{簇内离散度}/(n-K)}
\]

**越大越好。**

优点是计算较快。缺点是偏好凸形、方差较小的簇，有时也偏好较大的簇数。

### 3. Davies–Bouldin 指数

衡量每个簇与最相似其他簇之间的相对重叠程度：

\[
DB=
\frac{1}{K}
\sum_i
\max_{j\ne i}
\frac{S_i+S_j}{M_{ij}}
\]

其中 \(S_i\) 表示簇内离散程度，\(M_{ij}\) 表示簇中心之间的距离。

**越小越好。**

优点是计算简单；缺点同样偏好紧凑、近似球形的簇。

### 4. 簇内平方和与肘部法

K-Means 常使用：

\[
WCSS=
\sum_k\sum_{x_i\in C_k}
\lVert x_i-\mu_k\rVert^2
\]

随着 \(K\) 增大，WCSS 一定下降。肘部法寻找下降速度明显变缓的位置。

问题是“肘部”经常不明显，因此不宜把它作为唯一依据。

### 5. Gap Statistic

将真实数据的簇内离散程度与无结构的随机参考数据比较。如果真实数据的聚类改善明显，说明聚类结构不只是随机现象。

它比单纯肘部法更有统计依据，但需要反复生成参考数据和聚类，计算成本较高。

## 五、有真实标签时的外部指标

聚类标签本身可以任意置换：

```text
真实类别：猫=0，狗=1
聚类结果：猫=7，狗=3
```

这仍然可能是完美聚类。因此不能直接用普通 accuracy，除非先进行最优标签匹配。

### Adjusted Rand Index，ARI

比较任意两个样本在真实标签和聚类结果中是否被放在一起，并校正随机一致性。

- 1：完全一致；
- 0：接近随机水平；
- 可能小于 0：比随机还差。

优点是对聚类标签编号不敏感，也是最常用的外部指标之一。

### NMI：归一化互信息

衡量聚类标签和真实标签共享了多少信息：

\[
NMI(Y,C)
=
\frac{I(Y;C)}
{\text{归一化项}}
\]

通常在 0 到 1 之间，越大越好。

NMI 对标签置换不敏感，但不同归一化方式可能产生略有差异的结果。

### Homogeneity、Completeness 与 V-measure

- Homogeneity：一个簇里是否尽量只有同一真实类别；
- Completeness：同一真实类别是否尽量被放进同一个簇；
- V-measure：两者的调和平均。

这组指标很适合分析具体问题：

- Homogeneity 高、Completeness 低：一个真实类别被拆成了很多小簇；
- Homogeneity 低、Completeness 高：多个真实类别被合并到了一个大簇。

### Purity

计算每个簇中数量最多的真实类别占比。

直观，但容易被滥用：如果每个样本单独成为一簇，Purity 会达到 1。因此必须结合簇数和其他指标评价。

## 六、稳定性评价

没有标签时，内部指标高不代表发现了真实且可靠的结构。还应检查聚类是否稳定：

1. 对数据进行不同的随机抽样；
2. 改变初始化；
3. 略微改变超参数；
4. 重新运行聚类；
5. 使用 ARI、NMI 等比较多次结果。

如果稍微改变数据，聚类结果就完全不同，说明结构可能不可靠。

还可以检查：

- 每个簇的大小是否极端失衡；
- 簇中心或代表样本是否稳定；
- 新数据能否合理分配；
- 不同时间段得到的簇是否一致。

---

## 七、业务和可解释性评价

实际任务中，数学指标只是参考。还要问：

- 每个簇能否用特征清晰描述？
- 簇之间是否对应可行动的差异？
- 是否出现大量只有几个样本的碎片簇？
- 聚类结果能否在新数据上复现？
- 分群能否改善推荐、营销、异常检测等下游任务？

例如用户分群中，轮廓系数最高的方案不一定最有价值。业务可能更希望得到：

```text
价格敏感用户
高频忠诚用户
新注册低活跃用户
即将流失用户
```

这些簇需要稳定、可解释，而且能对应不同策略。

## 八、如何选择算法

可以按数据特点初步判断：

- 数据量大、簇近似球形：K-Means 或 Mini-Batch K-Means；
- 有异常值，希望中心是真实样本：K-Medoids；
- 需要概率归属、簇有重叠：GMM；
- 不知道簇数、存在噪声、形状复杂：DBSCAN；
- 不同簇密度差异较大：HDBSCAN 或 OPTICS；
- 想观察层级关系、样本量不太大：层次聚类；
- 簇呈环形、月牙形或图结构：谱聚类；
- 超大规模或流式数据：BIRCH、Mini-Batch K-Means。

推荐评价流程是：

1. 标准化特征并选择合理距离度量；
2. 尝试多个算法和参数；
3. 查看二维降维图，但不要只凭图判断；
4. 比较 Silhouette、CH、DB 等内部指标；
5. 检查不同抽样和初始化下的稳定性；
6. 有标签时使用 ARI、NMI、V-measure；
7. 最后检查簇的规模、解释性和业务价值。

核心原则是：**评价聚类不能只看一个分数。需要同时考虑簇内紧密度、簇间分离度、稳定性、可解释性，以及真实任务价值。**
