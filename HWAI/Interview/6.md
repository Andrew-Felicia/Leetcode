GBDT、XGBoost、Random Forest、LightGBM分别是什么？它们的原理和区别是什么？




先抓住最重要的关系：

> **Random Forest 属于 Bagging；GBDT 属于 Boosting；XGBoost 和 LightGBM 是对 GBDT 思想的工程化与算法增强。**

所以它们并不是四个完全平级的概念：

```text
集成学习
├─ Bagging
│  └─ Random Forest
└─ Boosting
   └─ Gradient Boosting / GBDT
      ├─ XGBoost
      └─ LightGBM
```

## 一、核心区别总览

| 维度 | Random Forest | 传统 GBDT | XGBoost | LightGBM |
|---|---|---|---|---|
| 集成思想 | Bagging | Boosting | Boosting | Boosting |
| 树之间关系 | 相互独立、并行 | 串行修正 | 串行修正 | 串行修正 |
| 每棵树学习什么 | 完整目标 | 前面模型的负梯度 | 一阶、二阶梯度 | 一阶、二阶梯度 |
| 常用树类型 | 较深的决策树 | 较浅回归树 | 正则化 CART | Histogram-based tree |
| 树的生长 | 通常逐层 | 通常逐层 | 通常逐层，可配置 | 默认 Leaf-wise |
| 分裂计算 | 原始特征候选点 | 原始特征候选点 | Exact、Approx 或 Hist | Histogram |
| 并行能力 | 树之间可以并行 | 树之间不能直接并行 | 主要在单棵树内部并行 | 主要在单棵树内部并行 |
| 过拟合风险 | 相对较低 | 需要控制 | 正则化较丰富 | Leaf-wise 较容易过拟合 |
| 训练速度 | 较快 | 相对较慢 | 中等 | 大数据上通常很快 |
| 内存效率 | 中等 | 中等 | 中等 | 通常较好 |
| 缺失值处理 | 依实现而定 | 通常需预处理 | 原生支持 | 原生支持 |
| 类别特征 | 通常需要编码 | 通常需要编码 | 通常需要编码 | 支持原生类别特征 |
| 主要特点 | 稳定、少调参 | 梯度提升基础形式 | 精度、正则化、工程成熟 | 大规模、高维、速度快 |

# 二、Random Forest

Random Forest 即随机森林，是许多决策树的 Bagging 集成。

## 1. Bootstrap 抽样

从原训练集有放回地抽取多个训练子集：

```text
原始数据
├─ Bootstrap 样本 1 → 树 1
├─ Bootstrap 样本 2 → 树 2
├─ Bootstrap 样本 3 → 树 3
└─ Bootstrap 样本 M → 树 M
```

不同树通常可以并行训练。

## 2. 随机选择特征

每个节点分裂时，不是查看所有特征，而是只查看一个随机特征子集。

假设共有 100 个特征，每次节点分裂可能只从其中随机选出的 10 个特征中寻找最佳分裂。

这样做是为了降低树之间的相关性。如果所有树都优先选择同一个特别强的特征，它们可能长得非常相似，平均之后就没有多少收益。

## 3. 汇总预测

分类任务采用投票或平均类别概率：

\[
\hat y=\operatorname{mode}
\{T_1(x),T_2(x),\dots,T_M(x)\}
\]

回归任务采用平均：

\[
\hat y=\frac{1}{M}\sum_{m=1}^{M}T_m(x)
\]

## 4. Random Forest 解决了什么

单棵深决策树通常：

- 训练误差低；
- 对训练数据变化非常敏感；
- 方差大，容易过拟合。

随机森林通过“不同训练样本 + 不同特征子集 + 多棵树平均”，主要降低方差。

## 5. 优缺点

优点：

- 稳定、鲁棒；
- 不容易因为树数量增加而严重过拟合；
- 超参数相对容易调；
- 可以并行训练；
- 对异常值和非线性关系有一定适应能力；
- 可以利用 OOB 样本进行验证。

缺点：

- 相比 Boosting，精度上限经常稍低；
- 树很多时模型体积大；
- 推理需要遍历所有树；
- 难以外推训练数据之外的连续趋势；
- 特征重要性可能存在偏差。

Random Forest 是一个很好的表格数据基线。

# 三、传统 GBDT

GBDT 全称 Gradient Boosting Decision Tree，即梯度提升决策树。

它不是独立训练很多棵树，而是串行训练：

```text
初始模型
  ↓
树 1：修正当前错误
  ↓
树 2：继续修正剩余错误
  ↓
树 3：继续修正
  ↓
所有树相加
```

最终模型是加法模型：

\[
F_M(x)
=
F_0(x)+\sum_{m=1}^{M}\eta T_m(x)
\]

其中：

- \(T_m(x)\)：第 \(m\) 棵树；
- \(\eta\)：学习率；
- \(M\)：树的数量。

## 1. 从拟合残差到拟合负梯度

对于平方误差：

\[
L(y,F(x))=\frac12(y-F(x))^2
\]

当前模型的残差为：

\[
r_i=y_i-F_{m-1}(x_i)
\]

下一棵树拟合这些残差：

\[
T_m(x)\approx r
\]

然后更新：

\[
F_m(x)
=
F_{m-1}(x)+\eta T_m(x)
\]

但“拟合残差”只适用于平方损失的直观解释。更一般地，GBDT 拟合损失函数关于当前预测的负梯度：

\[
r_{im}
=
-
\left[
\frac{\partial L(y_i,F(x_i))}
{\partial F(x_i)}
\right]_{F=F_{m-1}}
\]

因此只要损失函数可求梯度，GBDT 就可以用于：

- 回归；
- 二分类；
- 多分类；
- 排序；
- Poisson 回归；
- 分位数回归等。

## 2. 为什么通常使用浅树

GBDT 的每棵树只需要修正一部分错误，因此常使用较浅的树，比如深度 3～8。

每棵树可以理解为学习一些特征交互规则：

```text
年龄 < 30
并且
月消费 > 500
并且
最近登录 < 7 天
```

大量浅树逐步累加后，可以表达复杂的非线性关系。

## 3. 学习率与树数量

学习率越小，每棵树的修正越保守：

- 小学习率 + 较多树：通常泛化更好，但训练更慢；
- 大学习率 + 较少树：训练快，但更容易过拟合或震荡。

这是 GBDT 中最重要的权衡之一。

## 4. 优缺点

优点：

- 表格数据上通常表现优秀；
- 可以学习复杂非线性关系和特征交互；
- 支持多种可微损失；
- 不需要特征标准化；
- 通常比随机森林偏差更低。

缺点：

- 树之间必须串行，训练并行性有限；
- 对超参数比较敏感；
- 标签噪声和异常样本可能被后续树持续关注；
- 树太深、数量太多时容易过拟合；
- 传统实现处理大规模数据的效率一般。

---

# 四、XGBoost

XGBoost 可以理解为：

> **在 GBDT 基础上加入二阶优化、显式正则化、采样、缺失值处理和高效并行实现。**

它仍然是一棵树接一棵树地修正模型。

## 1. 使用一阶和二阶梯度

传统 Gradient Boosting 主要从一阶梯度角度构造下一棵树。XGBoost 对损失函数做二阶泰勒展开：

\[
L^{(t)}
\approx
\sum_i
\left[
g_i f_t(x_i)
+
\frac12 h_i f_t(x_i)^2
\right]
+
\Omega(f_t)
\]

其中：

\[
g_i=
\frac{\partial L}{\partial \hat y_i},
\qquad
h_i=
\frac{\partial^2 L}{\partial \hat y_i^2}
\]

二阶信息能更准确地衡量一次更新会如何影响损失。

## 2. 显式正则化树结构

XGBoost 的目标中包含：

\[
\Omega(f)
=
\gamma T+\frac12\lambda\sum_{j=1}^{T}w_j^2
\]

其中：

- \(T\)：叶子节点数量；
- \(w_j\)：第 \(j\) 个叶子的预测值；
- \(\gamma\)：增加叶子的复杂度成本；
- \(\lambda\)：叶子权重的 L2 正则化。

因此，一个新分裂只有在带来的收益足够大时才会被接受。

XGBoost 还支持：

- L1 正则化；
- `max_depth`；
- `min_child_weight`；
- 行采样 `subsample`；
- 列采样 `colsample_*`；
- 学习率 `eta`；
- Early Stopping。

## 3. 分裂增益

对于一个候选节点，它会根据一阶、二阶梯度统计量计算分裂前后的目标函数改善。

如果分裂收益不足，节点不会继续分裂。这比单纯比较分类纯度更贴合最终训练目标。

## 4. 缺失值处理

XGBoost 不一定需要先填补缺失值。

训练时，它会对每个分裂学习：

```text
缺失值默认走左边
还是
缺失值默认走右边
```

选择能使目标函数改善更多的方向。

因此“是否缺失”本身也可能成为预测信息。不过业务上仍需判断缺失是否合理，不能完全把数据问题交给模型。

## 5. 高效实现

XGBoost 包含很多工程优化：

- 多线程寻找分裂；
- 稀疏感知算法；
- 缓存优化；
- 外存训练；
- Exact、Approx、Histogram 等建树方式；
- 分布式和 GPU 训练。

需要注意：Boosting 轮次之间仍然是串行的；所谓并行通常指单棵树内部候选分裂计算和数据处理的并行。

## 6. 优缺点

优点：

- 预测精度高；
- 正则化机制丰富；
- 对稀疏值和缺失值支持较好；
- 工程成熟；
- 支持分类、回归、排序等多种任务。

缺点：

- 超参数较多；
- 大数据上可能比 LightGBM 慢、占用更多内存；
- 参数设置不当仍会过拟合；
- 类别特征通常需要合理编码或使用其特定类别支持方式；
- 大量深树会增加训练和推理成本。

# 五、LightGBM

LightGBM 同样是梯度提升树，但重点是：

> **用 Histogram、Leaf-wise 生长及一系列优化，提高大规模数据上的训练速度和内存效率。**

## 1. Histogram 直方图算法

传统建树可能考虑每个连续特征的所有取值作为候选分裂点。

LightGBM 先把连续值离散到有限个桶中：

```text
原始年龄：
18, 19, 20, 21, ..., 85

离散后：
桶 1、桶 2、...、桶 63
```

然后只在桶边界上寻找分裂。

优点：

- 降低计算量；
- 减少内存占用；
- 直方图可以快速累积；
- 离散化本身可能带来轻微正则化效果。

代价是丢失少量精确数值信息，但通常对预测影响不大。

## 2. Leaf-wise 生长

传统逐层生长 Level-wise：

```text
        根
      /    \
   同时扩展同一层的节点
```

LightGBM 默认使用 Leaf-wise：

```text
每一步寻找当前所有叶子中
“分裂收益最大”的那个叶子继续分裂
```

### Leaf-wise 的优势

在相同叶子数量下，它通常能更快降低训练损失。

### Leaf-wise 的风险

树可能在某一条路径上长得很深：

```text
根
└─ 叶子
   └─ 叶子
      └─ 叶子
         └─ ...
```

这使 LightGBM 在小数据上更容易过拟合。

因此 LightGBM 中非常重要的参数是：

- `num_leaves`；
- `max_depth`；
- `min_data_in_leaf` / `min_child_samples`；
- `min_gain_to_split`；
- `feature_fraction`；
- `bagging_fraction`；
- `lambda_l1`、`lambda_l2`。

## 3. GOSS

GOSS 即 Gradient-based One-Side Sampling。

直觉是：

- 梯度大的样本：当前模型预测得不好，更重要，尽量保留；
- 梯度小的样本：已经预测得较好，可以抽样保留。

这样能减少用于分裂计算的样本数量，同时尽量保存重要信息。

不过，现代实际使用中是否启用以及具体形式取决于 boosting 配置，并不是所有 LightGBM 训练都必须使用 GOSS。

## 4. EFB

EFB 即 Exclusive Feature Bundling。

如果两个稀疏特征几乎不会同时为非零，就可以把它们捆绑到同一列中，从而减少有效特征数量。

例如 one-hot 特征：

```text
城市_北京
城市_上海
城市_深圳
```

同一个样本通常只会有一个值为 1。这类互斥特征适合进行捆绑。

EFB 对高维稀疏数据尤其有意义。

## 5. 类别特征支持

LightGBM 可以直接处理类别特征，不一定要展开成大量 one-hot 列。

它会寻找类别集合的有效划分，而不是简单把类别编码后的数字当作连续大小。

但仍需：

- 正确声明哪些列是类别特征；
- 保持训练与推理的类别映射一致；
- 处理未知类别；
- 防止高基数类别过拟合。

## 6. 优缺点

优点：

- 大数据、高维数据上通常训练很快；
- 内存效率较好；
- 支持原生类别特征；
- 对稀疏特征友好；
- 表格任务中精度通常很高。

缺点：

- Leaf-wise 在小数据上容易过拟合；
- `num_leaves` 等参数需要仔细控制；
- 极小数据集上未必优于 XGBoost；
- 对参数和数据表示方式较敏感；
- 并不是所有任务都能从 GOSS、EFB 中明显获益。

# 六、Random Forest 与 Boosting 的本质差异

## Random Forest：独立建树后平均

```text
树 1 ─┐
树 2 ─┼→ 平均 / 投票
树 3 ─┘
```

每棵树都尝试独立完成整个预测任务。

主要效果是：

\[
\text{降低方差}
\]

只要树之间的错误没有高度相关，平均后预测就更稳定。

## GBDT / XGBoost / LightGBM：逐步纠错

```text
模型 0
  + 树 1 的修正
  + 树 2 的修正
  + 树 3 的修正
```

每棵新树都依赖之前模型的预测。

主要效果是：

\[
\text{逐步降低偏差，同时控制方差}
\]

因此 Boosting 通常比 Random Forest 更准确，但也更容易因为参数设置不当而过拟合。

# 七、GBDT、XGBoost、LightGBM 的关系

可以把它们理解为：

### GBDT

一种算法思想和基础框架：

- 使用加法模型；
- 每轮拟合损失函数的负梯度；
- 逐棵加入回归树。

### XGBoost

强调：

- 二阶梯度；
- 显式正则化；
- 稀疏与缺失值处理；
- 灵活的分裂算法；
- 成熟、稳定的工程实现。

### LightGBM

强调：

- Histogram 建树；
- Leaf-wise 生长；
- 大数据训练速度；
- 内存效率；
- 类别和稀疏特征处理。

因此，XGBoost 和 LightGBM 都属于 Gradient Boosting 家族，但具体目标函数、建树策略和工程实现不同。

# 八、实际应该怎么选

## 优先选择 Random Forest

当你：

- 需要一个稳定、容易使用的基线；
- 不想花太多时间调参；
- 数据量中等；
- 标签噪声较多；
- 希望并行训练；
- 更看重鲁棒性而不是极致精度。

Random Forest 常见起点：

- 增加 `n_estimators`；
- 限制 `max_depth`；
- 设置合理的 `min_samples_leaf`；
- 调整 `max_features`。

## 优先选择传统 GBDT

当你：

- 数据规模不大；
- 希望理解标准 Gradient Boosting 原理；
- 使用的工具已有成熟传统实现；
- 不需要处理超大规模或高维稀疏数据。

实际生产和竞赛中，传统 GBDT 经常被 XGBoost、LightGBM 或其他现代实现替代，但它仍是理解后者的基础。

## 优先选择 XGBoost

当你：

- 数据量中小到中大型；
- 希望有稳健的正则化；
- 更看重准确率和稳定性；
- 数据含缺失值或稀疏特征；
- 愿意进行系统调参；
- 希望使用成熟、广泛验证的实现。

它通常是表格数据的可靠默认选择。

## 优先选择 LightGBM

当你：

- 样本很多；
- 特征维度高；
- 存在大量稀疏特征；
- 训练时间或内存是瓶颈；
- 有较多类别特征；
- 能认真控制叶子数和最小叶子样本数。

小数据使用 LightGBM 时，应特别限制：

```text
num_leaves
max_depth
min_data_in_leaf
```

# 九、关键参数如何对应

| 目的 | Random Forest | XGBoost | LightGBM |
|---|---|---|---|
| 树数量 | `n_estimators` | `n_estimators` | `n_estimators` / `num_iterations` |
| 树复杂度 | `max_depth` | `max_depth` | `num_leaves`、`max_depth` |
| 最小叶子样本 | `min_samples_leaf` | `min_child_weight` 间接控制 | `min_data_in_leaf` |
| 行采样 | `max_samples` | `subsample` | `bagging_fraction` |
| 列采样 | `max_features` | `colsample_bytree` | `feature_fraction` |
| 学习率 | 不需要 | `learning_rate` | `learning_rate` |
| L1/L2 | 通常不作为核心参数 | `reg_alpha` / `reg_lambda` | `lambda_l1` / `lambda_l2` |
| 分裂最低收益 | `min_impurity_decrease` | `gamma` | `min_gain_to_split` |

注意：不同库中的同名参数不一定具有完全相同的数学定义，不能机械照搬数值。

# 十、一句话记忆

- **Random Forest**：很多棵相互独立、带随机性的树，最后平均，重点是降低方差。
- **GBDT**：一棵树接一棵树拟合负梯度，重点是逐步纠错。
- **XGBoost**：带二阶信息、显式正则化和高效实现的梯度提升树。
- **LightGBM**：使用 Histogram 和默认 Leaf-wise 生长，强调大规模数据下的速度与内存效率。

实际表格任务中，一个很实用的策略是：

1. 用 Random Forest 建立稳定基线；
2. 用 XGBoost 获得稳健的高精度结果；
3. 数据量大、类别或稀疏特征多时尝试 LightGBM；
4. 使用相同交叉验证划分比较泛化性能、训练时间、推理速度和模型大小，而不是只看训练集分数。
