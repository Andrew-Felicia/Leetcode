不借助深度学习框架，直接用 numpy 写一版自注意力（self-attention）前向计算，你会怎么实现和验证正确性？


我会先实现“多头 + causal mask + padding mask”的通用版本；令 `num_heads=1` 就是单头自注意力。

核心计算是：

```text
Q = X @ Wq
K = X @ Wk
V = X @ Wv

scores  = Q @ K^T / sqrt(head_dim)
weights = masked_softmax(scores)
context = weights @ V
output  = concat(context_heads) @ Wo
```

## 1. NumPy 实现

```python
import numpy as np


def masked_softmax(scores, mask, axis=-1):
    """
    scores: 任意形状
    mask:   可广播到 scores，True 表示允许参与 softmax

    对全部被 mask 的行返回全 0，避免 -inf - (-inf) 产生 NaN。
    """
    masked_scores = np.where(mask, scores, -np.inf)

    max_scores = np.max(masked_scores, axis=axis, keepdims=True)

    # 如果整行都被 mask，max 是 -inf；临时替换成 0
    max_scores = np.where(np.isfinite(max_scores), max_scores, 0.0)

    exp_scores = np.where(
        mask,
        np.exp(masked_scores - max_scores),
        0.0,
    )

    denominator = np.sum(exp_scores, axis=axis, keepdims=True)

    probabilities = np.divide(
        exp_scores,
        denominator,
        out=np.zeros_like(exp_scores),
        where=denominator != 0,
    )

    return probabilities


def self_attention(
    x,
    Wq,
    Wk,
    Wv,
    Wo,
    num_heads,
    causal=False,
    attention_mask=None,
):
    """
    多头自注意力前向计算。

    参数
    ----
    x:
        [batch_size, seq_len, model_dim]

    Wq, Wk, Wv, Wo:
        [model_dim, model_dim]

    num_heads:
        Attention head 数量，model_dim 必须能被 num_heads 整除。

    causal:
        True 时，第 i 个 token 只能看到位置 <= i 的 token。

    attention_mask:
        [batch_size, seq_len] 的布尔数组。
        True 表示真实 token，False 表示 padding。
        这里同时：
        1. 屏蔽 padding key；
        2. 将 padding query 的最终输出置零。

    返回
    ----
    output:
        [batch_size, seq_len, model_dim]

    cache:
        用于调试的 Q、K、V、scores 和 attention weights。
    """
    x = np.asarray(x)

    if x.ndim != 3:
        raise ValueError("x 必须是 [batch_size, seq_len, model_dim]")

    batch_size, seq_len, model_dim = x.shape

    if model_dim % num_heads != 0:
        raise ValueError("model_dim 必须能被 num_heads 整除")

    expected_weight_shape = (model_dim, model_dim)

    for name, weight in {
        "Wq": Wq,
        "Wk": Wk,
        "Wv": Wv,
        "Wo": Wo,
    }.items():
        if weight.shape != expected_weight_shape:
            raise ValueError(
                f"{name}.shape 应为 {expected_weight_shape}，"
                f"实际为 {weight.shape}"
            )

    head_dim = model_dim // num_heads

    # 1. 线性投影
    # [B, T, D] @ [D, D] -> [B, T, D]
    q = x @ Wq
    k = x @ Wk
    v = x @ Wv

    # 2. 拆分多头
    # [B, T, D]
    # -> [B, T, H, Dh]
    # -> [B, H, T, Dh]
    q = q.reshape(
        batch_size, seq_len, num_heads, head_dim
    ).transpose(0, 2, 1, 3)

    k = k.reshape(
        batch_size, seq_len, num_heads, head_dim
    ).transpose(0, 2, 1, 3)

    v = v.reshape(
        batch_size, seq_len, num_heads, head_dim
    ).transpose(0, 2, 1, 3)

    # 3. Scaled dot-product
    #
    # q:                    [B, H, T, Dh]
    # transpose(k):         [B, H, Dh, T]
    # scores:               [B, H, T, T]
    scores = q @ k.transpose(0, 1, 3, 2)
    scores = scores / np.sqrt(head_dim)

    # 4. 构造可广播的 Attention mask
    #
    # 最终 allowed shape: [B, 1, T, T]
    # 之后广播到 scores 的 [B, H, T, T]
    allowed = np.ones(
        (batch_size, 1, seq_len, seq_len),
        dtype=bool,
    )

    if causal:
        causal_mask = np.tril(
            np.ones((seq_len, seq_len), dtype=bool)
        )

        # [1, 1, T, T]
        allowed &= causal_mask[None, None, :, :]

    if attention_mask is not None:
        attention_mask = np.asarray(
            attention_mask,
            dtype=bool,
        )

        expected_mask_shape = (batch_size, seq_len)

        if attention_mask.shape != expected_mask_shape:
            raise ValueError(
                "attention_mask.shape 应为 "
                f"{expected_mask_shape}，"
                f"实际为 {attention_mask.shape}"
            )

        # 这里只屏蔽 Key 位置：
        #
        # [B, T] -> [B, 1, 1, T]
        key_mask = attention_mask[:, None, None, :]
        allowed &= key_mask

    # 5. Masked softmax
    attention_weights = masked_softmax(
        scores,
        allowed,
        axis=-1,
    )

    # 6. 加权汇总 V
    #
    # [B, H, T, T] @ [B, H, T, Dh]
    # -> [B, H, T, Dh]
    context = attention_weights @ v

    # 7. 合并多头
    #
    # [B, H, T, Dh]
    # -> [B, T, H, Dh]
    # -> [B, T, D]
    context = context.transpose(0, 2, 1, 3)
    context = context.reshape(
        batch_size, seq_len, model_dim
    )

    # 8. 输出投影
    output = context @ Wo

    # Padding query 的输出置零
    if attention_mask is not None:
        output = output * attention_mask[:, :, None]

    cache = {
        "q": q,
        "k": k,
        "v": v,
        "scores": scores,
        "attention_weights": attention_weights,
        "allowed": allowed,
    }

    return output, cache
```

## 2. 为什么要除以 `sqrt(head_dim)`

如果 Q、K 的每个分量方差接近1，那么点积：

```text
q · k
```

的方差会随着 `head_dim` 增大。

维度很大时，Attention logits 可能绝对值很大，使 Softmax 接近 one-hot：

```text
softmax([100, 0, -100])
≈ [1, 0, 0]
```

此时梯度容易变得很小。

缩放：

```text
scores = Q @ K^T / sqrt(head_dim)
```

可以让 logits 的尺度更加稳定。

## 3. 用显式循环写参考实现

为了验证向量化实现，我会再写一个低效但直观的循环版本。

它不追求速度，只作为正确性基准：

```python
def self_attention_slow(
    x,
    Wq,
    Wk,
    Wv,
    Wo,
    num_heads,
    causal=False,
    attention_mask=None,
):
    """
    使用 Python 循环实现的参考版本。
    """
    batch_size, seq_len, model_dim = x.shape
    head_dim = model_dim // num_heads

    q = (x @ Wq).reshape(
        batch_size, seq_len, num_heads, head_dim
    )
    k = (x @ Wk).reshape(
        batch_size, seq_len, num_heads, head_dim
    )
    v = (x @ Wv).reshape(
        batch_size, seq_len, num_heads, head_dim
    )

    if attention_mask is None:
        attention_mask = np.ones(
            (batch_size, seq_len),
            dtype=bool,
        )
    else:
        attention_mask = np.asarray(
            attention_mask,
            dtype=bool,
        )

    attention_weights = np.zeros(
        (batch_size, num_heads, seq_len, seq_len),
        dtype=x.dtype,
    )

    # context 暂时使用 [B, T, H, Dh]
    context = np.zeros(
        (batch_size, seq_len, num_heads, head_dim),
        dtype=x.dtype,
    )

    scale = 1.0 / np.sqrt(head_dim)

    for b in range(batch_size):
        for h in range(num_heads):
            for query_pos in range(seq_len):
                allowed_key_positions = []

                for key_pos in range(seq_len):
                    if not attention_mask[b, key_pos]:
                        continue

                    if causal and key_pos > query_pos:
                        continue

                    allowed_key_positions.append(key_pos)

                if not allowed_key_positions:
                    continue

                logits = []

                for key_pos in allowed_key_positions:
                    score = (
                        np.dot(
                            q[b, query_pos, h],
                            k[b, key_pos, h],
                        )
                        * scale
                    )
                    logits.append(score)

                logits = np.asarray(logits)

                # 稳定 Softmax
                probabilities = np.exp(
                    logits - np.max(logits)
                )
                probabilities /= probabilities.sum()

                for probability, key_pos in zip(
                    probabilities,
                    allowed_key_positions,
                ):
                    attention_weights[
                        b, h, query_pos, key_pos
                    ] = probability

                    context[b, query_pos, h] += (
                        probability * v[b, key_pos, h]
                    )

    context = context.reshape(
        batch_size, seq_len, model_dim
    )

    output = context @ Wo
    output *= attention_mask[:, :, None]

    return output, attention_weights
```

## 4. 完整测试

```python
def make_weights(model_dim, seed=0):
    rng = np.random.default_rng(seed)

    # 类似 Xavier 的简单初始化
    scale = 1.0 / np.sqrt(model_dim)

    return tuple(
        rng.normal(
            loc=0.0,
            scale=scale,
            size=(model_dim, model_dim),
        )
        for _ in range(4)
    )


def run_tests():
    rng = np.random.default_rng(123)

    batch_size = 2
    seq_len = 5
    model_dim = 8
    num_heads = 2

    x = rng.normal(
        size=(batch_size, seq_len, model_dim)
    ).astype(np.float64)

    Wq, Wk, Wv, Wo = make_weights(
        model_dim=model_dim,
        seed=456,
    )

    # 第二个样本最后两个位置是 padding
    attention_mask = np.array(
        [
            [True, True, True, True, True],
            [True, True, True, False, False],
        ]
    )

    output, cache = self_attention(
        x=x,
        Wq=Wq,
        Wk=Wk,
        Wv=Wv,
        Wo=Wo,
        num_heads=num_heads,
        causal=True,
        attention_mask=attention_mask,
    )

    reference_output, reference_weights = (
        self_attention_slow(
            x=x,
            Wq=Wq,
            Wk=Wk,
            Wv=Wv,
            Wo=Wo,
            num_heads=num_heads,
            causal=True,
            attention_mask=attention_mask,
        )
    )

    weights = cache["attention_weights"]

    # 1. 检查输出形状
    assert output.shape == (
        batch_size,
        seq_len,
        model_dim,
    )

    assert weights.shape == (
        batch_size,
        num_heads,
        seq_len,
        seq_len,
    )

    # 2. 与循环参考实现对比
    np.testing.assert_allclose(
        output,
        reference_output,
        rtol=1e-10,
        atol=1e-10,
    )

    np.testing.assert_allclose(
        weights,
        reference_weights,
        rtol=1e-10,
        atol=1e-10,
    )

    # 3. 每个有效 Query 的 Attention 概率和应为 1
    row_sums = weights.sum(axis=-1)

    for b in range(batch_size):
        for query_pos in range(seq_len):
            if attention_mask[b, query_pos]:
                np.testing.assert_allclose(
                    row_sums[b, :, query_pos],
                    np.ones(num_heads),
                    rtol=1e-12,
                    atol=1e-12,
                )

    # 4. Causal mask：未来位置概率必须为 0
    future_positions = np.triu(
        np.ones((seq_len, seq_len), dtype=bool),
        k=1,
    )

    assert np.all(
        weights[:, :, future_positions] == 0.0
    )

    # 5. Padding Key 的概率必须为 0
    for b in range(batch_size):
        padding_positions = np.where(
            ~attention_mask[b]
        )[0]

        if len(padding_positions) > 0:
            assert np.all(
                weights[
                    b,
                    :,
                    :,
                    padding_positions,
                ]
                == 0.0
            )

    # 6. Padding Query 的最终输出应为 0
    assert np.all(
        output[1, 3:, :] == 0.0
    )

    # 7. 输出不能有 NaN 或 Inf
    assert np.all(np.isfinite(output))
    assert np.all(np.isfinite(weights))

    print("基础测试全部通过")


if __name__ == "__main__":
    run_tests()
```

## 5. 验证 Causal Attention 的前缀不变性

因果注意力中，前面的 token 不允许看到未来。

因此，修改未来 token 后，前缀位置的输出必须保持不变：

```python
def test_causal_prefix_invariance():
    rng = np.random.default_rng(10)

    batch_size = 1
    seq_len = 6
    model_dim = 8
    num_heads = 2
    prefix_length = 3

    x1 = rng.normal(
        size=(batch_size, seq_len, model_dim)
    )

    x2 = x1.copy()

    # 只大幅修改未来 token
    x2[:, prefix_length:, :] = rng.normal(
        loc=100.0,
        scale=20.0,
        size=x2[:, prefix_length:, :].shape,
    )

    Wq, Wk, Wv, Wo = make_weights(
        model_dim=model_dim,
        seed=11,
    )

    output1, _ = self_attention(
        x1,
        Wq,
        Wk,
        Wv,
        Wo,
        num_heads=num_heads,
        causal=True,
    )

    output2, _ = self_attention(
        x2,
        Wq,
        Wk,
        Wv,
        Wo,
        num_heads=num_heads,
        causal=True,
    )

    # 前3个位置不能受未来 token 影响
    np.testing.assert_allclose(
        output1[:, :prefix_length, :],
        output2[:, :prefix_length, :],
        rtol=1e-10,
        atol=1e-10,
    )

    print("Causal 前缀不变性测试通过")
```

这是非常有价值的性质测试。它能发现：

- Causal mask 方向写反；
- Query/Key 维度转置错误；
- Mask 广播维度错误。

## 6. 验证均匀 Attention

令：

```text
Wq = 0
Wk = 0
```

则所有允许位置的 Attention score 都是0，Softmax 应该均匀分布。

再令：

```text
Wv = I
Wo = I
```

对于 Causal Attention，第 `i` 个输出应该是前 `i+1` 个输入的平均值：

```python
def test_uniform_attention():
    rng = np.random.default_rng(20)

    batch_size = 1
    seq_len = 4
    model_dim = 6
    num_heads = 2

    x = rng.normal(
        size=(batch_size, seq_len, model_dim)
    )

    zeros = np.zeros((model_dim, model_dim))
    identity = np.eye(model_dim)

    output, cache = self_attention(
        x=x,
        Wq=zeros,
        Wk=zeros,
        Wv=identity,
        Wo=identity,
        num_heads=num_heads,
        causal=True,
    )

    expected = np.stack(
        [
            x[:, : position + 1, :].mean(axis=1)
            for position in range(seq_len)
        ],
        axis=1,
    )

    np.testing.assert_allclose(
        output,
        expected,
        rtol=1e-10,
        atol=1e-10,
    )

    weights = cache["attention_weights"]

    # 第3个位置应该均匀关注位置 0、1、2
    np.testing.assert_allclose(
        weights[0, :, 2, :3],
        np.full((num_heads, 3), 1.0 / 3.0),
        rtol=1e-10,
        atol=1e-10,
    )

    print("均匀 Attention 测试通过")
```

这个测试具有明确的人工预期，比单纯与另一个向量化实现比较更可靠。

## 7. 验证非因果注意力的排列等变性

如果没有：

- Causal mask；
- 位置编码；
- Padding；

那么 Self-Attention 对 token 排列是等变的：

```text
先打乱输入，再做 Attention
=
先做 Attention，再用同样方式打乱输出
```

```python
def test_permutation_equivariance():
    rng = np.random.default_rng(30)

    batch_size = 1
    seq_len = 5
    model_dim = 8
    num_heads = 2

    x = rng.normal(
        size=(batch_size, seq_len, model_dim)
    )

    permutation = np.array([2, 4, 0, 3, 1])

    Wq, Wk, Wv, Wo = make_weights(
        model_dim=model_dim,
        seed=31,
    )

    output, _ = self_attention(
        x,
        Wq,
        Wk,
        Wv,
        Wo,
        num_heads=num_heads,
        causal=False,
    )

    permuted_output, _ = self_attention(
        x[:, permutation, :],
        Wq,
        Wk,
        Wv,
        Wo,
        num_heads=num_heads,
        causal=False,
    )

    np.testing.assert_allclose(
        permuted_output,
        output[:, permutation, :],
        rtol=1e-10,
        atol=1e-10,
    )

    print("排列等变性测试通过")
```

这也说明 Self-Attention 本身不知道 token 的顺序，因此 Transformer 需要位置编码。

## 8. 验证数值稳定性

Softmax 必须先减最大值，否则较大的 logits 可能让 `exp` 溢出。

```python
def test_numerical_stability():
    rng = np.random.default_rng(40)

    batch_size = 2
    seq_len = 8
    model_dim = 16
    num_heads = 4

    # 故意制造较大的输入
    x = rng.normal(
        size=(batch_size, seq_len, model_dim)
    ) * 1e4

    Wq, Wk, Wv, Wo = make_weights(
        model_dim=model_dim,
        seed=41,
    )

    output, cache = self_attention(
        x,
        Wq,
        Wk,
        Wv,
        Wo,
        num_heads=num_heads,
        causal=True,
    )

    assert np.all(np.isfinite(output))
    assert np.all(
        np.isfinite(cache["attention_weights"])
    )

    print("数值稳定性测试通过")
```

如果写成：

```python
np.exp(scores) / np.exp(scores).sum(...)
```

这个测试很容易出现 Inf 或 NaN。

## 10. 最容易写错的地方

### 缩放维度错误

应该除以：

```text
sqrt(head_dim)
```

不是 `sqrt(model_dim)`。

### K 的转置维度错误

拆头之后：

```text
Q: [B, H, T, Dh]
K: [B, H, T, Dh]
```

需要：

```text
Q @ transpose(K, [B, H, Dh, T])
```

得到：

```text
[B, H, T, T]
```

### Causal mask 方向写反

正确语义：

```text
query i 可以看 key j，当且仅当 j <= i
```

所以使用下三角矩阵。

### Softmax 维度错误

Softmax 应沿 Key 序列维度进行：

```text
axis = -1
```

每个 Query 对所有 Key 的概率之和为1。

### Mask 放在 Softmax 之后

正确做法是在 Softmax 之前屏蔽 logits。Softmax 之后再乘0，会导致剩余概率和不再为1。

### 多头 reshape 顺序错误

必须明确：

```text
[B, T, D]
→ [B, T, H, Dh]
→ [B, H, T, Dh]
```

合并时执行逆过程。

### 把 Padding Query 和 Padding Key 混为一谈

- Padding Key 必须在 Softmax 前屏蔽；
- Padding Query 通常在最终输出或 Loss 中屏蔽。

### 忘记位置编码

这段代码只实现 Self-Attention，本身不包含位置编码。实际 Transformer 通常在进入 Attention 前加入绝对位置编码，或者在 Q/K 上应用 RoPE、相对位置偏置等。

验证正确性时，我会优先采用：

1. 与显式循环版本对比；
2. 检查形状和概率和；
3. 检查 mask 后概率严格为0；
4. Causal 前缀不变性；
5. 均匀 Attention 的人工可推导结果；
6. 无位置非因果 Attention 的排列等变性；
7. 大数输入的数值稳定性。

这比只检查“代码能运行且输出形状正确”可靠得多。
