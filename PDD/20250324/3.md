# Delete palindromic substrings

## General solution

Use interval dynamic programming. `dp[l][r]` is the minimum operations to
erase `s[l:r+1]`. Delete `s[l]` alone, pair it with an adjacent equal
character, or pair it with a later equal character after the middle has
disappeared. Trying all matching partners gives the optimum.

## ASCII picture

```text
   l             k             r
   a   [ middle ] a   [ right ]
       erase first      erase later

Once middle is gone, the two 'a' characters meet and leave together.
dp[l][r] <- dp[l+1][k-1] + dp[k+1][r]
```

## Why it works

The algorithm maintains exactly the invariant shown in the diagram. Each greedy
choice or dynamic-programming transition accounts for every legal possibility
that can affect the optimum, while discarding only states that are provably no
better. Therefore the value printed at the end is the required optimum.

## Complexity

O(n^3) worst-case time and O(n^2) memory.

## Code

```python
import sys


def minimum_deletions(s):
    n = len(s)
    dp = [[0] * n for _ in range(n)]
    for left in range(n - 1, -1, -1):
        dp[left][left] = 1
        for right in range(left + 1, n):
            best = 1 + dp[left + 1][right]
            if s[left] == s[left + 1]:
                best = min(best, 1 + (dp[left + 2][right] if left + 2 <= right else 0))
            for partner in range(left + 2, right + 1):
                if s[left] == s[partner]:
                    middle = dp[left + 1][partner - 1]
                    tail = dp[partner + 1][right] if partner < right else 0
                    best = min(best, middle + tail)
            dp[left][right] = best
    return dp[0][n - 1]


def main():
    tokens = sys.stdin.buffer.read().split()
    test_cases = int(tokens[0])
    print("\n".join(str(minimum_deletions(tokens[i].decode()))
                    for i in range(1, test_cases + 1)))


if __name__ == "__main__":
    main()
```
