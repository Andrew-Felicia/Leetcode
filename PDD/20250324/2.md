# Alice removes numbers, Bob negates numbers

## General solution

Sort descending and build prefix sums. If Alice removes exactly `r` values,
an exchange argument shows she can remove the `r` largest ones. Bob then
applies `-k` to the next `m` largest remaining values. Evaluate every legal
`r` from 0 through `d` and keep Alice's best final sum.

## ASCII picture

```text
sorted:   [9, 8, 7, 4, 2]
           Alice removes r=2
          X  X [7, 4] [2]
                Bob       unchanged
value = remaining_sum - (k+1) * sum(Bob's block)
```

## Why it works

The algorithm maintains exactly the invariant shown in the diagram. Each greedy
choice or dynamic-programming transition accounts for every legal possibility
that can affect the optimum, while discarding only states that are provably no
better. Therefore the value printed at the end is the required optimum.

## Complexity

O(n log n) time and O(n) memory per test case.

## Code

```python
import sys


def game_value(values, m, k, d):
    values.sort(reverse=True)
    prefix = [0]
    for value in values:
        prefix.append(prefix[-1] + value)

    n = len(values)
    answer = -10**40
    for removed in range(min(d, n) + 1):
        changed = min(m, n - removed)
        remaining_sum = prefix[n] - prefix[removed]
        changed_sum = prefix[removed + changed] - prefix[removed]
        answer = max(answer, remaining_sum - (k + 1) * changed_sum)
    return answer


def main():
    numbers = iter(map(int, sys.stdin.buffer.read().split()))
    test_cases = next(numbers)
    answers = []
    for _ in range(test_cases):
        n, m, k, d = next(numbers), next(numbers), next(numbers), next(numbers)
        values = [next(numbers) for _ in range(n)]
        answers.append(str(game_value(values, m, k, d)))
    print("\n".join(answers))


if __name__ == "__main__":
    main()
```
