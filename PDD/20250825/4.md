# Longest alternating binary substring after block reversals

## General solution

Reversing chosen blocks can realize adjacent swaps, so after any number of
operations the zeroes and ones may be permuted arbitrarily. An alternating
string uses one of each character per pair and can use one extra character
from the majority. Therefore the answer is `2*min(zeroes,ones)` plus one
when the counts differ.

## ASCII picture

```text
zeroes: 3   ones: 2
         pair pair
         0 1 0 1   + one extra 0
longest = 2*2 + 1 = 5
```

## Why it works

The algorithm maintains exactly the invariant shown in the diagram. Each greedy
choice or dynamic-programming transition accounts for every legal possibility
that can affect the optimum, while discarding only states that are provably no
better. Therefore the value printed at the end is the required optimum.

## Complexity

O(n) time and O(1) extra memory.

## Code

```python
import sys


def longest_alternating(s):
    zeroes = s.count("0")
    ones = len(s) - zeroes
    return 2 * min(zeroes, ones) + (zeroes != ones)


def main():
    tokens = sys.stdin.buffer.read().split()
    n = int(tokens[0])
    s = tokens[1].decode()
    print(longest_alternating(s[:n]))


if __name__ == "__main__":
    main()
```
