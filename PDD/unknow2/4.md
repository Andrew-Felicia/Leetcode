# Insert trees to destroy every target-sum interval

## General solution

Within the current untouched segment, a target-sum subarray appears when
two prefix sums differ by `M`. Keep all prefix sums seen since the last
insertion. If `prefix-M` is already present, greedily insert immediately
before the current tree, breaking every dangerous interval ending here;
then restart the prefix-sum set for the new segment.

## ASCII picture

```text
prefix sums seen: {0, 3, 0}
next value 2 gives prefix 2; 2-M = 3 when M=-1
collision => subarray sum -1
             ^ insert boundary here, reset segment
```

## Why it works

The algorithm maintains exactly the invariant shown in the diagram. Each greedy
choice or dynamic-programming transition accounts for every legal possibility
that can affect the optimum, while discarding only states that are provably no
better. Therefore the value printed at the end is the required optimum.

## Complexity

O(n) expected time and O(n) memory.

## Code

```python
import sys


def minimum_insertions(values, target):
    answer = 0
    prefix = 0
    seen = {0}
    for value in values:
        prefix += value
        if prefix - target in seen:
            answer += 1
            prefix = value
            seen = {0, prefix}
        else:
            seen.add(prefix)
    return answer


def main():
    numbers = list(map(int, sys.stdin.buffer.read().split()))
    n, target = numbers[0], numbers[1]
    print(minimum_insertions(numbers[2:2+n], target))


if __name__ == "__main__":
    main()
```
