# Pairs whose sum is divisible by m

## General solution

Only remainders modulo `m` matter. Scan prices once. Before inserting the
current remainder `r`, add the number of earlier prices with remainder
`(-r) mod m`; this counts each unordered pair exactly once.

## ASCII picture

```text
r + complement == 0 (mod m)
1 + 3 == 0 (mod 4)
current r=3 looks up bucket 1, then joins bucket 3
```

## Why it works

The algorithm maintains exactly the invariant shown in the diagram. Each greedy
choice or dynamic-programming transition accounts for every legal possibility
that can affect the optimum, while discarding only states that are provably no
better. Therefore the value printed at the end is the required optimum.

## Complexity

O(n) time and O(m) memory.

## Code

```python
import sys

MOD = 998244353


def count_pairs(values, modulus):
    counts = [0] * modulus
    answer = 0
    for value in values:
        remainder = value % modulus
        answer += counts[-remainder % modulus]
        counts[remainder] += 1
    return answer % MOD


def main():
    numbers = list(map(int, sys.stdin.buffer.read().split()))
    n, modulus = numbers[0], numbers[1]
    print(count_pairs(numbers[2:2+n], modulus))


if __name__ == "__main__":
    main()
```
