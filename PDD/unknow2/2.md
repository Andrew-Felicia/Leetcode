# Maximum animals that can be fed

## General solution

Accepting the animal arriving on day `i` permanently costs
`c[i] * (n-i+1)` fruits over the whole season. Every accepted animal has the
same value (one happy animal), so sort these total costs and buy the cheapest
ones until the budget is exhausted.

## ASCII picture

```text
day:          1      2      3
daily food:   2      2      2
total cost: 2*3    2*2    2*1  -> [6,4,2]
budget 8 buys costs 2 and 4 => 2 animals
```

## Why it works

The algorithm maintains exactly the invariant shown in the diagram. Each greedy
choice or dynamic-programming transition accounts for every legal possibility
that can affect the optimum, while discarding only states that are provably no
better. Therefore the value printed at the end is the required optimum.

## Complexity

O(n log n) time and O(n) memory.

## Code

```python
import sys


def maximum_animals(daily_food, fruits):
    n = len(daily_food)
    costs = [food * (n - day) for day, food in enumerate(daily_food)]
    costs.sort()
    accepted = 0
    for cost in costs:
        if cost > fruits:
            break
        fruits -= cost
        accepted += 1
    return accepted


def main():
    numbers = list(map(int, sys.stdin.buffer.read().split()))
    n, fruits = numbers[0], numbers[1]
    print(maximum_animals(numbers[2:2+n], fruits))


if __name__ == "__main__":
    main()
```
