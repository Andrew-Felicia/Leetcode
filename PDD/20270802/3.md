## Main algorithm

Normally, Dijkstra stores one distance for each city. Here, reaching the same city produces two different situations:

- `normal[city]`: minimum cost when the coupon has not been used.
- `coupon_used[city]`: minimum cost when the coupon has already been used.

You can think of every city as two graph nodes:

```text
(city, coupon unused)
(city, coupon used)
```

For an edge `u → v` costing `w`, there are three possible state transitions:

```text
(u, unused) → (v, unused)  cost w
(u, unused) → (v, used)    cost 0
(u, used)   → (v, used)    cost w
```

All transition costs are non-negative, so Dijkstra works.

## Line-by-line explanation

### Imports

```python
import heapq
```

Imports Python’s minimum heap implementation. Dijkstra uses it to obtain the unprocessed state with the smallest cost.

```python
import sys
```

Used for fast input through `sys.stdin.buffer.read()`.

### Shortest-path function

```python
def shortest_cost(n, graph):
```

Calculates the minimum cost from city `1` to city `n`.

- `n`: number of cities.
- `graph`: directed adjacency list.

```python
infinity = 10**30
```

Represents an unreachable distance. It is much larger than any possible answer.

```python
normal = [infinity] * (n + 1)
coupon_used = [infinity] * (n + 1)
```

Creates the two distance arrays.

For example:

```python
normal[5]
```

is the cheapest cost to reach city `5` without using the coupon.

```python
coupon_used[5]
```

is the cheapest cost to reach city `5` after using the coupon.

The arrays have size `n + 1` because cities are numbered from `1` to `n`.

```python
normal[1] = 0
```

We begin at city `1`, having paid nothing and without using the coupon.

```python
heap = [(0, 1, 0)]
```

Adds the initial state to the priority queue.

Each heap element contains:

```text
(cost, city, used)
```

Here, `used` is:

- `0`: coupon not used.
- `1`: coupon already used.

Therefore:

```python
(0, 1, 0)
```

means “city 1, cost 0, coupon unused.”

### Dijkstra loop

```python
while heap:
```

Continues until there are no reachable states left to process.

```python
cost, city, used = heapq.heappop(heap)
```

Removes the state with the smallest current cost.

```python
distances = coupon_used if used else normal
```

Selects the relevant distance array.

Equivalent longer version:

```python
if used:
    distances = coupon_used
else:
    distances = normal
```

```python
if cost != distances[city]:
    continue
```

This is Dijkstra’s stale-entry check.

A city might be added to the heap multiple times. If a better path was found later, an older, more expensive heap entry remains in the heap. This check ignores that obsolete entry.

```python
if city == n and used:
    return cost
```

If city `n` is removed from the heap with the coupon-used state, this is the minimum possible answer.

Dijkstra removes states in increasing cost order, so it is safe to return immediately.

### Examine outgoing edges

```python
for next_city, price in graph[city]:
```

Processes every directed edge leaving the current city.

### Option 1: pay normally

```python
new_cost = cost + price
```

Calculates the cost when the edge’s normal price is paid.

```python
if new_cost < distances[next_city]:
```

Checks whether this route improves the distance to `next_city` while keeping the same coupon state.

```python
distances[next_city] = new_cost
```

Records the improved distance.

```python
heapq.heappush(heap, (new_cost, next_city, used))
```

Adds the improved state to the priority queue.

Notice that `used` does not change because the coupon was not used on this edge.

### Option 2: use the coupon

```python
if not used and cost < coupon_used[next_city]:
```

This transition is available only if the coupon has not already been used.

Because the current edge becomes free, the cost of reaching `next_city` remains `cost`, rather than `cost + price`.

```python
coupon_used[next_city] = cost
```

Records the cost after using the coupon on this edge.

```python
heapq.heappush(heap, (cost, next_city, 1))
```

Adds the new state to the heap.

The final value is `1`, indicating that the coupon has now been used.

```python
return -1
```

If the heap becomes empty without reaching city `n`, no valid route exists.

## Small example

For:

```text
1 → 2, cost 5
2 → 3, cost 7
```

Possible coupon choices:

```text
Coupon on 1 → 2: 0 + 7 = 7
Coupon on 2 → 3: 5 + 0 = 5
```

Therefore, the answer is `5`.

## Complexity

The expanded graph has:

- `2N` states.
- At most `3M` transitions.

Therefore:

```text
Time:  O((N + M) log N)
Space: O(N + M)
```

The algorithms and structures used are:

- Directed adjacency list
- Dijkstra’s shortest-path algorithm
- State expansion/layered graph
- Minimum priority queue
- Lazy deletion of stale heap entries



The easiest way to understand the solution is:

> Make two copies of every city.

- Top layer: coupon not used.
- Bottom layer: coupon already used.

## Original graph

Suppose the graph is:

```text
       5          7
City 1 ----> City 2 ----> City 3
```

You can make one edge free.

Without the coupon, the cost is:

```text
5 + 7 = 12
```

## Expand every city into two states

```text
U = coupon Unused
C = coupon already Consumed

                 pay 5                 pay 7
             +---------->          +---------->
Top layer:   (1, U)                 (2, U)                 (3, U)
                \                      \
                 \ free 0               \ free 0
                  \                      \
                   v                      v
Bottom layer: (1, C) ---- pay 5 ----> (2, C) ---- pay 7 ----> (3, C)
```

The program starts here:

```text
(1, U)
```

The required destination is:

```text
(3, C)
```

because the coupon should have been used.

## Choices on every edge

When the coupon is unused:

```text
                         Pay normally
                    +-------------------->
                    |
(city, unused) -----+
                    |
                    +-------------------->
                         Use coupon
                         Cost = 0
                         Move to used layer
```

When it has already been used:

```text
(city, used) -------- pay normally --------> (next city, used)
```

You can never move from the used layer back to the unused layer:

```text
(city, used) --X--> (next city, unused)
```

A coupon cannot be reused.

## Two possible paths in the example

### Use coupon on the first edge

```text
          free                     pay 7
(1, U) ----------> (2, C) --------------------> (3, C)

Total = 0 + 7 = 7
```

### Use coupon on the second edge

```text
          pay 5                    free
(1, U) ----------> (2, U) --------------------> (3, C)

Total = 5 + 0 = 5
```

Therefore:

```text
answer = min(7, 5) = 5
```

## How the two arrays represent the diagram

```python
normal = [infinity] * (n + 1)
coupon_used = [infinity] * (n + 1)
```

They represent the two layers:

```text
normal:

City       1       2       3
         +-------+-------+-------+
Cost     |   0   |   5   |  12   |
         +-------+-------+-------+
Coupon is still unused


coupon_used:

City       1       2       3
         +-------+-------+-------+
Cost     |  INF  |   0   |   5   |
         +-------+-------+-------+
Coupon has already been used
```

For the example:

```python
normal[2] = 5
```

means:

```text
We reached city 2, paid 5, and still have the coupon.
```

```python
coupon_used[2] = 0
```

means:

```text
We reached city 2 for free by using the coupon on 1 → 2.
```

## What happens while processing an edge

For an edge:

```text
city ---- price ----> next_city
```

### Choice 1: pay the price

```python
new_cost = cost + price
```

State does not change:

```text
unused → unused
used   → used
```

ASCII:

```text
(city, U) ---- price ----> (next_city, U)

(city, C) ---- price ----> (next_city, C)
```

### Choice 2: use the coupon

```python
if not used:
```

The price becomes zero:

```text
(city, U) ---- 0 ----> (next_city, C)
```

This is implemented by:

```python
coupon_used[next_city] = cost
```

Notice that it uses `cost`, not `cost + price`.

## What the heap does

The heap always chooses the currently cheapest state:

```text
Heap:

(cost 0, city 1, unused)
(cost 5, city 2, unused)
(cost 0, city 2, used)
...
```

It repeatedly removes the smallest:

```text
             +-------------------------+
             | Get cheapest state      |
             +------------+------------+
                          |
                          v
             +-------------------------+
             | Examine outgoing edges  |
             +------------+------------+
                          |
                 +--------+--------+
                 |                 |
                 v                 v
          Pay normally      Use coupon
                            if unused
                 |                 |
                 +--------+--------+
                          |
                          v
                 Put improved states
                    into the heap
```

This is Dijkstra’s algorithm. The only special addition is the two coupon states.
