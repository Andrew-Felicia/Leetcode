# Longest substring with equal A and B counts

## General solution

Map `A` to +1 and `B` to -1. A substring has equal counts exactly when the
prefix balance is the same at both ends. Store the earliest index for each
balance; seeing it again gives the longest substring ending here with net
balance zero.

## ASCII picture

```text
string:       A  B  B  A
prefix index -1  0  1  2  3
balance:       0  1  0 -1  0
                     ^       ^ same balance -> equal A/B between
```

## Why it works

The algorithm maintains exactly the invariant shown in the diagram. Each greedy
choice or dynamic-programming transition accounts for every legal possibility
that can affect the optimum, while discarding only states that are provably no
better. Therefore the value printed at the end is the required optimum.

## Complexity

O(n) time and O(n) memory.

## Code

```python
import sys


def longest_balanced(s):
    earliest = {0: -1}
    balance = 0
    answer = 0
    for index, character in enumerate(s):
        balance += 1 if character == "A" else -1
        if balance in earliest:
            answer = max(answer, index - earliest[balance])
        else:
            earliest[balance] = index
    return answer


def main():
    tokens = sys.stdin.buffer.read().split()
    n = int(tokens[0])
    print(longest_balanced(tokens[1].decode()[:n]))


if __name__ == "__main__":
    main()
```
