# Available time outside warning intervals

## General solution

Sort the inclusive warning intervals by start, merge every overlap, and sum
each merged interval's integer length `right-left+1`. Subtract that blocked
duration from the total `H`.

## ASCII picture

```text
[10--------20]
      [15----------25]     -> merged [10-------------25]
inclusive blocked length = 25-10+1
```

## Why it works

The algorithm maintains exactly the invariant shown in the diagram. Each greedy
choice or dynamic-programming transition accounts for every legal possibility
that can affect the optimum, while discarding only states that are provably no
better. Therefore the value printed at the end is the required optimum.

## Complexity

O(N log N) time and O(N) memory per test case.

## Code

```python
import sys


def available_time(total, intervals):
    intervals.sort()
    blocked = 0
    left, right = intervals[0]
    for start, end in intervals[1:]:
        if start <= right:
            right = max(right, end)
        else:
            blocked += right - left + 1
            left, right = start, end
    blocked += right - left + 1
    return total - blocked


def main():
    numbers = iter(map(int, sys.stdin.buffer.read().split()))
    test_cases = next(numbers)
    answers = []
    for _ in range(test_cases):
        total, n = next(numbers), next(numbers)
        intervals = [(next(numbers), next(numbers)) for _ in range(n)]
        answers.append(str(available_time(total, intervals)))
    print("\n".join(answers))


if __name__ == "__main__":
    main()
```
