# Teleport for free or walk to a neighbor

## General solution

Model teleport edges with cost 0 and walking edges to `i-1` and `i+1` with
cost 1. All weights are 0 or 1, so use 0-1 BFS: improved zero-cost states go
to the front of the deque; walking states go to the back.

## ASCII picture

```text
  i-1 <--1-- i --1--> i+1
                                   \--0--> a[i]
deque front = free teleport, deque back = one more walking step
```

## Why it works

The algorithm maintains exactly the invariant shown in the diagram. Each greedy
choice or dynamic-programming transition accounts for every legal possibility
that can affect the optimum, while discarding only states that are provably no
better. Therefore the value printed at the end is the required optimum.

## Complexity

O(n) time and O(n) memory.

## Code

```python
import sys
from collections import deque


def minimum_walks(teleport):
    n = len(teleport) - 1
    distance = [n + 1] * (n + 1)
    distance[1] = 0
    queue = deque([1])
    while queue:
        u = queue.popleft()
        v = teleport[u]
        if distance[u] < distance[v]:
            distance[v] = distance[u]
            queue.appendleft(v)
        for v in (u - 1, u + 1):
            if 1 <= v <= n and distance[u] + 1 < distance[v]:
                distance[v] = distance[u] + 1
                queue.append(v)
    return distance[1:]


def main():
    numbers = list(map(int, sys.stdin.buffer.read().split()))
    n = numbers[0]
    print(*minimum_walks([0] + numbers[1:1+n]))


if __name__ == "__main__":
    main()
```
