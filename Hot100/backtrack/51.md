The **N-Queens** puzzle is the absolute poster child for an algorithmic technique called **Backtracking**.

Think of backtracking like exploring a maze: you walk down a path, and the moment you hit a dead end (a rule is broken), you take a step back, undo your last choice, and try a different path.

---

### The Strategy: Row-by-Row Placement

Because two queens can never share the same row, we can simplify our lives by placing exactly **one queen per row**, moving from Row 0 down to Row $n-1$.

When we are at a specific row, we try placing a queen in each column one by one. But before we commit, we have to check if that spot is safe. A queen attacks horizontally, vertically, and diagonally. Since we only place one queen per row, we don't need to check rows. We only need to check:

1. **The Column:** Has another queen already been placed in this vertical column?
2. **The Diagonals:** There are two types of diagonals to watch out for:
* **Positive Diagonals (Bottom-Left to Top-Right):** Along these lines, the row index plus the column index ($row + col$) is always a constant number.
* **Negative Diagonals (Top-Left to Bottom-Right):** Along these lines, the row index minus the column index ($row - col$) is always a constant number.



By using hash sets to keep track of which columns, positive diagonals, and negative diagonals are currently occupied, we can check if a spot is safe in instant $O(1)$ time!

### Python 3 Implementation

```python
class Solution:
    def solveNQueens(self, n: int) -> list[list[str]]:
        solutions = []
        # Create an empty board filled with '.'
        board = [["."] * n for _ in range(n)]
        
        # Track occupied lines
        cols = set()
        pos_diag = set()  # (row + col)
        neg_diag = set()  # (row - col)
        
        def backtrack(row: int):
            # Base Case: If we successfully placed queens in all rows, record the solution
            if row == n:
                # Convert the board grid of characters into strings
                solutions.append(["".join(r) for r in board])
                return
            
            # Try placing a queen in every column of the current row
            for col in range(n):
                # If this spot is attacked, skip it!
                if col in cols or (row + col) in pos_diag or (row - col) in neg_diag:
                    continue
                
                # 1. Choose: Place the queen
                board[row][col] = "Q"
                cols.add(col)
                pos_diag.add(row + col)
                neg_diag.add(row - col)
                
                # 2. Explore: Move to the next row
                backtrack(row + 1)
                
                # 3. Un-choose (Backtrack): Clean up sets and board for the next iteration
                board[row][col] = "."
                cols.remove(col)
                pos_diag.remove(row + col)
                neg_diag.remove(row - col)
                
        # Start the backtracking process from row 0
        backtrack(0)
        return solutions

```

### C++ Implementation

```cpp
#include <vector>
#include <string>
#include <unordered_set>

class Solution {
private:
    std::vector<std::vector<std::string>> solutions;
    std::unordered_set<int> cols;
    std::unordered_set<int> pos_diag; // row + col
    std::unordered_set<int> neg_diag; // row - col

    void backtrack(int row, int n, std::vector<std::string>& board) {
        if (row == n) {
            solutions.push_back(board);
            return;
        }

        for (int col = 0; col < n; ++col) {
            // Check if column or diagonals are under attack
            if (cols.count(col) || pos_diag.count(row + col) || neg_diag.count(row - col)) {
                continue;
            }

            // Choose
            board[row][col] = 'Q';
            cols.insert(col);
            pos_diag.insert(row + col);
            neg_diag.insert(row - col);

            // Explore
            backtrack(row + 1, n, board);

            // Un-choose (Backtrack)
            board[row][col] = '.';
            cols.erase(col);
            pos_diag.erase(row + col);
            neg_diag.erase(row - col);
        }
    }

public:
    std::vector<std::vector<std::string>> solveNQueens(int n) {
        solutions.clear();
        std::vector<std::string> board(n, std::string(n, '.'));
        backtrack(0, n, board);
        return solutions;
    }
};

```

---

### The Diagonal Trick Explained

The math behind the diagonals trips up almost everyone at first. Let's look at why $row + col$ and $row - col$ uniquely identify diagonals on a $4 \times 4$ board:

**Positive Diagonals ($row + col$):**
If you look at the diagonal running from bottom-left to top-right:

* Coordinate $(2, 0) \rightarrow 2 + 0 = \mathbf{2}$
* Coordinate $(1, 1) \rightarrow 1 + 1 = \mathbf{2}$
* Coordinate $(0, 2) \rightarrow 0 + 2 = \mathbf{2}$

Every single cell along that specific diagonal sums up to exactly $2$. If a queen lands on any of these spots, we just put the number `2` into our `pos_diag` set. Any future queen that sums up to $2$ will immediately know it is illegal to step there.

---

### Complexity Analysis

* **Time Complexity:** $O(n!)$ — In the first row, you have $n$ choices. In the second row, you have at most $n-2$ choices, and so on. This creates a factorial branching factor. However, because the safety checks prune invalid paths incredibly fast, it executes near-instantaneously for the constraint $n \le 9$.
* **Space Complexity:** $O(n^2)$ to store the board layout state, along with $O(n)$ space for our hash sets and recursion call stack stack tracking.
