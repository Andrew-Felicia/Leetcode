We want to know:



VERY IMPORTANT:

```text id="d9jlwm"

```

means:

```text id="x0jlwm"
substring from index 0 up to i
(not including i)
```

# Initial state

Empty string always works:

```python id="jlwm4j"

```


# Main idea

Suppose we are trying to compute:

```python id="x6jlwm"
dp[i]
```

We try every possible cut position:

```text id="1tjlwm"
0 ... j | j ... i
```

If:

1. left part already works

```python id="9qjlwm"
dp[j] == True
```

AND

2. right part is a dictionary word

```python id="l8jlwm"
s[j:i] in wordDict
```

Then:

```python id="jlwm0u"
dp[i] = True
```

# Transition

dp[i]=True\ \text{if there exists}\ j<i\ \text{such that}\ dp[j]=True\ \text{and}\ s[j:i]\in wordDict

---

# Code

```python id="3vjlwm"
class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:

        wordSet = set(wordDict)

        dp = [False] * (len(s) + 1)

        dp[0] = True

        for i in range(1, len(s) + 1):

            for j in range(i):

                if dp[j] and s[j:i] in wordSet:
                    dp[i] = True
                    break

        return dp[len(s)]
```

---

# Why convert to set?

This:

```python id="h6jlwm"
s[j:i] in wordSet
```

becomes fast:

```text id="jlwmb2"
O(1)
```

instead of slow list search.

Here:

```text id="w7jlwm"
If left substring works,
and current chunk is a word,
then larger substring works.
```
