This problem is called **Partition Labels**. The constraint *"each letter appears in at most one part"* gives us a huge hint.

If a part contains the letter `'a'`, then **every single `'a'` in the entire string must be trapped inside this same part**. Therefore, the moment we look at a letter, the current part *must* extend at least as far as the absolute **last occurrence** of that letter in the string.

This leads us to a beautiful **Greedy Strategy** that runs in $O(n)$ time.

---

### The Strategy

1. **Find the Last Occurrences:** First, scan through the string once and record the last index where each character appears.
2. **Expand the Boundary:** Scan through the string a second time. As you look at each character, update your "current boundary" (`end`) to be the maximum of your current boundary and the last occurrence of this new character.
3. **Cut the String:** The moment your moving index `i` catches up to your boundary `end`, it means you have successfully trapped all the characters you've seen so far. You make a cut right there, record the size, and reset your starting point for the next chunk.

---

### Visualizing Example 1: `s = "ababcbacadefegdehijhklij"`

Let's look at how the boundary expands during the second pass:

* We start walking. At `i = 0`, we see `'a'`. The last `'a'` in the string is at index **8**. So, our chunk *must* go at least up to index 8 (`end = 8`).
* At `i = 1`, we see `'b'`. The last `'b'` is at index 5. Our boundary is already 8, which is further, so we keep `end = 8`.
* We keep walking, and the boundary stays 8 because no character we meet forces us to stretch further.
* When we finally reach `i = 8`, **our index matches our boundary (`i == end`)**. We cut here! The size of this first chunk is $8 - (-1) = 9$.
* We reset our starting point and repeat the process for the remaining letters.

### Python 3 Implementation

```python
class Solution:
    def partitionLabels(self, s: str) -> list[int]:
        # Step 1: Record the last occurrence of each character
        last_seen = {char: index for index, char in enumerate(s)}
        
        partitions = []
        start = 0
        end = 0
        
        # Step 2: Scan the string to find the natural break points
        for i, char in enumerate(s):
            # The current partition must extend to the last occurrence of the current character
            end = max(end, last_seen[char])
            
            # If we reach the end of the stretched boundary, we make a cut
            if i == end:
                partitions.append(i - start + 1)
                start = i + 1  # The next partition starts at the next index
                
        return partitions

```

### C++ Implementation

Instead of a heavy hash map, we can use a small fixed-size array of 26 integers since the constraints mention only lowercase English letters.

```cpp
#include <vector>
#include <string>
#include <algorithm>

class Solution {
public:
    std::vector<int> partitionLabels(std::string s) {
        // Step 1: Record the last occurrence of each character
        int last_seen[26] = {0};
        for (int i = 0; i < s.length(); ++i) {
            last_seen[s[i] - 'a'] = i;
        }
        
        std::vector<int> partitions;
        int start = 0;
        int end = 0;
        
        // Step 2: Scan the string to find the break points
        for (int i = 0; i < s.length(); ++i) {
            end = std::max(end, last_seen[s[i] - 'a']);
            
            if (i == end) {
                partitions.push_back(i - start + 1);
                start = i + 1;
            }
        }
        
        return partitions;
    }
};

```

---

### Complexity Analysis

* **Time Complexity:** $O(n)$ — We pass through the string exactly twice (once to map the last positions, once to cut chunks).
* **Space Complexity:** $O(1)$ — The dictionary/array tracks at most 26 lowercase English letters, requiring a constant amount of memory regardless of how long the string is.
