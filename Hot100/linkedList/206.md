how to reverse the elements in java ArrayList<Integer>?


There are two main ways to reverse an `ArrayList<Integer>` in Java: the fast way using a built-in library, and the interview way using a custom two-pointer swapping algorithm.

---

## 1. The Fast Way: `Collections.reverse()`

The absolute easiest and most common way to reverse a list is by using the `java.util.Collections` utility class. It modifies your existing list completely **in-place**.

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.Collections;

public class Main {
    public static void main(String[] args) {
        ArrayList<Integer> list = new ArrayList<>(Arrays.asList(1, 2, 3, 4, 5));
        
        // Reverse the ArrayList in-place
        Collections.reverse(list);
        
        System.out.println(list); // Output: [5, 4, 3, 2, 1]
    }
}

```

* **Time Complexity:** $O(n)$ because it loops through half the list to swap elements.
* **Space Complexity:** $O(1)$ auxiliary space since it modifies the list directly without creating a new one.

---

## 2. The Interview Way: The Two-Pointer Approach

If you are in a technical interview and your interviewer asks you to implement the reversal manually without using built-in methods like `Collections.reverse()`, you should use the **Two-Pointer Swap** method.

You set one pointer at the start (index `0`) and one pointer at the end (index `size() - 1`). You swap the elements they point to, then move the pointers toward the middle until they meet.

```java
import java.util.ArrayList;
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        ArrayList<Integer> list = new ArrayList<>(Arrays.asList(10, 20, 30, 40, 50));
        
        int left = 0;
        int right = list.size() - 1;
        
        while (left < right) {
            // 1. Keep track of the left element temporary
            int temp = list.get(left);
            
            // 2. Overwrite the left element with the right element
            list.set(left, list.get(right));
            
            // 3. Overwrite the right element with the temp value
            list.set(right, temp);
            
            // 4. Move pointers closer to the middle
            left++;
            right--;
        }
        
        System.out.println(list); // Output: [50, 40, 30, 20, 10]
    }
}

```

### Key ArrayList methods used here:

* **`list.get(index)`**: Retrieves the value at that specific index.
* **`list.set(index, element)`**: Replaces the value at that specific index with your new element (this is how you modify elements in an `ArrayList` instead of using the `[]` brackets of primitive arrays).
