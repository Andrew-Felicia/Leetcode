“0–1 knapsack”里的 **0–1** 表示：每件物品只能选择一次——要么选（1），要么不选（0）。

## 1. 问题是什么？

假设背包最多承重 `4`，有三件物品：

| 物品 | 重量 | 价值 |
|---|---:|---:|
| A | 1 | 15 |
| B | 3 | 20 |
| C | 4 | 30 |

目标：在总重量不超过 `4` 的情况下，让总价值最大。

可能的选择：

- 只选 A：重量 1，价值 15
- 只选 B：重量 3，价值 20
- 只选 C：重量 4，价值 30
- 选 A + B：重量 4，价值 35

所以最优答案是：选择 A 和 B，最大价值为 `35`。

---

## 2. 最简单的方法：枚举

每件物品都有“选”和“不选”两种状态。

三件物品一共有：

```text
2 × 2 × 2 = 2³ = 8
```

种组合。

如果有 `n` 件物品，就有 `2ⁿ` 种组合。物品数量大时会非常慢，因此我们使用动态规划。

---

## 3. 动态规划的含义

定义：

```python
dp[c] = 背包容量为 c 时，能够得到的最大价值
```

初始时什么都没选：

```text
容量 c     0   1   2   3   4
dp[c]      0   0   0   0   0
```

处理完每件物品后：

| 已处理物品 | 容量0 | 容量1 | 容量2 | 容量3 | 容量4 |
|---|---:|---:|---:|---:|---:|
| 无 | 0 | 0 | 0 | 0 | 0 |
| A | 0 | 15 | 15 | 15 | 15 |
| A、B | 0 | 15 | 15 | 20 | **35** |
| A、B、C | 0 | 15 | 15 | 20 | **35** |

最终答案就是 `dp[4] = 35`。

## 4. 状态转移公式

对于重量为 `w`、价值为 `v` 的物品，在容量 `c` 下有两个选择：

1. 不选它：价值仍然是 `dp[c]`
2. 选它：价值变成 `dp[c - w] + v`

所以：

```python
dp[c] = max(dp[c], dp[c - w] + v)
```

---

## 5. Python代码

```python
def knapsack(weights, values, capacity):
    dp = [0] * (capacity + 1)

    for weight, value in zip(weights, values):
        # 必须从大容量向小容量遍历
        for c in range(capacity, weight - 1, -1):
            dp[c] = max(
                dp[c],                     # 不选当前物品
                dp[c - weight] + value     # 选择当前物品
            )

    return dp[capacity]


weights = [1, 3, 4]
values = [15, 20, 30]
capacity = 4

print(knapsack(weights, values, capacity))  # 35
```

时间复杂度为 `O(n × capacity)`，空间复杂度为 `O(capacity)`。

---

## 6. 为什么容量必须倒序遍历？

这是0–1背包最重要的一点：

```python
for c in range(capacity, weight - 1, -1):
```

假设物品A的重量为 `1`、价值为 `15`。

如果从小到大遍历：

```text
dp[1] = dp[0] + 15 = 15
dp[2] = dp[1] + 15 = 30
```

计算 `dp[2]` 时使用了刚更新的 `dp[1]`，相当于把物品A选择了两次。

而0–1背包规定每件物品最多选择一次。因此要倒序更新，保证使用的是“还没选择当前物品”时的旧状态。

简单记忆：

```text
0–1背包：容量倒序
完全背包：容量正序
```

## 7. 二维写法

初学时，二维动态规划可能更容易理解。

定义：

```text
dp[i][c] = 只考虑前 i 件物品，容量为 c 时的最大价值
```

状态转移：

```python
dp[i][c] = dp[i - 1][c]  # 不选择第 i 件物品

if c >= weight:
    dp[i][c] = max(
        dp[i][c],
        dp[i - 1][c - weight] + value
    )
```

完整代码：

```python
def knapsack(weights, values, capacity):
    n = len(weights)
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        weight = weights[i - 1]
        value = values[i - 1]

        for c in range(capacity + 1):
            # 不选当前物品
            dp[i][c] = dp[i - 1][c]

            # 选择当前物品
            if c >= weight:
                dp[i][c] = max(
                    dp[i][c],
                    dp[i - 1][c - weight] + value
                )

    return dp[n][capacity]
```

二维写法容易理解，但空间复杂度为 `O(n × capacity)`。一维写法是它的空间优化版本。

## 8. 和量化问题的关系

你的量化问题与0–1背包很像，但有一点不同：

- 普通0–1背包：每件物品可以选或不选
- 量化问题：每一层必须从多个位宽方案中选择一个

例如：

```text
第1层：选择8bit或者16bit
第2层：选择8bit或者16bit
第3层：选择8bit或者16bit
```

这种问题叫做**分组背包**或**多选背包**：每一组代表一个网络层，每组必须选择一个方案。

它的核心仍然是动态规划：

```text
前面已经得到的状态
        +
当前层的某个量化方案
        ↓
产生新的精度损失和内存状态
```

所以掌握0–1背包后，分组背包只是把“选或不选一个物品”，扩展成“从当前组中选择一个方案”。
